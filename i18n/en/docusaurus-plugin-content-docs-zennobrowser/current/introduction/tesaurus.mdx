# Key Concepts
<DisclaimerNotice />

**ZennoBrowser/ZB** is an anti-detect browser created by ZennoLab for working with multiple profiles.

**ZennoPoster/ZennoPoster7/ZP/ZP7** is a program offering a comprehensive solution for browser automation tasks related to SEO.

**Anti-detect browser** is a special type of browser that masks or changes the user's digital fingerprint to conceal their identity and avoid tracking or blocks online.

**Browser profile/profile** is an isolated environment in an anti-detect browser with unique fingerprints and settings, used to automate tasks without linking sessions together.
