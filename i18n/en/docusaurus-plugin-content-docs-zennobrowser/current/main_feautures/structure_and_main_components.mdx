## **Structure and Main Components**

**ZennoBrowser** includes two main modules for effective management:

 1. Profile Manager — centralized management of local and cloud profiles.
 2. Proxy Manager — management and configuration of proxy servers.

### **Profile Management**

Organization and storage structure:
 - Local profiles are stored on your device;
 - Cloud profiles are synchronized via the cloud;
 - Folders — a hierarchical structure is created for convenient navigation.

**Profile Table Interface:**

![structure_and_main_components](..\main_feautures\assets\structure_and_main_components\structure_and_main_components.png)

**Display Settings:**
 - Editable table with the ability to hide columns;
 - Rearranging columns in a convenient order;
 - Up to 1000 profiles per page.

**Table Columns:**

| **Column** | **Description** | 
|------------|----------------|
| Profile Name | Custom name for identification | 
| Management | Profile control elements | 
| Tags | Labels for categorization and quick search |
| Proxy | Assigned proxy servers | 
| Notes | Additional comments |
| Usage Time | Duration of use | 
| Last Run | Date of last activity |

**Search and Sorting:**

 - Sorting — by any table column;
 - Search — profiles by name, notes, and ID.

### **Bulk Operations**

**Profile Selection:** A checkbox system lets you select multiple profiles for group actions.

**Available Bulk Actions:**
 - Start profiles;
 - Stop profiles;
 - Replace proxy;
 - Move to another folder;
 - Manage tags;
 - Export cookies;
 - Bulk change of mobile proxy IP;
 - Delete profiles.
