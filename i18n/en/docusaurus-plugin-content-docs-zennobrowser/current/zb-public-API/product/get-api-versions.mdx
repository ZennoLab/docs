**Description:** This method returns the versions of all Public API documents. Object keys are document names and values are versions in `major.minor` format.

#### **Request parameters:**

This method does not require request parameters.

#### **Request example:**

**GET**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/product/api_versions' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Get,
    RequestUri = new Uri("http://localhost:8160/v1/product/api_versions"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**
```
http://localhost:8160/v1/product/api_versions
```

#### **API response:**

| Response code | Result |
| :---: | :---: |
| `200 OK` | Object containing API document versions |
| `401 Unauthorized` | Unauthorized |
| `403 Forbidden` | Access forbidden |

**Successful response (200 OK):**

```json
{
  "workspaces.v1": "1.0",
  "profiles.v1": "1.2",
  "proxies.v1": "1.0",
  "browser_instances.v1": "1.2",
  "threads.v1": "1.0",
  "presets.v1": "1.0",
  "product.v1": "1.0"
}
```
