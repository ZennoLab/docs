**Description:** This method creates the new browser instance using the specified profile with optional workspace and desktop settings.

#### **Request parameters:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| profileId | string | uuid | (required) | Unique identifier of the profile to associate with the browser instance (required). |
| workspaceId | integer | int64 | -1 | Workspace identifier. -1 means the default workspace. |
| desktopName | string |  | (empty) | The name of the desktop environment (optional). Defaults to empty. |
| threadToken | string |  | (empty) | Thread token for the browser instance. To create a new execution thread, pass an empty string (default). |
| environmentTags | string |  | (empty) | Tags to configure the environment for the browser instance. |
| commandLineArguments | string |  | (empty) | Custom command line arguments to pass to the browser on startup |

#### **Example request:**

**POST**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/browser_instances/create?profileId=123e4567-e89b-12d3-a456-426614174000&workspaceId=-1&desktopName=Desktop%201&threadToken=thread-token-1&environmentTags=&commandLineArguments=--disable-gpu' \
  --request POST \
  --header 'Api-Token: YOUR_SECRET_TOKEN'

```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Post,
    RequestUri = new Uri("http://localhost:8160/v1/browser_instances/create?profileId=123e4567-e89b-12d3-a456-426614174000&workspaceId=-1&desktopName=Desktop%201&threadToken=thread-token-1&environmentTags=&commandLineArguments=--disable-gpu"),
    Headers =

    response.EnsureSuccessStatusCode();

    Console.WriteLine(body);
}
```
