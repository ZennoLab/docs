**Description:** This method moves one or more browser profiles to the specified target folder within the workspace.

#### **Request parameters:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| targetFolderId | string | uuid | (empty) | The unique identifier of the target folder to move profiles to. |
| workspaceId | integer | int64 | -1 | Workspace identifier. -1 means the default workspace. |

#### **Request body:**

| Field | Type | Format | Required | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| body | array[string] | uuid | (optional) | Array of profile IDs to move. |

#### **Example request:**

**POST**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profiles/move?targetFolderId=223e4567-e89b-12d3-a456-426614174000&workspaceId=-1' \
  --request POST \
  --header 'Api-Token: YOUR_SECRET_TOKEN' \

  --header 'Content-Type: application/json' \
  --data '[
  "123e4567-e89b-12d3-a456-426614174000"
]'
```

**C#:**

