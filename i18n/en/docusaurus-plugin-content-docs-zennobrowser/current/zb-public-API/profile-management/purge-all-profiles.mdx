<DisclaimerNotice />

**Description:** This method permanently deletes all profiles from the local and cloud wastebaskets in the specified workspace.

:::warning
The profiles and their data cannot be recovered after this operation.
:::

#### **Request parameters:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| workspaceId | integer | int64 | \-1 | Workspace identifier. `-1` means the default workspace. |

#### **Request example:**

**DELETE**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profiles/wastebasket?workspaceId=-1' \
  --request DELETE \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Delete,
    RequestUri = new Uri("http://localhost:8160/v1/profiles/wastebasket?workspaceId=-1"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**
```
http://localhost:8160/v1/profiles/wastebasket?workspaceId=-1
```

#### **API response:**

| Response code | Result |
| :---: | :---: |
| `200 OK` | Wastebasket emptied; response body is empty |
| `401 Unauthorized` | Unauthorized |
| `403 Forbidden` | Access forbidden |
| `500 Internal Server Error` | Internal server error |

**Error response (500):**

```json
{
  "message": null
}
```
