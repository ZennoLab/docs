# Profile Creation
:::info **Please read the [*Material Usage Rules on this site*](../Disclaimer).**
:::

**Single profile creation:**

 1. In the Profile Manager, click "New Profile".
 2. Select the "New Profile" mode.
 3. Fill in the main parameters:
 - Profile name — any convenient name;
 - Profile type — local or cloud;
 - Folder — choose a folder for organization;
 - Tags — add tags for searching (optional).

![profile_creation1](..\install-and-setting\assets\profile_creation\profile_creation1.png)
![profile_creation2](..\install-and-setting\assets\profile_creation\profile_creation2.png)

 4. Choose one of the options:
 - No proxy — to use a connection without a proxy;
 - New proxy — enter a proxy while creating the profile;
 - Select proxy — manually choose a specific proxy from previously created ones.

![profile_creation3](..\install-and-setting\assets\profile_creation\profile_creation3.png)

**Additional settings:**

 - Import cookies if necessary;
 - Add notes for your convenience.
