# Getting Started
<DisclaimerNotice />

You can use ZennoBrowser in two modes: manual profile handling and integration with ZennoPoster 7.

**Manual profile handling:**

 - Manual work with the antidetect browser
 - Local profile management
 - Optimal for small tasks

**Integrated mode:**

 - Process automation via ZennoPoster
 - Scaling up tasks using algorithms
 - A comprehensive solution for large projects

### **Advantages of Each Mode**

**Manual profile handling:**

 - Flexibility in management
 - Easy setup
 - Instant start

**Integrated mode:**

 - Automation of routine tasks
 - Scalability of processes
 - Efficiency when working with large volumes

Choose **manual handling** if:

 - You work with a small number of profiles
 - You prefer manual management
 - You're solving specific, targeted tasks

Use **integration** if:

 - You need automated processes
 - You work on large-scale projects
 - You need to process large amounts of data
