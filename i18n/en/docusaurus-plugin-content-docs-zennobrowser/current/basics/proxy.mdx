## **Proxy Setup**


 1. Open the Proxy Manager.
 2. Click the Add Proxy button.
 3. Enter the proxy in one of the supported formats:

192.168.0.1:8000

http://192.168.0.1:8000

192.168.0.1:8000:login:password

socks5://login:password@192.168.0.1:8000

![proxy1](..\basics\assets\proxy\proxy1.png)


 4. Click "Check Proxy" to test if it works.
 5. Create a proxy list for easy organization.

![proxy2](..\basics\assets\proxy\proxy2.png)

### Proxy addition rules:

 - One proxy per line;
 - Maximum 1000 proxies per operation;
 - HTTP protocol is used by default;
 - For IPv6, enclose addresses in square brackets [ ].
