# Deleting ZennoBrowser Profiles
<DisclaimerNotice />

The "Delete ZennoBrowser profiles" action is intended for permanently removing selected browser profiles from the ZennoBrowser system.

![profile_deleting_ZB](..\zp-integr\assets\profile_deleting_ZB\profile_deleting_ZB.png)

### **Ways to Specify Profiles for Deletion**

 1. **Manual ID Entry:** enter the profile ID in the "Set profile IDs" field.

You can use variables to dynamically specify the IDs.

 2. **Selection from the List:**
 - Select the profile folder from the dropdown list;
 - Choose the specific profile to delete from the selected folder.

### **Refreshing the Profile List**

To get the latest list of available profiles, use the "Refresh" button in the action's settings.
