# Integration with the "Launch Instance" Action
<DisclaimerNotice />  

This action is designed to launch a browser using a specific ZennoBrowser profile by its identifier.

![integr_instans1](..\zp-integr\assets\integr_instans\integr_instans1.png)
![integr_instans2](..\zp-integr\assets\integr_instans\integr_instans2.png)

### **How it works**

The action takes the ZennoBrowser profile ID and initiates the launch of a browser instance with the corresponding profile settings, including:
 - Browser digital fingerprints
 - Proxy settings
 - User data
 - Extensions and configurations

### **Profile setup**

When you first open the action settings, the current list of profiles is automatically loaded from ZennoBrowser. There are two ways to specify a profile:

 1. **Manual ID entry:** Enter the profile identifier into the appropriate field.

 2. **Select from the list:**

 -> First, select the profile folder from the dropdown menu.

 -> Then, choose the specific profile within the selected folder.

### **Refreshing the profile list**

To get up-to-date information on available profiles, use the "Refresh" button in the action settings. This is especially useful when you add new profiles to ZennoBrowser.

![integr_instans3](..\zp-integr\assets\integr_instans\integr_instans3.png)

### **New browser option**

A new browser type has been added to the standard "Launch Instance" action — "Chromium from ZennoBrowser (beta)".

![integr_instans4](..\zp-integr\assets\integr_instans\integr_instans4.png)

This integration provides a unified approach to launching different types of browsers within a single action.
