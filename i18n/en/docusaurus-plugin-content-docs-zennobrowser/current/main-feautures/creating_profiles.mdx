# Profile Creation
:::info **Please read the [*Material Usage Rules on this site*](../Disclaimer).**
:::

### **Ways to Create Profiles**

The "New Profile" button opens a window with two modes:

![creating_profiles1](..\main-feautures\assets\creating_profiles\creating_profiles1.png)

#### **Single Profile Creation in “New Profile” Mode**

**Features:**

 - Set a profile name;
 - Import cookies;
 - Add notes;
 - Set advanced parameters.

**Advanced parameters** include screen size, RAM, language, geolocation, and others, which directly affect your ability to complete tasks successfully and maintain profile anonymity:

![creating_profiles2](..\main-feautures\assets\creating_profiles\creating_profiles2.png)
![creating_profiles3](..\main-feautures\assets\creating_profiles\creating_profiles3.png)

#### **Bulk Profile Creation in “Bulk Creation” Mode**

**Features:**
 - Up to 1000 profiles in one operation;
 - Configure unique proxy assignments.

**General settings for all types:**
 - Choose destination folder;
 - Profile type—cloud or local;

### **Tag Settings**

#### **Proxy Settings During Creation:**

| **Option** | **Description** |
|-------------|-------------|
| No proxy | Create a profile without a proxy server |
| New proxy | Automatically assign a new proxy |
| Select proxy | Manually select a specific proxy |
| Proxy list | For bulk creation with selection from a list |
