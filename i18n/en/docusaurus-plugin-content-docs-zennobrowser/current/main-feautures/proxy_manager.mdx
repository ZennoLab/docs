# Proxy Manager
:::info **Please read the [*Material Usage Rules on this site*](../Disclaimer).**
:::

The **Proxy Manager** provides centralized proxy management with the ability to:
 - Create lists;
 - Check availability;
 - Perform bulk operations.

**Interface structure:**

![proxy_manager](..\main-feautures\assets\proxy_manager\proxy_manager.png)

The **proxy table** contains the following columns:

| **Column** | **Description** | 
|------------|----------------|
| Proxy name | User-friendly name for identification |
| Status | Current state of the proxy server |
| Type | Connection protocol (HTTP, SOCKS5, etc.) |
| Host:port | Address and port of the proxy server |
| Login:password | Authentication details |
| IP change link | URL where you can change the proxy address |


**Organization:**
 - Proxy lists — create themed groups;
 - Display — up to 1000 proxies on one page;
 - Counter — shows the number of proxies added.
