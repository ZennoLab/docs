# ZennoDroid 1.1.0.0

### New features:

[+] Latest version of BlueStacks.

[+] On the first launch of ZennoDroid, the required version of the BlueStacks virtual machine is downloaded, installed, and configured.

[+] Parameter configuration: ability to overwrite the build.prop file, set the WiFi network name, set GPS coordinates, set IMEI and other parameters via BlueStacks GUID.

[+] Root added to BlueStacks.

[+] Added the ability to execute console commands.

[+] Improved interface and virtual machine responsiveness.

[+] Improved stability.

[+] Added a [wiki article](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534053867 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534053867") *(link outdated)* about two ways to work with the virtual machine:

- the virtual machine saves its state when the project is closed;

- creating clean virtual machines each time a new project run starts.

### Bug fixes:

[\] Fixed issues with launching on Windows Server.

[\] Fixed crashes when using vertical screen orientation.

[\] Fixed Diagnostics functionality.

[\] Fixed an issue where ZennoPoster could not run simultaneously with ZennoDroid.

[\] Numerous other fixes.
