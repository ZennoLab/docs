07.07.2026

**Added:**

[+] When executing the "Touch" and "Perform event" actions, the **touch point** is now shown on the screen for better clarity.

[+] **More responsive interface** and smoother image rendering when controlling the device with the mouse.

**Fixed:**

[\] **ZD PRO.** Fixed a **critical bug** that often made the emulator launch fail at the stage of disabling ads, emulating the battery and others.

[\] **ZD ENTERPRISE.** The **LSPosed Helper module** has been updated to version 2.2.0. Fixed a bug that prevented the module from starting on some firmware, which made the LSPosed Management actions stop working.

[\] **ZD ENTERPRISE.** Fixed the **"Reconnect"** button in the Device Manager.

[\] Fixed an issue where pressing **zoom in and zoom out** at the same time blocked the buttons.

[\] **ZD ENTERPRISE.** Fixed **image capture in MJPEG mode**.

[\] Fixed a bug that made the **screen image render with a delay** when moving the cursor with the mouse button held down.

[\] Fixed an error that occurred when the **destination folder** was missing while retrieving the apk of an application.
