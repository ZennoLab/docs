# ZennoDroid 2.1.0.0

### New features:

[+] Added an action to create a virtual machine with the ability to retrieve its index or name after execution.

[+] Added an action to clone a virtual machine with the ability to retrieve its index or name after execution.

[+] Added an action to import a virtual machine in .ovo format with the ability to retrieve its index or name after execution.

[+] Extracting the screen element structure as an XML string.

[+] Added a toggle for automatically updating the element tree on click.

[+] Environment variable macro for the MEmu directory path `{ -Environment.EmulatorDirectory- }`

[+] Added a wait option in the install, get value, and execute event actions.

[+] Updated the ProjectMaker shortcut.

### Bug fixes:

[\] Fixed incorrect image capture when starting a virtual machine.

[\] Fixed an issue where image click coordinates were determined incorrectly when scaling was enabled in Windows 7.

[\] Fixed an issue where a thin vertical line was displayed instead of the emulator window.
