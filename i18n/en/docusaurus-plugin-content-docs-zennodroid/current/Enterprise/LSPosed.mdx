## Description
The ZennoDroid module is needed to spoof key device parameters: IMEI, Android ID, mobile operator, model, WiFi, Bluetooth, and others.
:::info **Root access is required for the module to work**
Supported phones: Android 9-16
:::

Starting with ZennoDroid 2.5.0.0, installing the module needs [**Magisk**](https://github.com/topjohnwu/Magisk/releases/latest) with **Zygisk** active and **LSPosed v.2**.
_________________
## Enabling Zygisk
### Enabling the built-in Zygisk
Open the Magisk settings, turn **Zygisk** on and reboot the device.

### Enabling a third-party Zygisk
For better anti-detection of Magisk, we recommend a third-party Zygisk (for example, [**Zygisk Next**](https://github.com/LSPosed/ZygiskNext/releases/latest)) instead of the one built into Magisk.

1. Download the Zygisk Next module. In the device window's [**actions menu**](../pm/Interface/DeviceWindow#actions-menu), choose **Magisk / LSPosed** → **Install module...**, pick the downloaded file and click **Install**.
2. Open the Magisk settings and turn the built-in **Zygisk** off.
3. Reboot the device.

## Installing the LSPosed Framework
### Installing from the actions menu (ZennoDroid 2.6.2+)
**LSPosed v.2** comes with ZennoDroid, and you can install it right from ProjectMaker through the actions menu:

1. In the device window's [**actions menu**](../pm/Interface/DeviceWindow#actions-menu), choose **Magisk / LSPosed** → **Modules...**: the [**Magisk modules**](../pm/Interface/DeviceWindow#magisk-modules) window opens.
2. Click **Install...** → **Install LSPosed**.
3. When *Module installed* appears at the bottom of the window, reboot the device, for example with the [**Device** → **Reboot**](../pm/Interface/DeviceWindow#device) menu item.

## Installing the ZennoDroid Module
### Installing from the actions menu (ZennoDroid 2.6.2+)
The easiest way to install the ZennoDroid module is right from ProjectMaker:

1. In the device window's [**actions menu**](../pm/Interface/DeviceWindow#actions-menu), choose **Magisk / LSPosed** → **Module settings...**: the [**LSPosed module settings**](../pm/Interface/DeviceWindow#lsposed-module-settings) window opens.
2. Leave `com.zennolab.zennodroid` in the **Module** field, check **Enable the module** and check the apps whose device parameters will be spoofed.
3. Click **Apply**.

ZennoDroid installs the module by itself and turns it on for the checked apps.

### Manual installation
The ZennoDroid module is installed automatically when you first try to change device parameters or when you run any action from the [LSPosed Management](./LSPosed_Control) group.

On the first launch, your device will ask for superuser rights. You'll need to tap the **"Allow"** button (when using Magisk, permission is granted automatically).

### Important Information
- You should only add the apps to the spoof list that actually need their data changed. **There's no need to add the system framework.**
- If you delete an app after activating it, then reinstall it, you must re-activate it in the spoof list **(uncheck and check the box)**.

:::tip **LSPosed has a visual bug.**
When you remove an app, it disappears from the spoof list. If you reinstall it, it won't show up in the list automatically (the box might be checked, but spoofing won't work).
:::

- Not all apps appear in the list by default. If you don't see the app you need (like Google Chrome), go to the **Settings** menu and select the right group.

<details>
<summary>**Choosing a group of apps.**</summary>
<!--All you need is a blank line-->

![System](./assets/LSPosed/LSPosed_pic11.png)
</details>

- After picking the apps for spoofing, go back to ZennoDroid and tap **"Restart"**. Once it restarts, a notification will show that the module is ready to use. Now you can change device parameters with actions.

<details>
<summary>**The module is ready.**</summary>
<!--All you need is a blank line-->

![Module is on](./assets/LSPosed/LSPosed_pic12.png)
</details>

- After spoofing device parameters, close the necessary apps. It's best to do this with the **"Close app"** action.

:::tip **You can close apps before spoofing.**
But some system apps will restart themselves right after, so they might see the old parameters.
:::

## API for managing LSPosed (ZennoDroid 2.4.0+)
In **ZennoDroid 2.4.0**, we added an API for managing LSPosed.

Main functions:
- enable and disable the required module;
- select apps in the spoof list of the required module, and also add or remove them from the list;
- create and restore a settings backup (saving to both the phone and a computer is supported);
- get information about LSPosed.
