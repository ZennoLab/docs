For traffic analysis, you can use [**Burp Suite Community Edition**](https://portswigger.net/burp/communitydownload) from PortSwigger.

## Setting up Burp Suite
:::info **You can download all the required files here:**
[Frida\_Burp\_HttpToolkit.zip](https://www.dropbox.com/scl/fi/1vp7g23me9ekr34aacsfh/Frida_Burp_HttpToolkit.zip?rlkey=8ykdpi0jve6aplqpfpoh0rcoq&st=lac44ugj&dl=0) (password for `zenno.pfx`: `123`)
:::
_________________
### 1. Download and install
<details>
<summary>1. Select **Burp Suite Community Edition** and click **Download**.</summary>

![Download](./assets/BurpSuite/BurpSuite_pic1.png)
</details>

<details>
<summary>2. Create a **Temporary** project.</summary>

![Next](./assets/BurpSuite/BurpSuite_pic2.png)
</details>

<details>
<summary>3. Use **Burp defaults** for the project.</summary>

![StartBurp](./assets/BurpSuite/BurpSuite_pic3.png)
</details>

### 2. Configure Burp Suite to process traffic from your computer's local network
<details>
<summary>1. Open **Settings**.</summary>

![Settings](./assets/BurpSuite/BurpSuite_pic4.png)
</details>

<details>
<summary>2. Go to **Tools → Proxy** and click **Import / Export CA certificate**.</summary>

![Import](./assets/BurpSuite/BurpSuite_pic5.png)
</details>

<details>
<summary>3. Select **Certificate and private key from PKCS#12 keystore**, then choose the **zenno.pfx** file (*password: **123***).</summary>

![Private key](./assets/BurpSuite/BurpSuite_pic6.png)
_________________
![Private key](./assets/BurpSuite/BurpSuite_pic7.png)
</details>
