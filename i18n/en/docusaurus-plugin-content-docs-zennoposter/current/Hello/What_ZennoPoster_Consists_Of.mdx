ZennoPoster is a software suite made up of several applications that let you automate your actions in a web browser. This software is suitable for everyone—from SEOs working on online promotion to experienced web developers creating complex bots.

The ZennoPoster package includes the following applications:

**ZennoPoster** is the main application, designed for running automated action templates (bots) in a browser. It allows you to manage threads while executing templates, use different proxies for your bots, and also comes with a [❗→ built-in scheduler](/wiki/spaces/RU/pages/534086320 "/wiki/spaces/RU/pages/534086320") for running templates on a schedule.

**ProjectMaker** is the application for creating automated action templates. This is where you'll record and automate your actions on web pages. It's quite easy to use—the program comes with a set of [❗→ standard actions (actions)](https://zennolab.atlassian.net/wiki/spaces/RU/pages/486342706/ProjectMaker "https://zennolab.atlassian.net/wiki/spaces/RU/pages/486342706/ProjectMaker") for the web browser, which you can use as blocks to build your template. There's also a recording mode that adds every action you take in the browser to the template. The app also lets you work with [❗→ lists](/wiki/spaces/RU/pages/534053375 "/wiki/spaces/RU/pages/534053375"), [❗→ tables](/wiki/spaces/RU/pages/735903776 "/wiki/spaces/RU/pages/735903776"), [❗→ Google Sheets](https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google- "https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google-"), [❗→ databases](/wiki/spaces/RU/pages/486473806 "/wiki/spaces/RU/pages/486473806"), text files, and other [❗→ files](/wiki/spaces/RU/pages/486309948 "/wiki/spaces/RU/pages/486309948") on your computer and upload them to the web. This makes things much easier for SEO specialists.
