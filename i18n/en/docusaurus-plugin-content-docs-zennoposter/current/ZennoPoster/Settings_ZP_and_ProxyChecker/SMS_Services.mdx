## Description  
Some websites require you to enter a mobile phone number to confirm your registration. A verification code will be sent to this number.

_______________________________________________ 

## How to connect?
![How to connect?](./Settings_ZennoPoster/assets/SMS_Services/SMS_pic1.png)
### Secret key
Most services require an **API key**. This is a *unique string of random characters* that allows the service to identify you. For example, it might look like this: `8fc9b30e544885b8480fb590dfcbdd71`.  

To get an API key, visit the website of a suitable service and review its terms. Once you’ve chosen a service, register with it and get your *API key* from your account.  

### Additional parameters
Enter the **URL (domain)** used to receive API requests here. It’s set by default in the program, so **you don’t need to change it unless necessary**. If the URL isn’t pre-filled, check the documentation for your chosen service.  

### Balance  
Once you’ve signed in to the service, your current balance will appear in this field.  

:::warning **If this field is still empty after you enter the API key**
An error has occurred. Possible causes include an incorrect key, a service issue, or a banned key.
:::

## Your own service
### Add your own service (module)  
You can also add your own SMS receiving service based on the APIs of popular services.  

![How to connect?](./Settings_ZennoPoster/assets/SMS_Services/SMS_pic4.png)  

### Required parameters 
:::tip **Not sure what information to enter?**
Please contact your service provider.
:::
#### Module name  
Enter a name for the new service, **up to 20 characters**.  

#### API  
![How to connect?](./Settings_ZennoPoster/assets/SMS_Services/SMS_pic5.png)  

Select the API of the service your module will be based on.  

#### API-key
The service key. Use the same key you enter in the **Secret key** field when connecting to the service.  

#### Server  
The URL (domain) where requests for receiving SMS will be sent.  

#### Icon  
The selected image will appear next to your module.  

![How to connect?](./Settings_ZennoPoster/assets/SMS_Services/SMS_pic6.png)  

Available formats: `jpg`, `bmp`, `gif`, `png`.

### Using the added service
After adding the module, you can select it in the action for working with [**SMS services**](/zennoposter/ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/SMS_Processing_Services). Then you can use it just like the built-in services. 

![How to connect?](./Settings_ZennoPoster/assets/SMS_Services/SMS_pic7.png)  

### Removing a module  
To remove a module you created from the program, **you need to delete two files**:  
- `c:\Users\USERNAME\AppData\Roaming\ZennoLab\Configs\ИмяМодуля.dll.config`  
- `c:\Users\USERNAME\AppData\Roaming\ZennoLab\CustomModules\Sms\ИмяМодуля.dll`  

:::warning **We recommend closing ZennoPoster and ProjectMaker before deleting these files**
:::
