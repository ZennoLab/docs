# ZennoPoster 5.0.2.0 (21.06.2013)

### New features:

[+] Added the “Follow Cursor” function to the browser context menu.

[+] Improved notifications — you can now choose the theme and screen position.

[+] Added a system for restoring open projects after an unexpected program shutdown.

[+] The “Pause” action now displays its value.

[+] Minor improvements.

### Bug fixes:

[\] Fixed an issue where projects could not be saved when working with large projects.

[\] Fixed an error in profile operations.

[\] Fixed issues causing the debugger to freeze.

[\] Preview and updating of lists and tables now take macros in the file name into account.

[\] For the Option tag, setting and retrieving the Value attribute now works correctly.

[\] If a variable is not found when executing a macro, an error is now displayed indicating the variable is missing instead of a meaningless message.

[\] The Variables window in record/playback mode is now always shown on double-click.

[\] Saving and loading a profile from code. Added the previously missing ToString() and FromString(string) methods.

[\] If you open a project by double-clicking it in Windows Explorer, it could not be run “From the beginning” in ProjectMaker.

[\] Fixed an error when uploading files to a server via SFTP (SSH File Transfer Protocol).

[\] Default links in the GAC link list were displayed incorrectly.

[\] If, in the table operation action settings, you create a new variable when extracting a row into variables, it was not displayed in the variables list until debugging started.

[\] Fixed errors when compiling “Custom Code” in ZennoPoster that occurred on some systems.

[\] When making changes in InputSettings, the project save status is now calculated correctly.

[\] Fixed form layout issues when using enlarged system fonts.

[\] The Variables window is now always displayed on top of all windows.

[\] Fixed errors in ProxyChecker that caused proxy checking to stop.

[\] Fixed errors in ProxyChecker that caused ZennoPoster to crash.

[\] Reduced CPU usage when adding new proxies.

[\] Minor fixes.
