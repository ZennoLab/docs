# ZennoPoster 5.26.0.0 (27.12.2018)

### New features:

[+] Expanded functionality for managing ZennoPoster from the command line and generating bat files.

[+] Errors from the “Solve ReCaptcha” action are now saved to project.GetLastError() (error text in project.GetLastError().Exception.Message).

[+] Ability to create a Solve ReCaptcha V3 action when the module name is passed from a variable.

[+] ProxyChecker: Memory usage optimization.

[+] Improvements to the Diagnostic utility.

[+] Chrome Edition: SOCKS4 support.

[+] Chrome Edition: Display mouse coordinates in the browser.

[+] Chrome Edition: Optimizations to speed up the interface.

[+] Chrome Edition: Added thumbnail recording.

### Bug fixes:

[\] CodeCreator: Fixed display of static blocks.

[\] Fixed disappearing lists and tables when reopening a project in ProjectMaker.

[\] Fixed slow switching between advanced and regular editors.

[\] Fixed an issue where some cookies were not being saved to CookieContainer.

[\] Fixed an issue where the Accept-Language header and Navigator.Language field did not match the profile language.

[\] Fixed capturing a screenshot of the visible area.

[\] Chrome Edition: Fixed the “Solve ReCaptcha” action in a tab for the CapMonster2 module.

[\] Chrome Edition: Fixed errors during recording.

[\] Chrome Edition: Fixed Chrome browser display (sometimes it did not appear on the first try).

[\] Chrome Edition: File upload.

[\] Chrome Edition: Fixed input of the “\_” character.

[\] Chrome Edition: Fixed loading of http://csgocasino.ru and some other sites.

[\] Chrome Edition: Fixed an issue where socks5 proxies returned the error chrome-error:/chromewebdata/ after clearing the cache.

[\] Chrome Edition: Fixed tab closing (popup that closes itself via JavaScript).
