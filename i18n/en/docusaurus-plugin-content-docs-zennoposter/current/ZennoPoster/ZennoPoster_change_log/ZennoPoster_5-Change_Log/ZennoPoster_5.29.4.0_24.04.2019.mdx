# ZennoPoster 5.29.4.0 (24.04.2019)

### New features:

[+] Improved work with the GeoIP database.

[+] Improved handling of instance processes in ZennoPoster.

[+] Added a button that allows you to disable “Auto-fit row height” in the log control, which helps speed up its performance and prevents the ZennoPoster interface from freezing when large amounts of information are written to the log.

[+] Browser data from the profile is no longer lost when working in the “browserless” template.

### Bug fixes:

[\] Fixed handling of proxies that break the certificate in Chrome.

[\] Fixed CSS disabling in Chrome on some websites.

[\] Fixed localStorage in Chrome (authorization would be lost on some websites).

[\] Fixed loading of variables from the profile when adding non-existent variables.

[\] Fixed element selection in the element tree.

[\] Fixed saving of entered data in plugins.

[\] Fixed ProjectMaker freezing on startup in some cases.

[\] Fixed an issue with blocking access to directories used as the download directory for files in HTTP requests when using the HTTP Connection Pool.

[\] Fixed Traffic Monitor when working with Firefox without display.

[\] Fixed display errors in Traffic Monitor. Sometimes the response body could appear empty.

[\] Fixed macro processing. In some cases, they could run unreasonably long.

[\] Interface fixes.
