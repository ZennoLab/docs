# ZennoPoster 5.47.0.0 (24.09.2020)

### New features:

[+] Improved Chrome extensions emulation.

[+] If your ZennoPoster version is lower than the version required by the project being launched, instead of the error "The project does not contain input settings," you will now see the error: "This project requires ZennoPoster version XX.XX or higher. Please update."

[+] Added automatic recovery of input settings if the input settings file was corrupted.

### Bug fixes:

[\] Fixed an issue where the lines "Set Task ID" and "Store in variable" disappeared in ProjectMaker in the ReCaptcha recognition action.

[\] Fixed an issue where mobile profiles had a missing or incorrect screen orientation.

[\] Fixed microphone and camera emulation for mobile profiles.

[\] Fixed WebGL Antialiasing emulation.

[\] Fixed timeout handling when downloading large files while using an alternative method of sending HTTP requests.

[\] Fixed a cosmetic bug where the error "Project completed with errors" appeared after a Bad End was triggered in ProjectMaker.

[\] Fixed project selection in ZennoPoster using the Shift key.

[\] Fixed an issue where tasks were mixed up during ReCaptcha2 recognition via CapMonster.dll -&gt; In the tab.

[\] Fixed an issue where ReCaptcha2 Invisible recognition continued after it was successfully solved.

[\] Fixed ReCaptcha2 recognition on some websites.
