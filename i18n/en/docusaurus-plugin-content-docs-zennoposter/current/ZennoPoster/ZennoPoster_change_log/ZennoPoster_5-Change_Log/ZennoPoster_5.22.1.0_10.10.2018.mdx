# ZennoPoster 5.22.1.0 (10.10.2018)

### New features:

[+] Improved mobile device emulation.

[+] Added the window.orientation property for mobile device emulation.

[+] Added automatic enabling/disabling of TouchEvent (disabled for desktop User Agent, enabled for tablet and mobile).

[+] Added orientation type emulation (Instance.ScreenOrientation); the orientation angle changes automatically, and browser profiles will also adopt this setting and set the orientation themselves.

[+] Added the ability to report incorrect ReCaptcha2 responses when solving via RuCaptcha and other services.

[+] Reduced HTTPS page loading time in the browser; unnecessary requests have been disabled.

### Bug fixes:

[\] Fixed AirSocks integration; proxies with authorization were not working.

[\] Fixed bugs with page parsing.

[\] Fixed domain truncation in supercookies when saving a profile.

[\] Fixed an issue where an action disappeared when replacing an action in ProjectMaker.

[\] Fixed a bug with YouTube authorization via HTTP request.

[\] Fixed sorting in the GetTraffic method.

[\] Fixed minor UI bugs.
