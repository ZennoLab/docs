# ZennoPoster 5.10.3.1 (25.01.2017)

### New features:

[+] Improved issue diagnostics tools.

[+] Enhanced project execution animation in ProjectMaker.

[+] Optimized automatic proxy search via Google/Bing — it now consumes significantly less CPU.

### Bug fixes:

[\] Fixed an issue with instances hanging on startup.

[\] Fixed a memory leak when working with email.

[\] Fixed the ability to enable WebRTC.

[\] Fixed clicking in the country list in Yandex Direct.
