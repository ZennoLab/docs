# ZennoPoster 5.10.0.1 (23.09.2016)

### New features:

[\] Increased the speed of HTML element search.

### Bug fixes:

[\] Fixed high CPU usage when running with a small number of threads.

[\] Reduced memory usage when working with Facebook pages; the bug was reported to Mozilla.

[\] Fixed keyboard emulation during debugging in ProjectMaker.

[\] Fixed an issue where the copy button in the regex builder did not work.

[\] Fixed misses and focus issues for elements in the action builder.

[\] The page no longer scrolls up when searching for elements.

[\] Removing duplicates from a table caused an error if there were empty rows.

[\] The request to clear Cookies and Cache appeared twice.

[\] Fixed deletion of rows in the list.

[\] Fixed project execution in CodeCreator.

[\] Fixed display of tables with \n.
