# ZennoPoster 5.17.1.0 (20.04.2018)

### New features:

[+] Improved emulation of JavaScript features for browsers other than Firefox (in the profile settings, simply check the JS Features box).

[+] New action for lists. You can now get the number of lines based on conditions.

### Bug fixes:

[\] Fixed browser errors related to aboutNetError.

[\] Fixed redirects in POST and GET requests.

[\] Fixed the reset of “How many to run” to the default value in the Task Manager.

[\] Fixed code highlighting in the C# code debugger.

[\] Fixed mimeType emulation when permissions are empty.
