# ZennoPoster 5.32.0.0 (15.08.2019)

### New features:

[+] Added an alternative method for checking proxies. In the ProxyChecker settings, a new option has been added: “Use .NET process for proxy checking.” The alternative method helps avoid unexpected error 217 on problematic systems and also reduces resource usage during proxy checking.

[+] Added support for proxies in the domain:port format for the Infatica service.

### Bug fixes:

[\] Fixed an issue with calling the action constructor on some websites in Chrome.

[\] Fixed an issue with translations in BotUI.
