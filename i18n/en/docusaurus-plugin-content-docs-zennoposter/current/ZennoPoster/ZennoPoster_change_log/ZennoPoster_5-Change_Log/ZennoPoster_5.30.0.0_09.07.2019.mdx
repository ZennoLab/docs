# ZennoPoster 5.30.0.0 (09.07.2019)

### New features:

[+] Added a super user emulation mode. It allows you to bypass bot detectors based on neural networks, such as Akamai Bot Detector.

[+] Improved popup window handling in Chrome.

[+] Improved integration with CapMonster.Cloud.

[+] Improvements to the troubleshooting utility.

### Bug fixes:

[\] Fixed the appearance of the context menu when working in Chrome.

[\] Fixed automatic proxy search.

[\] Fixed the “Follow cursor” feature.

[\] When resizing, elements were displayed incorrectly on some websites in FireFox.

[\] Fixed incorrect encoding of the & character in BotUI.

[\] Fixed copying of the static BotUI block.

[\] Fixed display of the Execution Log in the Scheduler.

[\] Fixed the “Debug thread error” with subsequent ProjectMaker shutdown.

[\] Fixed escaping of ? when adding a URL to the Blacklist.

[\] Fixed parsing of complex JSON objects.

[\] Fixed the GetTraffic method in the Chrome engine.

[\] Fixed photo uploads in the Chrome engine and Instagram (mouse emulation must be used).

[\] Minor UI fixes.
