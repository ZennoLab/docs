# ZennoPoster 5.35.1.0 (02.10.2019)

### New features:

[+] Optimized launching of Chrome-based databases in ZennoPoster.

[+] You can now refresh the contents of a TrafficItem or wait for a response to a request. The TrafficItem object now includes the methods Refresh, WaitResponse, and WaitResponseAsync.

[+] A new checkbox has been added in the instance settings: “Do not automatically clear traffic on Navigate” (a restart is required for the setting to take effect).

[+] Added the Serbia flag to ProxyChecker.

### Bug fixes:

[\] Fixed saving and loading of the ProxyChecker proxy database.

[\] Fixed regular expressions in browser content policies.

[\] Fixed an issue where an empty response was returned for requests to certain websites when using the alternative HTTP method.

[\] Fixed interruption while waiting for ReCaptcha2 recognition.

[\] Fixed the display of SMS services in BotUI.
