# ZennoPoster 5.8.0.1 (22.05.2015)

### Bug fixes:

[\] Fixed instance freezes when working with captchas.

[\] Fixed a C# macro compilation error in ProjectMaker.

[\] Fixed incorrect handling of HTTP requests via C# code when an empty header is specified in AdditionalHeaders.

[\] Fixed processing of multi-part requests in HTTP POST.

[\] Fixed generation of file names when uploading via HTTP requests.

[\] Fixed the `{ -Page.LastAlertText- }` macro.

[\] Fixed inputSettings in ProjectMaker when the project is not saved.

[\] Fixed step-by-step debugging of nested projects.
