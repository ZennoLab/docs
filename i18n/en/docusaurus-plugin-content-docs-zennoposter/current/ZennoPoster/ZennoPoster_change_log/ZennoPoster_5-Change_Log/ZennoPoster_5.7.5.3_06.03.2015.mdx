# ZennoPoster 5.7.5.3 (06.03.2015)

### New features:

[+] Added the “Clear consecutive failures” option to the bat file settings. The corresponding ZennoPoster.ClearFails method for C# code has also been added.

[+] Added the ability to copy OwnCodeUsings between projects.

[+] In the table action settings, the text field for adding rows and cells is now multi-line.

### Bug fixes:

[\] Fixed retrieving rows from a table into a list.

[\] Fixed loading of Russian domains in the browser.

[\] Fixed handling of POST multipart/data requests when posting an empty file.

[\] Fixed mail processing with deletion of downloaded emails.

[\] Fixed task scheduler operation.

[\] Fixed saving of lists and tables with non-standard separators.

[\] Fixed the captcha recognition window freezing and added a notification for bad captchas; if the captcha fails to load, an image with the text “Bad captcha” will be displayed.
