# ZennoPoster 5.17.2.0 (25.05.2018)

### New features:

[+] Improved automatic updates for purchased templates in ZennoPoster/ZennoBox.

[+] Improved browser emulation regarding browser-specific JS features.

[+] Added WebRTC address emulation when setting up a proxy.

[+] Added automatic support for back connect proxies.

[+] Improved font emulation.

[+] Added a convenient action history — you can now easily roll back to the required edit in your project.

[+] Improvements to displaying the project name in the log.

[+] Added the ability to retrieve a line containing text that matches a regular expression in list and table operations, similar to deleting rows.

[+] Added the ability to pass a request body for the HTTP DELETE method.

[+] Added the ability to debug code in “Common Code”.

[+] Added ProjectName to the LastError class.

[+] Added the ContentDocument property for iframe elements for easier interaction with the frame document.

[+] Minor UI improvements.

### Bug fixes:

[\] Fixed sound issues when working with ZennoPoster.

[\] Fixed ignoring of Http.ResponceType in ZennoPoster.HTTP.RequestBytes methods.

[\] Fixed HTTP methods working with SOCKS proxies for IPv6.

[\] Fixed ReCaptcha2 sitekey detection on some websites.

[\] Fixed system bitness check in browserless projects.

[\] Fixed notifications when checking proxy sources with JavaScript execution enabled.
