# ZennoPoster 5.44.0.0 (11.06.2020)

### New features:

[+] Added the setting Other → Disable project settings recovery dialog.

### Bug fixes:

[\] Restoring the task list in ZennoPoster now also restores input settings.

[\] ZennoPoster now closes databases more promptly, which helps reduce RAM usage.

[\] Fixed browser launch and synchronization in ProjectMaker.

[\] Fixed execution of the Plugin action when the project is not saved.

[\] Fixed layout of Select fields in the InputSettings input settings.

[\] Fixed the behavior of ZennoPoster.GetTaskInfo — the method now always returns up-to-date data.

[\] Changed the plugin download folder for purchased templates. The folder named after the template will no longer be deleted.

[\] Fixed working with profiles and CookieContainer when switching projects in ProjectMaker.

[\] Now, in the Project in Project action, a variable is no longer deleted when it is renamed.

[\] ProjectMaker now notifies you about project changes when editing the Profile Processing action.

[\] Fixed opening of the browser context menu when executing the “oncontextmenu” call.

[\] Fixes to full mouse emulation when working with small elements.

[\] Other fixes and improvements.
