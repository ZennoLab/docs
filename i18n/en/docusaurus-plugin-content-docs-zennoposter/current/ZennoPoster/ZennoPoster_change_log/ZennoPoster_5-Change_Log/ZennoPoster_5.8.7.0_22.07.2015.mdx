# ZennoPoster 5.8.7.0 (22.07.2015)

### New features:

[+] Firefox engine updated.

[+] The ProxyChecker built into ZennoPoster has been updated to ProxyChecker 3.0. If you have purchased ZennoProxyChecker, its features will also be available in ZennoPoster. There’s no need to run two programs at the same time anymore.

[+] Added the ability to interrupt text input during debugging in ProjectMaker.

[+] Added the ability to save a set of browser plugins to a profile.

[+] Added the ability to make the instance size smaller than 1024x600.

### Bug fixes:

[\] Improved stability.

[\] Fixed some bugs when disabling ads.

[\] Fixed an issue where characters were entered with significant delay.

[\] Fixed memory leaks that occurred on some computers with Windows 7+ even while idle.

[\] Fixed memory leaks that occurred during GET/POST requests on some devices.

[\] Fixed issues with GET/POST requests on devices with incorrect DNS configuration.

[\] Fixed debugger freezing during GET/POST requests and when pressing the Stop button, even if the proxy connection had hung.

[\] Fixed an issue with comparing multi-line data to an empty string in the IF action.

[\] Fixed the issue of the Trash folder growing excessively.

[\] Restored the channel tester functionality.

[\] Fixed variable reassignment in ProjectMaker during recursive project calls.

[\] Fixed the behavior of the GetLastError method in ProjectMaker when a nested project fails.

[\] Fixed the issue of invisible links appearing when merging two groups of actions.
