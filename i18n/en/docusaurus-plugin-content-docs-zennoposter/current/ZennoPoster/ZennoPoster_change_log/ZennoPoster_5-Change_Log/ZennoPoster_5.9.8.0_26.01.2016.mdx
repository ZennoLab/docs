# ZennoPoster 5.9.8.0 (26.01.2016)

### New features:

[+] Added an action for working with databases.

[+] Added C# methods for working with databases [ZennoPoster.Db](https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic445.html "https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic445.html").

[+] In ProjectMaker, the delay when hiding/showing the toolbar in the advanced editor has been removed.

[+] Added the method [project.ExecuteMacro(string)](https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic602.html "https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic602.html"), which processes macros in text and returns the text with the processed macros.

### Bug fixes:

[\] Fixed processing of boolean values in input settings.

[\] Fixed some code generation errors.
