# ZennoPoster 5.46.0.0 (20.08.2020)

### New features:

[+] The profile generation system has been completely revamped. Numerous issues where a profile could be generated with incorrect parameters have been resolved.

[+] You can now interrupt a long-running "Run Program" action; the launched process will be closed.

[+] The "Check entered data compliance" setting has been disabled and removed.

[+] The log now displays the plugin name and its ID when errors occur.

### Bug fixes:

[\] Fixed manual profile saving (Profile -&gt; Save). All profile settings are now saved.

[\] All captcha-related cubes now send the correct Content-Type.

[\] Fixed the issue where variables disappeared when editing the "Project in Project" action.

[\] Added a hint that a program restart is required to apply the "Use GPU" option.

[\] The notification that the project version does not match the program version is now displayed correctly.

[\] When attempting to load a profile from a non-existent path, a more detailed error message is now shown explaining the issue.

[\] The "Deferred rendering of execution process" option has been removed from ProjectMaker settings, as it duplicates the functionality of the "Deferred rendering" button.

[\] Fixed an issue on some websites where they failed to load when using an alternative HTTP method and proxy.

[\] Other fixes and improvements.
