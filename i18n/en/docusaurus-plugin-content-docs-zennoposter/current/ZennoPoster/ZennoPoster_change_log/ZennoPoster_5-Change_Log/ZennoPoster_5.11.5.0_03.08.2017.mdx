# ZennoPoster 5.11.5.0 (03.08.2017)

### New features:

[+] Added the ability to retrieve a list of folders in the directory operations action.

[+] Added text input to the ReCaptcha2 recognition action.

[+] Added an option to disable autocomplete in input fields within actions, for those who find its default behavior inconvenient.

### Bug fixes:

[\] Fixed freezes during project execution.

[\] Fixed freezes during instance execution.

[\] Fixed issues with Invisible ReCaptcha2 when solving on some websites via the Anti-Gate and RuCaptcha services.

[\] Fixed an issue with ReCaptcha2 on VKontakte when solving via the Anti-Gate and RuCaptcha services.

[\] Increased the minimum number of recognition attempts for ReCaptcha2 via services so workers have enough time to solve it.

[\] Fixed issues with the virtual mouse.

[\] Fixed an issue where the context menu disappeared when right-clicking in the ProjectMaker browser.

[\] Fixed an issue when first opening BotUI settings in ZennoPoster.

[\] Fixed JavaScript issues in BotUI.

[\] Fixed an issue where the language window could not be opened in BotUI.

[\] Fixed content disappearing in the first BotUI tab after opening a new tab.

[\] Fixed BotUI error logging.

[\] Fixed deletion of list and table files when working simultaneously in ZennoPoster and ProjectMaker with the same file.

[\] Fixed an issue with ZennoPoster taking a long time to close under heavy load.

[\] Fixed proxy functionality in nested projects.

[\] Fixed registration issues on some Polish websites.

[\] Fixed a memory leak in ProjectMaker in lists and tables not linked to a file.

[\] Improved interaction with Proxifier.

[\] Fixed the display of HTTP requests using GET/POST methods in the traffic window.

[\] Fixed an issue where selecting one project in the recovery window would restore all projects.

[\] Minor UI fixes.
