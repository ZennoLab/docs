# ZennoPoster 5.0.4.0 (07.08.2013)

### New features:

[+] Alert messages are now also written to the execution log.

[+] When errors occur in a project, the user comment for the failed action is now written to the log, if one is provided.

[+] Added the Tab.MouseMove method, which allows you to simulate mouse movement in the current tab.

[+] Added the Tab.MouseClick method, which allows you to simulate mouse button events in the current tab.

[+] The table with classic element search in action properties now resizes correctly, taking up all available space. Other action settings containing tables have also been adapted to resize properly.

[+] The position of the quick access toolbar is now saved after restarting the program.

[+] In the debugging settings, you can now increase the size of notifications.

[+] Minor improvements.

### Fixed bugs:

[\] Reduced ZennoPoster memory usage.

[\] Fixed IntelliSearch behavior during debugging and recording.

[\] ProjectMaker and ZennoPoster now work correctly when using the same file simultaneously for lists and tables.

[\] Fixed several errors when using HTTP POST and multipart/form-data.

[\] Selecting a download folder for files now applies to the GET/POST action.

[\] The C# macro tester did not work if external assemblies (not from the GAC) were connected.

[\] Fixed several CodeCreator errors when debugging PHP code.

[\] The comment/uncomment buttons for PHP in CodeCreator did not work.

[\] The separator is no longer reset when merging list rows.

[\] Fixed an issue where a table linked to a file would stop syncing when dynamically linked to a file.

[\] Fixed an error when clicking on certain Flash objects.

[\] Fixed errors that could cause variable values to reset while editing a project.

[\] Optimized CPU usage.

[\] Fixed freezing when working with FTP in case of a connection drop. The action now exits with an error.

[\] Setting dropdown values from profile macros now works correctly when IntelliSearch is disabled.

[\] The large captcha no longer overlaps the captcha text input field during manual entry.

[\] When deleting a variable from “Auto,” the selected category is no longer reset.

[\] Fixed loss of focus from the project editor in debugging mode.

[\] Minor fixes.
