# ZennoPoster MP 4.0.8.0 (30.07.2012)

### New features:

[+] New feature [❗→ context-recognizer](https://zennolab.atlassian.net/wiki/spaces/RU/pages/489193483/web- "https://zennolab.atlassian.net/wiki/spaces/RU/pages/489193483/web-").

[+] Improved image search quality, added image match percentages.

[+] Now, when debugging image clicks and coordinate clicks, you can see where the click occurred. A crosshair appears at the click location for a few seconds.

### Bug fixes:

[\] ProjectMaker now consumes less memory. Several memory leaks have been fixed.

[\] Project debugging has been moved to a separate process, which also significantly reduces memory leaks.

[\] Project execution parameters have been optimized to save memory.

[\] CAPTCHA now loads on Yahoo.

[\] CAPTCHA is no longer cropped when images are disabled.

[\] ProjectMaker no longer crashes when tabs are auto-closed.

[\] PanelConatiner is no longer displayed.

[\] The log now auto-scrolls during debugging when switching between actions.

[\] Fixed coordinate clicking; elements no longer scroll.

[\] In the email confirmation action, macros are now displayed correctly during debugging.

[\] Fixed a bug with table processing mentioned by Boxcutter.

[\] Fixed a bug with tables when the separator is a period.

[\] Minor fixes.
