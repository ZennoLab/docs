# ZennoPoster MP 4.3.7.0 (17.01.2013)

### New features:

[+] Users can now reload an instance while it is running (browser settings → reload instance). This helps deal with browser memory leaks when working with large projects.

[+] You can now check proxies for Google bans in ZennoPoster.

[+] Added Windows application automation commands.

[+] The “New variable” item is now first instead of last.

[+] Minor improvements to anonymity with default settings.

[+] You can set cookies and a user agent for HTTP GET/POST.

[+] You can add text to a list; the text will be split according to the list separator and added to the list.

[+] Set the maximum row height for the log and variables tables — convenient when working with large texts.

[+] Added the function project.GetLastError(), which returns information about where the last error occurred.

### Bug fixes:

[\] Fixed freezing or failure to stop the debug thread.

[\] Fixed bugs with tables not linked to a file and adding rows with empty cells.

[\] When saving and loading a profile, generated fields such as login and password are now saved as well.

[\] Setting an empty proxy during debugging is no longer considered an invalid action.

[\] Closing static block settings with Alt+F4 now works correctly.

[\] During keyboard emulation, `{PGUP}` and `{PGDN}` were working as `{UP}` and `{DOWN}`.

[\] Support for global variables from custom code now works correctly.

[\] Adding library references for C# code from the GAC that are not part of the standard .NET Framework library now works correctly.

[\] Some localization errors fixed.

[\] Minor bug fixes.
