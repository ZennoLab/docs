# ZennoPoster 5.29.1.0 (28.03.2019)

### New features:

[+] DevExpress components have been updated, which should improve UI responsiveness and reduce the number of bugs.

[+] When a C# code error occurs during execution, ProjectMaker shows the line where the error happened, if possible.

[+] Improved emulation of clientHeight and clientWidth.

[+] Improved display when working with the browser without rendering content in Chrome. In ProjectMaker, the browser is shown at a reduced frame rate so you can debug the project. When running in ZennoPoster, rendering is disabled to save resources, and also in case you do not want to show what is happening in the browser for any reason.

### Fixed bugs:

[\] Fixed the window resizing method for Firefox.

[\] Fixed the ReCaptcha2 recognition action.

[\] Fixed CSS styles being disabled in Firefox when closing all tabs.

[\] Fixed incorrect behavior when switching the engine from Firefox to Chrome in project settings.

[\] Fixed compilation errors in shared code and C# code.

[\] Fixed the display of the next run time in the schedule.

[\] Fixed automatic condition detection for the Action Builder.

[\] Fixed setting dropdown lists in Chrome.

[\] Fixed data deletion in BotUI.

[\] Minor UI fixes.
