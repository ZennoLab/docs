# ZennoPoster 5.34.0.0 (11.09.2019)

### New features:

[+] Updated the Chrome engine to version 76.

[+] Improved special character input emulation in Chrome.

[+] Added an alternative method for sending HTTP requests. You can choose the method globally in the program settings under the “Execution” tab or locally in the project settings.

[+] Added the ability to remove default headers in HTTP requests in C# code (removeDefaultHeaders argument).

[+] A message is now written to the log if page navigation fails.

[+] A message is now written to the log when sending an HTTP request with a non-existent file.

### Bug fixes:

[\] Fixed cookie transfer when solving ReCaptcha3.

[\] Fixed automatic email receiving setup.

[\] Fixed copying of lists/tables.

[\] Fixed copying of the action ID from the log.

[\] Fixed an issue with encoding \ in HTTP requests (use the alternative request sending method).

[\] Fixed an issue with infinite redirects caused by converting the + sign in HTTP requests (use the alternative request sending method).

[\] Fixed detection of memory usage by an instance.

[\] Other fixes and improvements.
