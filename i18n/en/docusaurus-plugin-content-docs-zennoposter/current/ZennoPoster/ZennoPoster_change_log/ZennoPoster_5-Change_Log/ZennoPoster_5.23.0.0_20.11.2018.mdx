# ZennoPoster 5.23.0.0 (20.11.2018)

### New features:

[+] Onboarding added to ProjectMaker and ZennoPoster.

[+] UI improvements in ProjectMaker.

[+] Added conversion of parsing cubes to C#.

[+] Added the ability to delete a column in a table.

[+] FTP connections can now be renamed.

### Bug fixes:

[\] Fixed issues with modifying POST requests in the browser.

[\] Fixed an error updating CookieContainer when closing the browser via a cube with the “Use current browser profile” option enabled.

[\] Fixed a memory leak when an error occurred while deleting an email on the server.

[\] Fixed escaping of special characters in Plugin settings.

[\] Fixed an issue with an empty ResponseBody in the GetTraffic method.

[\] Fixed data substitution not triggering in AJAX requests.

[\] Fixed the appearance of “ghost” tabs.

[\] Fixed action settings resetting.

[\] Fixed loading of the website http://mixcloud.com.

[\] Fixed FtpChmode functionality.
