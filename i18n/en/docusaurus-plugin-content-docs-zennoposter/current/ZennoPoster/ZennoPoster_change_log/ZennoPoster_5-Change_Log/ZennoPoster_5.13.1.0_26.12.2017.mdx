# ZennoPoster 5.13.1.0 (26.12.2017)

### New features:

[+] Improved font emulation. Added the [instance.FontsFolder](https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic340.html "https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic340.html") property, which allows you to add fonts without installing them into the system.

[+] Added methods for working with time zones in IANA format: [instance.GetIanaTimezone](https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic205.html "https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic205.html") and [instance.SetIanaTimezone](https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic289.html "https://help.zennolab.com/en/v5/zennoposter/5.13.1.0/webframe.html#topic289.html") (work on Firefox 52+ engines).

[+] Improved detection of active ReCaptcha2 using the standard action when solving through recognition services.

### Bug fixes:

[\] Hotfix: fixed time zone emulation.

[\] Disabled WebGL2 emulation in Firefox 45, as it is not supported there.

[\] Fixed a ProjectMaker crash when accessing BotUI on a 32-bit system.

[\] Fixed updating of element properties when inspecting an element.
