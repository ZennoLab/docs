# ZennoPoster 5.29.7.0 (18.06.2019)

### New features:

[+] Integrated with CapMonster.Cloud.

[+] Added the ability to configure [❗→ connection parameters](https://zennolab.atlassian.net/wiki/spaces/RU/pages/494862427/Chrome "https://zennolab.atlassian.net/wiki/spaces/RU/pages/494862427/Chrome") for the Chrome browser. This is relevant if your proxies have connection limits.

[+] Added an article about [❗→ how to properly enable Flash in Chrome](https://zennolab.atlassian.net/wiki/spaces/RU/pages/494862427/Chrome "https://zennolab.atlassian.net/wiki/spaces/RU/pages/494862427/Chrome"). Flash is disabled by default for security reasons.

### Bug fixes:

[\] Fixed the behavior of throw new Exception() in plugins.

[\] Fixed an issue when saving an image via CaptchaSaver.dll with an incorrect file name.

[\] Fixed the reset of the “Show Quick Access Toolbar Below the Ribbon” setting in ProjectMaker and ZennoPoster.

[\] Fixed an issue with deleting data from BotUI.

[\] Fixed the display of the project closing window.

[\] Minor UI fixes.
