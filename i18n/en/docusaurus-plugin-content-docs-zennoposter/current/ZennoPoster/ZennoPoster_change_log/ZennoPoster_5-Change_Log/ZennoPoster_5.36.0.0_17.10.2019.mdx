# ZennoPoster 5.36.0.0 (17.10.2019)

### New features:

[+] Added the ability to sell bots with plugins.

[+] Added the CapMonsterCloud.dll module to the reCAPTCHA recognition action.

[+] Added the 2Captcha captcha recognition module.

[+] Added the Instance.ClearTrafficWhenNavigate property to enable or disable traffic clearing within a project.

[+] Added the ability to choose encoding in the UrlEncode and UrlDecode text processing actions, as well as in the Macros.TextProcessing.UrlEncode and Macros.TextProcessing.UrlDecode methods.

[+] Macro processing has been sped up.

### Bug fixes:

[\] Fixed cookie handling in the alternative HTTP request method.

[\] Fixed element tree updating in auto-hide mode.
