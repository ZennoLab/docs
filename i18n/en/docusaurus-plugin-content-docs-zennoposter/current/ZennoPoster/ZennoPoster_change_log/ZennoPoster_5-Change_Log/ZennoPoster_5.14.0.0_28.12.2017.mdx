# ZennoPoster 5.14.0.0 (28.12.2017)

### New features:

[+] Added support for emulating basic [WebGL](https://help.zennolab.com/en/v5/zennoposter/5.14.0.0/webframe.html#topic530.html "https://help.zennolab.com/en/v5/zennoposter/5.14.0.0/webframe.html#topic530.html") parameters.

[+] Added support for emulating [AudioDevice](https://help.zennolab.com/en/v5/zennoposter/5.14.0.0/webframe.html#topic17.html "https://help.zennolab.com/en/v5/zennoposter/5.14.0.0/webframe.html#topic17.html") parameters.

### Bug fixes:

[\] Fixed freezing when editing in the PropertyGrid within BotUI properties on Windows 10 (1709).

[\] Fixed loading of additional fonts from the profile.

[\] Fixed proxy check freezes.

[\] Minor UI fixes.
