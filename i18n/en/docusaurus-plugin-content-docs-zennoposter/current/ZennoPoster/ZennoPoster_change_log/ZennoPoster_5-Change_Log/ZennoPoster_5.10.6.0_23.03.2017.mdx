# ZennoPoster 5.10.6.0 (23.03.2017)

### New features:

[+] Added support for images with transparency when rotating in ZennoPoster.

[+] Added support for the SMS service http://give-sms.com.

[+] Added the [GetTraffic](https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic398.html "https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic398.html") method to retrieve the latest URLs that were navigated to.

[+] Added the [PageScale](https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic437.html "https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic437.html") method to set the page scale from code.

[+] Added the [GetBrowserPreference](https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic200.html "https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic200.html") and [SetBrowserPreference](https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic245.html "https://help.zennolab.com/en/v5/zennoposter/5.10.6.0/webframe.html#topic245.html") methods for managing browser settings.

[+] Improvements to automatic system time emulation.

### Bug fixes:

[\] Fixed an issue opening some websites.

[\] Fixed an error when setting the default time zone via cubes.

[\] Fixed opening pages in Yandex.Webmaster when time zone emulation is enabled.

[\] Fixed mouse emulation on a tab created automatically.

[\] Fixed mouse emulation moving off-screen (infinite scrolling).

[\] Fixed HTTP GET/POST handling during redirects.

[\] When sending an element to the Constructor, its properties and focus in the element tree were not displayed.

[\] Fixed an issue in C# code where instance.SetProxy did not change the project.Proxy property.

[\] Fixed an error when loading a profile without a proxy. The existing proxy was not cleared.

[\] project.Proxy was not updated after returning from a nested project.

[\] The Spam folder was not processed when downloading mail from Gmail.

[\] The “Delete previous proxies” option in the proxy source did not remove proxies from the live list.

[\] Documentation updates.

[\] Minor UI bug fixes.
