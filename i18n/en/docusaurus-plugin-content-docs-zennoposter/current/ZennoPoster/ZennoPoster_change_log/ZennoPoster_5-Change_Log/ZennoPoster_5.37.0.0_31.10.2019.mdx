# ZennoPoster 5.37.0.0 (31.10.2019)

### New features:

[+] A Time column has been added to the Traffic window, and the ability to choose which columns are displayed has been implemented.

### Bug fixes:

[\] Fixed header retrieval in the alternative HTTP request method.

[\] Fixed proxy ban checking in Google when using the alternative HTTP request method.

[\] Fixed CookieContainer behavior in the alternative HTTP request method.

[\] Fixed writing to a table cell by column index.

[\] Fixed variable transfer when copying a static BotUI block.

[\] Fixed the operation of the reCAPTCHA Recognition action via the CapMonsterCloud module and 2Captcha via sitekey.

[\] Fixed SOCKS proxy search in ProxyChecker.

[\] Fixed macro handling in the file path with code in the static General Code block.

[\] Fixed project.LogOptions.LogFile.

[\] Fixed JSON parsing errors caused by invalid characters.

[\] Fixed collapsing of groups in the Traffic window.

[\] Other fixes and improvements.
