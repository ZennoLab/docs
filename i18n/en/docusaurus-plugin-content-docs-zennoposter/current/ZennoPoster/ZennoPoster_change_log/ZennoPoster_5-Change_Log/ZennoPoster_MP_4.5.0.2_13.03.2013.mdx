# ZennoPoster MP 4.5.0.2 (13.03.2013)

### New features:

[+] You can set a timeout for instance action execution (Start → ZennoPoster Settings → Instance).

[+] Email actions are now automatically recorded in CodeCreator.

[+] Proxies that don’t need to be checked for availability are quickly added to the list of available proxies.

### Bug fixes:

[\] Fixed some causes of thread freezing.

[\] Fixed some causes of CodeCreator not launching.

[\] Minor CapMonster fixes.

[\] Fixed some ZennoPoster interface crashes with red crosses.

[\] Minor bug fixes.
