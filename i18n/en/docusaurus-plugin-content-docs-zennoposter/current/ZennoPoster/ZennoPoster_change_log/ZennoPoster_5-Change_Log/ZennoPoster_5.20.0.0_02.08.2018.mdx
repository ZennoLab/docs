# ZennoPoster 5.20.0.0 (02.08.2018)

### New features:

[+] Plugins have been added to ProjectMaker.

[+] ProjectMaker now preserves default values when copying actions from one template to another.

[+] A forced template termination feature has been added to ZennoPoster. You can now set a time after which frozen template threads will be automatically terminated.

[+] In ProxyChecker, you can now set the number of source download threads to more than 20.

### Bug fixes:

[\] Fixed an error that would not disappear when renaming a list.

[\] Fixed an issue where the WebGL image hash was not being emulated.

[\] Improved ProxyChecker stability.
