# ZennoPoster 5.21.0.0 (20.08.2018)

### New features:

[+] Added the ability to save variables to a profile.

[+] Added default settings for adding a proxy source.

### Bug fixes:

[\] Fixed an issue where clearing unused variables removed plugin variables.

[\] Fixed an empty execution log in the Task Manager scheduler.

[\] Fixed missing saving and restoring of settings.
