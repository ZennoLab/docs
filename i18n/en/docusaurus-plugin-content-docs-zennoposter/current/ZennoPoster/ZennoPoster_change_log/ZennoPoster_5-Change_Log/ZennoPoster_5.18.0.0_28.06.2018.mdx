# ZennoPoster 5.18.0.0 (28.06.2018)

### New features:

[+] Improved project publishing, added upload to the Personal Account.

[+] Added computer resource monitoring, which speeds up project preparation and launch in ZennoPoster and reduces execution errors when system performance is insufficient.

[+] Added CookieContainer support in HTTP POST/GET, etc. Now cookies are synchronized between the browser and POST/GET requests.

[+] Added a scroll-to-element method for the virtual mouse: FullEmulationMouseWheel(IHtmlElement he, int topOffsetToElementCenter = 50, int leftOffsetToElementCenter = 50).

[+] Improved UI responsiveness in ZennoPoster.

[+] Added support for AirSocks proxies.

[+] Added support for SocksHub proxies.

### Bug fixes:

[\] Restored table handling logic.

[\] Fixed the operation of http://sms-acktiwator.ru.

[\] Fixed saving of the emulated IP in WebRTC.

[\] Fixed a bug with displaying field values in the Profile.

[\] Fixed project execution freezing when Browser Profile loading errors occur.

[\] ZennoPoster.HTTP.RequestBytes now recognizes contentType = «multipart/form-data».

[\] Fixed FullEmulationMouseMoveAboveHtmlElement freezing when scrolling is blocked on the page.

[\] Fixed searching for the Recaptcha2 response input field when there are multiple on the page.

[\] Fixed the Contains method in IZennoList.

[\] Fixed the Switch behavior in ProjectMaker.

[\] Improved the authorization form.

[\] Fixed an issue where input settings would not open.
