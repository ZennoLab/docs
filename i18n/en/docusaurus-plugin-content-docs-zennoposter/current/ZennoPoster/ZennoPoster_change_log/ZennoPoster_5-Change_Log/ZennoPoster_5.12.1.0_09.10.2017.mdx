# ZennoPoster 5.12.1.0 (09.10.2017)

### New features:

[+] Added regular expression history in the builder.

[+] Removed the 24-hour limit in the scheduler when scheduling by minutes.

### Bug fixes:

[\] Fixed execution of custom JavaScript code on the page.

[\] Fixed the invisible ReCaptcha2 cube on the page http://search.google.com/test/mobile-friendly.

[\] Fixed profile saving via C# when the browser is disabled.

[\] Fixed glitches in the action builder with a specific window layout.

[\] Fixed a bug with tiny font in notes that could not be increased afterward.

[\] Fixed a bug where the “Show instances” button would disappear.
