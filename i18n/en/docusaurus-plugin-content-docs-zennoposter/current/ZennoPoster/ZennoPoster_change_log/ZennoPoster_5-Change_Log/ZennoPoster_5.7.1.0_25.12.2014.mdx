# ZennoPoster 5.7.1.0 (25.12.2014)

### New features:

[+] Added automatic matching of variables by name in the “Project in Project” action.

[+] A button to enable deferred rendering of the execution process has been added to the main ProjectMaker panel.

[+] Pop-up messages can now be closed by clicking anywhere on the message.

### Bug fixes:

[\] Fixed handling of debug control buttons when using nested projects.

[\] Fixed instance handling in nested projects.

[\] Fixed an issue with loading an empty nested project.

[\] When deleting variables, the mapping list in the “Project in Project” action is now updated.

[\] Fixed file-related issues when working over a local network.

[\] Fixed project locking issues.

[\] Fixed the behavior of the action builder when an element’s properties are closed.

[\] Fixed scrolling of open project names in the “Recording and Debugging” tab.

[\] Fixed the table and list content viewer.

[\] You can now use the Delete button to remove groups and blocks in the ProjectMaker project editor.

[\] Fixed the manual captcha recognition form; in rare cases it could not be expanded.
