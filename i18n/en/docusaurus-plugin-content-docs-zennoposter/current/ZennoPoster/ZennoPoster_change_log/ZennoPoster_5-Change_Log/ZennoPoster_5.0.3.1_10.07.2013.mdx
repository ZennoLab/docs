# ZennoPoster 5.0.3.1 (10.07.2013)

### New features:

[+] Added the ability to control the stop criterion via a bat file.

[+] The project startup behavior has been moved to the settings.

[+] For C# macros, you can now connect external references not from the GAC.

### Bug fixes:

[\] Hotfix for 5.0.3.0 (the scheduler form would not open, zlib1.dll was missing).

[\] Added small icons for the debugger menu: “From Start”, “Step Forward”, “Run to Breakpoint”, “Stop”.

[\] In the action “Table Operations” → “Save to Variables”, the variables table now resizes in all directions.

[\] The position and size of the toolbar in the advanced editor are now remembered.

[\] The Text → To Table action no longer corrupts table settings.
