# ZennoPoster 5.33.0.0 (30.08.2019)

### New features:

[+] Improved special character input emulation in Chrome.

[+] Optimal settings for Windows emulation are now set by default in the Chrome browser profile.

[+] Added tooltips for BotUI elements.

[+] In the “Using directives and shared code” block, the “Shared code” tab is now placed first.

### Bug fixes:

[\] Fixed referer handling on some websites in Chrome.

[\] Fixed issues causing account logouts while working in ZennoPoster.

[\] Fixed proxy usage by an instance when launching an instance from a browserless project.

[\] Fixed copying of linked lists/tables when copying List/Table Operations actions to another project.

[\] Restored the file selection button in Shared Code.
