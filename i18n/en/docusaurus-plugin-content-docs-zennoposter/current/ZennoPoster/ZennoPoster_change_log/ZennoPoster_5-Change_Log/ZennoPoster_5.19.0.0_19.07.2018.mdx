# ZennoPoster 5.19.0.0 (19.07.2018)

### New features:

[+] New nationalities in the profile: England, France, Germany, Spain.

[+] You can specify the name of a list or table right when creating it.

[+] Exceptions for ZennoPoster.Db methods (throwException parameter, default is false).

[+] Optimized performance of lists and tables without file synchronization.

[+] Added the “Do not save new project” option, which removes the save dialog for new projects after clicking the “From the beginning” button.

### Bug fixes:

[\] Fixed a bug with reassigning Hotkeys after restarting the program.

[\] ZennoPoster.AudioMute correctly mutes sound, including in Flash.

[\] Fixed some errors that occurred during step-by-step debugging of C# code.

[\] Fixed error messages that appeared when publishing projects.

[\] Fixed setting table row and column separators via C#.

[\] Fixes in POST/GET request handling.

[\] Fixes in CookieContainer handling.
