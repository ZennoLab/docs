# ZennoPoster 5.16.2.0 (02.03.2018)

### New features:

[+] Added element search by CSS selector. The methods [QuerySelector](https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic47.html "https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic47.html") and [QuerySelectorAll](https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic48.html "https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic48.html") have been added.

[+] Improved the responsiveness of the ZennoPoster interface when handling a large number of tasks.

[+] Added a global timeout for regular expression parsing. Now your project in ZennoPoster won’t unexpectedly freeze if a regular expression is written incorrectly.

### Bug fixes:

[\] Fixed the display of the notification when loading purchased templates.
