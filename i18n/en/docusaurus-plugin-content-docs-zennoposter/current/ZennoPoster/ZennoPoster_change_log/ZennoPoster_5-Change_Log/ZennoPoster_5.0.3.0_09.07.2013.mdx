# ZennoPoster 5.0.3.0 (09.07.2013)

### New features:

[+] The debugger now has new debug buttons: “From Start”, “Execute Action”, “Run to Breakpoint”, “Stop”.

[+] The task manager has been redesigned.

[+] In the debugger, when you click “From Start”, a confirmation dialog now appears.

[+] Improved performance and reduced memory usage when working with large projects in the editor.

[+] Improved debugging speed when working with large projects.

[+] You can now resize the settings windows in the advanced editor.

[+] Added [❗→ keyboard shortcuts](https://zennolab.atlassian.net/wiki/spaces/RU/pages/475332762 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/475332762") in the project editor.

[+] Improved adding actions in the advanced editor when dragging and dropping or inserting from the context menu. Previously, if the space under the cursor was occupied, the action would not be added; now it is inserted into the nearest available area.

[+] Information about the current version and update checks have been added to the top of the start page in ProjectMaker.

[+] A visual dialog in the debugger: “Continue execution from cursor or from last action”.

[+] Optimized execution of C# macros during debugging in ProjectMaker.

[+] The project autosave timeout has been moved to the settings.

[+] Minor improvements.

### Bug fixes:

[\] The “Follow Cursor” function has been finalized. The page in the browser no longer jumps, the selected state is not reset, and the frame moves with a delay so you can switch to the element properties window or the element tree.

[\] Fixed attribute lists for Get and Set actions in the action builder.

[\] The scheduler deletes the trigger file after checking all tasks.

[\] Tooltips were not displayed in the “Browser → File to Upload to Server” action.

[\] In the advanced editor, you couldn’t add a variable in the variables window.

[\] Profile operations now work correctly without starting the project from the beginning.

[\] Fixed an error during bulk email downloads where some emails had the send date detected incorrectly, causing them not to be downloaded.

[\] The CaptchaSaver module now creates a folder to save the image if it does not exist.

[\] The ContextRecognition tester has been restored.

[\] Fixed PHP debugging in some cases.

[\] Minor fixes.
