# ZennoPoster MP 4.3.6.0 (06.12.2012)

### New features:

[+] An option to disable the creation of the Cookie cleanup action at the beginning of a project (ProjectMaker → Settings → Project Recording).

[+] Ability to display instances for a single project (the option is available in the project’s context menu in ZennoPoster).

[+] By popular request, the IF action can now be inserted anywhere within an ActionGroup.

### Bug fixes:

[\] Fix 4.3.5. Issues opening popups.

[\] Fix 4.3.5. Issues opening iframes.

[\] Thread freezing during long-term operation via GET/POST.

[\] Corrupted files after downloading via a GET request.

[\] Minor bug fixes.
