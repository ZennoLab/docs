# ZennoPoster 5.10.7.0 (20.04.2017)

### New features:

[+] Added support for automatic daylight saving time detection when automatically emulating a time zone.

[+] Added the ability to adjust the number of downloaded emails when processing mail, which helps speed up projects and reduce traffic usage.

[+] Added the method [FullEmulationMouseWheel](https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic394.html "https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic394.html") to emulate scrolling with a virtual mouse.

[+] Added the method [instance.StopDownloads()](https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic277.html "https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic277.html") to stop background downloads.

[+] Improved stability.

[+] The “Line numbering in C# cube” option is now saved.

[+] Expanded diagnostic tools for troubleshooting.

### Bug fixes:

[\] Fixed simultaneous scrolling of two windows in ProjectMaker on Windows 7.

[\] Fixed retrieving the current project proxy in the Get Proxy cube in a browserless project.

[\] Fixed an element receiving focus on right-click.

[\] Fixed duplicate headers when responding to a GET request with a redirect.

[\] Fixed conversion of database actions into C# code.

[\] Fixed a bug where JavaScript would execute on a page “all the time” with a complex nested frame structure.

[\] Fixed minor UI bugs.
