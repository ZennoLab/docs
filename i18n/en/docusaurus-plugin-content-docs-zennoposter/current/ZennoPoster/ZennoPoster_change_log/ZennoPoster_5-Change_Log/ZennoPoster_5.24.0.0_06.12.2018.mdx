# ZennoPoster 5.24.0.0 (06.12.2018)

### New features:

[+] The ReCaptcha2 recognition algorithm in the tab has been updated to the latest version.

[+] The built-in module for working with the http://Anti-Captcha.com service has been updated to API version V2.

[+] BotUI: Added the LanguageSelection control.

[+] Added conversion of the Text Processing → Regex action into C# code.

[+] Optimized the Diagnostics utility for systems with a large number of ZennoLab products installed.

### Bug fixes:

[\] Fixed the installer on some systems.

[\] Fixed an issue where a template would execute with an incorrect proxy format and cause ProjectMaker to crash.

[\] The ReCaptcha2 recognition action now uses server addresses from the settings.

[\] Fixed the behavior of project.GetLastError().Exception code in ZennoPoster and during code debugging in ProjectMaker.

[\] Fixed the behavior of ZennoLab.AudioMute.exe on some systems.

[\] Fixed traffic display issues in ProjectMaker.

[\] Fixed the behavior of the “Completed” mode for action settings in the Advanced Editor.

[\] Fixed the behavior of the Project Minimap window.

[\] Interface improvements.
