# ZennoPoster 5.8.0.2 (04.06.2015)

### New features:

[+] ZennoPoster startup has been sped up.

[+] Proxy source parsing has been sped up.

### Bug fixes:

[\] Fixed text input emulation.

[\] Fixed the cause of instance crashes in 5.8.0.0(1).

[\] Fixed recognition of numeric captchas via the JsDati module.

[\] Fixed loss of focus in the manual captcha recognition module.

[\] Fixed uploading files with long names via HTTP GET/POST.

[\] Fixed POST requests with redirects.

[\] Fixed simultaneous upload of multiple files.

[\] Fixed passing CSS settings for new browser tabs.

[\] Fixed the If action when comparing empty values in texts containing “!=” and “==”.
