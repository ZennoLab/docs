# ZennoPoster 5.29.0.0 (25.03.2019)

### New features:

[+] Chrome engine updated to version 72 with the latest security patches.

[+] Interface performance optimization.

[+] Chrome: Improved instance stability.

[+] Optimized GET/POST request handling for the HTTPS protocol.

[+] Passing current cookies for ReCaptcha2 recognition.

[+] Added the ability to search across all page frames in the “Parsing Assistant.”

[+] Improvements to Page.LastAlertText.

[+] Ability to execute GET/POST requests using the current profile.

[+] BotUI: Added the ability to set the placeholder from settings without editing HTML.

[+] Improvements in handling POST requests with multipart/form-data.

[+] Fixed the “Receive Mail” cube when using a proxy in advanced mode.

[+] Added captcha recognition service http://cheapcaptcha.com.

### Bug fixes:

[\] Fixes in the HttpConnection Pool.

[\] Fixed Copy/Paste hotkeys for actions from one project to another.

[\] Fixed email search in Inbox subfolders.

[\] Fixed browser crash when enabling the “no content display” option.

[\] Fixed incorrect behavior in the Parsing Assistant.

[\] Creation of the ExternalAssemblies folder after installation.

[\] Code was converted to lowercase when uncommenting via hotkeys.

[\] Unable to create a new variable in BotUI on the Advanced tab.

[\] Fixed ZennoPoster project management via code (ITaskManagerService).

[\] Fixed projects running without a browser in ProjectMaker.

[\] Fixed the Profile.UserAgentOsCpu macro.

[\] Fixed instance operation in a subproject.

[\] Chrome: Fixed setting values in page elements.

[\] Chrome: Fixed instance reload issue.

[\] Chrome: Restored the “Browser without content display” mode. For Chrome in ProjectMaker, page content continues to be displayed for debugging purposes.

[\] Chrome: Restored Ctrl + mouse wheel zoom functionality.

[\] Chrome: Fixes in WebRTC emulation.

[\] Chrome: many minor improvements and fixes.

[\] Fixes in BotUI.

[\] Interface fixes and improvements to the project diagram functionality.
