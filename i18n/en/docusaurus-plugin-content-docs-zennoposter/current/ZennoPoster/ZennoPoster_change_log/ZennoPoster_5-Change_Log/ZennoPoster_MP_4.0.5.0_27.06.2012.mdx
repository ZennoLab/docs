# ZennoPoster MP 4.0.5.0 (27.06.2012)

### New features:

[+] ZennoPoster threads now use less memory. They should run more stably under prolonged load.

[+] ProjectMaker uses less memory during extended operation.

[+] New macro `{ -String.Tab- }`.

### Bug fixes:

[\] Action settings now open faster.

[\] Action settings are now always displayed when you double-click an action.

[\] When copying actions between projects, the variables used are also copied (only the variables that store data are copied).

[\] Extra line breaks are no longer inserted into lists during parsing.

[\] ProjectMaker and ZennoPoster threads no longer crash when pop-up blocking is enabled.

[\] ProjectMaker and ZennoPoster now handle large Excel tables correctly without consuming excessive memory.
