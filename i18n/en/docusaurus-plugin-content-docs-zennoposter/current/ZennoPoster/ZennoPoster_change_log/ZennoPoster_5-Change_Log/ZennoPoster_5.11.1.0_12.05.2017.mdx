# ZennoPoster 5.11.1.0 (12.05.2017)

### New features:

[+] Removed dependencies on HtmlAgilityPack.

### Bug fixes:

[\] Fixed browser crash when working in popup mode and on some websites.

[\] Fixed an error when opening a nested project with a browser.

[\] Restored support for the MicrosoftTranslate API.

[\] Fixed simultaneous addition of “Input Settings” and BotUI.

[\] Fixed UI issues when displaying settings on small screens.
