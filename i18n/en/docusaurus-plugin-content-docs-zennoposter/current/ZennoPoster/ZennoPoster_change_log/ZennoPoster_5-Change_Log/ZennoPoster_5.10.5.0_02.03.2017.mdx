# ZennoPoster 5.10.5.0 (02.03.2017)

### New features:

[+] Added functionality to determine location by IP. When setting up a proxy, you can enable the options “Emulate time zone” and “Emulate geolocation.” ZennoPoster will determine the IP’s geographic location and apply the necessary settings.

[+] Improved the use of cookies from the profile.

[+] Added SMS service http://simsms.org.

[+] Added SMS service getsms.online.

[+] Added display of browser zoom level when it differs from 100%.

[+] Added additional checks for installed libraries at program startup to ensure proper operation.

[+] Added methods for working with IP [see here](https://help.zennolab.com/en/v5/zennoposter/5.10.5.0/webframe.html#topic540.html "https://help.zennolab.com/en/v5/zennoposter/5.10.5.0/webframe.html#topic540.html"), such as determining GeoPosition and TimeZone.

[+] Improved the [SetProxy](https://help.zennolab.com/en/v5/zennoposter/5.10.5.0/webframe.html#topic255.html "https://help.zennolab.com/en/v5/zennoposter/5.10.5.0/webframe.html#topic255.html") method for working with geolocation and time zone detection.

### Bug fixes:

[\] Fixed an issue with the context menu not disappearing.

[\] Fixed an issue with the default form and document number.

[\] Fixed an issue where an extra action was added when saving a comment to an action.

[\] Fixed an issue with an instance not terminating after a reload in a nested project.

[\] Fixed an issue with incorrect project file association.

[\] Fixed some issues with IntelliSearch.

[\] Fixed a ProjectMaker crash when opening the Profile - Person/Browser tabs.

[\] Fixed some issues in the ProjectMaker UI.

[\] Fixed an issue with proxy sources terminating unexpectedly.

[\] Fixed frame disabling.

[\] Fixed the error reporting disable setting.
