# ZennoPoster 5.12.3.0 (21.11.2017)

### New features:

[+] Optimized browser engine startup and performance.

[+] Restored support for the standard KeyCaptcha version (requires a CapMonster license).

[+] Added an option to disable log notifications when using the multi-browser (Settings → Debug → Show warning about incompatible browser version).

[+] Ability to enable the required browser version via C# (method void Instance.Launch(BrowserType type, bool useProfile) ).

[+] Improved program stability.

[+] Interface improvements.

### Bug fixes:

[\] Fixes in BotUI when clearing unused variables.

[\] Fixes for importing BotUI input settings.

[\] Fixed text display in BotUI.

[\] Fixed an issue with macros in static CodeCreator blocks.

[\] Fixed an issue where Firefox 52 crashed when clearing the cache for a specific domain.

[\] Fixed saving proxy sources after restarting the program.

[\] Interface fixes.

[\] Fixed the http://sms-reg.com service.

[\] Fixed the GetSmsOnline service.
