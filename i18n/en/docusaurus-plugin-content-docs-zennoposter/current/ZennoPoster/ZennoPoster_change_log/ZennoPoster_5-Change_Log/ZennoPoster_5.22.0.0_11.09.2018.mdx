# ZennoPoster 5.22.0.0 (11.09.2018)

### New features:

[+] Added a helper for parsing data on pages.

### Bug fixes:

[\] Fixed escaping of @ in HTTP request URLs.

[\] Fixed incorrect behavior of the GET request for downloading a file from C# code when an invalid encoding was specified.

[\] Fixed an issue where values were not returned from Plugins.

[\] Fixed a bug with incorrect display of C# compilation errors.

[\] Fixed a bug where changes in the General code were not immediately applied in C# blocks.

[\] Fixed the huge size of the action builder on small screens.

[\] UI bug fixes.
