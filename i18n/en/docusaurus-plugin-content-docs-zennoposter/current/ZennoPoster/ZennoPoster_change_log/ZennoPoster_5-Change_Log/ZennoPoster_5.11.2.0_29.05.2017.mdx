# ZennoPoster 5.11.2.0 (29.05.2017)

### New features:

[+] Added manual HTML code editing [❗→ BotUI](https://zennolab.atlassian.net/wiki/spaces/RU/pages/492175377/BotUI "https://zennolab.atlassian.net/wiki/spaces/RU/pages/492175377/BotUI").

[+] Improved performance of [❗→ BotUI](https://zennolab.atlassian.net/wiki/spaces/RU/pages/492175377/BotUI "https://zennolab.atlassian.net/wiki/spaces/RU/pages/492175377/BotUI").

[+] Added the ability to modify request and response content: [ChangeRequest](https://help.zennolab.com/en/v5/zennoposter/5.11.2.0/webframe.html#topic190.html "https://help.zennolab.com/en/v5/zennoposter/5.11.2.0/webframe.html#topic190.html") and [ChangeResponse](https://help.zennolab.com/en/v5/zennoposter/5.11.2.0/webframe.html#topic191.html "https://help.zennolab.com/en/v5/zennoposter/5.11.2.0/webframe.html#topic191.html").

[+] Improved connection handling (Read more [❗→ here](https://zennolab.atlassian.net/wiki/spaces/RU/pages/494993515/ZennoPoster+Mozilla+Firefox "https://zennolab.atlassian.net/wiki/spaces/RU/pages/494993515/ZennoPoster+Mozilla+Firefox")).

[+] Minor UI improvements.

### Bug fixes:

[\] Fixed importing input settings via a bat file.

[\] Fixed errors when copying a table block between projects.

[\] The link from the ProjectMaker browser address bar is not copied with right-click.

[\] Fixed the accumulation of junk files during operation.

[\] Fixed instance reload in ProjectMaker.
