# ZennoPoster 5.17.0.0 (10.04.2018)

### New features:

[+] Updated profile generation with Fingerprint in the program.

[+] BotUI: Added a tool for importing InputSettings into BotUI.

[+] BotUI: Added the ability to create custom elements in the page code.

[+] Added the class [ZennoPoster.Http](https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic715.html "https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic715.html"), which allows you to create any HTTP request such as PUT/DELETE/PATCH, etc.

[+] Added the method [EvaluateScript](https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic32.html "https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic32.html") to the page document. This allows you to execute JavaScript bypassing CORS.

[+] Added support for the new KeyCaptcha type.

[+] Added support for absolute paths for (S)FTP(S).

### Bug fixes:

[\] Fixed ReCaptcha2 auto-submit on websites with complex nested frame architecture.

[\] BotUI: Fixed issues with incorrect variables.

[\] Fixed launching ProjectMaker with detailed logging enabled.

[\] Fixed opening the page source code — it now opens in the foreground.

[\] Fixed an issue where task launch bat files stop working after updating the version (you will need to regenerate the bat files).

[\] Fixed an issue with http://window.name.

[\] Fixed an issue where the log showed an incorrect line number when a compilation error occurred.

[\] Fixed reset in the task manager to the default value.

[\] Fixed false positive detections by antivirus software.

[\] Fixed photo upload to http://cloud.google.com/vision.

[\] Fixed photo upload to http://imgur.com.
