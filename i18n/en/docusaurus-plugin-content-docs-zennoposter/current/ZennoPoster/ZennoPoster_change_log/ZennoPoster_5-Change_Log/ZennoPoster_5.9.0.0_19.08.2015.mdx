# ZennoPoster 5.9.0.0 (19.08.2015)

### New features:

[+] The Firefox engine has been updated.

[+] With tight integration with CapMonster2, support has been added for solving [❗→ ReCaptcha2](https://zennolab.atlassian.net/wiki/spaces/RU/pages/514949190/ReCaptcha2 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/514949190/ReCaptcha2") and [❗→ KeyCaptcha](https://zennolab.atlassian.net/wiki/spaces/RU/pages/526417933/KeyCaptcha "https://zennolab.atlassian.net/wiki/spaces/RU/pages/526417933/KeyCaptcha").

[+] In the “Image Processing” action, offset parameters for the watermark position have been added to the “Watermark” action.

[+] Multi-select and drag-and-drop have been added to the input settings editing window.

[+] The options “Set value from profile” and “Set value from variable” have been added to the context menu for fields in the HTML element search tables.

[+] The “Run Program” action now includes a “Do not wait for completion” option.

[+] Added the instance.AddToTitle method to append text to the instance window title.

[+] The NavigatorField enumeration has been expanded; the ShowNavigatorField and HideNavigatorField methods have been added, accepting any text field values.

[+] Task interruption has been added to the ZennoPoster Task Manager.

[+] using System.Threading; has been added by default for C# code.

[+] Added the “Convert to C#” button to the context menu, allowing you to obtain C# code for certain actions.

### Bug fixes:

[\] Fixed the “Image Processing” action in the “Resize” action when the “Maintain aspect ratio” parameter is enabled.

[\] Fixed a bug with dynamic binding of lists and tables.

[\] Fixed several bugs that caused ZennoPoster to crash during intensive proxy checking.

[\] Optimized memory usage by instances.

[\] Fixed database launch limitations; templates using 1 thread per database are now taken into account.
