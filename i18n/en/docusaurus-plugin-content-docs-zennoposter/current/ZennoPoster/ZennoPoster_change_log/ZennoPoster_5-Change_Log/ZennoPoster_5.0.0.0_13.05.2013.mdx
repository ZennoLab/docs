# ZennoPoster 5.0.0.0 (13.05.2013)

### New features:

[+] Project recording and debugging are now tightly integrated, so you no longer have to start over every time a debugging error occurs! After recording a project, you can start debugging and, if there are errors, re-record the project right in debugging mode and then continue debugging further.

[+] You can continue debugging from any point, switch between debugging and recording at any time, etc. This improvement significantly speeds up project development and keeping projects up to date!

[+] The debugging progress is displayed directly in the project. You can always see how and where your project has progressed and where it is currently during execution. You can also expand the editor to full screen for advanced project configuration.

[+] ProxyChecker now includes a very useful feature — auto-search! Just enable proxy search, and ProxyChecker will find proxies on its own! No need to specify proxy sources or configure anything — click one button, and in 5 minutes you’ll get hundreds of live fresh proxies with the parameters you need.

[+] A new browser context menu function “Inspect Element” shows the element in the tree and all its properties. This helps you better navigate the layout of elements on a web page.

[+] A task scheduler has been added. Now you can group several tasks and configure their execution settings by time or by event. For example, an external program creates a file, ZennoPoster detects its appearance and starts the task. Or you launch a dozen projects and they run sequentially — each next one starts after the previous one finishes.

[+] You can view and edit the current profile. Not only profile fields such as login, password, etc. are available for editing, but also browser headers. This allows you, for example, to record a project on the mobile version of a site.

[+] A unified context menu is now available in most input fields for inserting values from the profile or current variables.

[+] Drag&Drop support has been added. You can drag elements using DOM element search, by coordinates, or even via image search. In many services, this action is now required when setting up accounts.

[+] Added the ability to execute JavaScript on the current page rather than through a JavaScript engine isolated from the web page.

[+] CodeCreator has been adapted to the new version of ZennoPoster; projects from the previous version work without modification.

[+] CodeCreator now more closely resembles a standard development environment. Support has been added for exporting projects to Visual Studio (if you want to write in php in Visual Studio, you need to install [Phalanger](http://phalanger.codeplex.com/ "http://phalanger.codeplex.com/").

[+] Added the ability to package CodeCreator projects and projects exported to Visual Studio into a special vsproj format. This format stores only the data necessary to run the project in ZennoPoster without the ability to edit it. All projects written in Visual Studio must be packaged in the vsproj format.

[+] Action settings now open significantly faster.

[+] Improved action display — they are now easier to navigate, and more useful information is shown on each action.

[+] Minor bugs fixed, and the ImageTyperz captcha recognition service has been added.

[+] Many minor improvements.
