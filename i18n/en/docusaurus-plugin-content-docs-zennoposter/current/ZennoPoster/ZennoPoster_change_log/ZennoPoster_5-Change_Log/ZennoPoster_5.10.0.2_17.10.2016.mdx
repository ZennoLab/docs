# ZennoPoster 5.10.0.2 (17.10.2016)

### New features:

[+] Added scrolling in static blocks, useful when there are many blocks.

[+] Added support for processing multi-line names with parameters in the input settings.

[+] Reduced CPU usage, WMI Process Host no longer consumes many resources.

### Bug fixes:

[\] Right-click in a popup in ProjectMaker stopped working after several openings and closings of the popup.

[\] Fixed UI freezes in ZennoPoster and ProjectMaker.

[\] The traffic monitoring window did not display on some systems.

[\] Fixed saving and loading of session cookies on some websites.

[\] Fixed an interface error when selecting table separators.

[\] Fixed clearing of tags when changing the form number in the Action Builder.

[\] Fixed issues with MouseMove rendering in ProjectMaker.

[\] Waiting for an element did not work when searching via IntelliSearch.

[\] Fixed display of Facebook comment widgets.

[\] The browser without content display showed content in ZennoPoster under certain conditions.

[\] Fixed incorrect arrow rendering in ProjectMaker.

[\] The Odnoklassniki website did not work properly.

[\] Fixed the appearance of a border around elements.

[\] Fixed instance restart in nested projects.

[\] Fixed working with Proxifier on some systems.

[\] Fixed a bug when launching a project with Canvas emulation.
