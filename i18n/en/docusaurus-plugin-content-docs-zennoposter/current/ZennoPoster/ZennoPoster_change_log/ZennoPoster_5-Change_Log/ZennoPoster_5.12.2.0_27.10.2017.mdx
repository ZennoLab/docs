# ZennoPoster 5.12.2.0 (27.10.2017)

### New features:

[+] New button types in BotUI. Added ZennoPoster template management.

[+] Execution of interactive actions via buttons in BotUI.

[+] BotUI design improvements.

[+] Added the DeathByCaptcha service for solving ReCaptcha2.

[+] Improvements to the Proxy Blacklist (sorting in the blacklist and its import/export).

[+] Added the throwException parameter to the BulkMailDownload method, allowing exceptions to be generated when processing errors occur.

[+] Optimized performance of the Firefox 52 browser.

### Bug fixes:

[\] Fixed several interface issues.

[\] Improved handling of authorization errors (Get Auth Credentials).

[\] Correct use of proxies when solving ReСaptcha2 in browserless projects.

[\] When moving a file into itself in the Move action, the file is not deleted and a warning is written to the log.

[\] Fixed plugin emulation in Firefox 52.

[\] Fixed file uploads via opening and closing a popup, such as http://www.photodex.com.
