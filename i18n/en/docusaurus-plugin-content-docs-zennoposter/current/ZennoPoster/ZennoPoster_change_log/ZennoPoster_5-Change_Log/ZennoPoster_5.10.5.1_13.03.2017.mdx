# ZennoPoster 5.10.5.1 (13.03.2017)

### New features:

[+] Added IP emulation methods for WebRTC. [SetWebRTCAdresses](https://help.zennolab.com/en/v5/zennoposter/5.10.5.1/webframe.html#topic265.html "https://help.zennolab.com/en/v5/zennoposter/5.10.5.1/webframe.html#topic265.html") and [GetWebRTCAdresses](https://help.zennolab.com/en/v5/zennoposter/5.10.5.1/webframe.html#topic211.html "https://help.zennolab.com/en/v5/zennoposter/5.10.5.1/webframe.html#topic211.html") allow you to show IP detection methods via WebRTC the IP addresses you want to display.

[+] Now, when attempting to automatically retrieve mail settings, the message “Failed to automatically retrieve mail settings” is shown for domains whose automatic settings are unknown.

[+] An agreement has been concluded with Kaspersky so that it does not consider our software a virus; new versions will be regularly added to the whitelist. For the program whitelist to work, the Kaspersky Security Network (KSN) setting must be permanently enabled — this is a setting in Kaspersky Anti-Virus. KSN is a cloud storage where data from the whitelist database is stored. If this option is not enabled and there is no active internet connection, Kaspersky Anti-Virus will not receive information about the launched file.

### Fixed bugs:

[\] Fixed the cause of ZennoPoster crashing during long-term operation. If the problem occurs again, we recommend enabling the “Output notifications to log only” setting in ZennoPoster and sending us a diagnostic report.

[\] Fixed the cause of ProjectMaker crashing while inspecting an element.

[\] Fixed ProjectMaker interface freezing when opening properties of certain actions with long text.

[\] Fixed entering text into a comment instead of an action field, the Ctrl key getting stuck, issues with pasting actions via Ctrl+V, and using other hotkeys.

[\] Fixed downloading files via a tricky JavaScript redirect.

[\] Removed unnecessary operations in the interface that caused the UI to slow down.

[\] Fixed the Add tags/Remove tags button in the Element Tree window.

[\] Fixed processing of 32-bit images when resizing and cropping.

[\] Fixed layout issues in some action settings.

[\] Fixed a memory leak in CheckingProcessor during idle time.
