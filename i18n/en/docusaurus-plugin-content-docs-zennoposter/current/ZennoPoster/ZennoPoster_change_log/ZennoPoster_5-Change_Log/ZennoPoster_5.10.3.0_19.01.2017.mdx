# ZennoPoster 5.10.3.0 (19.01.2017)

### New features:

[+] DevExpress components have been updated, which improved responsiveness, interface performance, and localization.

[+] Added time zone emulation for JavaScript. You can set it via Browser ➙ Settings ➙ Time zone. It can also be set from code using the [SetTimezone](https://help.zennolab.com/en/v5/zennoposter/5.10.3/webframe.html#topic259.html "https://help.zennolab.com/en/v5/zennoposter/5.10.3/webframe.html#topic259.html") method.

[+] Tabs have been added to the regular expression builder.

[+] The regular expression builder now displays the parsing time for a regex, helping you create faster regular expressions.

[+] Invalid images are no longer sent to captcha recognition services.

[+] Added a method for forced memory cleanup in an instance. Details are available [here](https://help.zennolab.com/en/v5/zennoposter/5.10.3/webframe.html#topic223.html "https://help.zennolab.com/en/v5/zennoposter/5.10.3/webframe.html#topic223.html").

[+] When opening a project directory, the project file is now selected automatically.

[+] Optimizations to improve loading speed and memory usage.

[+] Improved Canvas blocking.

[+] Improved instance cleanup after finishing work with them.

### Bug fixes:

[\] Fixed a bug related to minimizing ProjectMaker.

[\] Fixed the causes of interface freezes in ZennoPoster and ProjectMaker.

[\] Fixed the causes of slow ZennoPoster shutdown.

[\] Fixed work with the admin panel at http://worpress.com.

[\] While waiting for user action in an instance, you can now upload files.

[\] Fixed instance display during operation.

[\] Fixed project writing in CodeCreator.

[\] Fixed an error accessing globalsettings from Appdomain when executing OwnCode.

[\] Fixed proxy sources dying over time on heavily loaded systems.

[\] Fixed re-checking of live proxies on large databases.
