# ZennoPoster 5.28.0.0 (27.02.2019)

### New features:

[+] Chrome Edition now runs on the latest Chrome 72 engine.

[+] Optimized loading of additional C# libraries in the ProjectMaker editor.

[+] AWM Proxy integration added to the “Proxy Services” section.

[+] Ability to save log filters in ZennoPoster.

[+] Added the ability to create variables during profile loading if they are missing.

[+] Increased the default maximum number of threads in ZennoPoster Pro for new installations.

[+] Display of subscription expiration dates for purchased templates in ZennoPoster and ZennoBox.

[+] Optimized ZennoPoster thread performance.

[+] ProxyChecker: DNSBL support and blacklist checking.

[+] Optimized file handling for HTTP requests.

[+] Improvements to the project diagram.

[+] Other improvements and modifications.

### Bug fixes:

[\] Fixed incorrect detection of ReCaptcha2 on a page.

[\] Improved BotUI processing and stability.

[\] Fixed Boundary for HTTP request blocks and legacy C# HTTP methods.

[\] Automatically removes Accept-Encoding: br from HTTP requests.

[\] Fixed CookieContainer and traffic monitor functionality.

[\] Fixed opening of templates created in Chrome Edition.

[\] Fixed an issue where GAC libraries connected to a project could disappear.

[\] Fixed file upload via ZennoPoster.HTTP.Request.

[\] Fixed loading of WebRTC operating mode from profile.

[\] Fixed webcam functionality.

[\] Chrome Edition: Fixed plugin emulation errors.

[\] Chrome Edition: Fixed screenshot capture and image search.

[\] Chrome Edition: Fixed working with frames.

[\] Chrome Edition: Fixed click emulation on certain websites.

[\] Chrome Edition: Fixed keyboard emulation.

[\] Chrome Edition: Fixed instance window size in ZennoPoster.

[\] Chrome Edition: Interface fixes.

[\] Chrome Edition: Fixed Flash support.

[\] Chrome Edition: Fixed header emulation.

[\] Chrome Edition: Fixed AppleMusic authorization and playback.

[\] Other fixes.
