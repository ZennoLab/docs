# ZennoPoster 5.31.0.0 (07.08.2019)

### New features:

[+] Added a new proxy service http://Infatica.io.

[+] Improved click emulation in Chrome.

[+] Added Intl object emulation for possible profile locales.

[+] Added automatic emulation of navigator.connection and navigator.battery in Chrome.

[+] The results of the “Run Program” action can now be saved to a variable.

### Bug fixes:

[\] Fixed the HTTPS proxy checking algorithm.

[\] Fixed WebRTC IP emulation.

[\] Fixed the proxy rules list in the Task Manager.

[\] Fixed setting the ReCaptcha2 response on http://olx.ua in Chrome.

[\] Fixed the Instance.FormTitle property.

[\] Fixed templates disappearing after the first launch of ZennoPoster.

[\] Fixed window.screen emulation in Chrome (videos were not playing on PornHub).

[\] Fixed working with localStorage in Chrome.

[\] Errors related to missing or mismatched plugins or embedded projects are now displayed in ZennoPoster, even if there is a failed branch.

[\] Fixed audio parameter emulation in Chrome.

[\] Fixed the Tab.KeyEvent method.

[\] Fixed saving a list to a file when the path contains non-existent directories.

[\] Fixed the action for getting the number of lines in a list.

[\] Fixed plugin emulation in Chrome.

[\] Fixed timezone and geolocation emulation errors for some IP addresses.

[\] Fixed the Telegram web version in Chrome.

[\] Fixed the issue with double slashes after the `{ -Project.Directory- }` macro for Instance.DownloadsPath.

[\] Fixed file upload initialization in Chrome (for example, uploading an avatar on Instagram).

[\] Fixed the display of binary data in the traffic monitor.

[\] Fixed browser notification management.

[\] Other fixes and improvements.
