# ZennoPoster 5.11.7.0 (06.09.2017)

### New features:

[+] Added emulation of the [getClientRects](https://browserleaks.com/rects "https://browserleaks.com/rects") fingerprint and corresponding C# properties in the API: [instance.ClientRectWorkMode](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic324.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic324.html"), [instance.ClientRectSeed](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic323.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic323.html").

[+] Added [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB "https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB") management in ZennoPoster.  
Corresponding C# methods in the API: [instance.LoadIndexedDb](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic228.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic228.html"), [instance.SaveIndexedDb](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic254.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic254.html").

[+] Added support for sorting decimal numbers in tables.

[+] Added support for loading .NET Framework 4.5 assemblies.

### Bug fixes:

[\] For those who experienced issues with quickly increasing the number of threads, a new setting “Launch databases sequentially” has been added in the settings section: Settings → Instance.

[\] Fixed proxy mix-ups in some cases when running 5+ threads per process.

[\] Incorrect browser switching in ProjectMaker when switching from a browserless project to a project with a browser.

[\] Improved stability; fixed an issue that caused ZennoPoster to freeze on some computers.

[\] Fixed date selection in no-content mode.

[\] Optimized thread stopping.

[\] Fixed an issue with canvas size in BotUI.
