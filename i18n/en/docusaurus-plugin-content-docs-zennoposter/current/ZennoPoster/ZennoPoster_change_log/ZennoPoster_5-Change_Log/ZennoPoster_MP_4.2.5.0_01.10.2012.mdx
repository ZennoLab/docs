# ZennoPoster MP 4.2.5.0 (01.10.2012)

### New features:

[+] Support for creating bat files.

[+] New WordAi Spintax action (http://wordai.com/).

[+] Button to delete all proxies in the “Sources” tab in ProxyChecker.

[+] Button to clear the list of live proxies.

[+] Comments in the action builder.

[+] Proxies in the format “127.0.0.1:Port” will now be loaded from sources.

### Bug fixes:

[\] Fixed a bug where links disappeared during debugging and when saving/loading a project.

[\] Fixed a bug where deleting an auto-variable actually deleted a variable from the first tab.

[\] HTTP GET requests did not work simultaneously in ZennoPoster and ProjectMaker.

[\] Scrapebox did not work when ProjectMaker was enabled.

[\] Glitch with the settings sliders in ZennoPoster.

[\] An empty element sometimes appeared in the Switch block during debugging.

[\] When adding the Pause action, there was no warning that the element was not configured.

[\] A long comment for an action group extended beyond the group’s boundaries.

[\] Minor bug fixes.
