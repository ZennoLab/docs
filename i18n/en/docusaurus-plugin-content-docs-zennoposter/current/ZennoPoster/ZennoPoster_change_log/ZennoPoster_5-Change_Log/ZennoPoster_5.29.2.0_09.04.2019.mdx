# ZennoPoster 5.29.2.0 (09.04.2019)

### New features:

[+] Regular expression processing errors are now displayed in the regular expression builder.

[+] The keyboard emulation has been extended with modifiers `{CTRLDOWN}`, `{CTRLUP}`, `{SHIFTDOWN}`, `{SHIFTUP}`, `{ALTDOWN}`, `{ALTUP}` and keys `{CTRL}`, `{SHIFT}`, `{ALT}`.

[+] Added the checked field to “Element Properties” for radio buttons and checkboxes.

[+] Updated Microsoft Translate API from version 2 to version 3 (version 2 will stop working on April 30, 2019).

[+] Improved ZennoPoster stability.

[+] Group comments have been added to template search.

### Bug fixes:

[\] Fixed hotkey behavior when working with multiple monitors.

[\] In the C# code window, inserting variables and snippets now replaces the selected fragment.

[\] Various interface fixes.

[\] Fixed an issue with blocking access to directories used as the download directory for HTTP requests (for the mode without HttpConnectionPool).

[\] Fixed the “Get proxy” action in ProjectMaker.

[\] Fixed the “Restart instance” action in ProjectMaker.

[\] Fixed an issue with changing the number of worker threads in ZennoPoster.

[\] Fixed adding a list to a table into any previously non-existent column.

[\] Fixed setting Accept-Language in Firefox engines.

[\] Fixed sorting projects by status and other columns with images in ZennoPoster.

[\] Fixed HTTP request timeouts.

[\] Fixed mouse emulation in Chrome (issue with selecting fields).

[\] Fixed favicon loading in Firefox.

[\] Fixed re-acquiring a proxy when using acquire-with-removal.

[\] Fixed Firefox crashing when setting connection limits.

[\] Fixed FullEmulationMouseMove and other actions after restarting an instance.
