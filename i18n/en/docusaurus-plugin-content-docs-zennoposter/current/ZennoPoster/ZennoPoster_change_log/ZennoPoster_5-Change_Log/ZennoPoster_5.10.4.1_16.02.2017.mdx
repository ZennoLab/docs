# ZennoPoster 5.10.4.1 (16.02.2017)

### New features:

[+] Starting from this version of ZennoPoster, in the encryption block you can choose which version of ZennoPoster the project will work with. This option increases project compatibility and security.

[+] Improved virtual mouse functionality and enhanced simulation of reading and viewing elements.

[+] The parameters of the [❗→ virtual mouse](https://zennolab.atlassian.net/wiki/spaces/RU/pages/489291804 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/489291804") can now be configured from code.

[+] Added access to document properties from C# code: [document.ReadyState](https://help.zennolab.com/en/v5/zennoposter/5.10.4.1/webframe.html#topic65.html "https://help.zennolab.com/en/v5/zennoposter/5.10.4.1/webframe.html#topic65.html") and [document.Referrer](https://help.zennolab.com/en/v5/zennoposter/5.10.4.1/webframe.html#topic66.html "https://help.zennolab.com/en/v5/zennoposter/5.10.4.1/webframe.html#topic66.html").

### Bug fixes:

[\] Fixed high CPU usage in ProjectMaker on some computers.

[\] Fixed a memory leak in ZennoPoster during active operation.

[\] Made adjustments to speed up opening nested projects.

[\] Fixed minor UI issues.
