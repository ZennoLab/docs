# ZennoPoster 5.13.0.0 (21.12.2017)

### New features:

[+] Added support for 64-bit Firefox.

[+] Added the ability to add proxy services.

[+] Added support for AWM proxy.

[+] Added support for the service http://virtualsms.ru.

[+] Canvas emulation now supports emulation when working with WebGL and WebGL2 contexts.

[+] Improved time emulation.

[+] Improved ProjectMaker performance when working with large projects.

### Bug fixes:

[\] Improved hiding of navigator object fields.

[\] Improved program stability.

[\] Fixed browser launch errors.

[\] Fixed errors when working with HID.exe.

[\] Fixed issues with copying BotUI elements.

[\] Fixed image corruption during Canvas emulation.

[\] Fixed retrieving `{ -Page.Dom- }` from a page.

[\] When copying an action with a list/table, the file binding no longer gets lost.

[\] Fixed project autosave when there is no free space on the C:\ drive.

[\] Fixed parameter serialization error.

[\] Fixed errors when solving ReCaptcha2 via the RuCaptcha and Anti-Captcha services.
