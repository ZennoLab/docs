# ZennoPoster 5.0.4.2 (15.08.2013)

### New features:

[+] Added the “Regex Builder” and “Context Recognition” buttons to CodeCreator (if these buttons are not displayed, go to the %APPDATA%\ZennoLab\ZennoPoster\5 folder and delete the CodeCreator folder inside it).

[+] Improved the display of log entries for the English version.

### Bug fixes:

[\] Fixed a bug with the login and password input window display during debugging.

[\] Fixed one of the causes of project execution freezing.
