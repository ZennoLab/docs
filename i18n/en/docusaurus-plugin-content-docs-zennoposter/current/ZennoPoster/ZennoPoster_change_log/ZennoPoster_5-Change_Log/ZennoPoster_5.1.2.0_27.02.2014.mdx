# ZennoPoster 5.1.2.0 (27.02.2014)

### New features:

[+] Added a diagnostic utility to collect information when issues occur (Diagnostic.exe file or Settings → Other → Diagnostics).

[+] The email processing window opened when recording a project can now be maximized to full screen and resized.

[+] In email processing, when parsing an email, the rows in the results table now have automatic height.

[+] The variables window in ProjectMaker now remembers its position, size, column sorting, and filtering.

[+] In ProjectMaker, the “IF” action now has a multi-line field for more convenient editing.

[+] Added a Save All button.

### Bug fixes:

[\] Optimized CPU usage in ZennoPoster when running a large number of projects/threads.

[\] Fixed an issue where an “Unknown error” would appear when launching ZennoPoster during license loading.

[\] Fixed an issue in ProjectMaker where double-clicking an action could cause it to shift within a group of actions.

[\] Other minor fixes.
