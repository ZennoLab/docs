# ZennoPoster MP 4.3.7.1 (19.01.2013)

### New features:

[+] Multi-editing of permissions for open projects (ProjectMaker → Settings → Editor → Tools).

[+] You can open multiple projects at once in the project open dialog.

[+] Added support for http://ImageDecoders.com — the service sent us a module for ZennoPoster, so we decided to add it.

### Bug fixes:

[\] Hotfix for issues that appeared in version 4.3.7 but were not present in 4.3.6 (issues occurring after debugging).

[\] Minor bug fixes.
