# ZennoPoster 5.12.0.0 (22.09.2017)

### New features:

[+] Starting with this version, ZennoPoster becomes multi-browser. In addition to Firefox 45 ESR, the Firefox 52 ESR engine has been added. Now you can test new browser features without breaking your existing projects.

[+] Added the “Launch Browser” action. Now, in the middle of a project run, you can launch the browser version you need if you suddenly require it.

[+] Added a button element to BotUI for more convenient editing.

[+] Added the “Show date” setting to the template execution log in ZennoPoster.

### Bug fixes:

[\] Fixed ProjectMaker freezing when showing a notification about a new available version.

[\] Fixed thread startup freezing after some time.

[\] Fixed issues with loading projects and libraries downloaded from the internet.

[\] Fixed ignoring of “,” characters when loading a \.csv table.

[\] Fixed photo uploads via proxy in Google services.

[\] Fixed clicking in the input field on Hotmail.

[\] Fixed uploading table files in CodeCreator.

[\] Fixed scroll positioning when working with the project minimap.
