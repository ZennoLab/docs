# ZennoPoster Change Log

:::info Notice for English-speaking users
The complete ZennoPoster change log with detailed version history is only available in Russian.

**[→ View the full change log in Russian](/ru/zennoposter/ZennoPoster/category/zp_changelog)**
:::

## Why is the full history only in Russian?

The detailed change log includes extensive historical information about older versions (ZennoPoster 5 and ZennoPoster 7), which is primarily relevant for Russian-speaking users maintaining legacy systems.

**English-speaking users always receive the latest stable version** through official distribution channels, so historical version details are typically not necessary.

## Need information about specific features?

- **Current version documentation** is fully available in English throughout this site
- For questions about specific features or updates, visit [ZennoPoster Forum](https://zennolab.com/discussion/)
- Latest release information is available on the official [ZennoPoster website](https://zennolab.com/products/zennoposter/)
- Contact support at [support@zennolab.com](mailto:support@zennolab.com)
