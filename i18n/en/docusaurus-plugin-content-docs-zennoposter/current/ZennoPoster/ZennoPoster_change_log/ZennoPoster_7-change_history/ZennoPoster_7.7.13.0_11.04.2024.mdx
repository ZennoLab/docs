# ZennoPoster 7.7.13.0 (11.04.2024)

**New features:**

[+] Chromium browser updated to version 123.

**Bug fixes:**

[\] Fixed page loading status freezing in Chromium.
[\] Fixed SMS services functionality.
[\] Fixed setting the value "gzip, deflate, br" in the AcceptEncoding header of the CEF browser.
[\] Fixed an issue with page decoding in the CEF browser; the zstd algorithm is now forcibly excluded from AcceptEncoding, as the browser does not support it.
[\] Fixed display of the configured proxy in ProjectMaker for the CEF browser.
[\] Fixed display of page load timeout in ProjectMaker for the Chromium browser.
[\] Fixed browser restart in ProjectMaker when clicking the "From the beginning" button if the running browser used a profile folder while the opened project does not use a browser at all.
