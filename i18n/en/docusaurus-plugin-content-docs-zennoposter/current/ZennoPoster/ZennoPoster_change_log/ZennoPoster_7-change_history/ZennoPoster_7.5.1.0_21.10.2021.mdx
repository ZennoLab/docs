[+] Chromium integration added to ProjectMaker.
[+] Improved AudioContext emulation.
[+] Improved fingerprint emulation; the database of unique profiles has become even larger.
[+] Implemented support for the "Element Tree" in Chromium.
[+] Implemented support for "Element Properties" in Chromium.
[+] Implemented support for the "Action Builder" in Chromium.
[+] Implemented support for "Data Parsing" in Chromium.
[+] Implemented support for "Inspect Element" in Chromium.
[+] Implemented support for "Follow Element" in Chromium.
[+] Implemented handling of JS events for Chromium.
[+] Many other tasks completed for Chromium integration in PM.
[+] Added touch mode support in Chromium.
[+] Implemented auto-submit in the hCaptcha cube.
[+] CEF updated to version 93.
[+] Improved backup handling for ZennoPoster tasks (Tasks.dat file).

**Bug fixes:**

[\] Fixed Chromium authorization in Google.
[\] Fixed instance viewing in ZennoPoster on Windows 2012 Server.
[\] Fixed a Chromium memory leak in ZennoPoster on Windows 2016 Server.
[\] Restored HSTS saving and loading in CEF.
