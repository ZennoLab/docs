# ZennoPoster 7.7.6.0 (25.08.2023)

**New features:**

[+] The Chromium browser has been updated to version 115.

**Bug fixes:**

[\] A limit has been added to the number of requests in the traffic monitor for the Chromium browser. This fixes a memory leak when working with Chromium.

[\] Fixed a ProjectMaker crash when opening cube settings in Windows 11 and when opening the profile window.

[\] Fixed ZennoPoster’s operation on multi-processor systems. Previously, ZennoPoster recognized only one processor in the system.

[\] Fixed Metamask functionality in the Chromium browser.

[\] Fixed mouse emulation in Chromium when the browser size exceeds the screen size.
