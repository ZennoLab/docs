# ZennoPoster 7.8.4.1 (27.05.2025)

**Added:**

[+] Optimized the integration between ZennoPoster7 and ZennoBrowser.

**Fixed:**

[\] Fixed thread degradation when using the ZennoPoster7 - ZennoBrowser integration.

[\] Fixed an issue that caused threads to freeze when launching the Chromium and Chromium from ZB browsers.

[\] Fixed the behavior of browserless projects that launch a browser during execution. Such projects now run faster and more stable than before.
