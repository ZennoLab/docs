# ZennoPoster 7.3.1.1 (20.01.2021)

### New features:

[+] Added program authorization mirrors.

### Bug fixes:

[\] Fixed thread startup in ZennoPoster.

[\] Sped up loading of new profiles (noticeable with a large number of threads in a browserless project).

[\] Fixed the date format in ZennoPoster task scheduler settings.

[\] Now, when updating profiles, the profile language no longer resets to Russian.

[\] Fixed setting a file for upload in the Chrome browser.

[\] Captcha and reCAPTCHA module names are now written correctly and handled case-insensitively.

[\] Fixed loading of the profile folder when the browser is active in ProjectMaker.

[\] Fixed the Export Cookies cube in a browserless project.

[\] Fixed retrieving rows from Google Sheets when the "First row is headers" option is enabled.
