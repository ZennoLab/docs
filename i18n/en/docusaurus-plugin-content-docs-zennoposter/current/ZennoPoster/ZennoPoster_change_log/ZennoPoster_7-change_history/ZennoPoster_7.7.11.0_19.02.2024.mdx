# ZennoPoster 7.7.11.0 (19.02.2024)

**New features:**

[+] Chromium browser updated to version 121.
[+] ZennoPoster now displays available physical memory and available allocated memory separately in the system resource monitoring bar.
[+] Updated links to system libraries.

**Bug fixes:**

[\] Fixed an issue with slow loading that caused blank pages to appear in the Chromium browser.
[\] Fixed WebRTC emulation in Chromium.
[\] Improved emulations for working with Cloudflare.
[\] Fixed the application of Chromium browser window sizes in ProjectMaker after clicking the “From the beginning” button.
