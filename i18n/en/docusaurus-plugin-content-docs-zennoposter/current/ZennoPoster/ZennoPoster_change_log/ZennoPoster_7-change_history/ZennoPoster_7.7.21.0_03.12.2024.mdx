# ZennoPoster 7.7.21.0 (03.12.2024)

**Added:**

[+] Chromium browser updated to version 131.

**Fixed:**

[\] Fixed excessive disk usage caused by the Chromium browser.

[\] Fixed ENTER key input in keyboard emulation for the Chromium browser.

[\] Investigated the issue of missed mouse clicks during full mouse emulation on websites with complex styles. To configure the clickable area of an element, it is recommended to use [<u data-renderer-mark="true">this method</u>](https://help.zennolab.com/en/v7/zennoposter/7.1.4/webframe.html#topic610.html "https://help.zennolab.com/en/v7/zennoposter/7.1.4/webframe.html#topic610.html").

[\] Fixed ZennoPoster crash when enabling RSS parsing in ProxyChecker.

[\] Fixed copying to clipboard and saving live proxies in ProxyChecker. Now, in the "Accept Mail" cube, automatic creation of a non-existent variable works as it does in other cubes.

[\] Fixed the "Use autocomplete in dropdown lists" option.

[\] Fixed task selection in the ZennoPoster Task Manager; previously, in some cases, a task would not remain selected after clicking on its row.
