# ZennoPoster 7.7.0.0 (03.03.2022)

**New features:**

[+] A new canvas emulation mode called "Super Emulation" has been added. For it to work correctly, enable it in the browser profile settings when starting the project, or during project execution via the Browser → Settings → Canvas cube. The new mode allows canvas data to be emulated consistently with other profile data, providing real uniqueness instead of 100% uniqueness like when adding noise.

[+] The "Install Extension" cube now lets you set a pause to ensure the extension installs correctly before you start working with it.

[+] Added the ability to disable certificate verification when connecting a mail account.

[+] The "Settings" cube option has been moved to a separate cube called "Wait for User Actions" in the Logic section. Existing templates will continue to work as before; the cube will simply look different.

[+] A new action "Reload Table" has been added to the "Google Sheets Operations" cube.

[+] A new action "Clear" has been added to the "Variable Processing" cube, allowing you to clear selected or all variables.

[+] The Chromium browser engine has been updated to version 96.

[+] Added support for Chromium browser launch arguments.

[+] Added the DevTools Frontend window for the Chromium browser. The window size and position are saved correctly. The context menu is also displayed correctly.

[+] Improved worker handling in the Chromium browser.

[+] Improved anonymity of the Chromium browser.

[+] Improved stability of launching and running the Chromium browser.

[+] Disabled saving browser metrics in the Chromium profile folder. This significantly reduces the size of profile folders.

**Bug fixes:**

[\] Fixed Widevine functionality in CEF ([❗→ Usage instructions](https://zennolab.atlassian.net/wiki/spaces/RU/pages/2104492033/Widevine "https://zennolab.atlassian.net/wiki/spaces/RU/pages/2104492033/Widevine")).

[\] Fixed the hCaptcha cube properties and restored the "Store in variable" field.

[\] Fixed ProjectMaker being blocked by dialogs appearing behind the PM window.

[\] Fixed interface element resizing when changing the ProjectMaker window state.

[\] Fixed cases where a tab created by an extension had an empty address.

[\] Fixed the "Activate Extension" cube for extensions without a popup.

[\] Fixed Metamask extension handling in Chromium.

[\] Emulations applied on pages generated by extensions are now applied more correctly and in a timely manner.

[\] Fixed the "Restart Instance" cube freezing in ProjectMaker.

[\] Fixed the "Run Instance" cube freezing.

[\] Fixed ProjectMaker freezing when launching the browser with a profile folder.

[\] Fixed browser profile selection in the "Run Instance" cube when using default browser profile settings.

[\] Removed the explicit geolocation request, most often encountered on the Yandex website.

[\] Icons in the "Set Value from Profile" menu are now colored to make them easier to distinguish.

[\] Fixed Chromium browser flickering when scrolling pages.

[\] Fixed possible causes of Chromium browser freezing when navigating to a page.

[\] Fixed the display of the extension window when switching to a browserless project.

[\] Fixed the DrawToBitmap method (ReCaptcha2 recognition did not work on some websites).

[\] Fixed file dialog handling while waiting for user actions in Chromium.

[\] Fixed image loading for Facebook and Instagram.

[\] Fixed data parsing with the "Search in all frames" option in Chromium.

[\] On navigation errors, the page URL now becomes chrome-error://chromewebdata/

[\] Fixed referrer passing in the navigation cube in Chromium and CEF.

[\] Fixed ReCaptcha2 recognition on some websites in Chromium and CEF.

[\] Minor fixes in loading session cookies in Chromium and CEF.

[\] Fixed socks5 proxy handling with login/password containing a semicolon.

[\] Fixed the display of instance previews in ZennoPoster.

[\] Other fixes and improvements.
