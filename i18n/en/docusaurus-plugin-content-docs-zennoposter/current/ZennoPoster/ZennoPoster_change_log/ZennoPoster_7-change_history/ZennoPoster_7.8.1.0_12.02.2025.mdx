# ZennoPoster 7.8.1.0 (12.02.2025)

**Added:**

[+] Chromium browser updated to version 132.

[+] Now, if the browser crashes in ProjectMaker, the "Restart browser" button launches the last opened browser instead of the browser from the current project settings.

**Fixed:**

[\] Fixed the auto-search for sources — the search is now performed using the browser. The proxy checking process has also been improved, and ProxyChecker now finds significantly more proxies.

[\] Fixed a cosmetic issue in ZennoPoster where the URL of one browser page was displayed in another browser window.

[\] Now in ProjectMaker, when the browser address bar is focused, its value does not change and does not interfere while you type a new address.

[\] Fixed ProjectMaker freezing when restarting the browser after clicking the "From the beginning" button.

[\] Fixed the selected category being reset in ZennoPoster in some cases.
