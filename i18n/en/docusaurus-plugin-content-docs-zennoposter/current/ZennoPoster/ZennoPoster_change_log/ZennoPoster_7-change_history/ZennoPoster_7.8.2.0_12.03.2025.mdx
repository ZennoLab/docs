# ZennoPoster 7.8.2.0 (12.03.2025)

**Added:**

[+] Chromium browser updated to version 133.

[+] Added the ability to block file downloads for Chromium and ChromiumFromZB browsers. To do this, set the value to &lt;deny&gt; in the file download path cube or in the *instance.DownloadsPath property.

**Fixed:**

[\] Now, when using the ZennoPoster7–ZennoBrowser integration, redirects to [!\[\](http://rc.zennoposter.com/favicon.ico)Test Page for the Nginx HTTP Server on Fedora](http://rc.zennoposter.com) no longer appear in the browser history.

[\] Fixed the blue frame highlighting of elements on the page for Chromium and ChromiumFromZB browsers.

[\] Now, ZennoBrowser browsers in ZennoPoster are displayed in the foreground.

[\] ZennoPoster no longer resizes ZennoBrowser browser windows.
