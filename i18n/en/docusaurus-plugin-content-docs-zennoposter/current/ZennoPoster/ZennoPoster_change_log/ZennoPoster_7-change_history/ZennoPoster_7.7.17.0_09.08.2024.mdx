# ZennoPoster 7.7.17.0 (09.08.2024)

**New features:**

[+] Chromium browser updated to version 127.

[+] Improved screen coordinate emulation when simulating mouse events for Chromium.

[+] Updated proxy source search in ProxyChecker. Auto-search will now look for proxies with hosts in IP format, as before. For manually added sources, ProxyChecker will search for proxies with any host format.

**Bug fixes:**

[\] Fixed the display of the devtools window for the Chromium browser.

[\] Fixed solving ReCaptcha2 via CapMonster2 in a tab.
