# ZennoPoster 7.8.8.0 (12.08.2025)

**Added:**

[+] Now the "Launch Browser" action with the without-browser option or the similar C# method *instance.Launch, *instance.Stop closes the browser in ProjectMaker as well.
At the same time, clicking "From the beginning" in a project without a browser will not close the browser, but only hide it, as before.

[+] Added the *instance.Stop() method. Calling this method closes the launched browser; it works in both ZennoPoster and ProjectMaker.

[+] Proxy settings were added to the *IntegratedBrowserLaunchSettings object for launching a browser from ZennoBrowser with proxy override via the *instance.Launch method.

**Fixed:**

[\] Fixed Chromium browser crashes on some websites.

[\] Fixed the *instance.Launch method when using *BrowserType.WithoutBrowser.

[\] Fixed the *instance.IntegrationLaunch method.

[\] Fixed the *instance.Reload method.

[\] Fixed the behavior of labels in ZennoPoster.
