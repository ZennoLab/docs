# ZennoPoster 7.8.5.0 (05.06.2025)

**Added:**

[+] Chromium browser updated to version 136.

**Fixed:**

[\] Fixed the file selection dialog display for Chromium and ChromiumFromZB.

[\] Fixed an issue where the “Waiting for user actions” banner disappears when creating a new tab in Chromium and ChromiumFromZB.

[\] Changed the server auto-switching algorithm, which should help in case of server blocks.

[\] Fixed a memory leak that appeared in 7.8.4.1 when working with Chromium and ChromiumFromZB browsers.

[\] Minor adjustments made to thread degradation during integration with ZennoBrowser.
