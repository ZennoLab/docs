# ZennoPoster 7.7.5.0 (07.07.2023)

**New features:**

[+] Chromium updated to version 114.

[+] Added the ability to allow selected websites or requests to run without a proxy in the Chromium browser. The API now includes the method *Instance.SetProxyExclusions(IEnumerable&lt;string&gt; exclusions) and the *Exclusions property in the ProxySettings class, which is used in the method *Instance.SetProxy(ProxySettings proxySettings, NetworkSettings networkSettings).
