# ZennoPoster 7.7.10.0 (19.01.2024)

**New features:**

[+] The Chromium browser has been updated to version 120.

**Bug fixes:**

[\] Fixed an issue launching Chrome and Chromium browsers with a profile folder in ZennoPoster.
[\] Fixed freezes when loading pages in the Google Chrome extension store.
[\] Fixed the display of the Chromium browser when changing the Windows text scaling.
[\] Fixed handle leak issues in the dwm system process when working with Chromium browsers.
