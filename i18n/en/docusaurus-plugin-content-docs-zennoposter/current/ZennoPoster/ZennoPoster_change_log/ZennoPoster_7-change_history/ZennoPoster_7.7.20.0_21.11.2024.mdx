# ZennoPoster 7.7.20.0 (21.11.2024)

**Added:**

[+] Chromium browser updated to version 130.

[+] Added the ability to adjust the timeout for requests to SMS services. The SMS service configuration now includes the settings *timeout_sec — total request waiting timeout (180 seconds by default) and *delay_between_request_sec — delay between requests (22 seconds by default).

**Fixed:**

[\] Fixed the layout of the URL field in the hCaptcha cube.

[\] Fixed the layout of the “Document No.” label in the Action Builder.

[\] Fixed the setting of the maximum number of threads if the first launched product was ZennoPoster and not ProjectMaker.

[\] Fixed the emulation of system key presses such as `{DOWN}` in the Chromium browser.

[\] Fixed the --ignore-certificate-errors=false argument in the Chromium browser.

[\] Now when you add new projects to ZennoPoster, they are instantly saved to backup and, in case of a crash, will be guaranteed to be offered for recovery.

[\] Fixed the versions of Chrome\Chromium profiles that are marked as Up to date.
