# ZennoPoster 7.8.11.0 (08.10.2025)

**Added:**

[+] For Chromium browsers integrated with ZennoBrowser, the ability to change the window size via the instance.SetWindowSize method has been unlocked.

[+] Improved highlighting of search results in C# actions, the regular expression tool, and the Dom, Text, and Source page views. Highlighting of all search results found within the text has also been enabled.

**Fixed:**

[\] Fixed cookie deletion in the Current profile->Cookies form.

[\] Fixed resizing of action settings in some ProjectMaker styles.

[\] Removed inactive scrollbars of text fields in action settings.
