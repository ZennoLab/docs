# ZennoPoster 7.2.1.1 (12.11.2020)

### New features:

[+] For the schedule execution types Consecutive and Consecutive with pause, the status "Waiting for repetition to finish" has been added to the next run time field.

[+] Added display of a project load error if there are issues loading ExternalAssemblies for the project.

### Bug fixes:

[\] Fixed the If action when comparing double numbers.

[\] Fixed the schedule behavior for the completion type "After N repetitions".

[\] Fixed issues with displaying the next run time in the ZennoPoster schedule.

[\] Fixed the behavior of actions created using the "Repeat in loop" menu item.

[\] Fixed the placeholder of the JavaScript action.

[\] Fixed the display of some actions in the ProjectMaker dark theme.

[\] Fixed working with task settings in the ZennoPoster Task Manager.
