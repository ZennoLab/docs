# ZennoPoster 7.7.7.0 (05.10.2023)

**New features:**

[+] Chromium updated to version 117.

**Bug fixes:**

[\] Fixed bypass of Qrator protection in the Chromium browser (for example, on the Sportmaster website). To work correctly with such sites, use site isolation mode.

[\] Fixed WebRTC emulation when using an IPv6 proxy; now both IPv4 and IPv6 proxy exit addresses are involved in WebRTC emulation (automatic mode only), and an IPv4 proxy exit address is no longer required for the emulation to work. At the same time, geolocation and timezone emulation still require an IPv4 proxy. Fix in the Chromium browser.

[\] Fixed Google services freezing when signing into a Google account in the Chromium browser.

[\] Fixed the CapMonster Cloud extension in the Chromium browser.
