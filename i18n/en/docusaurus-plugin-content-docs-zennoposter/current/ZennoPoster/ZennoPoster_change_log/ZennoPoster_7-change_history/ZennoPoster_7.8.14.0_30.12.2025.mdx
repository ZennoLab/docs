# ZennoPoster 7.8.14.0 (30.12.2025)

**Added:**

[+] The Chromium browser has been updated to version 143.0.7499.170.

[+] ZennoPoster has been migrated to .Net Framework 4.8.

**Fixed:**

[\] Fixed screenshot capture for Chromium and ChromiumFromZB browsers with the “Site Isolation” option enabled.

[\] Fixed the functionality of the context menu in DevTools.

[\] Fixed mouse emulation for Chromium browsers with site isolation enabled, as well as for browsers integrated with ZennoBrowser. The virtual mouse should now move quickly and correctly.

[\] Fixed Touch event emulation in Chromium and ChromiumFromZB browsers.

[\] In the Chromium browser, file downloads now display a progress bar in the browser status bar, and it is now possible to cancel downloads in the ProjectMaker UI.

[\] Fixed the layout in the “Launch ZennoBrowser instance” action block.
