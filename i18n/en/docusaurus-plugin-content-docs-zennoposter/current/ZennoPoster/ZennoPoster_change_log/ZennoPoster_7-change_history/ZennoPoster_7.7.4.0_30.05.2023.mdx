# ZennoPoster 7.7.4.0 (30.05.2023)

**New features:**

[+] Chromium updated to version 112.

[+] Improved handling algorithms for advanced Canvas emulation.

[+] Added a new browser launch argument --zl-deny-ws-localhost. Using this argument, you can disable browser tracking by desktop applications (such as Discord).

**Bug fixes:**

[\] Fixed hotkeys in Windows 11.

[\] Changed the default address for the 5sim SMS module to improve service integration performance.

[\] The “Clear Variables” cube can now be found in the action search.

[\] Fixed the starting coordinates for page view emulation.

[\] Fixed CloudFlare bypass in the Chromium browser.

[\] Fixed the ScreenMaximize mode and the *instance.SetWindowSize method in Chromium.

[\] Fixed the display of child browser windows, such as Chromium extensions.
