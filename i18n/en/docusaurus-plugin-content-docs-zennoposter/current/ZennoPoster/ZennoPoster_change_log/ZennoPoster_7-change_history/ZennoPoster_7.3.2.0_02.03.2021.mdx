# ZennoPoster 7.3.2.0 (02.03.2021)

### New features:

[+] ZennoPoster now includes the ability to import and export projects for working in Visual Studio. This feature replaces CodeCreator.
[+] ZennoPoster now supports spoofing microphone and camera input from a file to output image and sound to websites.
[+] In the ZennoPoster log, you can now get the action ID for any notification from the context menu and navigate to the action in ProjectMaker.
[+] The traffic monitor now displays the time spent on a request for browserless projects.
[+] ProjectMaker now allows you to set a proxy by clicking the “No proxy” label at the bottom of the instance window.

### Bug fixes:

[\] Fixed an issue where the Language setting was not saved in the profile.

[\] Fixed an issue where updating a profile changed the browser profile emulation parameters.

[\] Fixed a bug where ProjectMaker could freeze when opening a project.

[\] Fixed automatic proxy search in ProxyChecker.

[\] Fixed an issue where a large number of browserless project threads interfered with launching browser project threads.
