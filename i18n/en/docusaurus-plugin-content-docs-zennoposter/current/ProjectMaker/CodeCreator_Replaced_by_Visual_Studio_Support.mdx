# 📑 CodeCreator (replaced by Visual Studio support)

:::warning Attention
Attention! CodeCreator is no longer supported starting from ZennoPoster 7 and has been replaced with Visual Studio. If you want to use the program, please use ZennoPoster 5.
:::

**CodeCreator** has the same functionality as ProjectMaker, but instead of creating, editing, and debugging projects like in ProjectMaker, CodeCreator is used to write, edit, and debug code written in C# or PHP.

CodeCreator is available to all users via the Start menu or in the main program folder.

You can find video tutorials on YouTube at these [links](https://www.youtube.com/watch?v=k_DRWhsBcx8 "https://www.youtube.com/watch?v=k_DRWhsBcx8") and [here](https://www.youtube.com/watch?v=tpF3bKE2pFA "https://www.youtube.com/watch?v=tpF3bKE2pFA").
