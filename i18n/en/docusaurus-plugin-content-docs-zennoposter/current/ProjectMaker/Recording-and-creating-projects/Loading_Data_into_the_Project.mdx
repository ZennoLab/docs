# Loading Data into the Project

There are several ways to obtain data for use in your project:

- [❗→ Lists](/wiki/spaces/RU/pages/534020137 "/wiki/spaces/RU/pages/534020137") - mainly used to retrieve line-by-line data from a text document (such as a list of emails, article headlines, etc.).
- Simple [❗→ Tables](/wiki/spaces/RU/pages/534315019 "/wiki/spaces/RU/pages/534315019") and [❗→ Google Sheets](https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google- "https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google-") - used for obtaining more complexly structured data (for example, a list of products for an online store, where each line contains different data: name, price, description, etc.).
- [❗→ Files](/wiki/spaces/RU/pages/486309948 "/wiki/spaces/RU/pages/486309948") - when you need to upload the entire contents of a file into your project at once for further processing.
- [❗→ Databases](/wiki/spaces/RU/pages/486473806 "/wiki/spaces/RU/pages/486473806") - allow you to store large amounts of data with complex structures and relationships. Databases can be stored locally or remotely.
- [❗→ Input Settings](/wiki/spaces/RU/pages/492339208 "/wiki/spaces/RU/pages/492339208") and [❗→ Bot Interface (BotUI)](/wiki/spaces/RU/pages/725352539 "/wiki/spaces/RU/pages/725352539") - these methods are used when you need to set basic project settings: specify paths to required files, choose operation mode, select a captcha service, and other necessary options.
