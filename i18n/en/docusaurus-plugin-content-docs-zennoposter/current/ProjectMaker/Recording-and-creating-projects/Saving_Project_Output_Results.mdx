If, after the project has finished running, you need to save certain data, you can use the same tools as for [❗→ loading data](https://zennolab.atlassian.net/wiki/spaces/RU/pages/483426328/1 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/483426328/1"): [❗→ lists](/wiki/spaces/RU/pages/534020137 "/wiki/spaces/RU/pages/534020137"), [❗→ files](/wiki/spaces/RU/pages/486309948 "/wiki/spaces/RU/pages/486309948"), [❗→ tables](/wiki/spaces/RU/pages/534315019 "/wiki/spaces/RU/pages/534315019"), [❗→ Google Sheets](https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google- "https://zennolab.atlassian.net/wiki/spaces/RU/pages/509411347/Google-"), [❗→ databases](/wiki/spaces/RU/pages/486473806 "/wiki/spaces/RU/pages/486473806").

For example, let's say you've created a template for registration on a website. You used profile variables for the username and password: `{ -Profile.Login- }` and `{ -Profile.Password- }`.

To save this data, you can use one of the following actions: [❗→ List Operations -&gt; Add Row](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534085798#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D1%83 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534085798#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D1%83"), [❗→ Table Operations -&gt; Add Row](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534052972#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D1%83 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534052972#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D1%83") or [❗→ Files -&gt; Write](https://zennolab.atlassian.net/wiki/spaces/RU/pages/486309948#%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BA%D1%81%D1%82 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/486309948#%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BA%D1%81%D1%82"). And in the "value" field, you add these variables with whatever delimiter you need.

If, for some reason, your project ends with an error (which often happens when using low-quality proxies), you can still save the necessary data that was grabbed during the project's execution (for example, an email address from a list), by using [❗→ Bad end](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534020265/Bad+End "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534020265/Bad+End").
