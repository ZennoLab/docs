## Description
Allows you to click an element using visual search. We recommend using it when you cannot find the element by other means. It is also suitable for Flash and [Canvas](https://developer.mozilla.org/ru/docs/Web/API/Canvas_API).

:::warning Uses a lot of computer resources
:::

![image-20200813-211635](./assets/Image_Search/Image_Search_pic1.png)

### How to add to your project?
Hover your mouse over the element and right-click to open the context menu:

![image-20200813-211831](./assets/Image_Search/Image_Search_pic2.png)

_______________________________________________ 
## How it works

![image-20200814-180030](./assets/Image_Search/Image_Search_pic3.png)

1. **Adjustable search area** — select a unique part of the element that distinguishes it from the others.
2. **Click target** — sets the click location inside the search area and can be moved.
3. **Match accuracy** — specify, as a percentage, how closely the element must match the sample.
4. **Search** — search in the browser window.

:::info The element found will be highlighted with a red frame

![image-20210613-082930](./assets/Image_Search/Image_Search_pic4.png)
:::

5. **Yes** — confirm that the element found meets your criteria.

6. **No** — reject the result to change the search parameters.

### Click settings
These apply to the successfully found element.

![image-20200814-180412](./assets/Image_Search/Image_Search_pic5.png)

1. Choose the **Click type**:
    - *Left click* — a regular left mouse button click;
    - *Right click* — a right mouse button click on the element;
    - *Double click* — a double left mouse button click;
    - *Drag event* — an event that occurs while the object is being **dragged**;
    - *Drop event* — an event that occurs when the object is **released** in a valid area.
2. Test the click in the browser window.
3. Add the configured action to your project.

## Example usage
### Search example
Suppose you need to find a particular button to click on a page:  

![image-20200814-180819](./assets/Image_Search/Image_Search_pic6.png)

Open image search in the browser window and specify a unique area:


| Unique area | Contains a lot of uniform color |
| -------- | ------- |
| ![image-20200814-181437](./assets/Image_Search/Image_Search_pic7.png) | ![image-20200814-181200](./assets/Image_Search/Image_Search_pic8.png) |

Now choose the click type (**Left click** in this example) and test it in the browser window: 

![image-20200814-181604](./assets/Image_Search/Image_Search_pic9.png)

The click succeeded, so add the action to the project canvas:

![image-20200814-181704](./assets/Image_Search/Image_Search_pic10.png)

  
### Project example
This feature can be useful in Flash games or applications where you cannot access individual elements. The workflow is as follows:

![image-20200814-182208](./assets/Image_Search/Image_Search_pic12.png)

1. Go to the page and wait for it to fully load.
2. Hover your mouse over the element, open the context menu, and select **Image Search**.
3. Specify a unique search area and the click parameters.
4. Test in the browser window.
5. Add the action to your project.
