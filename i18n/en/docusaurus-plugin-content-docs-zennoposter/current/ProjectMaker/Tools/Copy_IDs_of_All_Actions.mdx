## Description

This feature allows you to get comments and IDs for all actions in a project.

  

## How does it work?

![image-20210920-044532](./assets/Copy_IDs_of_All_Actions/Copy_IDs_of_All_Actions_pic1.png)



Simply click the "Copy IDs of All Actions" item in the “File” menu. The data will be automatically copied to your clipboard, after which you can paste it into any text editor.

  

## Data Format

Information for each action will be placed on a new line.
First comes the *action comment*, then, separated by a tab character, the action ID.
