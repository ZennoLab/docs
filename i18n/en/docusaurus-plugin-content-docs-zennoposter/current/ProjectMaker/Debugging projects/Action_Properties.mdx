## Description
While editing and debugging your project, you can modify any previously recorded action parameters. 

### How to open the window? {#how-to-open-the-window}
This depends on the display mode of the open project:

#### Without browser
Double-click an action to open its properties window. In this mode, you can open properties windows for several actions at once.

![image-20210221-164336](./assets/Action_Properties/Action_Properties_pic2.png)

#### With browser
Enable the window via **Window → Action Properties**. The window that appears displays the settings of the selected action.

![image-20210221-163159](./assets/Action_Properties/Action_Properties_pic1.png)

:::tip Properties windows for several actions at once
This is also possible in this mode.  
Go to **Edit → Settings → Editor**.  
Enable the “Open multiple action settings” option.
:::

| “With browser” mode | “Without browser” mode |
| -------- | ------- |
| ![image-20210221-163324](./assets/Action_Properties/Action_Properties_pic3.png) | ![image-20210221-163606](./assets/Action_Properties/Action_Properties_pic4.png) |

## The “Completed” Button
If you encounter an error while debugging an action, you can change its parameters in real time:

![image-20210221-165031](./assets/Action_Properties/Action_Properties_pic5.png)

Once you activate this feature, [variables](https://zennolab.atlassian.net/wiki/spaces/RU/pages/735608872 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/735608872") are replaced with their stored values.

:::warning This only works after the action has been executed
:::

## Comment
For easier navigation within your project, you can add a comment to any action:

![image-20210221-165248](./assets/Action_Properties/Action_Properties_pic8.png)

You can then change this text by right-clicking the action and selecting **Comment** from the context menu:

![image-20210221-165428](./assets/Action_Properties/Action_Properties_pic9.png)

## Breakpoint
A breakpoint pauses project execution at the selected action. This is useful for debugging when you need to analyze the contents of variables or the page at a specific point in the project's execution.

There are two ways to enable it: through the context menu or the action properties.

| Context menu | Action properties |
| -------- | ------- |
| ![image-20210222-194754](./assets/Action_Properties/Action_Properties_pic10.png) | ![image-20210222-194929](./assets/Action_Properties/Action_Properties_pic11.png) |

:::info Once enabled, a red circle appears:
![image-20210222-195052](./assets/Action_Properties/Action_Properties_pic12.png)
:::

## Optional
When this option is enabled, the action always follows the successful (green) branch, even if it actually ends with an error.

![image-20210222-195919](./assets/Action_Properties/Action_Properties_pic13.png)

As with breakpoints, you can make an action optional in two ways: through the context menu or the action properties.

![image-20210222-195755](./assets/Action_Properties/Action_Properties_pic14.png)

:::info Once enabled, an arrow appears next to the action:
![image-20210222-200119](./assets/Action_Properties/Action_Properties_pic15.png)
:::
