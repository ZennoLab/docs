## Menu Button Settings
Click this button to open an additional menu where you can choose which tool and section buttons appear at the top of the program. This lets you keep only frequently used features visible.

### Tool Button Settings
Select which tool buttons to display in the top menu.

![image-20200812-120352](./assets/Appearance/Appearance_pic15.png)

Once you select the desired buttons and click **Apply**, they immediately appear on the toolbar:

![image-20200812-120512](./assets/Appearance/Appearance_pic16.png)

### Section Button Settings
Select which sections to display at the very top of the program.

![image-20200812-120552](./assets/Appearance/Appearance_pic17.png)

Once you select the necessary sections, they appear in the main menu:

![image-20200812-120649](./assets/Appearance/Appearance_pic18.png)

### Button Arrangement
You can manually arrange buttons and sections in the order that suits you. To do this, hold down the left mouse button on the desired item and drag it to the position you want.

![1NFJfjUKn7](./assets/Appearance/Appearance_pic19.gif)

With **Reset**, you can return the items in the current settings window to their default positions.  

**Reset All** returns the buttons in both windows to their default arrangements.
