## Profile settings.  
![image-20240112-081209.png](./assets/Profile_PM/Profile_PM_pic1.png) 

Specify the characteristics that will be generated by default when the project starts.  
_______________________________________________
### Default nationality.  
![image-20200812-172201](./assets/Profile_PM/Profile_PM_pic2.png)
   
Nationality for profile generation. You can also change it at the template level in the project profile settings.  
_______________________________________________
### Registration email.  
The *email* specified in this setting will be used for all new profiles.  
You can also change it by remapping fields in **Profile Operations**.  
The value is stored in the `{-Profile.Email-}` environment variable.  

![image-20200812-171924](./assets/Profile_PM/Profile_PM_pic3.png)  
_______________________________________________
### Registration email password.  
This *email password* will be used for all new profiles. You can also change it in  
**Profile Operations**. The value is stored in the `{-Profile.EmailPassword-}` environment variable.
