## Description  
This settings section is used to connect mailboxes that you can then use to [**send emails**](/zennoposter/ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Mail/PM_Editor_Actions_SendMail). 

![image-20211207-054653](./assets/Mail_PM/Mail_PM_pic1.png)
_______________________________________________
## “Add” button
Clicking this button opens a window for adding a new connection.

![Add](./assets/Mail_PM/Mail_PM_pic2.png)


### Service name
A custom name for this account that you choose yourself. It will appear under this name in the list of available accounts, for example, in the [**Send email**](/zennoposter/ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Mail/PM_Editor_Actions_SendMail) action.  

:::warning **This is a required parameter and must be unique within the program**
:::  

### Sender name
This is the name that will appear in the sender field for the recipient.

### Email
The full email address that will be used to send mail.  

:::info **It must be a real address, otherwise the program will display an error**
:::  

### Password
The password for this mailbox.

Some email providers set a special password for connecting third-party programs for security reasons. This is called an **App password**. You can get one in the settings of the selected service.  

### “Sign in to email” button
When clicked, the connection details for the SMTP server will be checked. 

> *The Email-Password combination is not checked.*

If the connection is successful, a green message will appear at the bottom of the window:

![image-20211114-101602](./assets/Mail_PM/Mail_PM_pic3.png)

If the program cannot connect to the server, an error popup will appear:

![image-20211114-102731](./assets/Mail_PM/Mail_PM_pic4.png)

In this case, you need to configure the connection manually. To do this, uncheck the **Detect settings automatically** option.  

### Detect settings automatically  
When this setting is enabled, the program will try to automatically determine the SMTP server connection settings based on the email address you entered.

![image-20211114-104407](./assets/Mail_PM/Mail_PM_pic5.png)

If you get an error after the settings are detected automatically, uncheck the box and enter the settings manually, using the information on your provider's website as a guide.  

### Default
When this option is enabled, the current connection will be used by default in all [Send email](/zennoposter/ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Mail/PM_Editor_Actions_SendMail) blocks, unless specified otherwise.  

### Do not check server certificates
In some cases, you may get this error when connecting an account:  
**`An error occured while attempting to establish an SSL or TLS connection`**.  

This error most often occurs when establishing an unencrypted connection to the mail server. The provider then refuses the connection because the system cannot verify the authenticity of the SSL/TLS certificates.  

There can be various causes. Here are the most common ones:  
- An outdated version of Windows with long-unupdated trusted certificates;  
- Antivirus software that replaces server certificates to decrypt and inspect incoming traffic;  
- An enabled firewall.  

The solution depends on the specific cause. You can update Windows or disable the firewall. If antivirus software is the cause, pay special attention to its incoming traffic and email scanning settings.  

If nothing helps, enable this setting. After that, any certificates sent by the server to establish the connection will not be checked, and the connection will be marked as secure.  

:::warning **If you disable certificate checking, your traffic with the email provider may be intercepted.**
::: 

### “Send test email” button
When clicked, ZennoPoster will try to send an email to your address using the specified SMTP server. This is used to check whether the entered details are valid.  

If the account credentials are correct, the following status will appear: **`Test email sent successfully`**. This means the email service is ready to use in the program.  

If you enter incorrect information, an error will appear: **`Failed to send test email`**. You can see a more detailed description in the window.  

:::tip **Some email providers require you to explicitly enable email access for third-party programs**
You can find the appropriate settings yourself by searching for:  
`smtp настройки подключения <НАЗВАНИЕ_ВАШЕГО_ПРОВЙДЕРА>`
:::

## Additional buttons
### “Edit”
Use this button to edit previously added email accounts

### “Default”
This option lets you change the account that will be used by default

### “Delete”
Removes the selected account from the program settings.
