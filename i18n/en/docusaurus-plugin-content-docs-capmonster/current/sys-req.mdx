## Minimum requirements.
- **Processor:** Intel or AMD with at least 2 cores, no less than 2.2 GHz each.  
- **RAM:** at least 2048 MB.  
- **Storage space:** at least 1024 MB.  
- **Graphics card:** any.  
- **Operating system:** Windows 10 x64 or later (Server Core is not supported).  
- **.NET Framework 4.6.2+ required.**  
- **Visual C++ redistributable 2015–2019 also required.**  
- **Administrator rights.** You will need them to install and run the program.  
- **Internet.** Required. You won’t be able to work without it.  

## Recommended requirements.  
- **Processor:** Intel or AMD with at least 4 cores, no less than 3.1 GHz each.  
- **RAM:** 4 GB.
- **Storage space:** 2048 MB or more.  
- **Graphics card:** Nvidia GeForce with CUDA support.  
- **Operating system:** Windows 10 x64 or later (Server Core is not supported).  
- **.NET Framework 4.6.2+ required.**  
- **Visual C++ redistributable 2015–2019 also required.**  
- **Administrator rights.** You will need them to install and run the program.  
- **Internet.** Required. You won’t be able to work without it.
