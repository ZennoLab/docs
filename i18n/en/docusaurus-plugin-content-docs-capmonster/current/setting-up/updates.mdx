## Description.
We regularly update existing recognition modules and add new ones. To always have an up-to-date module database, you can enable automatic updates.  

![Module update settings](./assets/updates.png)  

### Enable updates.
Enables automatic updates of the module database. All current changes will be available immediately as they appear. 

### Update on program startup.  
When the program starts, it will check for new updates, which will be installed right away.  

### Update while the program is running.
The search for the latest changes will be performed directly while the program is running.   

Here you can also set the **Update interval** in minutes. For example, updates can be checked once an hour or every half hour.  

### Last update.  
The date and time when the last update was performed.  

### Update now.  
You can also update the modules by clicking this button.  

### Open log.
Allows you to view the update log.
