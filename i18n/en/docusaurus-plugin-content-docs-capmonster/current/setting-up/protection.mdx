## Description.
CapMonster supports protection against use by third-party users. To activate it, enable the corresponding option in the program settings.  

![Protection from third-party users](./assets/protection.png)  

When protection is enabled, only authorized users who provide an access key or a login and password will be able to send CAPTCHAs to CapMonster. Keys and passwords are set in a dedicated field.  

**If protection is disabled, any user can send CAPTCHAs.**
