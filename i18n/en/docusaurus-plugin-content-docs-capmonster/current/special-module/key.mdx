## Description.  
**KeyCaptcha** is an example of a non-standard CAPTCHA where, instead of entering characters from an image, the user **needs to assemble a puzzle** by moving its pieces on the screen.  

| This is what it looks like | 
| :--------: | 
| ![Icon](./assets/key.png)  | 

### Solution via ZennoPoster.  
:::info **Solving KeyCaptcha requires an active CapMonster subscription.**
:::

To solve this CAPTCHA in ZennoPoster, add the following code to your project:  
`ZennoPoster.CaptchaSpecialRecognition("keycaptcha.dll", instance);`
