## Описание.
### Новые фичи:  
:zap: Ускорено распознавание ReСaptcha2, уменьшены задержки.  
:zap: Ускорено распознавание других типов каптч, уменьшены задержки.    
:zap: Оптимизирована работа ReCaptchaSiteKeyAddon. Теперь решение заданий стало более быстрым и менее подозрительным для ReCaptcha2.  

:heavy_plus_sign: Добавлена настройка максимального количества процессов, запускаемых для решения ReCaptcha2.  
:heavy_plus_sign: Добавлена настройка максимального количества памяти, которую может потреблять ReCaptchaSiteKeyAddon.  

### Исправленные баги:  
:white_check_mark: Исправлена ошибка, при которой ReCaptchaSiteKeyAddon работал неправильно, когда URL в запросе был неполным.  
:white_check_mark: Исправлена ошибка, при которой ReCaptchaSiteKeyAddon работал неправильно для сайтов, в домене которых были не английские символы.  
:white_check_mark: Исправлена ошибка, при которой баланс не отображался при запросе с удаленного сервера.
