## Описание.
### Новые фичи:  
:zap: Ускорено распознавание ReСaptcha2.  
:zap: ReCaptchaSiteKeyAddon потребляет меньше ресурсов.    
:zap: Реализована одиночная отправка картинок в динамической ReCaptcha2, для быстрого распознавания.  

:heavy_plus_sign: В настройках CapMonster можно указать прокси, через которые будет работать ReCaptchaSiteKeyAddon.  
:heavy_plus_sign: Улучшена поддержка ReCaptcha2 на польском, французском и немецком языках.  
:heavy_plus_sign: Улучшено распознавание других типов каптч.

### Исправленные баги:  
:white_check_mark: Исправлена работа распознавания ReCaptcha2 sitekey на конкретных сайтах.
