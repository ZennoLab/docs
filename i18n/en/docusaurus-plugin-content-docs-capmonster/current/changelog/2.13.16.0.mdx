## Description.
### New features:  
:zap: Added support for uploading files via the RuCaptcha API using multipart in base64.  
:zap: Added support for returning cookies after solving ReCaptcha (via the Anti-Captcha API).    
:zap: CEF engine updated to version 107.      

### Fixed bugs:  
:white_check_mark: Changed the image resize algorithm for the universal module, which improved the recognition accuracy of small-sized captchas.    
:white_check_mark: The RuCaptcha API now takes into account all URL-encoded parameters that come after action.
