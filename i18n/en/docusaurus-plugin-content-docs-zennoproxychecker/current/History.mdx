<details>
<summary>***ZennoProxyChecker 3.1.0.0***</summary>

 > New features:
 > + Added the ability to delete default rules. You can restore them if needed.
 > + Added a source setting for immediate removal of proxies from the live list after a failed check.
 > + Added [login] and [password] macros to proxy distribution, which return the proxy login and password respectively. Also added the [auth] macro, which returns a string in the format login:password@ if authentication is required, and an empty string if authentication is not required. The default format in distribution tasks has been changed to [auth][ip]:[port].
 > + Added automatic GeoIP database updates.
 > + Added “Parse RSS text” and “Parse RSS links” flags to proxy source settings. When the first flag is enabled, proxies are searched not only in the source text but also in the RSS feed text, if available. When the second flag is enabled and an RSS feed is available, all links from it are parsed and processed the same way as automatically added resources, meaning only those containing proxies appear in the source list. New sources are marked with the “RSS” tag.
 > + Added the “Add local network addresses” flag to proxy source settings.
 > + Added the ability to use the `{-TimeNow.Date[Date format]-}` macro in the source address field, similar to its usage in ZennoPoster.
 > + Added the “Consider non-anonymous proxies as dead” setting to ProxyChecker.
 
 > Bug fixes:
 > + Fixed opening the proxy list for an anonymous source in ProxyChecker.
 > + Fixed calculation of the next proxy check time after being taken from the live list.
 > + Fixed the regular expression for parsing proxies with authentication. This resolved the issue where the first proxy in the list was skipped if it had authentication.
 > + Fixed working with proxy source groups.
</details>
