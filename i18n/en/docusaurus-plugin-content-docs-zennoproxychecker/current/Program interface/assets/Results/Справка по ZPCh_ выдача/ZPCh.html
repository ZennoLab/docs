Выдача

Описание

Во вкладке Выдача вы можете настроить выгрузку прокси в файл, на локальный сервер или на FTP.

Панель управления

Новая задача

Кнопка Новая позволяет создать новое правило для выгрузки прокси. После клика открывается окно, где нужно выбрать, куда вы хотите выгрузить прокси.

Выдача на жёсткий диск — выдаёт данные на жёсткий диск вашего компьютера.
Выдача на localhost — выдаёт данные на локальный сервер.
Выдача на ftp — выдаёт данные на ftp-сервер.

Ниже каждый тип будет описан более подробно.

Изменить

Эта кнопка позволяет редактировать уже существующий сценарий выгрузки.
Сначала нужно выделить желаемый сценарий, а затем нажать Изменить.

Удалить

Удаление выделенного сценария.

Выдача на жёсткий диск

После нажатия на кнопку Выдача на жесткий диск у вас откроется окно с настройками выдачи на жёсткий диск вашего устройства.

Название — здесь укажите название задачи.

Правило — тут нужно выбрать правило для фильтрации прокси. Подробнее о настройке правил здесь.

Если оставить строку Правило пустой, то в список будут сохраняться все живые прокси.

Путь к файлу — путь к файлу, в который будут сохраняться прокси.
Для выбора места сохранения нажмите кнопку с 3 точками.

Дописывать — если поставить галочку, то в файл будут дописываться новые прокси по мере парсинга.
Если эта опция будет выключена, то файл будет перезаписываться.

Формат записи — выберите необходимый формат, в котором прокси будут записаны в файл.
По умолчанию стоит формат [auth][ip]:[port].

Справка по формату:

[ip] — IP-адрес

[port] — Порт

[real_ip] — Реальный IP

[type] — Тип прокси

[white_list] — Содержание в чёрных списках. (true — не содержится)

[time_check] — Время проверки

[latency] — Задержка прокси

[time_now] — Текущее время

[country] — Страна

[country_code] — Код страны

[login] — Логин

Интервал (мин.) — как часто будут выгружаться прокси (в минутах).

Количество — количество выгружаемых прокси (от нуля до бесконечности).

С удалением — надо ли убирать прокси из списка живых после взятия.

Произвольные — если выбрано, то берутся случайные прокси, иначе — первые из списка.

Выдача на localhost

При выборе этого режима будет запущен локальный WEB-сервер и, перейдя по ссылке из поля Адрес, можно будет получить прокси.

Название — укажите название задачи.

Правило — выберите правило для фильтрации прокси. Подробнее о настройке правил здесь.

Если оставить строку Правило пустой, то в список будут сохраняться все живые прокси.

Формат записи — выберите необходимый формат, в котором прокси будут выгружены.
По умолчанию стоит формат [auth][ip]:[port].

Справка по формату:

[ip] — IP-адрес

[port] — Порт

[real_ip] — Реальный IP

[type] — Тип прокси

[white_list] — Содержание в чёрных списках. (true — не содержится)

[time_check] — Время проверки

[latency] — Задержка прокси

[time_now] — Текущее время

[country] — Страна

[country_code] — Код страны

[login] — Логин

Количество — количество выдаваемых прокси (от нуля до бесконечности).

С удалением — надо ли удалять прокси из списка живых после взятия.

Адрес — URL, по которому будут выдаваться прокси (генерируется автоматически на основе выбранного Правила).

Произвольные — если выбрано, то при каждом запросе будут возвращаться случайные прокси, иначе — первые из списка.

Настройки FTP-сервера

Сервер — Адрес сервера
Порт — Порт сервера
Протокол — Протокол сервера (FTP или FTPs)
Путь — Путь к файлу на сервере
Логин — Логин сервера
Пароль — Пароль сервера
Тест соединения — показывает результат теста (успешное соединение или ошибка)

Список сценариев

После того как вы настроили сценарий и нажали ОК, он будет добавлен в общий список, где будет отображена вся доступная по нему информация.

Обратите внимание на статус Последнее выполнение. Возможные состояния:
Зелёный — при последнем выполнении задачи был выдан хотя бы 1 прокси.
Красный — при последнем выполнении не было взято ни одного прокси.
