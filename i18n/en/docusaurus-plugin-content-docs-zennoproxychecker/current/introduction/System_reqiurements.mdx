## **Minimum Requirements:**

 - **Processor**: Intel or AMD, at least 1.5 GHz;
 - **RAM**: at least 1024 MB;
 - **Operating System**: Windows 10 x64 or later (Server Core is not supported);
 - [**.Net Framework 4.6.2 or higher;**](https://zennolab.com/discussion/threads/ustanovka-microsoft-net-framework-i-visual-c-redistributables.54092/)
 - [**Visual C++ redistributable 2008, 2010, 2013, 2017;**](https://zennolab.com/discussion/threads/ustanovka-microsoft-net-framework-i-visual-c-redistributables.54092/)
 - **Administrator rights** to install and run the program;
 - **Internet**: required.


## **Recommended Requirements:**

 - **Processor**: Multi-core Intel or AMD processor;
 - **RAM**: 4 GB;
 - **Operating System**: Windows 10 x64 or later;
 - [**.Net Framework 4.6.2 or higher;**](https://zennolab.com/discussion/threads/ustanovka-microsoft-net-framework-i-visual-c-redistributables.54092/)
 - [**Visual C++ redistributable 2008, 2010, 2013, 2017;**](https://zennolab.com/discussion/threads/ustanovka-microsoft-net-framework-i-visual-c-redistributables.54092/)
 - **DirectX 9+;**
 - **Administrator rights** to install and run the program;
 - **Internet**: required.
