## **Description**

**ZennoProxyChecker** is a software product designed for loading proxies, storing them, automatically re-checking them, and providing them in various ways according to flexible criteria.

**ZennoProxyChecker** allows you to: 

 - Store proxy sources and work with them conveniently; 
 - Load new proxies into storage from sources at a specified interval; 
 - Set filters for all sources and for each one individually; 
 - Flexibly configure proxy checking for each source; 
 - Provide verified proxies in different ways and according to specific rules.

## **Key Features**

**Adding Proxies**

Proxies can be added in various ways: either manually by directly pasting proxy addresses, or automatically, when the program itself searches for and collects (parses) proxy addresses from web pages or local files with proxy lists.

**Checking**

ProxyChecker can check proxies using about 20 parameters, filtering out unsafe ones and selecting the best and fastest. In addition, the program allows you to check proxies against a specific URL, selecting proxies suitable for working with the required web resources.

**Providing**

The program allows you to configure multiple proxy distribution channels so that different templates receive proxies with different parameters. Proxy lists can also be saved to local files and published to network resources, providing fresh proxies at a specified interval.
