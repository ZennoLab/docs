1. Register on the website: https://www.maxmind.com/en/account/login

2. Go to the Downloads section:

![Geo_ru.png](..\GeoIP\assets\Geo_ru.png)

3. Download the GeoLite2 City database:

![Geo2_ru.png](..\GeoIP\assets\Geo2_ru.png)

4. Extract the archive and place the GeoLite2-City.mmdb file into the folder:
 - for ZennoPoster C:\Users\{имя_пользователя}\AppData\Roaming\ZennoLab\ZennoPoster\7\Data\ 
 - for ProxyChecker  C:\Users\{имя_пользователя}\AppData\Roaming\ZennoLab\ProxyChecker\3\Data\
 - for ZennoDroid C:\Users\{имя_пользователя}\AppData\Roaming\ZennoLab\ZennoDroid\2\Data\


5. Set the GeoLite2-City.mmdb file to read-only:

![Geo3_ru.png](..\GeoIP\assets\Geo3_ru.png)
