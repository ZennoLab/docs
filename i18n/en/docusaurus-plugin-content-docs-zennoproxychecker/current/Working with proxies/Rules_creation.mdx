## **Why are rules needed?**


Rules are a set of conditions that allow you to select proxies from the list of “live” proxies. In other words, rules are applied to proxies that have already passed the check. You can use rules to configure proxy output according to various criteria. For example, you may need only anonymous or elite proxies, with maximum speed and minimal latency, not banned in Google or Twitter, only Russian proxies for working with Russian social networks, etc. 

Read more about setting up rules [here](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Rules).
