## Описание

Данный экшен служит для работы с директориями: 

- создание
- копирование
- перемещение
- удаление
- получение одного или нескольких файлов
- проверка существования Directories

## Как добавить действие в проект?

Через контекстное меню **Добавить действие** → **Данные** → **Directories**

![image-20200811-061128](./assets/Directories/Directories_pic1.png)



Либо воспользуйтесь [❗→ умным поиском](https://zennolab.atlassian.net/wiki/spaces/RU/pages/506200090/ProjectMaker+7#%D0%A3%D0%BC%D0%BD%D1%8B%D0%B9-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA-%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B9 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/506200090/ProjectMaker+7#%D0%A3%D0%BC%D0%BD%D1%8B%D0%B9-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA-%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B9").

## Где можно применить экшен?

- Получение файла из Directories (как по порядку так и случайного):

 - файл со статьёй для постинга в блог
 - картинка для аватара при регистрации на форуме
- При парсинге можно создавать для каждого товара свою директорию куда сохранять картинки, описание и другую нужную информацию

## Пример использования

Часто при регистрации на различных ресурсах необходимо загрузить аватарку. Представим, что у Вас есть директория с подготовленными картинками, внутри которой Files с различными расширениями (jpg, jpeg, png, tiff и др.) и нам надо выбрать один. Ресурс, на котором, надо зарегистрироваться требует, чтобы загружаемые Files были только в формате PNG. Для этой задачи воспользуемся действием *Путь к файлу и выбором случайного пути файла. Чтобы выбрать только PNG Files воспользуемся маской `*.png`

![image-20200811-062126](./assets/Directories/Directories_pic11.png)


 
> `{-Project.Directory-}` - это системная переменная ProjectMaker в которой хранится полный путь к папке, в которой находится файл шаблона.

 После запуска данного кубика в переменной *avatar будет находится абсолютный путь к файлу.

  

## Поиск по маске

При поиске по маске можно использовать специальные символы:

- ? - любой один символ кроме точки
- \ - любое количество любых символов
- | - данный символ использует когда нужно применить одновременно несколько масок (работает только с файлами)

<details>
<summary>Примеры</summary>

| **Маска** | **Описание** |
| --- | --- |
|`*.*` | Любые Files с любым расширением |
| `*.jpg` | Files с расширением `.jpg`:<br/>• image.jpg<br/>• аватарка.jpg<br/>• 1.jpg |
| `*.p*` | Files у которых расширение начинается на `p`:<br/>• document.pdf<br/>• презентация.ppt<br/>• документ.project<br/>• 1.p |
| `кар*.*` | Files с любым расширением, но имя которых начинается на `кар`:<br/>• карета.jpg<br/>• картинка.ico<br/>• картошка.html |
| `*mat?.html` | `.html` Files имя которых начинается с любой последовательности символов, затем идёт часть `mat` после которой один символ:<br/>• automate.html<br/>• tomato.html<br/>• mate.html |
| `doc?????.xls` | `.xls` файл начинающиеся на `doc` после чего идёт 5 любых символов (кроме точки):<br/>• document.xls<br/>• doc-1208.xls<br/>• doctrine.xls |
| `???.??` | Файл с тремя символами в имени и двумя в расширении:<br/>• abc.ps<br/>• job.ai<br/>• 123.45 |
| `?????` | Файл с пятью символами в имени и без расширения:<br/>• house<br/>• image<br/>• tasks |
| `*.xlsx \| *.docx` | Любой xlsx и/или docx документ:<br/>• invoice.docx<br/>• resume.docx<br/>• project.xlsx<br/>• default.xlsx |

</details>
