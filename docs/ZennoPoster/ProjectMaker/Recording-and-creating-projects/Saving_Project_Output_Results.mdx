## Описание
Если по завершению работы проекта вам нужно сохранить те или иные данные, то используйте те же инструменты, что и для их **Загрузки**:  
- [**Списки**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Lists/List_Operations)  
- [**Простые таблицы**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Tables)  
- [**Google таблицы**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Google_Sheets)  
- [**Файлы**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Files)  
- [**Базы данных**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Databases)

Представим, что вы создали шаблон для регистрации на сайте. Использовали при этом переменные профиля для логина и пароля: `{ -Profile.Login- }` и `{ -Profile.Password- }`.

Тогда для сохранения этих данных используйте один из перечисленных ранее экшенов. А в поле **значение** добавьте нужные переменные с подходящим разделителем.

Если проект по какой-то причине выполняется с ошибкой (такое, например, бывает при использовании некачественных прокси), тогда вы можете сохранить необходимые данные (взятые во время работы проекта) через экшен [**Bad end**](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Logic/BadEnd_Exit_on_Error).
