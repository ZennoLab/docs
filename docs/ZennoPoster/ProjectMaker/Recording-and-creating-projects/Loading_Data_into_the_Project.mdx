## Описание
Существует несколько способов получения данных для использования в проекте:

#### [Списки](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Lists/List_Operations)  
Используются преимущественно для получения построчно данных из текстового документа (например, список e-mail, заголовков для статей и пр.).  

#### [Простые таблицы](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Tables) и [Google таблицы](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Google_Sheets)  
Нужны для получения более сложно организованных данных (например, список товаров для интернет-магазина, где построчно представлены разные данные: название, цена, описание и пр.).

#### [Файлы](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Files) 
Пригодятся для загрузки в проект сразу всего содержимого файла для дальнейшей работы с ним.  

#### [Базы данных](../Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Databases)  
Позволяют хранить большие массивы данных со сложной структурой и связями. Они могут находиться как локально так и удалённо.  

#### [Входные настройки](../Project-editor/Static_blocks/Project_Input_Settings) и [Интерфейс бота (BotUI)](../Project-editor/Static_blocks/Bot_Interface)  
Данные способы подходят для задания базовых настроек проекта:  
- указать пути к необходимым файлам,  
- задать режим работы,  
- выбрать капча-сервис,  
- другие необходимые настройки.
