# Регулировка пула потоков процессов Chrome

:::warning Внимание
Внимание! Данные настройки предназначены для опытных пользователей, т.к. могут также и ухудшить ситуацию. Проверяйте на каждой машине индивидуально.
:::

:::info Информация
Данная статья может помочь вам оптимизировать производительность браузеров. Например, если ваша система начинает тормозить когда ресурсы компьютера еще не исчерпаны, возможно причина в большом количестве потоков. С помощью настроек, описанных в данной статье, можно несколько уменьшить количество потоков для процессов браузера.
:::

Браузер Chrome имеет множество вспомогательных процессов, необходимых для его работы. Вспомогательные процессы разделяются на несколько типов, таких как: рендеры табов, gpu процессы, network процессы и другие. Для процессов рендеров есть возможность регулировать пулы потоков с помощью аргументов командной строки:

**--num-raster-threads=N** - значение по умолчанию равно 4. Устанавливает количество потоков используемых для растеризации в процессе-рендерере.
**--zl-renderer-thread-pool=N** - значение по умолчанию: число логических процессоров минус 1. Задаёт максимальный размер пула потоков в процессе-рендерере (Доступно в версии ZennoPoster Выше 7.4.0.0).

Для уменьшения количества потоков попробуйте:

```csharp
--num-raster-threads=1 --zl-renderer-thread-pool=1
```
