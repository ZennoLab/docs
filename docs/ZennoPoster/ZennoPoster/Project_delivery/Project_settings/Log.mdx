# Лог

![Лог](./assets/Log/Log_pic1.png)



На вкладке **Лог** записываются уведомления о ходе выполнения проекта: ошибки, отметки об успешном / неуспешном выполнении проекта.

С помощью кнопок в правой части вкладки Вы можете очистить лог, включить автоматическую прокрутку, фильтровать сообщения по типу и/или цвету.

:::info Информация
Более подробно о работе с этим окном Вы можете прочитать в статье [❗→ Окно лога](https://zennolab.atlassian.net/wiki/spaces/RU/pages/725352532).
:::
