# ZennoPoster 7.8.11.0 (08.10.2025)

**Добавлено:**

[+] Для браузеров Chromium в интеграции с ZennoBrowser разблокирована возможность изменять размер через метод instance.SetWindowSize.

[+] Улучшена подсветка результатов поиcка в действиях C#, инструменте регулярных выражений, просмотре Dom, Text, Source страницы. Так же включена подсветка всех входящих в текст результатов поиска.

**Исправлено:**

[\] Исправлено удаление cookie в форме Текущий профиль->Cookies.

[\] Исправлено изменение размеров настроек действий в некоторых стилях ProjectMaker.

[\] Убраны неактивные скролы текстовых полей в настройках действий.
