# ZennoPoster 7.7.6.0 (25.08.2023)

**Новые фичи:**

[+] Браузер Chromium обновлен до версии 115.

**Исправленные баги:**

[\] Добавлено ограничение на количество запросов в мониторе трафика для браузера Chromium. Тем самым исправлена утечка памяти при работе c Chromium.

[\] Исправлен вылет ProjectMaker при открытии настроек кубиков в Windows 11 и открытии окна профиля.

[\] Исправлена работа ZennoPoster на многопроцессорных системах. Ранее ZennoPoster учитывал только один процессор в системе.

[\] Исправлена работа Metamask в браузере Chromium.

[\] Исправлена эмуляция мыши в Chromium при размерах браузера больше размеров экрана.
