# ZennoPoster 7.7.13.0 (11.04.2024)

**Новые фичи:**

[+] Браузер Chromium обновлен до 123 версии.

**Исправленные баги:**

[\] Исправлено зависание статуса загрузки страницы в Chromium.
[\] Исправлена работа СМС-сервисов.
[\] Исправлена установка значения "gzip, deflate, br" в заголовок AcceptEncoding браузера CEF.
[\] Исправлена проблема с декодированием страниц в браузере CEF, теперь алгоритм zstd принудительно исключается из AcceptEncoding, т.к. браузер его не поддерживает.
[\] Исправлено отображение установленного прокси в ProjectMaker для браузера CEF.
[\] Исправлено отображение таймаута загрузки страниц в ProjectMaker для браузера Chromium.
[\] Исправлен перезапуск браузера в ProjectMaker по нажатию кнопки "С начала", в случае если запущенный браузер использовал профиль папку, а открытый проект не использует браузер вовсе.
