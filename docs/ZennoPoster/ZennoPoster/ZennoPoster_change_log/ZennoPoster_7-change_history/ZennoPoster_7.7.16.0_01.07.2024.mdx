# ZennoPoster 7.7.16.0 (01.07.2024)

**Новые фичи:**

[+] Браузер Chromium обновлен до 126 версии.

[+] Для браузера Chromium в режим ожидания действий пользователя в ZennoPoster добавлено выпадающее меню с установленными расширениями. При клике на опцию меню откроется окно выбранного расширения.

[+] Снижено количество сервисных запросов, которые создаются ZennoPoster и браузерными процессами Chromium.

[+] В настройки смс-сервисов добавлен режим "operAndCountryMode".
В кубике "Смс-сервисы" для настройки оператора и страны используется одно поле, внутри обработчиков для этого поля выбран один из режимов, возможные значения: *OnlyOper, OnlyCountry, OperAndCountry, Nothing.
Теперь для сервисов SmsActivate, FiveSms, GetSmsOnline, SmsHub, VakSms, VirtualSms можно переопределить режим обработки этого поля через конфиг в %appdata%\ZennoLab\Configs .
Пример заполненной строки: &lt;add key="operAndCountryMode" value="OperAndCountry" /&gt;
Для режима "OperAndCountry" используется формат *country [operator], т.е. сначала задается страна и потом необязательный параметр "оператор", который указывается через пробел после "страны".

**Исправленные баги:**

[\] Повышена стабильность работы кубика "Navigate" в браузере Chromium при навигации внутри страницы.

[\] Повышена стабильность работы проектов в ZennoPoster.

[\] Исправлены многие причины возникновения ошибок получения cookie браузера Chromium и других ошибок обращения к инстансу.

[\] Повышена стабильность работы кубика "Активировать расширение".

[\] Улучшено отображение меню в devtools окна браузера Chromium.

[\] Теперь в браузере Chromium при выполнении "Navigate" открытый popup расширения закрывается.

[\] Исправлено значительное уменьшение размера окна браузера при его открытии в ZennoPoster или при создании новой вкладки в уже открытом окне браузера.

[\] Кнопки "Сохранить", "Восстановить", "Сбросить настройки", которые находятся в "Настройки -&gt; Другое", работают корректно.
