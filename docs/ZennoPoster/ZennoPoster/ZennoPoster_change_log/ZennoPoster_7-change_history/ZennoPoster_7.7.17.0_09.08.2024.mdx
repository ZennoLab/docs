# ZennoPoster 7.7.17.0 (09.08.2024)

**Новые фичи:**

[+] Браузер Chromium обновлен до 127 версии.

[+] Улучшена эмуляция screen координат при эмулировании событий мыши для Chromium.

[+] Обновлен поиск источников прокси в ProxyChecker, теперь автопоиск будет искать прокси с хостами в виде IP, как и ранее. Для вручную добавленных источников ProxyChecker будет искать прокси с любыми видами хостов.

**Исправленные баги:**

[\] Исправлено отображение devtools окна для браузера Chromium.

[\] Исправлено разгадывание ReCaptcha2 через CapMonster2 во вкладке.
