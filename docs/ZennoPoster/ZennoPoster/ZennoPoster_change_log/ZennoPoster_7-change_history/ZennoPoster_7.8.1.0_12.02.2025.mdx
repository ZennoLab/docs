# ZennoPoster 7.8.1.0 (12.02.2025)

**Добавлено:**

[+] Браузер Chromium обновлен до 132 версии.

[+] Теперь при падении браузера в ProjectMaker кнопка "Запустить браузер заново" запускает последний запущенный браузер, а не браузер из настроек текущего проекта.

**Исправлено:**

[\] Исправлена работа автопоиска источников, теперь поиск источников выполняется с использованием браузера. Также улучшен процесс проверки прокси, теперь ProxyChecker находит гораздо большее количество прокси.

[\] Исправлена косметическая проблема в ZennoPoster, при которой URL страницы одного браузера отображался в окне другого браузера.

[\] Теперь в ProjectMaker, когда в строке адреса браузера установлен фокус, значение не меняется и не мешает вам писать новый адрес.

[\] Исправлено зависание ProjectMaker при перезапуске браузера после нажатия кнопки "С начала".

[\] Исправлено сбрасывание выделенной категории в ZennoPoster в некоторых случаях.
