# ZennoPoster 7.6.0.0 (25.11.2021)

**Новые фичи:**

[+] Добавлена поддержка расширений для движка Chromium.

[+] В ProjectMaker добавлено уведомление, что расширения есть только в Chromium: «Работа с расширениями браузера доступна для браузера Chromium. Для смены типа браузера откройте Настройки проекта → Тип браузера».

[+] В ProjectMaker добавлен экшен «Эмуляция движения мыши» , в котором достаточно задать время от-до и в течение этого времени проект будет совершать человекоподобные движения мышью и скроллы по текущей загруженной странице.

[+] В ProjectMaker добавлен экшен «Отправить почту» , для отправки уведомления с Вашего почтового сервиса на любой адрес электронной почты, используя SMTP сервер.

[+] В ProjectMaker для движка Chromium добавлено окно Трафик.

[+] В Chromium появилась поддержка функции Политика содержимого.

[+] В ProjectMaker оптимизировано расположение кнопок в меню окна браузера.

[+] Улучшение анонимности в Chromium.

[+] Добавлена возможность подмены содержимого запросов и ответов: ChangeRequest и ChangeResponse для движка Chromium.

[+] В ProjectMaker для статического блока Добавить Google таблицу введён чекбокс "Запоминать закреплённые строки и столбцы". При загрузке таблицы будет выполнен дополнительный запрос на получение закреплённых столбцов и строк. Дополнительный запрос расходует лимит запросов аккаунта.

[+] Добавлено извлечение статьи (Article Extraction) для движка Chromium.

**Исправленные баги:**

[\] Устаранена ошибка, при которой не открывались настройки экшена "Отправить почту".

[\] Устранена ошибка, при которой в ProjectMaker забирался фокус при обновлении Дерева элементов.

[\] Исправлено распознавание hCaptcha на сайте http://bakecaincontrii.com

[\] Устранена ошибка, при которой в ProjectMaker у движка Chromium обрезалось отображение браузера при масштабе экрана 150%.

[\] Устранена ошибка, при которой экшен Swipe переставал работать и отображение курсора при свайпе ускорялось.

[\] Устранена ошибка, при которой в ProjectMaker после запуска проекта "С начала" ресайзы браузера Chromium переставали работать.

[\] Устранена ошибка, при которой у движка Chromium на десктопном профиле браузера отображается маленький размер видимой области.

[\] Устранена ошибка, при которой в ProjectMaker происходило выделение экшенов вместо перемещения после перемещения по проекту с помощью пробела и мыши.

[\] Устранена ошибка, при которой некорректно работал экшен получения скриншота всего инстанса на движке Chromium.

[\] Устранена ошибка, при которой мог зависать ProjectMaker при работе через RDP.

[\] Устранена ошибка, при которой в ProjectMaker не нажималась кнопка "Закончить" при обработке почты.

[\] Устранена ошибка, при которой очистка кеша на движке CEF после установки прокси формата socks5://username:password@ip:port приводила к их сбросу и прямому трафику с реального IP.

[\] Исправлена проблема открытия диалога выбора файла в CEF при ожидании действий пользователя.

[\] Устранена ошибка, при которой не синхронизировалась Google Таблица с 1000+ строками и включенной опцией "Первая строка - заголовки".
