# ZennoPoster 7.7.11.0 (19.02.2024)

**Новые фичи:**

[+] Браузер Chromium обновлен до версии 121.
[+] Теперь ZennoPoster показывает отдельно свободную физическую и отдельно свободную выделенную память в системе в полоске мониторинга ресурсов.
[+] Обновлены ссылки на системные библиотеки.

**Исправленные баги:**

[\] Устранена проблема медленной загрузки, при которой отображались пустые страницы в браузере Chromium.
[\] Исправлена эмуляция WebRtc в Chromium.
[\] Доработаны эмуляции для работы с Cloudflare.
[\] Исправлено применение размеров браузера Chromium в ProjectMaker после нажатия кнопки «С начала».
