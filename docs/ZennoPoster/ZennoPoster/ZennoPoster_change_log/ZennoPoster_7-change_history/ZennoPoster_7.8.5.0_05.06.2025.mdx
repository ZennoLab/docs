# ZennoPoster 7.8.5.0 (05.06.2025)

**Добавлено:**

[+] Браузер Chromium обновлен до 136 версии.

**Исправлено:**

[\] Исправлен показ диалогового окна выбора файлов для Chromium и ChromiumFromZB.

[\] Исправлена ситуация, когда плашка "Ожидание действий пользователя" пропадает при создании новой вкладки в Chromium и ChromiumFromZB.

[\] Изменен алгоритм автопереключения серверов, что должно помочь при блокировках серверов.

[\] Исправлена утечка памяти, которая появилась в 7.8.4.1 при работе с браузерами Chromium и ChromiumFromZB.

[\] Внесены небольшие правки по деградации потоков при интеграции с ZennoBrowser.
