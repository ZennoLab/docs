# ZennoPoster 7.7.4.0 (30.05.2023)

**Новые фичи:**

[+] Chromium обновлен до 112 версии.

[+] Улучшена обработка алгоритмов для супер эмуляции Canvas.

[+] Добавлен новый аргумент запуска браузера --zl-deny-ws-localhost. Используя этот аргумент, можно выключить трекинг браузера со стороны десктопных приложений (таких как Discord).

**Исправленные баги:**

[\] Исправлены хоткеи в Windows 11.

[\] Изменен адрес по умолчанию для смс-модуля 5sim для улучшения работоспособности интеграции сервиса.

[\] Теперь кубик «Очистить переменные» можно найти в поиске действий.

[\] Исправлены координаты начала работы эмуляции просмотра страницы.

[\] Исправлен обход CloudFlare в браузере Chromium.

[\] Исправлена работа режима ScreenMaximize и метода *instance.SetWindowSize в Chromium.

[\] Исправлено отображение дочерних окон браузера, например, расширений Chromium.
