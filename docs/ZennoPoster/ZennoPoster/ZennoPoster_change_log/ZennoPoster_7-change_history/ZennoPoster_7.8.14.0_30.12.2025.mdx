# ZennoPoster 7.8.14.0 (30.12.2025)

**Добавлено:**

[+] Браузер Chromium обновлен до 143.0.7499.170 версии.

[+] ZennoPoster переведен на .Net Framework 4.8.

**Исправлено:**

[\] Исправлено взятие скриншота для браузеров Chromium и ChromiumFromZB с включенной опцией «Изоляция сайтов».

[\] Исправлена функциональность работы контекстного меню в DevTools.

[\] Исправлена работа эмуляции мыши для браузеров Chromium с включенной изоляцией сайтов, так же и для бразуеров из интеграции с ZennoBrowser. Теперь виртуальная мышка должна перемещаться быстро и корректно.

[\] Исправлена работа эмуляции в режиме Touch событий в браузере Chromium и ChromiumFromZB.

[\] Теперь в браузере Chromium скачивание файлов показывает прогресс бар в строке состояния браузера, а так же имеется возможность отменить скачивание в UI ProjectMaker.

[\] Исправлена верстка в кубике «Запустить инстанс ZennoBrowser».
