# ZennoPoster MP 4.3.6.0 (06.12.2012)

### Новые фичи:

[+] Опция отключающая создание в начале проекта экшена очистки Cookie (ProjectMaker → Настройки → Запись проектов).

[+] Возможность показать инстансы для одного проекта (опция доступна в контекстном меню проекта в ZennoPoster).

[+] По многочисленным просьбам, экшен IF можно вставлять в любое место ActionGroup.
