# ZennoPoster 5.12.3.0 (21.11.2017)

### Новые фичи:

[+] Оптимизация запуска и работы базы браузера.

[+] Восстановлена работа со стандартным вариантом KeyCaptcha (для работы требуется наличие лицензии CapMonster).

[+] Добавлена настройка, позволяющая отключать уведомления в логе при использовании мульти-браузера (Настройки → Отладка → Показывать предупреждение о неподходящей версии браузера).

[+] Включение нужной версии браузера посредством C# (метод void Instance.Launch(BrowserType type, bool useProfile) ).

[+] Улучшение стабильности программы.

[+] Улучшения интерфейса.

### Исправленные баги:

[\] Исправления в BotUI при очистке неиспользуемых переменных.

[\] Исправления import входных настроек BotUI.

[\] Исправлено отображение текста в BotUI.

[\] Исправлена проблема с макросами в статических блоках CodeCreator.

[\] Исправлена проблема, когда Firefox 52 падал при очистке кеша для определенного домена.

[\] Исправлено сохранение источников прокси при перезапуске программы.

[\] Исправления интерфейса.

[\] Исправлена работа сервиса http://sms-reg.com.

[\] Исправлена работа сервиса GetSmsOnline.
