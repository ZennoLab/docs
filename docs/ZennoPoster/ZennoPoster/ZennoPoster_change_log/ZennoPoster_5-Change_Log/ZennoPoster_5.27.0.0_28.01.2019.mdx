# ZennoPoster 5.27.0.0 (28.01.2019)

### Новые фичи:

[+] Оптимизирована работа с HTTP-запросами: переиспользование соединений, сессий шифрования и т.д., если это возможно. Что позволило значительно сократить потребление CPU и повысить стабильность работы (Настройка «Использовать HTTP Connection Pool» включена по умолчанию, если в Ваших шаблонах возникли проблемы с новым режимом работы, то отключите данный режим, для возврата старого поведения).

[+] Добавлена возможность распознавать классический тип KeyCaptcha (с прямоугольниками):
ZennoPoster.CaptchaSpecialRecognition(«KeyCaptchaRects», instance, false);

[+] Действие «Распознать каптчу» теперь позволяет отправить каптчу из файла.

[+] Улучшение эмуляции и работы Canvas и WebGL.

[+] Улучшение анонимности ProjectMaker за счёт возможности отключения слоя с невидимыми элементами (например, рамка «Исследовать элемент»).

[+] Добавлено действие «Взять столбец» из таблицы в список.

[+] Добавлен метод [tab.GoBack()](https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic533.html "https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic533.html") для кода C#.

[+] Добавлен метод [project.GetProxy()](https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic1011.html "https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic1011.html") для кода C#.

[+] В метод [instance.ClearCache](https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic229.html "https://help.zennolab.com/en/v5/zennoposter/5.27.0.0/webframe.html#topic229.html") добавлен необязательный параметр storeCookie, по умолчанию true. Если false, то вызов метода также очистит cookies. Вместо вызова двух команд instance.ClearCache(); instance.ClearCookie(), можно написать instance.ClearCache(false). Кода меньше, работает быстрее и надёжнее.

[+] Действие «Очистить куки» завершится не успешно, если куки не очищены полностью, по каким-либо причинам.

[+] Улучшения в интерфейсе.
