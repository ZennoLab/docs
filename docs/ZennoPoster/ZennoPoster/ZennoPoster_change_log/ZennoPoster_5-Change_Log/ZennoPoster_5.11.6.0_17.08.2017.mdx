# ZennoPoster 5.11.6.0 (17.08.2017)

### Новые фичи:

[+] Добавлена эмуляция отпечатка аудио устройств в браузере (audio fingerprint). При старте проекта, генерируется уникальный отпечаток, он пишется в профиль, при сохранении и последующей загрузке профиля отпечаток восстанавливается. Добавлено соответствующее свойство C# - [AudioContextMode](https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic353.html "https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic353.html").

[+] Добавлена эмуляция устройств воспроизведения в WebRTC.

[+] Добавлен одновременный запуск нескольких шаблонов в Диспетчере задач (Появились группы заданий, группы выполняются по порядку. Шаблоны из группы стартуют одновременно, если группа разрывается другой группой, то это разные группы).

[+] Drag-And-Drop для виртуальной мыши. У вкладки появились C# методы [FullEmulationMouseDragAndDrop](https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic462.html "https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic462.html") (int fromX, int fromY, int toX, int toY) и [FullEmulationMouseDragAndDrop](https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic463.html "https://help.zennolab.com/en/v5/zennoposter/5.11.6.0/topic463.html") (HtmlElement fromHe, HtmlElement toHe).

[+] Появился Blacklist для источников прокси в ZennoPoster.

[+] Добавлен выбор папки в BotUI.

[+] Добавлена возможность удалять обработанный e-mail.

### Исправленные баги:

[\] Исправлены проблемы в эмуляции WebRTC при перезагрузке страницы.

[\] Исправлена работа Google переводчика через сайт http://translate.google.com.

[\] Исправлена проблема с загрузкой файлов через Flash.

[\] Исправлено отключение источников RSS в ProxyChecker.

[\] Исправлено появление пункта отправки прокси для модуля CapMonster2.dll в действии ReCaptcha2.

[\] Исправлена проблема с эмуляцией часового пояса на Яндекс почте.

[\] Исправлены щелчки звуковой карты при запуске программы.

[\] Улучшения в стабильности работы.

[\] Исправлено мешающее автодополнение в полях ввода в действиях.

[\] Исправлена проблема с сортировкой заданий по времени в ZennoPoster.
