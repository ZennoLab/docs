# ZennoPoster 5.10.4.0 (10.02.2017)

С новым релизом ZennoPoster мы подготовили две важные новости!

По вашим многочисленным просьбам, мы добавили в ZennoPoster виртуальную мышь. Она поможет лучше эмулировать поведение человека на сайте, например, совершать правильные движения курсором, эмуляцию чтения заголовков, статей или картинок. В качестве первого релиза, мы сделали эти функции доступными через C# сниппеты.

Вот как это выглядит в WebVisor [смотрите тут](https://help.zennolab.com/upload/Mojfe0.gif "https://help.zennolab.com/upload/Mojfe0.gif").

Методы движения виртуальной мыши [❗→ читайте в статье](https://zennolab.atlassian.net/wiki/spaces/RU/pages/489291804#%D0%9C%D0%B5%D1%82%D0%BE%D0%B4%D1%8B-%D0%B4%D0%B2%D0%B8%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B2%D0%B8%D1%80%D1%82%D1%83%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B9-%D0%BC%D1%8B%D1%88%D0%B8%3A "https://zennolab.atlassian.net/wiki/spaces/RU/pages/489291804#%D0%9C%D0%B5%D1%82%D0%BE%D0%B4%D1%8B-%D0%B4%D0%B2%D0%B8%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B2%D0%B8%D1%80%D1%82%D1%83%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B9-%D0%BC%D1%8B%D1%88%D0%B8%3A").

В следующих релизах мы планируем далее развивать функции виртуальной мыши, чтобы сделать её умнее и удобнее в использовании.

Ждем Ваших предложений и пожеланий.

Также, в текущей версии, 5.10.4.0, мы перевели программу на новый .NET Framework. Это позволит нам развивать наш продукт быстрее и качественней! Для корректной работы программы требуется .NET Framework 4.5.2 и выше. Это значит, что новые версии программы не будут работать на Windows XP и Windows Server 2003, так как сами Microsoft прекратили их поддержку ещё год назад, и не обновляют их инструментарий.

### Новые фичи:

[+] Добавлена расширенная эмуляция движений мыши.

[+] Добавлено закрепление проектов на стартовой странице.

[+] Работа с JSON и XML теперь потребляет значительно меньше памяти.

[+] Оптимизировано потребление CPU во время выполнения проектов.

[+] Оптимизировано отображение логов.

[+] Улучшен метод SetTimeZone, теперь он сам по умолчанию включает эмуляцию часового пояса. Вернуть на значение по умолчанию всегда можно с помощью свойства TimezoneWorkMode.

[+] Реализован метод instance.Reload() для перезапуска инстанса из кода.

### Исправленные баги:

[\] Починена активация окна браузера, эмуляция клавиатуры обрабатывается лучше.

[\] Исправлены ошибки в отображении проектов.

[\] Исправлено нечёткое отображение действий в редакторе.

[\] Улучшена эмуляция часового пояса, теперь сайты (например, http://instagram.com, http://textnow.com) при эмуляции часового пояса работают корректно.

[\] Исправлены ошибки при загрузке профиля и его последующей манипуляции через код.

[\] Открытие входных настроек больше не блокирует UI.

[\] Исправлено зависание ProjectMaker при работе в конструкторе действий и выборе поля для загрузки файла.

[\] Исправлена ошибка, когда при массовых выделениях проектов не всегда срабатывал старт и стоп.

[\] Исправлена ошибка, когда неактивно поле адреса при добавлении источника Proxy.

[\] Поле hardwareConcurrency имеет правильное значение по умолчанию.

[\] Исправлен баг отображения старого профиля в ProjectMaker во вкладках Браузер / Человек после загрузки нового профиля.

[\] Исправлены мелки баги UI.
