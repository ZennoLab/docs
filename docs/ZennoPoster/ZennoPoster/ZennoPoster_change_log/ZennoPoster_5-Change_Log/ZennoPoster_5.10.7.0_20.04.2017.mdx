# ZennoPoster 5.10.7.0 (20.04.2017)

### Новые фичи:

[+] Добавлена поддержка, автоматического определения летнего времени при автоматической эмуляции часового пояса.

[+] Добавлена возможность регулировать количество скачиваемых писем при обработке почты, что поможет ускорить работу проектов и уменьшить трафик.

[+] Добавлен метод [FullEmulationMouseWheel](https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic394.html "https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic394.html") для эмуляции скролла виртуальной мышью.

[+] Добавлен метод [instance.StopDownloads()](https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic277.html "https://help.zennolab.com/en/v5/zennoposter/5.10.7.0/webframe.html#topic277.html") для остановки фоновых загрузок.

[+] Улучшение стабильности.

[+] Включение опции «Нумерация строк в кубике C#», теперь запоминается.

[+] Расширены средства диагностики проблем.

### Исправленные баги:

[\] Исправлено скроллирование двух окон одновременно в ProjectMaker на Windows 7.

[\] Исправлено получение текущего прокси проекта в кубике Получение прокси в безбраузерном проекте.

[\] Исправлено получение фокуса элементом при клике правой кнопкой мыши.

[\] Исправлено дублирование заголовков при ответе на GET-запрос с редиректом.

[\] Исправлено конвертирование в C# код действия работы с базой данных.

[\] Исправлен баг при выполнении JavaScript на странице «все время» при сложной структуре вложенных фреймов.

[\] Исправлены мелкие UI баги.
