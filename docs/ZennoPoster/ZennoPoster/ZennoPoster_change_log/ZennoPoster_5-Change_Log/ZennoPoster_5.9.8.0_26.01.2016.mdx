# ZennoPoster 5.9.8.0 (26.01.2016)

### Новые фичи:

[+] Добавлено действие для работы с базами данных.

[+] Добавлены C# методы для работы с базами данных [ZennoPoster.Db](https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic445.html "https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic445.html").

[+] В ProjectMaker в расширенном редакторе убрана задержка при скрытии/раскрытии панели инструментов.

[+] Добавлен метод [project.ExecuteMacro(string)](https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic602.html "https://help.zennolab.com/en/v5/zennoposter/5.9.8/webframe.html#topic602.html"), обрабатывающий макросы в тексте и возвращающий текст с обработанными макросами.

### Исправленные баги:

[\] Исправлена обработка boolean значений входных настроек.

[\] Исправлены некоторые ошибки кодогенерации.
