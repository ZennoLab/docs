# ZennoPoster 5.13.0.0 (21.12.2017)

### Новые фичи:

[+] Добавлена поддержка 64 битного Firefox.

[+] Добавлена функция добавления прокси-сервисов.

[+] Добавлена поддержка AWM-прокси.

[+] Добавлена поддержка сервиса http://virtualsms.ru.

[+] Эмуляция работы Canvas теперь поддерживает эмуляцию при работе с контекстами WebGL и WebGL2.

[+] Улучшена эмуляция времени.

[+] Ускорена работа ProjectMaker при работе с большими проектами.

### Исправленные баги:

[\] Улучшено сокрытие полей объекта navigator.

[\] Улучшение стабильности работы программы.

[\] Исправлены ошибки не запуска браузера.

[\] Исправлены ошибки при работе HID.exe.

[\] Исправлены проблемы с копированием элементов BotUI.

[\] Исправлена порча картинки при эмуляции Canvas.

[\] Исправлено получение `{ -Page.Dom- }` у страницы.

[\] При копировании действия со списком/таблицей больше не слетает привязка к файлу.

[\] Исправлена работа автосохранения проекта при отсутствии места на диске C:\.

[\] Исправлена ошибка сериализации параметров.

[\] Исправлены ошибки при распознавании ReCaptcha2 через сервисы RuCaptcha и Anti-Captcha.
