# ZennoPoster 5.32.0.0 (15.08.2019)

### Новые фичи:

[+] Добавлен альтернативный способ проверки прокси. В настройках ProxyChecker добавлена опция «Использовать для проверки прокси .NET процесс». Альтернативный способ поможет избежать неожиданных ошибок error 217 на проблемных системах, а так же способствует уменьшению ресурсов при проверке прокси.

[+] Добавлена поддержка прокси в формате домен:порт для сервиса Infatica.

### Исправленные баги:

[\] Исправлена ошибка вызова конструктора действий на некоторых сайтах в Chrome.

[\] Исправлена проблема с переводами в BotUI.
