# ZennoPoster 5.20.0.0 (02.08.2018)

### Новые фичи:

[+] В ProjectMaker добавлены плагины.

[+] В ProjectMaker теперь работает перенос значений по-умолчанию при копировании действий из шаблона в шаблон.

[+] В ZennoPoster добавлена функция принудительного завершения шаблона. Теперь можно установить время, когда зависшие потоки шаблона будут автоматически завершаться.

[+] В ProxyChecker теперь можно установить число потоков загрузки источников больше 20.

### Исправленные баги:

[\] Исправлена неисчезающая ошибка при переименовании списка.

[\] Исправлена ошибка, когда не эмулировался WebGL image hash.

[\] Улучшена стабильность работы ProxyChecker.
