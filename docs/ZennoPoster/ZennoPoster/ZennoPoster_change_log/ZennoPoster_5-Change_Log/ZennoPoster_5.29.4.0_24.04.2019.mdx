# ZennoPoster 5.29.4.0 (24.04.2019)

### Новые фичи:

[+] Улучшена работа с базой GeoIP.

[+] Улучшена работа с процессами инстансов в ZennoPoster.

[+] Добавлена кнопка позволяющая отключать «Автоподбор высоты строк» в контрол лога, которая позволяет ускорить его работу и избежать подвисания интерфейса ZennoPoster при больших объемах вывода информации в лог.

[+] Браузерные данные из профиля теперь не теряются при работе в шаблоне «без браузера».

### Исправленные баги:

[\] Исправлена работа с прокси, которые ломают сертификат в Chrome.

[\] Исправлено отключение CSS в Chrome на некоторых сайтах.

[\] Исправлена работа localStorage в Chrome (слетала авторизация на некоторых сайтах).

[\] Исправлена загрузка переменных из профиля при добавлении несуществующих переменных.

[\] Исправлено выделение элементов в дереве элементов.

[\] Исправлено сохранение введённых данных в плагинах.

[\] Исправлено зависание ProjectMaker при запуске в некоторых случаях.

[\] Исправлена проблема с блокированием доступа к директориям, используемым как директория для загрузки файлов в HTTP-запросах, при использовании HTTP Connection Pool.

[\] Исправлена работа Traffic Monitor при работе с Firefox без отображения.

[\] Исправлены ошибки отображения в Traffic Monitor. Иногда тело ответа могло отображаться пустым.

[\] Исправлена обработка макросов. В некоторых случаях они могли необоснованно долго выполняться.

[\] Исправления интерфейса.
