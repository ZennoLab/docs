# ZennoPoster 5.31.0.0 (07.08.2019)

### Новые фичи:

[+] Добавлен новый прокси-сервис http://Infatica.io.

[+] Улучшена эмуляция кликов в Chrome.

[+] Добавлена эмуляция Intl объекта для возможных локалей профиля.

[+] Добавлена автоматическая эмуляция navigator.connection и navigator.battery в Chrome.

[+] Результаты действия «Запуск программы» теперь можно сохранять в переменную.

### Исправленные баги:

[\] Исправлен алгоритм проверки прокси для HTTPS.

[\] Исправлена эмуляция WebRTC IP.

[\] Исправлена работа списка правил прокси в Диспетчере заданий.

[\] Исправлена установка ответа ReCaptcha2 на сайте http://olx.ua для Chrome.

[\] Исправлено свойство Instance.FormTitle.

[\] Исправлено исчезновение шаблонов после первого запуска ZennoPoster.

[\] Исправлена эмуляция window.screen в Chrome (не воспроизводилось видео на PornHub).

[\] Исправлена работа с localStorage в Chrome.

[\] Ошибки отсутствия или несоответствие плагина или вложенного проекта теперь отображаются в ZennoPoster, даже если есть неуспешная ветка.

[\] Исправлена эмуляция параметров audio в Chrome.

[\] Исправлена работа метода Tab.KeyEvent.

[\] Исправлено сохранение списка в файл при наличии несуществующих директорий в пути.

[\] Исправлено действие получения количества строк в списке.

[\] Исправлена эмуляция плагинов в Chrome.

[\] Исправлена ошибка эмуляции таймзоны и геолокации для некоторых IP адресов.

[\] Исправлена работа веб-версии Telegram в Chrome.

[\] Исправлена проблема с двойными слешами после макроса `{ -Project.Directory- }` для Instance.DownloadsPath.

[\] Исправлена инициализация загрузки файлов в Chrome (например, загрузка аватарки в Instagram).

[\] Исправлено отображение бинарных данных в мониторе трафика.

[\] Исправлено управление уведомлениями в браузере.

[\] Другие исправления и улучшения.
