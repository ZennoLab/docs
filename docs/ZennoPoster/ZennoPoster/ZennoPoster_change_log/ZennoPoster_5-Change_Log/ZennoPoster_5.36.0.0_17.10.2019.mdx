# ZennoPoster 5.36.0.0 (17.10.2019)

### Новые фичи:

[+] Добавлена возможность продажи ботов с плагинами.

[+] В действии распознавания reCAPTCHA добавлен модуль CapMonsterCloud.dll.

[+] Добавлен модуль распознавания каптч 2Captcha.

[+] Добавлено свойство Instance.ClearTrafficWhenNavigate для включения или выключения очистки трафика внутри проекта.

[+] В действии обработка текста UrlEncode и UrlDecode, а так же в методы Macros.TextProcessing.UrlEncode и Macros.TextProcessing.UrlDecode добавлена возможность выбора кодировки.

[+] Ускорена обработка макросов.

### Исправленные баги:

[\] Исправлена обработка сookies в альтернативном методе HTTP запросов.

[\] Исправлено обновление дерева элементов в режиме автоматического скрытия.
