# ZennoPoster 5.16.0.0 (21.02.2018)

### Новые фичи:

[+] Beta: Добавлена новая функция для Публикации проектов.

[+] Улучшение анонимности пользователей. Программа больше не хранит email пользователя в реестре, вместо этого используется ID учётной записи. Это позволит избежать кражи учётных данных пользователя.

[+] Beta: Добавлена возможность автоматического обновления программы.

[+] Добавлены все возможные параметры эмуляции WebGL.

[+] Добавлена поддержка уведомлений браузера. Теперь можно принимать нотификации от сайтов и работать с ними. Можно включить и отключать сообщения. Прочитать полученные сообщения можно с помощью макросов `{ -Page.LastNotificationTitle- }` и `{ -Page.LastNotificationText- }`.

[+] Реализована возможность отправлять на прямую в CapMonster через sitekey без эмуляции сервисов.

[+] BotUI: Добавлена возможность установки прокси на проект и выбора правила для прокси.

[+] BotUI: Добавлена возможность двигать элементы по сетке стрелками зажав Ctrl.

[+] BotUI: Добавлена возможность смены шрифта для label.

[+] Добавлена возможно делать скриншоты видимой части страницы прямо из действия.

[+] Улучшен менеджер потоков ZennoPoster, теперь задания будут запускаться быстрее при большом количестве проектов добавленных в ZennoPoster.

[+] Улучшено логирование, добавлено название проекта, в котором произошла ошибка, что особенно удобно при большой вложенности проектов.

[+] Расширен метод [SetValue](https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic127.html "https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic127.html"). Теперь у него появился необязательный параметр, который позволяет дописывать в конец уже существующий текст, без удаления существующего.

[+] Расширен метод [GetTraffic](https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic488.html "https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic488.html") для получения тела запросов и ответов. Теперь анализировать трафик и перехватывать данные стало ещё удобнее.

[+] Добавлен сервис http://sms-acktiwator.ru.

[+] Расширен метод [EvaluateScript](https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic32.html "https://help.zennolab.com/en/v5/zennoposter/5.16.0.0/webframe.html#topic32.html"), для тех сайтов, на которых сломан метод eval. При указании альтернативного метода выполнения скрипта, скрипт будет пытаться исполниться без использования метода eval.
