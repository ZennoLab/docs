# ZennoPoster 5.26.0.0 (27.12.2018)

### Новые фичи:

[+] Расширен функционал управления ZennoPoster из командной строки и генерации bat-файлов.

[+] Ошибки действия «Распознать ReCaptcha» сохраняются в project.GetLastError() (текст ошибки в project.GetLastError() .Exception.Message).

[+] Возможность создать экшен Распознать ReCaptcha V3 для случая, когда имя модуля передаётся из переменной.

[+] ProxyChecker: Оптимизация использования памяти.

[+] Улучшения утилиты Diagnostic.

[+] Chrome Edition: Поддержка socks4.

[+] Chrome Edition: Отображение координат мыши в браузере.

[+] Chrome Edition: Оптимизации для ускорения работы интерфейса.

[+] Chrome Edition: Добавлена запись мини эскизов.

### Исправленные баги:

[\] CodeCreator: Исправлено отображение статических блоков.

[\] Исправлено исчезновение списков и таблиц при повторном открытии проекта в ProjectMaker.

[\] Исправлено долгое переключение между расширенным и обычным редакторами.

[\] Исправлена ошибка, когда в CookieContainer не записывались некоторые Cookies.

[\] Исправлена проблема когда заголовок Accept-Language и поле Navigator.Language не соответствует языку профиля.

[\] Исправлено получение скриншота видимой области.

[\] Chrome Edition: Исправлена работа действия «Распознать ReCaptcha» во вкладке для модуля CapMonster2.

[\] Chrome Edition: Исправлены ошибки при записи.

[\] Chrome Edition: Исправлено отображение браузера Chrome (иногда не показывался с первого раза).

[\] Chrome Edition: Загрузка (upload) файлов.

[\] Chrome Edition: Исправлен ввод символа «\_».

[\] Chrome Edition: Исправлена загрузка сайтов http://csgocasino.ru и некоторых других.

[\] Chrome Edition: Исправлено, когда socks5 прокси после очистки кеша выдают ошибку chrome-error:/chromewebdata/.

[\] Chrome Edition: Исправлено закрытие вкладок (popup, который сам закрывается через JavaScript).
