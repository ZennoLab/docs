# ZennoPoster 5.11.7.0 (06.09.2017)

### Новые фичи:

[+] Добавлена эмуляция отпечатка [getClientRects](https://browserleaks.com/rects "https://browserleaks.com/rects") и соответствующие C# свойства в API: [instance.ClientRectWorkMode](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic324.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic324.html"), [instance.ClientRectSeed](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic323.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic323.html").

[+] Добавлено управление [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB "https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB") в ZennoPoster.
Соответствующие C# методы в API: [instance.LoadIndexedDb](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic228.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic228.html"), [instance.SaveIndexedDb](https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic254.html "https://help.zennolab.com/en/v5/zennoposter/5.11.7.0/topic254.html").

[+] Добавлена поддержка сортировки дробных чисел в таблицах.

[+] Добавлена поддержка загрузки сборок .NET Framework версии 4.5.

### Исправленные баги:

[\] Для тех у кого возникали проблемы с быстрым набором потоков добавлена настройка «Запускать базы последовательно» в разделе настроек: Настройки → Инстанс.

[\] Исправлена путаница прокси в некоторых случаях при 5+ потоках на процесс.

[\] Некорректное переключение браузера в ProjectMaker при переключении из безбраузерного проекта на проект с браузером.

[\] Улучшена стабильность работы, исправлена ошибка приводившая к зависанию ZennoPoster, на некоторых компьютерах.

[\] Исправлена работа выбора даты в режиме без контента.

[\] Оптимизирована остановка потоков.

[\] Исправлена проблема с размерами полотна в BotUI.
