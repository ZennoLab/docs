# ZennoPoster 5.15.0.0 (24.01.2018)

### Новые фичи:

[+] Добавлена расширенная поддержка эмуляции параметров WebGL. См. [instance.WebGLPreferences](https://help.zennolab.com/en/v5/zennoposter/5.15.0.0/webframe.html#topic542.html "https://help.zennolab.com/en/v5/zennoposter/5.15.0.0/webframe.html#topic542.html").

[+] Добавлена эмуляция toString() у JavaScript объектов в зависимости от UserAgent эмулируемого браузера. Добавлено свойство bool Instance.UseToStringEmulation `{ get;set; }`.

[+] Добавлен функционал очистки прокси по времени, если прокси изначально считаются живыми. Опция в настройках источника прокси - «Удалять прежние прокси из живого списка при загрузке».

[+] Добавлен SMS-сервис http://smska.net.

[+] Добавлен SMS-сервис http://5sim.net.

[+] Улучшения в логировании.

### Исправленные баги:

[\] Исправлен запуск Firefox 45 на некоторых системах.

[\] Исправлена очистка неиспользуемые переменных.

[\] Исправлены проблемы запуска браузера в Demo версии.

[\] Исправлена работа окна загрузки файлов при ручных действиях в Firefox 52.

[\] Исправлена ошибка, при которой действие ReCaptcha2 ломало проект.

[\] Исправлены мелкие недочеты при выполнении JavaSctipt.

[\] Исправлено удаление файлов при неверно указанной директории с сервера FTP.

[\] Исправлено подвисание во время отладки в ProjectMaker.

[\] Мелкие исправления в UI.
