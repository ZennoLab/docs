# ZennoPoster 5.23.0.0 (20.11.2018)

### Новые фичи:

[+] Добавлен onboarding в ProjectMaker и ZennoPoster.

[+] Улучшения UI в ProjectMaker.

[+] Добавлена конвертация кубиков парсинга в C#.

[+] Добавлено удаление столбца в таблице.

[+] FTP соединение теперь можно переименовать.

### Исправленные баги:

[\] Исправлены проблемы с изменением POST-запроса в браузере.

[\] Исправлена ошибка обновления CookieContainer при выключении браузера через кубик с галкой «Использовать текущий профиль браузера».

[\] Устранена утечка памяти при ошибке удаления письма на сервере.

[\] Исправлено экранирование специальных символов в настройках Плагинов.

[\] Исправлена ошибка пустого ResponseBody в методе GetTraffic.

[\] Исправлена не срабатывающая подмена данных в AJAX запросе.

[\] Исправлено появление вкладок «призраков».

[\] Исправлено слетание настройки действий.

[\] Исправлена загрузка сайта http://mixcloud.com.

[\] Исправлена работа FtpChmode.
