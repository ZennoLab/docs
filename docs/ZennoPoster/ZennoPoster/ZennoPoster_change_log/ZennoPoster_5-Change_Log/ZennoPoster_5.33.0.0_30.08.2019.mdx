# ZennoPoster 5.33.0.0 (30.08.2019)

### Новые фичи:

[+] Улучшена эмуляция ввода спецсимволов в Chrome.

[+] В профиле браузера по умолчанию для Chrome проставлены оптимальные настройки для эмуляции Windows.

[+] Добавлены подсказки (тултипы) для элементов BotUI.

[+] В блоке «Директивы using и общий код» вкладка «Общий код» стоит на первом месте.

### Исправленные баги:

[\] Исправлена работа referer на некоторых сайтах в Chrome.

[\] Исправлены причины выхода из учётной записи при работе ZennoPoster.

[\] Исправлено использование прокси инстансом при запуске инстанса из безбраузерного проекта.

[\] Исправлено копирование связанных списков/таблиц при копировании действий Операции над списком/таблицей в другой проект.

[\] Восстановлена кнопка выбора файла в Общем коде.
