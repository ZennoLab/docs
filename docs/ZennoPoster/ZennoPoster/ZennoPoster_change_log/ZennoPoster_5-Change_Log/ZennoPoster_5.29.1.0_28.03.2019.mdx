# ZennoPoster 5.29.1.0 (28.03.2019)

### Новые фичи:

[+] Обновлены компоненты DevExpess, что должно увеличить отзывчивость UI и уменьшить количество багов в нём.

[+] При возникновении ошибки в C# коде во время выполнения в ProjectMaker показывает строку, в которой произошла ошибка, если это возможно.

[+] Улучшена эмуляция clientHeight и clientWidth.

[+] Улучшено отображение при работе с браузером без отображения содержимого в Chrome. В ProjectMaker браузер отображается, с пониженной частотой кадров, чтобы можно было отлаживать проект. При выполнении в ZennoPoster отображение не выводится для экономии ресурсов, а так же если Вы не хотите показывать, что происходит в браузере по каким-то соображениям.

### Исправленные баги:

[\] Исправлен метод установки размера окна для Firefox.

[\] Исправлена работа действия распознавания ReCaptcha2.

[\] Исправлено отключение CSS стилей в Firefox при закрытии всех вкладок.

[\] Исправлена некорректная работает смена движка с Firefox на Chrome в настройках проекта.

[\] Исправлены ошибки компиляции общего кода и кода C#.

[\] Исправлено отображение времени следующего запуска в расписании.

[\] Исправлен автоматический поиск условий для Конструктора действий.

[\] Исправлена установка выпадающих списков в Chrome.

[\] Исправлено удаление данных в BotUI.

[\] Небольшие исправления в UI.
