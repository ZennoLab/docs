# ZennoPoster 5.12.0.0 (22.09.2017)

### Новые фичи:

[+] С этой версии ZennoPoster становится мультибраузерным. В дополнении к Firefox 45 ESR появился движок Firefox 52 ESR. Теперь Вы можете проверять новые возможности браузера не ломая работу старых проектов.

[+] Появилось действие «Запустить браузер». Теперь по среди работы проекта Вы можете запустить браузер нужной версии, если он вдруг Вам понадобился.

[+] Добавили элемент кнопки в BotUI для удобства редактирования.

[+] Добавили настройку «Отображать дату» в логе выполнения шаблона в ZennoPoster.

### Исправленные баги:

[\] Исправлено зависание ProjectMaker от уведомления о доступной новой версии.

[\] Исправлено зависание запуска потоков, через некоторое время.

[\] Исправлена проблемы с загрузкой проектов и библиотек скаченных из сети.

[\] Исправлено игнорирование встречающихся «,» при загрузке таблицы \.csv.

[\] Исправлена загрузка фото через прокси в сервисах Google.

[\] Исправлено кликание в поле для ввода на Hotmail.

[\] Исправлена загрузка файлов таблиц в CodeCreator.

[\] Исправлено позиционирование скролла при работе с миникартой проекта.
