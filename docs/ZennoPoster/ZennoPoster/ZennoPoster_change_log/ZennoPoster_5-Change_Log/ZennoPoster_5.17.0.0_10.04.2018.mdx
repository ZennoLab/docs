# ZennoPoster 5.17.0.0 (10.04.2018)

### Новые фичи:

[+] Обновлена генерация профиля с Fingerprint в программе.

[+] BotUI: Появилось средство импорта InputSettings в BotUI.

[+] BotUI: Появилась возможность создавать пользовательские элементы в коде страницы.

[+] Добавлен класс [ZennoPoster.Http](https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic715.html "https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic715.html"), который позволяет создать любой HTTP запрос PUT/DELETE/PATH и др.

[+] Добавлен метод [EvaluateScript](https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic32.html "https://help.zennolab.com/en/v5/zennoposter/5.17.0.0/webframe.html#topic32.html") у документа страницы. Это позволит выполнять JavaScript в обход CORS.

[+] Добавлена поддержка нового типа KeyCaptcha.

[+] Добавлена поддержка абсолютных путей для (S)FTP(S).

### Исправленные баги:

[\] Исправлен автосабмит ReCaptcha2 на сайтах, со сложно архитектурой вложенных фреймов.

[\] BotUI: Исправлены проблемы с неправильными переменными.

[\] Исправлен запуск ProjectMaker с включенным подробным логом.

[\] Исправление открытие кода страницы, теперь оно открывается не в фоне.

[\] Исправлена проблема, что при обновлении версии перестают работать bat-файлы запуска заданий (bat-файлы придётся перегенерировать).

[\] Исправлена проблема с http://window.name.

[\] Исправлена проблема, когда при компиляции кода в логе указывается неверная строка с ошибкой.

[\] Исправлен сброс в диспетчере задач на значение по умолчанию.

[\] Исправлены ложно положительные срабатывания антивирусных программ.

[\] Исправлена загрузка фото на http://cloud.google.com/vision.

[\] Исправлена загрузка фото на http://imgur.com.
