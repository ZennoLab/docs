# ZennoPoster 5.19.0.0 (19.07.2018)

### Новые фичи:

[+] Новые национальности в профиле: Англия, Франция, Германия, Испания.

[+] Название списка или таблицы можно указать сразу при создании.

[+] Исключения для методов ZennoPoster.Db (параметр throwException, по умолчанию false).

[+] Оптимизация работы списков и таблиц без синхронизации с файлом.

[+] Добавлена опция «Не сохранять новый проект», которая убирает диалог сохранения для новых проектов после нажатия кнопки «С начала».

### Исправленные баги:

[\] Исправлен баг с переназначением Горячих клавиш после перезапуска программы.

[\] ZennoPoster.AudioMute правильно глушит звук, в том числе и во Flash.

[\] Исправлены некоторые ошибки возникающие при пошаговой отладке C# кода.

[\] Исправлены тексты ошибок возникающих при публикации проектов.

[\] Исправлена установка разделителей строк и столбцов таблицы через C#.

[\] Исправления в работе POST/GET-запросов.

[\] Исправления в работе CookieContainer.
