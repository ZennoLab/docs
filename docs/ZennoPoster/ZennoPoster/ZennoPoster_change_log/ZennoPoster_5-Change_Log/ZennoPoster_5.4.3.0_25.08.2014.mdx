# ZennoPoster 5.4.3.0 (25.08.2014)

### Новые фичи:

[+] Добавлена поддержка доменов, написанных не латиницей, для GET/POST запросов (например, «http://bücher.com», «http://мойдомен.рф», «παράδειγμα.δοκιμή»).

[+] Добавлена возможность импортировать входные настройки через bat файл.

[+] Добавлена возможность сворачивать ZennoPoster в трей.

[+] Добавлена опция состояния загрузки “Игнорировать Frame”.

[+] Добавлены перегрузки методов [SendErrorToLog](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendErrorToLog.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendErrorToLog.html"), [SendInfoToLog](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendInfoToLog.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendInfoToLog.html"), [SendWarningToLog](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendWarningToLog.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.InterfacesLibrary~ZennoLab.InterfacesLibrary.ProjectModel.IZennoPosterProjectModel~SendWarningToLog.html") объекта project, последний параметр отвечает за вывод сообщения и в ZennoPoster.

[+] Добавлены настройки лога. Можно редактировать время хранения и максимальное количество записей в логе.

[+] Ускорена загрузка и работа ProjectMaker.

[+] В действиях HTTP GET/POST улучшена возможность выбора файла профиля.

[+] Добавлен дополнительный параметр в метод [ZennoPoster.GetProxy](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~GetProxy.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~GetProxy.html") для возвращения прокси в каноническом формате адресов (protocol://login:pass@ip:port).

[+] Добавлены методы [ExportInputSettings](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~ExportInputSettings.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~ExportInputSettings.html") и [ImportInputSettings](http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~ImportInputSettings.html "http://help.zennolab.com/en/v5/zennoposter/5.4.3/webframe.html#ZennoLab.CommandCenter~ZennoLab.CommandCenter.ZennoPoster~ImportInputSettings.html") в класс ZennoPoster для работы с входными настройками.

[+] Добавлено прерывание действий Пауза и Работа с Email в ZennoPoster.

### Исправленные баги:

[\] Исправлена работа метода DrawToBitmap. В редких случаях, не получалось сохранить картинку или получить каптчу на длинных страницах из-за скроллинга.

[\] Исправлена работа эмуляции select. Теперь учитываются disabled элементы при полной эмуляции.

[\] Исправлено неверное определение кодировки для некоторых файлов, так же её можно отключить.

[\] Исправлено зацикливание перехода с неправильными авторизационными данными.

[\] Исправлена работа \.bat файлов.

[\] Исправлено выделение и копирование действия Switch в ProjectMaker.

[\] Исправлена работа ProjectMaker при загрузке файлов.

[\] Исправлены ошибки при запуске и работе CodeCreator.

[\] Исправлены ошибки нахождения элементов на странице.

[\] Исправлено обновление URL в строке адреса.

[\] При использовании своих символов в действии Random остальные флаги становятся не доступными.

[\] Добавлено экранирование спецсимволов при использовании функции «Поиск текста на странице».

[\] Исправлена работа SFTP без прокси.

[\] Исправлено открытие входных настроек проектов, добавленных в предыдущих версий ZennoPoster.
