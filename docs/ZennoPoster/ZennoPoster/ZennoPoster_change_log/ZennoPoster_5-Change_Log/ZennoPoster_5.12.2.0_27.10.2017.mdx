# ZennoPoster 5.12.2.0 (27.10.2017)

### Новые фичи:

[+] Новые типы кнопок в BotUI. Добавлено управление шаблонами ZennoPoster.

[+] Выполнение интерактивных действий по кнопкам в BotUI.

[+] Улучшения дизайна BotUI.

[+] Добавлен сервис DeathByCaptcha для распознавания ReCaptcha2.

[+] Улучшения Чёрного списка прокси (сортировку в чёрном списке и его импорт - экспорт).

[+] В метод BulkMailDownload добавлен параметр throwException, позволяющий генерировать исключения при возникновении ошибок в обработке.

[+] Оптимизирована работа браузера Firefox 52.

### Исправленные баги:

[\] Исправления некоторых ошибок в интерфейсе.

[\] Улучшена обработка ошибок авторизации (Get Auth Credentials).

[\] Правильное использование прокси при выполнении распознавания ReСaptcha2 для проектов без браузера.

[\] При перемещении файла сам в себя в действии Перемещение, файл не удаляется и в лог выводится предупреждение.

[\] Исправлена эмуляция плагинов в Firefox 52.

[\] Исправлена загрузка файлов через открытие и закрытие popup, таких как http://www.photodex.com.
