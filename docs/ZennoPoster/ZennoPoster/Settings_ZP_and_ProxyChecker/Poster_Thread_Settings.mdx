## Максимальное количество потоков
Задаёт общее количество потоков, которые могут одновременно использовать все запущенные проекты.

## Количество потоков в одном процессе
Определяет, сколько потоков будет работать в рамках одного процесса и совместно использовать ресурсы компьютера.  

Увеличение значения позволяет снизить потребление ресурсов, однако потоки внутри одного процесса могут выполняться немного медленнее.

:::warning Настройка работает только при использовании движка Firefox 45
Для остальных типов браузеров всегда запускается один поток в одном процессе независимо от указанного значения.
:::

## Отслеживание ресурсов компьютера
Если настройка включена, новые потоки будут запускаться только при наличии достаточного количества свободных ресурсов компьютера.
