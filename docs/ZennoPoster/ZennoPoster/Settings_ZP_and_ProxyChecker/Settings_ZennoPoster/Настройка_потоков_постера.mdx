## Максимальное количество потоков

Это максимально допустимое количество потоков для всех запущенных проектов.

## Количество потоков в одном процессе

:::warning Внимание
Данная настройка работает только при использовании движка Firefox 45.При использовании всех остальных типов браузеров всегда используется 1 поток в 1 процессе (независимо от значения в данной настройке).
:::

Позволяет объединить несколько потоков, работающих в рамках одного процесса и совместно использующих ресурсы компьютера. Это позволит сэкономить ресурсы, но потоки в рамках одного процесса будут выполняться чуть медленнее.

## Отслеживание ресурсов компьютера

Если данная настройка включена, то запуск потоков будет производиться только при наличии свободных ресурсов у компьютера.
