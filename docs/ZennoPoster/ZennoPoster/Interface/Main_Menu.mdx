# Главное меню

  

## Описание

![image-20210622-140732](./assets/Main_Menu/Main_Menu_pic1.png)



С помощью данного меню Вы можете управлять проектами - добавить и удалить, запустить и остановить, установить количество попыток, настроит [❗→ Диспетчер заданий](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198") и встроенный [❗→ ProxyChecker](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960").

  

## Панель быстрого доступа

![image-20210622-142317](./assets/Main_Menu/Main_Menu_pic2.png)



Сюда можно добавить кнопки для быстрого доступа к ним. Даже если Вы свернёте основное меню с кнопкам, данная панель всё-равно будет отображаться.
По умолчанию тут отображаются кнопки *Добавить новый проект, Запустить и остановить потоки [❗→ ProxyChecker](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960")’а (при запуске включается сбор и проверка прокси) и [❗→ Сетевой монитор](https://zennolab.atlassian.net/wiki/spaces/RU/pages/1721565250 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/1721565250").

Как добавить сюда новые кнопки будет описано ниже.

С помощью стрелки в правой части этой панели Вы можете скрыть\отобразить элементы не удаляя их.

![image-20210625-161257](./assets/Main_Menu/Main_Menu_pic3.png)



  

## Вкладки “Настройки” и “Проекты”

![image-20210622-155449](./assets/Main_Menu/Main_Menu_pic4.png)



Здесь Вы можете переключиться с окна проектов на [❗→ настройки ZennoPoster](https://zennolab.atlassian.net/wiki/spaces/RU/pages/852885655 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/852885655") и встроенного [❗→ ProxyChecker](https://zennolab.atlassian.net/wiki/spaces/RU/pages/848560318/ "https://zennolab.atlassian.net/wiki/spaces/RU/pages/848560318/").

  

## Меню

### Добавить

С помощью данной кнопки Вы можете добавить проект (-ы) в программу. После добавления они отобразятся в [❗→ Таблице проектов](https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528").

#### Добавление нескольких проектов одновременно

Если при добавлении проекта Вы выберите сразу несколько проектов, то откроется такое окно:

![image-20210622-163607](./assets/Main_Menu/Main_Menu_pic5.png)



Добавить\Удалить из списка

С помощью этих кнопок можно добавить новые файлы проектов или удалить лишние из списка добавляемых.

Назначить метки

Тут можно выбрать существующие или добавить новые метки. Выбранные метки будут применены ко всем добавляемым проекта. Подробней о них можно прочитать в статье про [❗→ вкладку Настройки](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897").

### Удалить

Удаляет все шаблоны выделенные в [❗→ Таблице проектов](https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528").

### Показать

Открывает [❗→ вкладку Инстансы](https://zennolab.atlassian.net/wiki/spaces/RU/pages/853803144 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/853803144").

### Показать инстансы

Открывает [❗→ вкладку Инстансы](https://zennolab.atlassian.net/wiki/spaces/RU/pages/853803144 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/853803144") и разворачивает во всё окно программы.

### Старт

Запускает выделенные, остановленные проекты.

### Стоп

Останавливает выполнение выделенных проектов.

### Добавление новых попыток

![image-20210622-164629](./assets/Main_Menu/Main_Menu_pic6.png)



Добавляет соответствующее количество выполнений шаблона к текущему значению.

При клике по кнопке с символом бесконечности (**∞**) выделенному проекту в графе [❗→ Сколько делать на вкладке Настройки](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897") будет установлено значение **-1** (минус один) - бесконечное выполнение. Шаблон будет работать до тех пор, пока Вы его не остановите либо не наступит одно из условий указанных во [❗→ вкладке Остановка](https://zennolab.atlassian.net/wiki/spaces/RU/pages/852885665 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/852885665").

### Ввод капч вручную

Открывает [❗→ окно для ввода капч](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705951 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705951").

### ProxyChecker

Открывает окно управления встроенным [❗→ ProxyChecker'ом](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851705960").

### Диспетчер заданий

Открывает вкладку управления [❗→ Диспетчером заданий](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198").

### Открыть в ProjectMaker

Запускает выделенные проекты в [❗→ ProjectMaker](https://zennolab.atlassian.net/wiki/spaces/RU/pages/505970699 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/505970699").

### Сворачивание меню

![image-20210625-155507](./assets/Main_Menu/Main_Menu_pic7.png)



При помощи кнопки в правой верхней части Вы можете свернуть\развернуть Главное меню (так же это можно сделать с помощью контекстного меню, описано ниже).

  

## Контекстное меню

![image-20210625-155839](./assets/Main_Menu/Main_Menu_pic8.png)



Для вызова контекстного меню достаточно кликнуть ПКМ по одной из кнопок.

### Add to Quick Access Toolbar

Добавить выбранную кнопку на Панель быстрого доступа (описана в начале статьи)

### Remove from Quick Access Toolbar

![image-20210625-160750](./assets/Main_Menu/Main_Menu_pic9.png)



Если кликнуть ПКМ по элементу, который уже есть на Панели быстрого доступа, то на первом месте отобразится данный пункт, позволяющий убрать (Remove) данный элемент из быстрого доступа.

### Show Quick Access Toolbar Below\Above the Ribbon

Позволяет переместить Панель быстрого доступа под (Below) Главное меню и вернуть обратно (Above):

**Above the Ribbon**

![image-20210625-160355](./assets/Main_Menu/Main_Menu_pic10.png)



**Below the Ribbon**

![image-20210625-160516](./assets/Main_Menu/Main_Menu_pic11.png)



### Minimize the Ribbon

Сворачивание Главного меню.
