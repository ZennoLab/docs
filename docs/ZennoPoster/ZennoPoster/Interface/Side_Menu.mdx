# Сайд-меню

  

## Описание

С помощью бокового меню можно фильтровать шаблоны в [❗→ таблице проектов](https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/853737528") по статусу (выполняется, остановлен, запланирован), по меткам (можно задать во вкладке [❗→ Настройки](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897")). Для этого достаточно выделить необходимый пункт в меню.
В скобках рядом со статусом или меткой отображено количество проектов, которые находятся в этой категории.

## Шапка меню

![image-20210809-112812](./assets/Side_Menu/Side_Menu_pic2.png)



### Потоки

Это число отображает количество всех работающих в данный момент потоков в программе, для всех шаблонов.

Максимально допустимое количество одновременно работающих потоков, для всех проектов вместе взятых. Изменить это число можно в [❗→ настройках потоков постера | Максимальное количество потоков](https://zennolab.atlassian.net/wiki/spaces/RU/pages/808812646#%D0%9C%D0%B0%D0%BA%D1%81%D0%B8%D0%BC%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5-%D0%BA%D0%BE%D0%BB%D0%B8%D1%87%D0%B5%D1%81%D1%82%D0%B2%D0%BE-%D0%BF%D0%BE%D1%82%D0%BE%D0%BA%D0%BE%D0%B2 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/808812646#%D0%9C%D0%B0%D0%BA%D1%81%D0%B8%D0%BC%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5-%D0%BA%D0%BE%D0%BB%D0%B8%D1%87%D0%B5%D1%81%D1%82%D0%B2%D0%BE-%D0%BF%D0%BE%D1%82%D0%BE%D0%BA%D0%BE%D0%B2") 

## Основное меню

### Задания

![image-20210809-113056](./assets/Side_Menu/Side_Menu_pic3.png)



Фильтрация проектов по их текущему статусу. 
В скобках возле слова “Задания” указано количество добавленных проектов.

**Выполняются** - работающие в данный момент шаблоны.
**Выполнены** - проекты, успешно завершившие работу.
**Остановлены** - проекты, выполнение которых остановлено.
**Запланированные** - проекты с настроенным и включенным [❗→ расписанием](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534086320 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534086320").

### Метки

![image-20210809-113144](./assets/Side_Menu/Side_Menu_pic4.png)



Фильтрация проектов по метке. Задать метку (-и) проекту можно во вкладке [❗→ Настройки](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851574897").
В скобках, возле слова “Метки” указано количество шаблонов, у которых установлена хоть одна метка.

В скобках возле меток отображено количество шаблонов, которым присвоена данная метка.

### Диспетчер заданий

Тут отображены задания из [❗→ Диспетчера заданий](https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/851116198") и в скобках указано количество шаблонов в каждом из заданий.
При клике по заданию в таблице проектов будут отображены входящие в него шаблоны.
