**Новые фичи:**

[+] Браузер Chromium обновлен до 124 версии.

[+] Добавлена опция «Альтернативная отрисовка браузера Chromium» в Настройки -&gt; Инстанс.
Опция распространяется только на ZennoPoster. При включении опции Chromium меняет режим отрисовки. В этом режиме меняется отрисовка миниатюр во вкладке Инстансы, а отрисовка браузеров в окнах отключается (черные окна).
Альтернативная отрисовка должна исправить проблемы:

- Сбои системы/перезагрузки/BSOD или утечки памяти, связанные с комбинацией DWM и драйверов.
- Работы GPU для отрисовки Canvas и WebGL (в стандартном режиме отрисовки используется софтверный рендерер независимо от наличия видеокарты).

**Исправленные баги:**

[\] Исправлена установка символов &, &lt;, &gt;, ', \ в значения профиля в кубике «Операции над профилем».

[\] Исправлена проблема отображения контекстного меню для devtools окна браузера Chromium.

[\] Исправлена установка сразу нескольких файлов для загрузки через кубик «Файлы для загрузки на сервер» в браузере Chromium.

[\] Теперь при добавлении плагина в ProjectMaker через интерфейс публикации проекта, он сразу же доступен в списке во вкладке Настройки -&gt; Плагины.

[\] В ProjectMaker исправлено отображение настроек кубика плагина при переключении на него после удаления другого кубика.
