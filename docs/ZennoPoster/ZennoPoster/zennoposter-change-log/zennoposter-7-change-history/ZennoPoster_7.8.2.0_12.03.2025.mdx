## **Добавлено:**

[+] Браузер Chromium обновлен до 133 версии.

[+] Добавлена возможность запретить загрузки файлов для браузера Chromium и ChromiumFromZB. Для этого в кубик пути для загрузки файлов или в свойство *instance.DownloadsPath нужно установить значение &lt;deny&gt;.

## **Исправлено:**

[\] Теперь при использовании интеграции ZennoPoster7-ZennoBrowser в истории браузера не появляются переходы на [!\[\](http://rc.zennoposter.com/favicon.ico)Test Page for the Nginx HTTP Server on Fedora](http://rc.zennoposter.com) .

[\] Исправлено выделение элементов на странице синей рамкой для браузера Chromium и ChromiumFromZB.

[\] Теперь в ZennoPoster браузеры из ZennoBrowser показываются на переднем плане.

[\] Теперь ZennoPoster не меняет размер окон браузера из ZennoBrowser.
