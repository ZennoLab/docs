**Новые фичи:**

[+] Браузер Chromium обновлен до версии 119. Исполняемый файл для браузера Chromium переименован в zbe1.exe.
[+] Обновлены библиотеки Newtonsoft.Json до версии 13.0.3.
[+] Для сервиса SmsHub добавлено "www" в адрес запроса баланса.
[+] Удaлено два неактуальных смс-сервиса: Smska и SmsVk.
[+] Изменены url'ы по умолчанию для следующих сервисов: SmsAcktiwator на [<u data-renderer-mark="true">https://smsak.org/api/</u>](https://smsak.org/api/ "https://smsak.org/api/") , SmsActivate на [<u data-renderer-mark="true">https://api.sms-activate.org/stubs/handler_api.php</u>](https://api.sms-activate.org/stubs/handler_api.php "https://api.sms-activate.org/stubs/handler_api.php") и VirtualSms на [<u data-renderer-mark="true">https://api.sms-activate.org/stubs/handler_api.php</u>](https://api.sms-activate.org/stubs/handler_api.php "https://api.sms-activate.org/stubs/handler_api.php").

**Исправленные баги:**

[\] Исправлено падение рендеров Chromium в некоторых случаях.
[\] Исправлено масштабирование изображения по умолчанию в браузере Chromium.
[\] Теперь в браузере Chromium при выключенной настройке «Отключить звук» будет проигрываться звук.
[\] Исправлены некоторые проблемы с touch событиями в браузере Chromium.
[\] Исправлены промахи полной эмуляции мыши в браузере Chromium.
[\] В браузере Chromium исправлен масштаб страницы при установке размеров окна больше, чем реальные.
[\] Исправлена проблема запуска CEF после запуска Chromium в ProjectMaker.
[\] Исправлена проблема, когда после длительной работы оставались незакрытые процессы браузера Chromium. Запуск и завершение процессов браузеров стали более надежными.
