### Новые фичи:

[+] Добавлен поиск элементов по CSS-селектору. Добавились методы [QuerySelector](https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic47.html "https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic47.html") и [QuerySelectorAll](https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic48.html "https://help.zennolab.com/en/v5/zennoposter/5.16.2.0/webframe.html#topic48.html").

[+] Улучшена отзывчивость интерфейса ZennoPoster при большом количестве заданий.

[+] Добавлен глобальный timeout на парсинг регулярным выражением, теперь выполнение проекта в ZennoPoster неожиданно не зависнет, если регулярное выражение составлено неверно.

### Исправленные баги:

[\] Исправлено отображение оповещения при загрузке купленных шаблонов.
