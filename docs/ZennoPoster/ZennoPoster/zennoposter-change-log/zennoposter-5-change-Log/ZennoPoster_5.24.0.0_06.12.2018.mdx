## Новые фичи:

[+] Обновлён до актуального состояния алгоритм распознавания ReCaptcha2 во вкладке.

[+] Обновлён встроенный модуль работы с сервисом  http://Anti-Captcha.com до API версии V2.

[+] BotUI: Добавлен контрол LanguageSelection.

[+] Добавлена конвертация действия Обработка текста → Regex в C# код.

[+] Оптимизация работы утилиты Diagnostics на системах с большим количеством продуктов ZennoLab.

[\] Исправлена работа установщика на некоторых системах.

[\] Для действия распознавания ReCaptcha2 теперь применяются адреса серверов из настроек.

[\] Исправлена работа кода project.GetLastError().Exception в ZennoPoster и при отладке кода в ProjectMaker.

[\] Исправлено поведение ZennoLab.AudioMute.exe на некоторых системах.

[\] Исправлены ошибки отображения трафика в ProjectMaker.

[\] Исправлено поведение режима «Выполненные» для настроек действий в Расширенном редакторе.

[\] Исправлено поведение окна с Миникартой проекта.
