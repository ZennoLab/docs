## Новые фичи:

[+] Добавлена блокировка рекламы на движке Chrome.

[+] Оптимизирована работа с логом при большом потоке сообщений.

[+] Отображение в логе ID действия, в котором сработало прерывание работы проекта по таймауту.

[+] Добавлена возможность использовать DirectX для отрисовки интерфейса ProjectMaker и ZennoPoster (чтобы использовать функцию, необходимо добавить параметр запуска -UseDirectX).

[+] Другие улучшения работы и интерфейса.

## Исправленные баги:

[\] Исправлен поиск notext в Chrome.

[\] Исправлен поиск элементов по regex в Chrome (теперь работает аналогично Firefox).

[\] В Chrome исправлено отображение кнопки «Продолжить выполнение» для метода WaitForUserAction.

[\] Исправлены Preferences Speech Recognition в Firefox.

[\] Исправлена работа метода GetAllMembersList (XML и JSON) в ZennoPoster.

[\] Исправлена работа метода ZennoPoster.HideInstance.

[\] Исправлена ситуация, когда очищался BotUI при переименовании переменных.

[\] Исправлены падения редактора шаблонов в ProjectMaker от длинного текста в заметке.

[\] Исправления в работе действия IF при содержании кавычек.

[\] Исправлена работа таблиц с большим количеством столбцов (больше 701).

[\] Исправлена отправка пустых запросов multipart в методе ZennoPoster.HTTP.Request POST.

[\] Исправлена возможная неверная замена в тексте при несуществующем макросе.

[\] Исправлена некорректная кодировка в ответе окна трафика.

[\] Исправлена работа с профилями в CodeCreator.

[\] Исправлена генерация имени загружаемого файла (Page.LastDownloadFile).

[\] Исправлена проверка прокси по DNSBL-листам.

[\] Исправлена возможность удалить собственный ID из блока шифрование в проекте.

[\] Другие исправления.
