### Новые фичи:

[+] Добавлена обработка HSTS Super Cookie. В метод сохранения профиля и в кубик добавлен флаг сохранять супер куки. Очистка HSTS Super Cookie производится вместе с очисткой других куков. По аналогии с обычными куками добавлены методы void instance.SaveSuperCookie(string path), byte[] instance.SaveSuperCookie(), void instance.LoadSuperCookie(string path), void instance.LoadSuperCookie(byte[] cookie), void instance.SetSuperCookie(string cookie), string instance.GetSuperCookie(string domain = default(string)).

[+] Добавлено действие для распознавания ReCaptcha2 через сервисы Anti-Captcha, RuCaptcha, Imagetyperz, CapMonster. Теперь можно просто добавить действие в проект, оно само найдёт ReCaptcha2 на странице и распознает её. Поддерживаются варианты ReCaptcha2, ReCaptcha2 Invisible, возможна работа через GET/POST при распознавании через сервисы Anti-Captcha, RuCaptcha, Imagetyperz.

[+] В BotUI добавлено мультиселектирование элементов.

[+] В BotUI добавлена история действий (Отменить/Повторить).

[+] В BotUI добавлено перемещение контролов по пикселю стрелками на клавиатуре.

[+] В BotUI добавлена поддержка Ctrl+C/Ctrl+V.

[+] Добавлены свойства HtmlElement.BoundingClientWidth и HtmlElement.BoundingClientHeight. В свойствах элемента и в конструкторе добавлены clientwidth и clientheight, их можно дёргать через HtmlElement.GetAttribute, возвращают BoundingClientWidth и BoundingClientHeight. В свойствах элемента старые width и height теперь отображают ScrollWidth и ScrollHeight.

[+] Добавлены кнопки вызова Входных настроек / BotUI в ZennoPoster.

[+] Добавлено копирование текста сообщения контекстного меню в логе ZennoPoster.

[+] Увеличена скорость запуска потоков.

[+] Улучшена работа эмуляции времени.

[+] Убрана зависимость от Newtonsoft.Json, если Вам нужна для работы какая-то определённая версия Newtonsoft.Json, то можете спокойно её использовать без правки config файлов.
