## Новые фичи:

[+] Добавлен новый статический блок BotUI.

[+] Добавлена опция выполнения JavaScript всё время «на всех вкладках».

[+] Добавлена настройка «Не перехватывать фокус с других процессов (некоторые сайты могут работать некорректно)». Эта настройка позволит избежать мерцания экрана и потери активного фокуса приложения при работе ZennoPoster, но нужно проверить, что Ваши проекты не сломались, т.к. некоторые сайты требуют корректного переключения фокуса для браузера во время работы (например, VK).

[+] Добавлена опция «Открывать браузер если требуется» для C# метода «Проект в проекте».

[+] Улучшена обработка сетевых подключений.

[+] Добавлен фильтр для «Cloudflare proxy» в ProxyChecker. Если сайты не находятся за Сloudflare, то IP Сloudflare не будут работать как HTTP прокси, этот фильтр позволит избежать попыток работы с такими сайтами.

[+] Небольшие улучшения UI.
