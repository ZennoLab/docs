### Новые фичи:

[+] Улучшена публикация проектов, добавлена загрузка в Личный кабинет.

[+] Добавлен мониторинг ресурсов компьютера, позволяющий ускорить подготовку и запуск проектов в ZennoPoster и уменьшающий ошибочные выполнения при нехватке производительности системы.

[+] Добавлена поддержка CookieContainer в HTTP POST/GET и др. Теперь cookies синхронизированны между браузером и POST/GET-запросами.

[+] Для виртуальной мыши добавлен метод скролла к элементу FullEmulationMouseWheel(IHtmlElement he, int topOffsetToElementCenter = 50, int leftOffsetToElementCenter = 50).

[+] Улучшена отзывчивость UI в ZennoPoster.

[+] Добавлена поддержка AirSocks прокси.

[+] Добавлена поддержка SocksHub прокси.

### Исправленные баги:

[\] Восстановлена логика работы с таблицами.

[\] Исправлена работа http://sms-acktiwator.ru.

[\] Исправлено сохранение эмулированного IP в WebRTC.

[\] Исправлен баг с отображением значений полей в Профиле.

[\] Исправлено зависание выполнения проекта при ошибках загрузки Профиля Браузера.

[\] ZennoPoster.HTTP.RequestBytes воспринимает contentType = «multipart/form-data».

[\] Исправлено зависание FullEmulationMouseMoveAboveHtmlElement когда на странице заблокирован скроллинг.

[\] Исправлен поиск поля ввода ответа для Recaptcha2 если их несколько на станице.

[\] Исправлена работа метода Contains в IZennoList.

[\] Поправлена работа Switch в ProjectMaker.

[\] Доработана форма авторизации.

[\] Исправлена проблема когда не открывались входные настройки.
