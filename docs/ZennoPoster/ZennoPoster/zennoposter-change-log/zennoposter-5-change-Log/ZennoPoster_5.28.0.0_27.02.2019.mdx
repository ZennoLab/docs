### Новые фичи:

[+] Chrome Edition теперь работает на свежем 72 движке Chrome.

[+] Оптимизация загрузки дополнительных библиотек С# в редактор ProjectMaker.

[+] Интеграция AWM Proxy в раздел «Прокси-сервисы».

[+] Возможность сохранять фильтры лога в ZennoPoster.

[+] Добавлена возможность создать переменные при их отсутствии во время загрузки из профиля.

[+] Для новых установок программы увеличено максимальное количество потоков по умолчанию в ZennoPoster Pro.

[+] Отображение срока подписки для купленных шаблонов в ZennoPoster и ZennoBox.

[+] Оптимизация работы потоков ZennoPoster.

[+] ProxyChecker: Поддержка DNSBL и проверка в чёрных списках.

[+] Оптимизация работы с файлами при HTTP-запросах.

[+] Улучшения в работе диаграммы проекта.

[+] Прочие улучшения и модификации.
