## Новые фичи:

[+] Улучшена эмуляция мобильных устройств.

[+] Добавлено свойство window.orientation при эмуляции мобильных устройств.

[+] Добавлено авто включение / выключение TouchEvent (для desktop User Agent выключено, для tablet и mobile включено).

[+] Добавлена эмуляция orientation type (Instance.ScreenOrientation), orientation angle меняется автоматически, так же браузерные профили подхватят эту тему и сами будут ставить orientation.

[+] Добавлена возможность жаловаться на плохие ответы ReCaptcha2 при распознавании через RuCaptcha и др. сервисы.

[+] Уменьшено время загрузки HTTPS страниц в браузере, отключены лишние запросы.

[\] Исправлен баг с авторизацией на YouTube через HTTP запрос.
