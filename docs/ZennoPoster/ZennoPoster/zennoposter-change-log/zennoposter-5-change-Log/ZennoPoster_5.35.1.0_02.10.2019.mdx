## Новые фичи:

[+] Оптимизирован запуск баз с Chrome в ZennoPoster.

[+] Теперь можно обновлять содержимое TrafficItem, либо дожидаться получения ответа на запрос. В объект TrafficItem добавлены методы Refresh, WaitResponse, WaitResponseAsync.

[+] В настройках инстанса появился новый чекбокс «Не очищать трафик автоматически при Navigate» (для применения настройки требуется перезапуск).

[+] Добавлен флаг Сербии для ProxyChecker.

## Исправленные баги:

[\] Исправлено сохранение и загрузка базы прокси ProxyChecker.

[\] Исправлена работа регулярных выражений в политиках содержимого браузера.

[\] Исправлена проблема, когда приходил пустой ответ на запрос на некоторые сайты через альтернативный метод HTTP.

[\] Исправлено прерывание ожидания распознавания ReCaptcha2.

[\] Исправлено отображение SMS сервисов в BotUI.
