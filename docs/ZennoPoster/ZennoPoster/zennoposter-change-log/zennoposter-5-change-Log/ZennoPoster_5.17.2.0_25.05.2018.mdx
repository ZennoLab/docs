### Новые фичи:

[+] Улучшено автоматическое обновление купленных шаблонов в ZennoPoster/ZennoBox.

[+] Улучшена эмуляция браузеров в отношении браузер специфичных JS Features.

[+] Добавлена эмуляция WebRTC адресов при установке прокси.

[+] Добавлена автоматическая поддержка back connect прокси.

[+] Улучшена эмуляция шрифтов.

[+] Добавлена удобная история действий, теперь можно удобно откатиться к нужной правке в проекте.

[+] Улучшения для названия проекта в логе.

[+] Добавлено взятие строки содержащей текст, удовлетворяющей регулярному выражению в операции со списком и с таблицей, по аналогии с удалением строк.

[+] Добавлена возможность передавать тело запроса для HTTP метода DELETE.

[+] Добавлена возможность отладки кода в «Общем коде».

[+] Добавлен ProjectName в класс LastError.

[+] Добавлено свойство ContentDocument для iframe элементов, для удобства взаимодействия с документом фрейма.

[+] Небольшие улучшения в UI.

### Исправленные баги:

[\] Исправлены проблемы со звуком при работе ZennoPoster.

[\] Исправлено игнорирование Http.ResponceType в методах ZennoPoster.HTTP.RequestBytes.

[\] Исправлена работа HTTP методов с socks прокси для IPv6.

[\] Исправлен поиск ReCaptcha2 sitekey на некоторых сайтах.

[\] Исправлена проверка безбраузерным проектом битности системы.

[\] Исправлены оповещения при проверке источников прокси с включенным выполнением JavaScript.
