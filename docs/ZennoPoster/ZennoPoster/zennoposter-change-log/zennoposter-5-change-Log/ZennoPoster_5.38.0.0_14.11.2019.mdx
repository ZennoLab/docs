### Новые фичи:

[+] Добавлено распознавание reCAPTCHA v3 в большинство сервисов.

[+] Вкладка переменных окружения теперь обновляется автоматически при переходах на страницы или смене таба браузера.

[+] Теперь опция «Использовать CookieContainer» в действиях HTTP запросов включена по умолчанию.

[+] Добавлена настройка «Перенос строк в C# блоке по умолчанию» в блоке Настройки → Редактор.

[+] Добавлена возможность передать пустой User-Agent или не передавать вообще в HTTP запросах через C# код. Чтобы передать пустой User-Agent необходимо установить аргументы UserAgent = «», removeDefaultHeaders = true. Чтобы не передавать User-Agent необходимо установить аргументы UserAgent = null, removeDefaultHeaders = true.

### Исправленные баги:

[\] Исправлено зависание инстансов в ZennoPoster (при ошибках Instance.PrepareInstance).

[\] Исправлена ошибка, когда список проектов в ZennoPoster мог пропасть.

[\] Исправлена ошибка, когда входные настройки могли быть сброшены.

[\] Исправлено появление предупреждения «Увеличьте размер полотна чтобы оно умещало Label» в ZennoPoster, приводившее к блокировке программы.

[\] Исправлено сохранение настроек действия «Обработка текста → Замена».

[\] Исправлено копирование переменных при копировании действия «Проект в проекте».

[\] Исправлена работа project.Profile в CodeCreator.

[\] Другие исправления и улучшения.
