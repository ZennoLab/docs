## Новые фичи:

[+] Добавлена настройка задержки между запуском баз, это позволит предотвратить пиковые нагрузки CPU на слабых компьютерах. Доступна в Настройки → Инстанс → Таймаут между запуском баз.

[+] В браузере Chrome добавлена возможность включить проверку сертификатов, для этого нужно использовать аргумент –ignore-certificate-errors=false

[+] Улучшена работа курсора при использовании метода FullEmulationMouseMove

[+] Добавлено отображение прокси в информации о запросе в окне Трафик.

[+] Добавлена возможность получать поля BrowserProfile в C# коде через project.Profile.BrowserProfile

[+] Добавлен метод ZennoPoster.SetMaxThreads

[+] В настройки источника ProxyCheker добавлена новая настройка «Удалять прежние прокси, кроме живого списка при загрузке».

## Исправленные баги:

[\] Исправлена ошибка в эмуляции часового пояса в Chrome, приводившая к проблемам на некоторых сайтах, например Avito.

[\] Исправлена работа popup вкладок в Chrome.

[\] Исправлена работа flash в Chrome.

[\] Исправлена навигация по IP в Chrome, для запуска по умолчанию добавлен флаг –ignore-certificate-errors

[\] Исправлена ошибка вызова конструктора действий в Chrome.

[\] Исправлена ошибка получения DOM и Text страницы в Chrome.

[\] Исправлены ошибки частого перезапуска баз, которые приводили к снижению скорости работы ZennoPoster в целом.

[\] Выключено автодополнение в поиске (Ctrl+F) по исходному коду страницы Text, Dom или Source.

[\] Исправлена доступность project.Json в новом проекте до нажатия «С начала».

[\] Теперь текст в кодировке windows-1251 правильно передается через multipart в альтернативном методе HTTP.

[\] Исправлено отображение ico картинок в окне Информация о запросе.

[\] Исправлено скачивание альтернативным методом HTTP, теперь расширение файла устанавливается корректно.

[\] Исправлены ошибки, приводящие к остановке проверки прокси в ProxyCheker.

[\] Исправлена ошибка, при которой в ProxyCheker иногда не работал автопоиск.

[\] Теперь при нажатии «С начала» project.Context очищается.

[\] Исправлена инициализация глобальных переменных в проекте, теперь они не перетираются, если уже используются в программе.
