## ZennoPoster - это программный пакет, который состоит из двух приложений  
Они позволяют автоматизировать ваши действия в веб-браузере. Данное программное обеспечение подойдет для каждого пользователя - как для SEO-шника, занимающегося продвижением в сети, так и для опытного веб-программиста, кодирующего сложных ботов.

### Пакет ZennoPoster включает в себя:
#### ZennoPoster.  
Основное приложение, предназначенное для выполнения автоматизированных шаблонов действий (ботов) в браузере.  

Данное приложение позволяет управлять потоками при выполнении шаблонов, использовать различные прокси для Ваших ботов, а также имеет [**встроенный Планировщик**](../ZennoPoster/Project_delivery/Project_settings/Schedule_planner/General_Information_About_Schedule_Planner) для выполнения шаблонов по расписанию.

#### ProjectMaker.  
Приложение для создания автоматизированных шаблонов действий. Именно в нем Вы будете записывать и автоматизировать свои действия на веб-страницах.  

Сделать это достаточно легко - программа имеет набор [**Cтандартных действий (экшенов)**](../category/actions-in-projectmaker) для веб-браузера. Из этих блоков в итоге конструируется шаблон.  

Также для создания шаблона важен режим записи действий, который добавляет в шаблон все ваши действия в браузере.  

Помимо прочего в ProjectMaker можно работать с:  
- ***[Таблицами](/zennoposter/ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Tables)***;  
- ***[Google Таблицами](../ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Tables/Operations_on_Google_Sheets)***;  
- ***[Списками](../ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Lists/List_Operations)*** (xlsx, ods, csv, либо свой формат);  
- ***[Простыми файлами](../ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Files)***;  
- ***[Базами данных](../ProjectMaker/Project-editor/Actions-in-ProjectMaker-Actions-Blocks/Data/Databases)***. 

Это значительно упрощает работу SEO-специалистов.
