# ZennoPoster MCP — Руководство по настройке для AI-ассистентов

> **Требования:** Перед подключением любого AI-ассистента должен быть запущен ProjectMaker. MCP-серверы запускаются автоматически вместе с ProjectMaker и работают по адресам:
> - **BrowserMCP** (управление браузером) → `http://localhost:6108`
> - **ProjectMCP** (управление проектом) → `http://localhost:6107`

---

# 1. GitHub Copilot

## Шаги

1. Убедитесь, что ProjectMaker запущен.
2. Откройте папку профиля пользователя: нажмите `Win + R`, введите `%USERPROFILE%`, нажмите Enter.
3. Создайте в этой папке файл `.mcp.json`  
   (пример: `C:\Users\YourName\.mcp.json`)
4. Вставьте следующий код:

```json
{
  "servers": {
    "BrowserMCP": {
      "type": "http",
      "url": "http://localhost:6108"
    },
    "ProjectMCP": {
      "type": "http",
      "url": "http://localhost:6107"
    }
  }
}
```

5. Перезапустите Visual Studio (или перезагрузите расширение Copilot).
6. Теперь Copilot получит доступ к обоим MCP-серверам во всех рабочих пространствах.

---

# 2. Claude Code (CLI)

## Шаги

1. Убедитесь, что ProjectMaker запущен.
2. Откройте терминал.
3. Выполните следующие команды:

```sh
claude mcp add BrowserMCP --transport http http://localhost:6108
claude mcp add ProjectMCP --transport http http://localhost:6107
```

4. Проверьте, что серверы зарегистрированы:

```sh
claude mcp list
```

5. MCP-серверы теперь доступны глобально во всех сессиях Claude Code.

> Чтобы удалить их позже:
>
> `claude mcp remove BrowserMCP`
>
> `claude mcp remove ProjectMCP`

---

# 3. OpenAI Codex CLI

## Шаги

1. Убедитесь, что ProjectMaker запущен.
2. Откройте терминал.
3. Выполните следующие команды:

```sh
codex mcp add BrowserMCP --url http://localhost:6108
codex mcp add ProjectMCP --url http://localhost:6107
```

4. Проверка:

```sh
codex mcp list
```

Покажи структуру текущего проекта —

```
Открой браузер,
перейди на страницу логина,

отправь форму

в переменную "LastVisitedUrl".
```

Получи структуру проекта,
найди все действия "NavigateToUrl"
и выведи список их URL.
