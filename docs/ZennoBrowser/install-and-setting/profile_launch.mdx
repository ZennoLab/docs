# Запуск профиля
<DisclaimerNotice />

 1. Найдите созданный профиль в папке.
 2. Используйте элементы управления в столбце "Управление".
 3. Нажмите кнопку запуска профиля.

 ![profile_launch1](..\install-and-setting\assets\profile_launch\profile_launch1.png)

### **Массовые операции (для продвинутых пользователей)**

 1. Создание множества профилей:
 2. Выберите "Массовое создание профилей".
 3. Укажите количество (до 1000 профилей).
 4. Настройте параметры для всех профилей одновременно.
 5. Выберите режим использования прокси.

![profile_launch2](..\install-and-setting\assets\profile_launch\profile_launch2.png)

### **Управление группой профилей:**

 1. Используйте чекбоксы для выбора нескольких профилей.
 2. Выполняйте массовые действия:
 - Запуск/остановка профилей;
 - Замена прокси;
 - Перемещение в папки;
 - Управление тегами;
 - Экспорт cookie-файлов.
 
### **Полезные функции интерфейса**

**Навигация и поиск:**
 - Поиск — по имени и ID профиля;
 - Сортировка — по любому столбцу таблицы;
 - Фильтрация — используйте теги для быстрого поиска;
 - Папки — упорядочивайте профили.

**ID профиля** нужен для работы в режиме интеграции с ZennoPoster. Для того чтобы его получить, нужно в самом ZennoBrowser навести курсор на поле с нужным профилем, в столбце “Управление” нажать на три точки и выбрать пункт “Копировать ID”:

![profile_launch3](..\install-and-setting\assets\profile_launch\profile_launch3.png)
![profile_launch4](..\install-and-setting\assets\profile_launch\profile_launch4.png)

**Сортировка** позволяет упорядочить список в любом удобном формате:

![profile_launch5](..\install-and-setting\assets\profile_launch\profile_launch5.png)

**Быстрый поиск** по тегам реализуется через нажатие на значок фильтра в правом верхнем углу поля:

![profile_launch6](..\install-and-setting\assets\profile_launch\profile_launch6.png)

**Папки** позволяют хранить профили локализованно: 

![profile_launch7](..\install-and-setting\assets\profile_launch\profile_launch7.png)

**Отображение:**
 - До 1000 профилей на странице (Менеджер профилей);
 - До 1000 прокси на странице (Менеджер прокси);
 - Настраиваемые столбцы таблицы;
 - Скрытие ненужных столбцов.

Чтобы упорядочить столбцы, нужно пролистать вправо при помощи ползунка, нажать на шестерёнку и задать нужные настройки отображения:

### **Рекомендации**

💡 Совет: Для эффективной работы рекомендуется использовать наш сервис [ZennoProxy](https://zenno.club/discussion/forums/zennoproxy.331/).

**Для начинающих:**

 1. Начните с создания 1-2 профилей для тестирования.
 2. Используйте локальные профили для начала.
 3. Создавайте папки для организации профилей.
 4. Добавляйте осмысленные имена и теги.

**Для опытных пользователей:**
 1. Используйте облачные профили для синхронизации.
 2. Настройте списки прокси по регионам/назначению.
 3. Применяйте массовые операции для эффективности.
 4. Регулярно проверяйте работоспособность прокси.
