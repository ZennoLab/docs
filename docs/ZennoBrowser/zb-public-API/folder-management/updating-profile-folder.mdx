**Описание:** Этот метод можно использовать для обновления имени папки профиля.

#### **Параметры запроса:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| profileFolderId | string | uuid |  | Уникальный идентификатор папки профиля, которую нужно обновить. |
| name | string |  |  | Новое имя папки профиля. |
| workspaceId | integer | int64 | \-1 | Идентификатор рабочего пространства, связанного с папкой профиля. По умолчанию \-1, если не указан. |

:::note
ID редактируемой папки профиля должен быть указан в фигурных скобках `{ }` в пути URL.
:::  

#### **Пример запроса:**

**PUT**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profile_folders/{profileFolderId}?name=&workspaceId=-1' \
  --request PUT \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Net.Http.Headers;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Put,
    RequestUri = new Uri("http://localhost:8160/v1/profile_folders/{profileFolderId}?name=&workspaceId=-1"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

#### **Ответ API:**

| Response code | Result |
| :---: | :---: |
| `200 OK` | Успех |
| `500 Error` | Внутренняя ошибка сервера |

**Успешный ответ (200 OK):**

При успешном обновлении содержимое не возвращается.

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
