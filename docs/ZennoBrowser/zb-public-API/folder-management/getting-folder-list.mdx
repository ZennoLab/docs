**Описание:** Этот запрос получает список папок, доступных в указанном рабочем пространстве.  
Дополнительно вы можете ограничить количество результатов, задать фильтры или указать условия сортировки.

#### **Параметры запроса:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| workspaceId | integer | int64 | \-1 | ID рабочего пространства, в котором будет создана папка профилей. По умолчанию \-1, если не указано. |
| start | integer | int32 | 0 | Индекс первой папки (начиная с нуля). |
| total | integer | int32 | 1000 | Максимальное количество папок для получения. |
| id | string | uuid | (empty) | Уникальный идентификатор папки (необязательный фильтр). |
| name | string |  | (empty) | Имя папки (необязательный фильтр). |
| sorting | string |  | (empty) | Условие сортировки: Id, Name, FolderType, Quantity (необязательный фильтр). |
| location | string (enum) |  | Local | Расположение папки: `"Local"` или `"Cloud"`. |

#### 

#### **Пример запроса:**

**GET**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profile_folders?workspaceId=-1&start=0&total=1000&id=&name=&sorting=&location=' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**С#:**

```csharp
using System.Net.Http.Headers;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Get,
    RequestUri = new Uri("http://localhost:8160/v1/profile_folders?workspaceId=-1&start=0&total=1000&id=&name=&sorting=&location="),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

#### **Ответ API:**

| Response code | Result |
| :---: | :---: |
| `200 OK` | Успешно |
| `500 Error` | Внутренняя ошибка сервера |

**Успешный ответ (200 OK):**

```json
{
  "totalCount": 1,
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000",
      "name": null,
      "location": "Local",
      "quantity": 1
    }
  ]
}
```

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
