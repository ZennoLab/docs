**Описание:** Этот метод возвращает список браузерных процессов, доступных для текущего пользователя, с подробной информацией.  
Результаты можно отфильтровать по ID профиля или ID процесса, а также при необходимости отсортировать или ограничить по количеству возвращаемых записей.

:::warning
Эти действия применяются **только** к экземплярам браузера, запущенным через API.
:::

#### **Параметры запроса:**

| Parameter | Type | Format | Default | Description |
| ----- | ----- | ----- | ----- | ----- |
| workspaceId | integer | int64 | \-1 | Идентификатор рабочего пространства. `-1` означает рабочее пространство по умолчанию. |
| start | integer | int32 | 0 | Начальный индекс для постраничного вывода |
| total | integer | int32 | 1000 | Максимальное количество результатов для возврата |
| profileId | string | uuid | (empty) | Фильтр по ID профиля (опционально). |
| processId | integer | int32 | (empty) | Фильтр по ID процесса браузера (опционально). |
| sorting | string |  | (empty) | Параметры сортировки: ConnectionString, ProcessId, ProfileId (опционально). |
 

#### **Пример запроса:**

**GET**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/browser_instances?workspaceId=-1&start=0&total=1000&profileId=&processId=&sorting=' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Net.Http.Headers;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Get,
    RequestUri = new Uri("http://localhost:8160/v1/browser_instances?workspaceId=-1&start=0&total=1000&profileId=&processId=&sorting="),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

#### **Ответ API:**

| Response code | Result |
| :---: | :---: |
| `200 OK` | Успешно |
| `500 Error` | Внутренняя ошибка сервера |

**Успешный ответ (200 OK):**

```json
{
  "totalCount": 1,
  "items": [
    {
      "profileId": "123e4567-e89b-12d3-a456-426614174000",
      "processId": 1,
      "connectionString": null
    }
  ]
}
```

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
