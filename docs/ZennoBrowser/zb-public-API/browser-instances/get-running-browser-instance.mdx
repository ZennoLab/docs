**Описание:** Этот метод возвращает данные запущенного экземпляра браузера для указанного профиля. Поле `connectionString` содержит WebSocket-строку для подключения к браузеру по Chrome DevTools Protocol (CDP), а поле `processId` — идентификатор процесса (PID) браузера. Если для профиля нет запущенного экземпляра, API возвращает ошибку.

#### **Параметры запроса:**

| Параметр | Тип | Формат | Значение по умолчанию | Описание |
| :-----: | :-----: | :-----: | :-----: | :----- |
| profileId | string | uuid | (required) | Уникальный идентификатор профиля. |
| workspaceId | integer | int64 | -1 | Идентификатор рабочего пространства. Значение `-1` означает рабочее пространство по умолчанию. |

#### **Пример запроса:**

**POST**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/browser_instances/get_running?profileId=123e4567-e89b-12d3-a456-426614174000&workspaceId=-1' \
  --request POST \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Post,
    RequestUri = new Uri("http://localhost:8160/v1/browser_instances/get_running?profileId=123e4567-e89b-12d3-a456-426614174000&workspaceId=-1"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**
```
http://localhost:8160/v1/browser_instances/get_running?profileId=123e4567-e89b-12d3-a456-426614174000&workspaceId=-1
```

**Дополнительно:**  
User-Agent: `{-Profile.UserAgent-}`  
Api-Token: токен из **UserArea2**.

#### **Ответ API:**

| Код ответа | Результат |
| :---: | :---: |
| `200 OK` | Успешно |
| `401 Unauthorized` | Не авторизован |
| `403 Forbidden` | Доступ запрещен |
| `409 Conflict` | Для указанного профиля нет запущенного экземпляра браузера |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

#### **Поля ответа:**

| Поле | Тип | Формат | Описание |
| :-----: | :-----: | :-----: | :----- |
| connectionString | string |  | WebSocket-строка для подключения к браузеру по Chrome DevTools Protocol (CDP). |
| processId | integer | int32 | Идентификатор процесса (PID) браузера. |
| profileId | string | uuid | Уникальный идентификатор профиля. |

**Успешный ответ (200 OK):**

```json
{
  "connectionString": "ws://127.0.0.1:12345/devtools/browser/example",
  "processId": 1234,
  "profileId": "123e4567-e89b-12d3-a456-426614174000"
}
```

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
