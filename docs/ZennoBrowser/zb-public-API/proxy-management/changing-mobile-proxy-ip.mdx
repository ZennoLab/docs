**Описание:** Этот метод инициирует смену IP-адреса для указанного мобильного прокси. У прокси должен быть настроен корректный URL для смены IP.

#### **Параметры запроса:**

| Параметр | Тип | Формат | Значение по умолчанию | Описание |
| :-----: | :-----: | :-----: | :-----: | :----- |
| proxyId | string | uuid | (required) | Уникальный идентификатор прокси, для которого необходимо сменить IP-адрес. |
| workspaceId | integer | int64 | -1 | Идентификатор рабочего пространства, в котором находится прокси. Значение `-1` означает рабочее пространство по умолчанию. |

#### **Пример запроса:**

**POST**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/proxies/123e4567-e89b-12d3-a456-426614174000/change_ip?workspaceId=-1' \
  --request POST \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Post,
    RequestUri = new Uri("http://localhost:8160/v1/proxies/123e4567-e89b-12d3-a456-426614174000/change_ip?workspaceId=-1"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

#### **Ответ API:**

| Код ответа | Результат |
| :---: | :---: |
| `200 OK` | Успешно |
| `401 Unauthorized` | Не авторизован |
| `403 Forbidden` | Доступ запрещен |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

**Успешный ответ (200 OK):**

Тело ответа отсутствует.

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
