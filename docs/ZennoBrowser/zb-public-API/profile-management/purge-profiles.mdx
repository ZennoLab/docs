**Описание:** Метод безвозвратно удаляет несколько профилей браузера из корзины.

:::warning
После выполнения операции профили и их данные невозможно восстановить.
:::

#### **Параметры запроса:**

| Parameter | Type | Format | Default | Description |
| :-----: | :-----: | :-----: | :-----: | :----- |
| workspaceId | integer | int64 | \-1 | Идентификатор рабочего пространства. `-1` означает рабочее пространство по умолчанию. |

Тело запроса — JSON-массив идентификаторов профилей в формате UUID.

#### **Пример запроса:**

**DELETE**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profiles/wastebasket/delete_bulk?workspaceId=-1' \
  --request DELETE \
  --header 'Api-Token: YOUR_SECRET_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '["123e4567-e89b-12d3-a456-426614174000","323e4567-e89b-12d3-a456-426614174000"]'
```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Delete,
    RequestUri = new Uri("http://localhost:8160/v1/profiles/wastebasket/delete_bulk?workspaceId=-1"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
request.Content = new StringContent("[\"123e4567-e89b-12d3-a456-426614174000\",\"323e4567-e89b-12d3-a456-426614174000\"]", Encoding.UTF8, "application/json");
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**
```
http://localhost:8160/v1/profiles/wastebasket/delete_bulk?workspaceId=-1
```

#### **Ответ API:**

| Код ответа | Результат |
| :---: | :---: |
| `200 OK` | Профили удалены; тело ответа отсутствует |
| `401 Unauthorized` | Не авторизован |
| `403 Forbidden` | Доступ запрещен |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

**Ответ с ошибкой (500):**

```json
{
  "message": null
}
```
