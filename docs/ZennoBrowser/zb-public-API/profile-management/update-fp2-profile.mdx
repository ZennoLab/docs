**Описание:** Изменяет только переданные параметры профиля fp2. Пустое значение параметра эмуляции сохраняет текущее значение.

Для ручных значений `screen`, `languages` и GPU сначала получите допустимые значения через [метод получения допустимых значений](./get-fp2-profile-choices). Пустые `proxyServerId` и `presetId` снимают соответствующую настройку.

#### **Параметры запроса:**

| Parameter | Type | Format | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| profileId | string | uuid | required | Уникальный идентификатор профиля (обязательный). |
| workspaceId | integer | int64 | -1 | Идентификатор рабочего пространства; `-1` означает выбранное в ZennoBrowser рабочее пространство. |
| folderId | string | uuid | (пусто) | Идентификатор папки профиля. |
| name | string |  | (пусто) | Имя профиля. |
| notes | string |  | (пусто) | Дополнительные заметки профиля. |
| tags | string |  | (пусто) | Теги профиля, разделённые пробелами. |
| commandLineArguments | string |  | (пусто) | Дополнительные аргументы командной строки браузера. |
| proxyServerId | string |  | (пусто) | Идентификатор прокси-сервера. Не передавайте параметр, чтобы сохранить значение; пустая строка удаляет настройку. |
| presetId | string |  | (пусто) | Идентификатор пресета для начальной конфигурации профиля. Не передавайте параметр, чтобы сохранить значение; пустая строка удаляет настройку. |
| screen | string |  |  | Экран: `auto`, `real` или токен из [списка допустимых значений](./get-fp2-profile-choices). Значение, не поддерживаемое устройством, может быть отклонено. |
| cpu | string |  |  | Количество логических процессоров: `auto`, `real` или число. |
| memory | string |  |  | Объём памяти устройства: `auto`, `real` или число. |
| locale | string |  |  | Локаль: `auto`, `real` или код, например `en-US`. |
| timeZone | string |  |  | Часовой пояс: `auto`, `real` или идентификатор IANA, например `Europe/Berlin`. |
| languages | string |  |  | Языки: `auto`, `real` или список через `;`, например `en-US;ru`. Значение, не поддерживаемое устройством, может быть отклонено. |
| gpuVendor | string |  |  | Производитель GPU: `auto`, `real` или имя из [списка допустимых значений](./get-fp2-profile-choices); при имени требуется `gpuRenderer`. Значение, не поддерживаемое устройством, может быть отклонено. |
| gpuRenderer | string |  |  | Рендерер GPU; используется только вместе с именем производителя в `gpuVendor`. |
| canvasNoise | string |  |  | Шум Canvas: `auto`, `on` или `off`. |
| clientRectsNoise | string |  |  | Шум ClientRects: `auto`, `on` или `off`. |
| webRtc | string |  |  | Режим WebRTC: `auto`, `real` или `hide`. |
| mediaDevices | string |  |  | Виртуальные медиоустройства: `auto` или `real`. |
| imagesVideosDownload | string |  |  | Загрузка изображений и видео: `on` или `off`. |

#### **Пример запроса:**

**PUT**

**CURL:**

```bash
curl -X PUT 'http://localhost:8160/v1/profiles/fp2/123e4567-e89b-12d3-a456-426614174000?workspaceId=-1' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Net.Http;
var client = new HttpClient();
using var request = new HttpRequestMessage(HttpMethod.Put, "http://localhost:8160/v1/profiles/fp2/123e4567-e89b-12d3-a456-426614174000?workspaceId=-1");
request.Headers.Add("Api-Token", "YOUR_SECRET_TOKEN");
using var response = await client.SendAsync(request);
response.EnsureSuccessStatusCode();
Console.WriteLine(await response.Content.ReadAsStringAsync());
```

**Cube:**

```
http://localhost:8160/v1/profiles/fp2/123e4567-e89b-12d3-a456-426614174000?workspaceId=-1
```

#### **Ответ API:**

| Код ответа | Результат |
| :--- | :--- |
| `200` | Успешно |
| `400` | Недопустимое значение параметра эмуляции |
| `401` | Не авторизован |
| `403` | Доступ запрещён |
| `500` | Внутренняя ошибка сервера |

При коде `400` поле `message` указывает недопустимую настройку и разрешённые значения.
