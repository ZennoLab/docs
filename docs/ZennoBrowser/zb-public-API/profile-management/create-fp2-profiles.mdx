**Описание:** Создаёт несколько профилей fp2 с одинаковыми настройками. Значения `auto` определяются отдельно для каждого профиля.

Все параметры эмуляции необязательны и чувствительны к регистру. Пустая строка позволяет движку выбрать значение. Ручные значения экрана, языков или GPU могут быть отклонены, если созданное устройство их не поддерживает.

#### **Параметры запроса:**

| Параметр | Тип | Формат | По умолчанию | Описание |
| :-----: | :-----: | :-----: | :-----: | :----- |
| count | integer | int32 |  | Количество создаваемых профилей. |
| workspaceId | integer | int64 | -1 | Идентификатор рабочего пространства; `-1` означает выбранное в ZennoBrowser рабочее пространство. |
| folderId | string | uuid | (пусто) | Идентификатор папки профиля. |
| tags | string |  | (пусто) | Теги профиля, разделённые пробелами. |
| notes | string |  | (пусто) | Дополнительные заметки профиля. |
| proxyServerId | string | uuid | (пусто) | Идентификатор прокси-сервера. |
| presetId | string | uuid | (пусто) | Идентификатор пресета для начальной конфигурации профиля. |
| commandLineArguments | string |  | (пусто) | Дополнительные аргументы командной строки браузера. |
| osVersion | string |  | (пусто) | Версия ОС для отпечатка: `win10` или `win11`; пустое значение определяет ОС хоста автоматически. |
| screen | string |  | (пусто) | Экран: `auto`, `real` или токен из [списка допустимых значений](./get-fp2-profile-choices). Значение, не поддерживаемое устройством, может быть отклонено. |
| cpu | string |  | (пусто) | Количество логических процессоров: `auto`, `real` или число. |
| memory | string |  | (пусто) | Объём памяти устройства: `auto`, `real` или число. |
| locale | string |  | (пусто) | Локаль: `auto`, `real` или код, например `en-US`. |
| timeZone | string |  | (пусто) | Часовой пояс: `auto`, `real` или идентификатор IANA, например `Europe/Berlin`. |
| languages | string |  | (пусто) | Языки: `auto`, `real` или список через `;`, например `en-US;ru`. После создания каждого профиля его поддерживаемые языки можно посмотреть в [списке допустимых значений](./get-fp2-profile-choices). Указанное при создании неподдерживаемое значение может быть отклонено. |
| gpuVendor | string |  | (пусто) | Производитель GPU: `auto`, `real` или имя из [списка допустимых значений](./get-fp2-profile-choices); при имени требуется `gpuRenderer`. Значение, не поддерживаемое устройством, может быть отклонено. |
| gpuRenderer | string |  | (пусто) | Рендерер GPU; используется только вместе с именем производителя в `gpuVendor`. |
| canvasNoise | string |  | (пусто) | Шум Canvas: `auto`, `on` или `off`. |
| clientRectsNoise | string |  | (пусто) | Шум ClientRects: `auto`, `on` или `off`. |
| webRtc | string |  | (пусто) | Режим WebRTC: `auto`, `real` или `hide`. |
| mediaDevices | string |  | (пусто) | Виртуальные медиоустройства: `auto` или `real`. |
| imagesVideosDownload | string |  | (пусто) | Загрузка изображений и видео: `on` или `off`. |

#### **Пример запроса:**

**POST**

**CURL:**

```bash
curl -X POST 'http://localhost:8160/v1/profiles/fp2/create_bulk?workspaceId=-1&count=2' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Net.Http.Headers;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Post,
    RequestUri = new Uri("http://localhost:8160/v1/profiles/fp2/create_bulk?workspaceId=-1&count=2"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**

```
http://localhost:8160/v1/profiles/fp2/create_bulk?workspaceId=-1&count=2
```

#### **Ответ API:**

| Код ответа | Результат |
| :--- | :--- |
| `200` | Успешно |
| `400` | Недопустимое значение параметра эмуляции |
| `401` | Не авторизован |
| `403` | Доступ запрещён |
| `500` | Внутренняя ошибка сервера |

**Пример успешного ответа (200):**

```json
[
  "123e4567-e89b-12d3-a456-426614174000"
]
```

При коде `400` поле `message` указывает недопустимую настройку и разрешённые значения.
