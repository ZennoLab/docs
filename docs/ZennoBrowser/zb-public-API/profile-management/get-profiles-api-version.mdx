**Описание:** Метод возвращает версию документа Profiles API. Версия изменяется при изменении этого API-документа.

#### **Параметры запроса:**

Для этого метода параметры запроса не требуются.

#### **Пример запроса:**

**GET**  
**CURL:**

```bash
curl 'http://localhost:8160/v1/profiles/api_version' \
  --header 'Api-Token: YOUR_SECRET_TOKEN'
```

**C#:**

```csharp
using System.Text;
var client = new HttpClient();
var request = new HttpRequestMessage
{
    Method = HttpMethod.Get,
    RequestUri = new Uri("http://localhost:8160/v1/profiles/api_version"),
    Headers =
    {
        { "Api-Token", "YOUR_SECRET_TOKEN" },
    },
};
using (var response = await client.SendAsync(request))
{
    response.EnsureSuccessStatusCode();
    var body = await response.Content.ReadAsStringAsync();
    Console.WriteLine(body);
}
```

**Cube:**
```
http://localhost:8160/v1/profiles/api_version
```

#### **Ответ API:**

| Код ответа | Результат |
| :---: | :---: |
| `200 OK` | Версия документа Profiles API |
| `401 Unauthorized` | Не авторизован |
| `403 Forbidden` | Доступ запрещен |

**Успешный ответ (200 OK):**

```json
"1.2"
```
