## **Главное окно (источники)** 


### **Описание**

![description_ru.png](.\assets\Sources\description_ru.png)

На этой вкладке отображаются все добавленные в программу источники прокси.

Здесь находятся элементы управления, которые позволяют менять настройки источников, удалять их, добавлять, увидеть количество прокси и др.


### **Панель управления**

![managing_panel_ru.png](.\assets\Sources\managing_panel_ru.png)

#### **Помощник**
Позволяет легко добавить прокси или источник для проверки. Подробно описан в статье [Помощник].

#### **Добавить прокси**
Позволяет добавить прокси списком.

![add_proxy_ru.png](.\assets\Sources\add_proxy_ru.png)

#### **Добавить источник**
Позволяет добавить источник сбора прокси. При клике открывается окно настроек источника. Подробнее об этом окне можно прочитать в статье [Настройки источников].
 
#### **Настройки источника**
Эта кнопка позволяет изменить настройки добавленных источников.
После клика по кнопке *Настройки источника* откроются настройки, которые подробно описаны в статье [Настройки источников].

**Удалить**

С помощью кнопки удаления вы сможете удалить ненужные источники. Для этого выделите источники и нажмите кнопку *Удалить*.

Удаление источника также повлечёт удаление всех прокси этого источника.

#### **Сохранить**
С помощью этой кнопки можно сохранить адреса источников в файл.

#### **Загрузить прокси**
Эта функция позволяет загрузить прокси из источника.

#### **Проверить прокси**
После того как вы загрузили прокси с источника, можете проверить их, чтобы узнать, сколько из этих прокси живые.

После нажатия этой кнопки в верхней части таблицы появится шкала прогресса. С помощью кнопки *Отмена*, справа от шкалы, можно остановить процесс проверки.

![proxy_checking_ru.png](.\assets\Sources\proxy_checking_ru.png)

#### **Допроверить живые**
Позволяет повторно проверить уже найденные живые прокси источников.
Появится такая же шкала прогресса, как и в режиме *Проверить прокси*.

#### **Развернуть**
Кнопка *Развернуть* разворачивает группу со списком источников, если она была до этого в свёрнутом виде.

![expand_ru](.\assets\Sources\expand_ru.gif)

#### **Свернуть**
Кнопка *Свернуть* сворачивает группу со списком источников.

![collapse_ru](.\assets\Sources\collapse_ru.gif)

#### **Панель авто-режима**
С помощью этой кнопки можно активировать панель для быстрого управления загрузкой и проверкой прокси. Появляется такая панель над списком источников:

![auto_panel_ru.png](.\assets\Sources\auto_panel_ru.png)

В левой части панели отображено количество источников (живые источники/общее количество).
Справа:
 - **Загрузить** —  загрузка прокси из источников.
 - **Автопоиск** — автоматический поиск новых источников прокси.
 - **Проверка** — проверка найденных прокси.

#### **Время загрузки**
Кнопка *Время загрузки* добавляет три новых столбца в таблицу источников “Интервал загрузки“, “Следующая загрузка“, ”Рейтинг” (они будут описаны ниже).

#### **Удалить все прокси**
Удаляет все прокси из программы.

#### **Чёрный список**

![blacklist1_ru.png](.\assets\Sources\blacklist1_ru.png)

Если прокси, содержащиеся в источнике, по каким-либо причинам не подходят для выполнения проекта, или сам источник не вызывает доверия, а ZennoProxyChecker продолжает добавлять и проверять прокси с этих источников, тратя драгоценное время и ресурсы, то такой источник можно добавить в *Чёрный список* и вы больше его не увидите.

![blacklist2_ru.png](.\assets\Sources\blacklist2_ru.png)

**Окно управления чёрным списком**

**Добавление в ЧС** — для ручного добавления введите адрес в поле и нажмите клавишу Enter. Также можно добавить через контекстное меню (описано ниже в статье, в разделе [Контекстное меню]).

**Удаление из ЧС** — выделите источник, кликнув слева от него (прямоугольник с цифрой 2 на скриншоте) и нажмите клавишу Delete.

**Импорт/экспорт** — эти кнопки позволяют сохранить (экспорт) текущий ЧС или загрузить (импорт) ранее сохранённый.

 - **Рейтинг** падает, если не удалось получить прокси из источника.

#### **Выделение сразу нескольких источников**
В таблице можно выделить сразу несколько источников для применения настроек сразу ко всем, а не по одному. Существует несколько способов сделать это:

##### **Ctrl**
Мышь + клавиша Ctrl — позволяет выделять несколько источников, но каждый по отдельности.

##### **Shift**
Мышь + клавиша Shift — позволяет выделять несколько источников подряд. Выделите один источник, нажмите Shift , затем кликните по другому источнику ниже или выше уже выбранного. В результате все, которые находятся между ними, будут также выделены.

##### **Выделение группы**
Если кликнуть по названию группы, то будут выделены все находящиеся в ней источники.

![group_selection_ru.png](.\assets\Sources\group_selection_ru.png)

##### **Ctrl+A**
Нажатие этой комбинации клавиш выделит все прокси в развёрнутых группах.

### **Вкладка “Источник прокси”**

#### **Настройки парсинга**

![parcing_settings_ru.png](.\assets\Sources\parcing_settings_ru.png)

**Адрес** — URL-адрес, с которого будут собираться прокси.

**Выполнение JavaScript** — эта настройка отвечает за выполнение JavaScript на странице сайта, с которого будут парситься прокси. В выпадающем меню выберите один из вариантов:
 - *Отключено*;
 - *Включено*;
 - *Автоопределение*.

**Удалять прежние прокси при запуске** — при каждом новом сборе прокси, собранные в прошлый раз, будут удаляться.

**Удалять прежние прокси, кроме живых, при загрузке** — при каждом новом сборе прокси будут удаляться все прокси из базы, кроме живых. Настройка активируется после включения *Удалять прежние прокси при запуске*.

**Удалять прежние прокси из живого списка при загрузке** — нужно ли удалять прокси из списка живых при каждом новом сборе прокси? Настройка активируется после включения *Удалять прежние прокси при запуске*.

**Добавлять адреса локальных сетей** — выберите этот пункт, если хотите, чтобы ZennoProxyChecker собирал также адреса локальных сетей.

**Парсить текст RSS** — при установке флага помимо текста источника ищутся прокси в тексте RSS ленты, если она есть.

**Парсить ссылки RSS** — если RSS лента есть, из неё парсятся все ссылки и обрабатываются так же, как автоматически добавленные ресурсы, т.е. появляются в списке источников только те, на которых нашлись прокси. Новые источники помечаются меткой “RSS”.


#### **Настройки проверки прокси**

![checking_settings_ru.png](.\assets\Sources\checking_settings_ru.png)

**Режим проверки:**

 - **Проверять прокси** — будет происходить проверка прокси на работоспособность;
 - **Считать все прокси живыми** — все прокси будут считаться живыми без проверки.

**Протокол** — здесь стоит выбрать протокол прокси, который используется в этом источнике. Если вы не знаете заранее протокол, то можете выбрать пункт *Определять автоматически* и тогда ProxyChecker самостоятельно вычислит его.

Возможные варианты:
 - HTTP;
 - SOCKS4;
 - SOCKS5;
 - Определять автоматически.


**Проверять POST** — проверяется, поддерживает ли прокси POST-запрос.

**POST** — запрос, который часто используется при отправке форм.

**Проверять HTTPS** — дополнительная проверка на доступность по HTTPS. Может снизить производительность.

**Измерить скорость** — в процессе проверки будет измерена также пропускная способность прокси. Включение этой настройки снижает производительность и увеличивает потребление трафика.

**Ждать ответ** — максимальное время ответа после запроса.  Если по истечении указанного здесь времени прокси не вернул ответ, то он считается нерабочим.

**Делать повторный запрос** — послать запрос ещё раз в случае успеха первого. Отсеивает плохие прокси, но увеличивает время проверки.

**Проверять на бан в Google** — прокси проверяется на бан в Google.


#### **Проверять на наличие в чёрных списках**

![blacklist_checking_ru.png](.\assets\Sources\blacklist_checking_ru.png)

Таблица появляется только после включения настройки.

Прокси проверяется на наличие в чёрных списках.

При клике по кнопке *Добавить* появится список из доступных адресов для проверки.

Кнопка *Удалить* позволяет удалить выделенные адреса из списка добавленных.

Некоторые DNS-сервера не пропускают большое количество запросов, из-за этого возможны ошибочные проверки.  В таких случаях рекомендуется настроить в системе использование DNS вашего провайдера.


#### **Проверка на любой URL**

![URL_checking_ru.png](.\assets\Sources\URL_checking_ru.png)

Эта функция предназначена для проверки, забанен ли прокси на конкретном сайте. **Чтобы выбрать правило**, нужно отметить чекбокс слева от названия правила (на скриншоте выбрано правило twitter).

При активации функции у вас появится дополнительное меню для настройки (по умолчанию там добавлено два правила для пример).

##### **Добавление нового URL для проверки**

Чтоб добавить новое правило, нажмите кнопку *Новое правило*. Откроется окно настроек:

![new_URL_ru.png](.\assets\Sources\new_URL_ru.png)

 - **Имя правила** — введите любое название, это никак не повлияет на проверку.
 - **Адрес (URL)** — введите URL-адрес сайта, на котором будет проходить проверку прокси.
 - **Иконка** — при желании можно загрузить favicon сайта, для этого нажмите кнопку *Загрузить*.
 - **Тип проверки** 
 
 —> *Содержит текст* — этот тип проверки позволяет проверить, содержится ли определённый текст на проверяемом сайте. Текст для проверки пишите в окне *Значение*.
 
 —> *Не содержит текст* — будет происходить проверка на отсутствие текста на сайте. Текст для проверки пишите в окне *Значение*.
 
 —> *Regex* —  здесь пишите значение регулярного выражения, в соответствии с которым будет происходить проверка.

Используйте макрос ``` json {-ProxyIp-} ```, чтобы подставить текущий прокси запроса в проверочное значение.

**Проверка**

![testing_ru.png](.\assets\Sources\testing_ru.png)

В этом разделе производится тестирование ваших настроек.

В поле **Адрес страницы**, автоматически подставляется URL-адрес, который вы добавили в поле *Адрес (URL)*.

**Прокси** — вы можете выбрать, использовать прокси или нет.

Формат protocol://login:password@ip:port или protocol://ip:port

После внесения всех настроек нажмите кнопку **Тестировать (1)**, и в графе **Результат (2)** отобразится результат теста: *Тест пройден* или *Тест не пройден*.

![testing2_ru.png](.\assets\Sources\testing2_ru.png)

Нажав на слово **Показать (3)**, вы увидите ответ сервера на тестовый запрос. Здесь можно проанализировать исходный код ответа и понять, почему тест мог провалиться.

![testing3_ru.png](.\assets\Sources\testing3_ru.png)

После того как вы всё настроили, нажмите *ОК* для сохранения правила.

### **Вкладка “Авто-режим”**

![auto_proxy_ru.png](.\assets\Sources\auto_proxy_ru.png)

#### **Настройка автоматического парсинга**
**Интервал загрузки проксей с источника** — пауза между сбором прокси из источника.

Например, если вы поставите интервал 20 минут, то прокси будут собираться каждые 20 минут.

**Проверить прокси только один раз** — при включении этой настройки все прокси с одного источника будут проверяться только один раз.

#### **Настройка автоматической проверки**
**Минимальный интервал после предыдущей проверки** — интервал между проверками прокси.

**Минимальный интервал после взятия из живого списка** — интервал, в течение которого прокси не будет проверен после взятия на использование.

#### **Живой список**
При неудачной проверке удалять прокси из живого списка немедленно — рекомендуется отключить для публичных прокси и включить для платных.
