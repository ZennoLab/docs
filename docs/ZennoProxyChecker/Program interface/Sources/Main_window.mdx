## **Главное окно (источники)** 


### **Описание**

![description_ru.png](.\assets\Sources\description_ru.png)

На этой вкладке отображаются все добавленные в программу источники прокси.

Здесь находятся элементы управления, которые позволяют менять настройки источников, удалять их, добавлять, увидеть количество прокси и др.


### **Панель управления**

![managing_panel_ru.png](.\assets\Sources\managing_panel_ru.png)

#### **Помощник**
Позволяет легко добавить прокси или источник для проверки. Подробно описан [в этой статье](https://docs.zennolab.com/zennoproxychecker/Working%20with%20proxies/Adding_proxy).

#### **Добавить прокси**
Позволяет добавить прокси списком.

![add_proxy_ru.png](.\assets\Sources\add_proxy_ru.png)

#### **Добавить источник**
Позволяет добавить источник сбора прокси. При клике открывается окно настроек источника. Подробнее об этом окне можно прочитать в статье [Настройки источников](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Sources).
 
#### **Настройки источника**
Эта кнопка позволяет изменить настройки добавленных источников.
После клика по кнопке *Настройки источника* откроются настройки, которые подробно описаны в статье [Настройки источников](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Sources).

**Удалить**

С помощью кнопки удаления вы сможете удалить ненужные источники. Для этого выделите источники и нажмите кнопку *Удалить*.

Удаление источника также повлечёт удаление всех прокси этого источника.

#### **Сохранить**
С помощью этой кнопки можно сохранить адреса источников в файл.

#### **Загрузить прокси**
Эта функция позволяет загрузить прокси из источника.

#### **Проверить прокси**
После того как вы загрузили прокси с источника, можете проверить их, чтобы узнать, сколько из этих прокси живые.

После нажатия этой кнопки в верхней части таблицы появится шкала прогресса. С помощью кнопки *Отмена*, справа от шкалы, можно остановить процесс проверки.

![proxy_checking_ru.png](.\assets\Sources\proxy_checking_ru.png)

#### **Допроверить живые**
Позволяет повторно проверить уже найденные живые прокси источников.
Появится такая же шкала прогресса, как и в режиме *Проверить прокси*.

#### **Развернуть**
Кнопка *Развернуть* разворачивает группу со списком источников, если она была до этого в свёрнутом виде.

![expand_ru](.\assets\Sources\expand_ru.gif)

#### **Свернуть**
Кнопка *Свернуть* сворачивает группу со списком источников.

![collapse_ru](.\assets\Sources\collapse_ru.gif)

#### **Панель авто-режима**
С помощью этой кнопки можно активировать панель для быстрого управления загрузкой и проверкой прокси. Появляется такая панель над списком источников:

![auto_panel_ru.png](.\assets\Sources\auto_panel_ru.png)

В левой части панели отображено количество источников (живые источники/общее количество).
Справа:
 - **Загрузить** —  загрузка прокси из источников.
 - **Автопоиск** — автоматический поиск новых источников прокси.
 - **Проверка** — проверка найденных прокси.

#### **Время загрузки**
Кнопка *Время загрузки* добавляет три новых столбца в таблицу источников “Интервал загрузки“, “Следующая загрузка“, ”Рейтинг” (они будут описаны ниже).

#### **Удалить все прокси**
Удаляет все прокси из программы.

#### **Чёрный список**

![blacklist1_ru.png](.\assets\Sources\blacklist1_ru.png)

Если прокси, содержащиеся в источнике, по каким-либо причинам не подходят для выполнения проекта, или сам источник не вызывает доверия, а ZennoProxyChecker продолжает добавлять и проверять прокси с этих источников, тратя драгоценное время и ресурсы, то такой источник можно добавить в *Чёрный список* и вы больше его не увидите.

![blacklist2_ru.png](.\assets\Sources\blacklist2_ru.png)

**Окно управления чёрным списком**

**Добавление в ЧС** — для ручного добавления введите адрес в поле и нажмите клавишу Enter. Также можно добавить через контекстное меню (описано ниже в статье, в разделе *Контекстное меню*).

**Удаление из ЧС** — выделите источник, кликнув слева от него (прямоугольник с цифрой 2 на скриншоте) и нажмите клавишу Delete.

**Импорт/экспорт** — эти кнопки позволяют сохранить (экспорт) текущий ЧС или загрузить (импорт) ранее сохранённый.


### **Таблица источников**

В этой таблице находится вся доступная информация по источникам прокси.


| **Тип источника** | **Тип источника** |
| ------------- | ------------- |
| Локальный источник (файл на жёстком диске) | Удалённый (источник по URL  адресу) |
| ![local_source_ru.png](.\assets\Sources\local_source_ru.png) | ![remote_source_ru.png](.\assets\Sources\remote_source_ru.png) |

| **Статус источника** | **Статус источника** | **Статус источника** |
| ------------- | ------------- | ------------- |
| Прокси успешно загружены | Недоступные адреса или несуществующий файл | Адрес доступен, но прокси на нём не найдено |
| ![pds_ru.png](.\assets\Sources\pds_ru.png) | ![uaouf_ru.png](.\assets\Sources\uaouf_ru.png) | ![aabnp_ru.png](.\assets\Sources\aabnp_ru.png) |

 - **Путь** — здесь будет указан путь к источнику. Это может быть URL-адрес или путь к файлу на жёстком диске.
 - **Живые** — количество живых прокси с этого источника. При клике по этому числу вы будете перенаправлены во вкладку *Прокси*, в которой будут показаны только прокси для этого источника.
 - **Всего** — общее количество прокси на этом источнике.

Следующие колонки появляются при активации кнопки *Время загрузки* на *Панели управления*.

 - **Интервал загрузки** — пауза между загрузками прокси с источника. Изменить можно в *Настройках источников*.
 - **Следующая загрузка** — обратный отсчёт до следующей загрузки прокси.
 - **Рейтинг** падает, если не удалось получить прокси из источника.

#### **Выделение сразу нескольких источников**
В таблице можно выделить сразу несколько источников для применения настроек сразу ко всем, а не по одному. Существует несколько способов сделать это:

##### **Ctrl**
Мышь + клавиша Ctrl — позволяет выделять несколько источников, но каждый по отдельности.

##### **Shift**
Мышь + клавиша Shift — позволяет выделять несколько источников подряд. Выделите один источник, нажмите Shift , затем кликните по другому источнику ниже или выше уже выбранного. В результате все, которые находятся между ними, будут также выделены.

##### **Выделение группы**
Если кликнуть по названию группы, то будут выделены все находящиеся в ней источники.

![group_selection_ru.png](.\assets\Sources\group_selection_ru.png)

##### **Ctrl+A**
Нажатие этой комбинации клавиш выделит все прокси в развёрнутых группах.


### **Контекстное меню источника**

![context_menu_ru.png](.\assets\Sources\context_menu_ru.png)

 - **Загрузить/проверить/допроверить прокси** — эти функции аналогичны одноимённым действиям из *Панели управления* (описано выше).
 - **Форсировать загрузку** — выполняет ту же функцию, что и *Загрузить прокси*.
 - **Открыть источник** — если это URL-адрес, то он будет открыт в браузере по умолчанию. Если это локальный файл, то он будет открыт в текстовом редакторе.
 - **Изменить метки** — позволяет задать новую метку для источника.

![examples_of_label_ru.png](.\assets\Sources\examples_of_label_ru.png)

 - **Настройки источника** — открывает окно настроек. Подробнее про него можно прочитать в этой статье.
 - **Добавить в чёрный список** — добавляет выделенные источники в ЧС. Подробнее о нём написано выше.
 - **Включить/выключить** — позволяет выключить/включить источники. Выключенный источник отображён серым цветом в таблице и с него не загружаются прокси.
 - **Удалить** — удаление источника и всех его прокси из программы.
