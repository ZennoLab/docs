### **Вкладка “Источник прокси”**

#### **Настройки парсинга**

![parcing_settings_ru.png](.\assets\Sources\parcing_settings_ru.png)

**Адрес** — URL-адрес, с которого будут собираться прокси.

**Выполнение JavaScript** — эта настройка отвечает за выполнение JavaScript на странице сайта, с которого будут парситься прокси. В выпадающем меню выберите один из вариантов:
 - *Отключено*;
 - *Включено*;
 - *Автоопределение*.

**Удалять прежние прокси при запуске** — при каждом новом сборе прокси, собранные в прошлый раз, будут удаляться.

**Удалять прежние прокси, кроме живых, при загрузке** — при каждом новом сборе прокси будут удаляться все прокси из базы, кроме живых. Настройка активируется после включения *Удалять прежние прокси при запуске*.

**Удалять прежние прокси из живого списка при загрузке** — нужно ли удалять прокси из списка живых при каждом новом сборе прокси? Настройка активируется после включения *Удалять прежние прокси при запуске*.

**Добавлять адреса локальных сетей** — выберите этот пункт, если хотите, чтобы ZennoProxyChecker собирал также адреса локальных сетей.

**Парсить текст RSS** — при установке флага помимо текста источника ищутся прокси в тексте RSS ленты, если она есть.

**Парсить ссылки RSS** — если RSS лента есть, из неё парсятся все ссылки и обрабатываются так же, как автоматически добавленные ресурсы, т.е. появляются в списке источников только те, на которых нашлись прокси. Новые источники помечаются меткой “RSS”.


#### **Настройки проверки прокси**

![checking_settings_ru.png](.\assets\Sources\checking_settings_ru.png)

**Режим проверки:**

 - **Проверять прокси** — будет происходить проверка прокси на работоспособность;
 - **Считать все прокси живыми** — все прокси будут считаться живыми без проверки.

**Протокол** — здесь стоит выбрать протокол прокси, который используется в этом источнике. Если вы не знаете заранее протокол, то можете выбрать пункт *Определять автоматически* и тогда ProxyChecker самостоятельно вычислит его.

Возможные варианты:
 - HTTP;
 - SOCKS4;
 - SOCKS5;
 - Определять автоматически.


**Проверять POST** — проверяется, поддерживает ли прокси POST-запрос.

**POST** — запрос, который часто используется при отправке форм.

**Проверять HTTPS** — дополнительная проверка на доступность по HTTPS. Может снизить производительность.

**Измерить скорость** — в процессе проверки будет измерена также пропускная способность прокси. Включение этой настройки снижает производительность и увеличивает потребление трафика.

**Ждать ответ** — максимальное время ответа после запроса.  Если по истечении указанного здесь времени прокси не вернул ответ, то он считается нерабочим.

**Делать повторный запрос** — послать запрос ещё раз в случае успеха первого. Отсеивает плохие прокси, но увеличивает время проверки.

**Проверять на бан в Google** — прокси проверяется на бан в Google.


#### **Проверять на наличие в чёрных списках**

![blacklist_checking_ru.png](.\assets\Sources\blacklist_checking_ru.png)

Таблица появляется только после включения настройки.

Прокси проверяется на наличие в чёрных списках.

При клике по кнопке *Добавить* появится список из доступных адресов для проверки.

Кнопка *Удалить* позволяет удалить выделенные адреса из списка добавленных.

Некоторые DNS-сервера не пропускают большое количество запросов, из-за этого возможны ошибочные проверки.  В таких случаях рекомендуется настроить в системе использование DNS вашего провайдера.


#### **Проверка на любой URL**

![URL_checking_ru.png](.\assets\Sources\URL_checking_ru.png)

Эта функция предназначена для проверки, забанен ли прокси на конкретном сайте. **Чтобы выбрать правило**, нужно отметить чекбокс слева от названия правила (на скриншоте выбрано правило twitter).

При активации функции у вас появится дополнительное меню для настройки (по умолчанию там добавлено два правила для пример).

##### **Добавление нового URL для проверки**

Чтоб добавить новое правило, нажмите кнопку *Новое правило*. Откроется окно настроек:

![new_URL_ru.png](.\assets\Sources\new_URL_ru.png)

 - **Имя правила** — введите любое название, это никак не повлияет на проверку.
 - **Адрес (URL)** — введите URL-адрес сайта, на котором будет проходить проверку прокси.
 - **Иконка** — при желании можно загрузить favicon сайта, для этого нажмите кнопку *Загрузить*.
 - **Тип проверки** 
 
 —> *Содержит текст* — этот тип проверки позволяет проверить, содержится ли определённый текст на проверяемом сайте. Текст для проверки пишите в окне *Значение*.
 
 —> *Не содержит текст* — будет происходить проверка на отсутствие текста на сайте. Текст для проверки пишите в окне *Значение*.
 
 —> *Regex* —  здесь пишите значение регулярного выражения, в соответствии с которым будет происходить проверка.

Используйте макрос ``` json {-ProxyIp-} ```, чтобы подставить текущий прокси запроса в проверочное значение.

### **Вкладка “Авто-режим”**

![auto_proxy_ru.png](.\assets\Sources\auto_proxy_ru.png)

#### **Настройка автоматического парсинга**
**Интервал загрузки проксей с источника** — пауза между сбором прокси из источника.

Например, если вы поставите интервал 20 минут, то прокси будут собираться каждые 20 минут.

**Проверить прокси только один раз** — при включении этой настройки все прокси с одного источника будут проверяться только один раз.

#### **Настройка автоматической проверки**
**Минимальный интервал после предыдущей проверки** — интервал между проверками прокси.

**Минимальный интервал после взятия из живого списка** — интервал, в течение которого прокси не будет проверен после взятия на использование.

#### **Живой список**
При неудачной проверке удалять прокси из живого списка немедленно — рекомендуется отключить для публичных прокси и включить для платных.
