## **Правила**


## **Описание**


![rules_description_ru.png](.\assets\Rules\rules_description_ru.png)

Вкладка **Правила** предназначена для настройки параметров, по которым впоследствии будут отбираться прокси.

**Правила** — это набор условий, по которым можно взять прокси из списка «живых». Таким образом, правила применяются к тем прокси, которые уже прошли проверку. Правила можно использовать для того, чтобы настроить выдачу прокси в соответствии с различными критериями. Например, нужны только анонимные прокси или элитные, с максимальной скоростью и минимальной задержкой, не забаненные в Google и Twitter, только российские прокси для работы с российскими социальными сетями и т.п.

## **Панель управления**

![managing_panel_rules_ru](.\assets\Rules\managing_panel_rules_ru.png)

### **Новое**
Позволяет создать новое правило с нуля.

Если в этот момент на панели сборки (описано ниже) есть несохранённое правило, то появится диалог с предложением сохранить изменения.

### **Очистить**
Кнопкой *Очистить* вы можете удалить компоненты в окне *Панель сборки*.

### **Сохранить**
Позволяет сохранить все изменения, которые были внесены.
Нажмите кнопку *Сохранить* и придумайте название для правила. Все сохранённые правила, а также предустановленные, можете увидеть в разделе *Список правил*, в нижней части окна.

### **Изменить**
Чтобы изменить правило, вам нужно его выделить в *Списке правил* и нажать кнопку *Изменить*, после чего на *Панель сборки* будут перенесены его компоненты.

### **Удалить**
Чтобы удалить правило из *Списка правил*, вам нужно его выделить и нажать кнопку *Удалить*.

### **Восстановить стандартные**
Позволяет восстановить стандартные значения у правил по умолчанию.

## **Доступные компоненты для правила**

![availible_components_ru.png](.\assets\Rules\availible_components_ru.png)

### **Метки**
Выбор прокси происходит по меткам.

Перечислите названия меток через “;“, чтобы определить, к каким меткам будет применён этот фильтр (*Правило*).

### **Задержка**
Происходит сортировка прокси по задержке по возрастанию.
Сначала идут прокси с меньшей задержкой, а в конце — с большей.

### **Тип прокси**
Укажите желаемый тип прокси: http, socks4, socks5.

### **Шлюзовость**
Показывает, является ли прокси тоннелем.
Если включено, то отбираются только шлюзовые прокси.
Если выключено, то отбираются только не шлюзовые прокси.
Для того чтобы выбрались и те и другие, удалите этот компонент.
Шлюзовые (gateway) прокси — это прокси-туннель для прокси.

### **Анонимность**
Скрывает ли прокси IP-адрес пользователя.
Должен ли прокси быть анонимным.
Анонимность (приватность, private) — признак для прокси, определяющий, скрывает ли этот прокси исходный IP-адрес или нет.

### **Элитность**
Прокси не выдаёт себя как прокси — не передаёт параметр HTTP_VIA в заголовке.
Должен ли прокси быть элитным. Элитный (высокоанонимный, high anonymous) прокси не передаёт параметр HTTP_VIA в заголовке (не выдаёт себя как прокси).

### **Cookie**
Поддержка Cookie.
Должен ли прокси поддерживать передачу Cookie в заголовке.

### **https**
Поддержка https.
Должен ли прокси поддерживать соединения по протоколу https.

### **POST**
Поддержка POST.
Должен ли прокси поддерживать передачу POST в заголовке. Очень часто передача POST необходима для отправки форм.

### **Referer**
Должен ли прокси поддерживать передачу Referer в заголовке.

### **Страны**
Разрешить — будут отобраны страны только из этого списка.
Запретить — прокси стран из списка будут проигнорированы.

#### **Как добавить страну?**
Нажмите на выпадающий список, найдите необходимую страну, выберите её, затем нажмите на зелёный “+” (плюс) рядом с этим списком. И так для каждой необходимой страны.

![country_adding_ru.gif](.\assets\Rules\country_adding_ru.gif)

#### **Удаление страны из списка**
Чтобы удалить страну, выделите её в списке добавленных и нажмите кнопку “-” (минус).

![country_deleting_ru.png](.\assets\Rules\country_deleting_ru.png)

### **Google passed**
Проверка на бан в поисковой системе Google.
При активации параметра *Успешный запрос* на Google становится доступным для активации второй параметр *Разрешить ответ* в виде капчи.

### **Проверка URL**
Позволяет проверить прокси на работоспособность на конкретном URL.
Выберите вариант: *Разрешить* или *Запретить*.
Добавить новые URL для проверки можно через *Настройки источников*.

#### **Добавление/удаление**
Процесс добавления и удаления правил такой же, как и в случае со *Странами* (описано выше).

### **IP-подсети**
Задаёт ограничения на допустимые IP-адреса прокси при помощи списка подсетей.

Укажите нужные вам подсети в следующих форматах:

Диапазон

11.22.33.1-11.22.33.255

11.22.1.1-11.22.255.255

Адрес сети с маской

11.22.33.0/255.255.255.0

11.22.0.0/255.255.0.0

![IP_subnetworks_ru.gif](.\assets\Rules\IP_subnetworks_ru.gif)

Подсети можно загрузить из файла. Для этого нажмите на иконку файла (1) и выберите файл с подсетями с вашего компьютера.

![IP_subnetworks2_ru.png](.\assets\Rules\IP_subnetworks2_ru.png)

#### **Добавление/удаление**
Процесс добавления и удаления правил такой же, как и в случае со *Странами* (описано выше).

### **Порты**
Задаёт ограничения по портам прокси.
Введите номера портов или их диапазоны через точку с запятой.

Пример: 80;1000 - 1080;8080

Вы можете *Разрешить* или *Запретить* порт, нажав на соответствующий пункт.

### **Нестрогость**
Делает правило нестрогим. При отсутствии подходящих будут браться шлюзовые (gateway) прокси.

### **Макс. задержка**
Фильтр по максимальной задержке прокси.
Определяет максимально допустимую задержку прокси в секундах. Все прокси, имеющие большую задержку, отсекаются.

### **Мин. скорость**
Фильтр по минимальной скорости прокси.
Определяет минимально допустимую скорость прокси. Все прокси, имеющие меньшее значение, отсекаются.

### **Источник**
Выбор прокси по источнику. Добавьте адрес/путь источника прокси.

### **White list**
Проверять на наличие в блэк-листах.

![blacklist_rules_ru.png](.\assets\Rules\blacklist_rules_ru.png)

## **Часто используемые правила**


Программа уже содержит набор наиболее часто используемых правил для отбора прокси.

**Live&Twitter passed** — анонимные прокси, не забаненные в Windows Live и Twitter.

**Twitter passed** — анонимные прокси, не забаненные в Twitter.

**Anonymous** — анонимные прокси, поддерживающие POST-запросы.

**Anonymous (HTTPS)** — анонимные прокси, поддерживающие POST-запросы и соединение по HTTPS.

**Google passed with Captcha** — прокси, не забаненные в Google, с подтверждением с помощью капчи.

**Google passed** — прокси, не забаненные в Google.

**Elite** — элитные прокси, поддерживающие POST-запросы.

**Elite (HTTPS)** — элитные прокси, поддерживающие POST-запросы и соединение по HTTPS.

**Socks** — прокси socks-типа.
