Вкладка “Управление“ доступна сразу после запуска программы: через неё осуществляется контроль сбора прокси, а также настройка каждого этапа.


![interface_ru](.\assets\Managing\interface_ru.png)


## **Панель управления** 

![managing_panel_ru](.\assets\Managing\managing_panel_ru.png)


 - **Старт/Стоп** — с помощью этих кнопок запускается или останавливается сбор и проверка прокси.
 - **Фильтры** — это набор правил, применяющийся к прокси до занесения в базу программы после загрузки их с источника. Более подробно можно прочитать в статье [Фильтры](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Filters).
 - **Правила** — это набор условий, по которым можно взять прокси из [списка живых](https://docs.zennolab.com/zennoproxychecker/Working%20with%20proxies/Live_list). Подробнее в статье [Правила](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Rules).
 - **Сетевой монитор** — с помощью этой встроенной утилиты вы можете протестировать интернет подключение на максимальное количество одновременных потоков.
 - **Справка** — открывает в браузере cправку.


## **Источники прокси**

![proxy_source_ru](.\assets\Managing\proxy_source_ru.png)

Тут настраивается загрузка прокси из источников.

При клике в области, где отображается количество источников, вы будете перенаправлены в [Источники](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Sources).


### **Количество источников**

![number_of_sources_ru](.\assets\Managing\number_of_sources_ru.png)

Нижнее число отображает общее количество источников, сохранённых в базе.

Верхнее — число рабочих источников.

### **Загружать прокси**

При клике по этой кнопке будет запущен сбор прокси из источников.

#### **Настройка количества потоков**


![setting_the_number_of_sources_ru](.\assets\Managing\setting_the_number_of_sources_ru.png)


Вы можете регулировать, сколько потоков будет задействовано в загрузке прокси из источников, для этого нужно нажать кнопку с изображением шестерёнки.


### **Включить автопоиск** 

![enable_auto_search_ru](.\assets\Managing\enable_auto_search_ru.png)

Кнопка активна только тогда, когда включена загрузка прокси.

При активации этой опции ProxyChecker будет самостоятельно искать в интернете источники с прокси.

После клика по шестерёнке откроются настройки источников, которые будут применены к найденным сайтам (подробнее об этих настройках можно прочитать [в этой статье](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Sources)).

В [настройках программы](https://docs.zennolab.com/zennoproxychecker/category/proxychecker-settings) вы можете установить лимиты, при которых автопоиск остановится.


## **База прокси** ##

![proxy_database_ru](.\assets\Managing\proxy_database_ru.png)

Здесь запускается процесс непосредственно проверки прокси. При клике в области, где отображается количество прокси, вы будете перенаправлены в [Источники](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Sources).


### **Проверять прокси** ###

Эта кнопка запускает процесс проверки.

#### **Настройки** ####

![settings_ru](.\assets\Managing\settings_ru.png)

При клике по кнопке с шестерёнкой будут открыты настройки проверки.

Тут вы можете задать число потоков проверки и ограничение по количеству живых прокси, по достижении которого проверка будет остановлена.


## **Живые прокси** ##

![live_proxies_ru](.\assets\Managing\live_proxies_ru.png)

Здесь отображается количество живых прокси и настраивается время, в течение которого прокси считается живым. При клике в области, где отображается количество живых, вы будете перенаправлены в [Прокси](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Proxy).

### **Очищать список** ###

При активации список живых будет очищаться согласно настройке времени жизни живого прокси.

#### **Время жизни** ####

![lifetime_ru](.\assets\Managing\lifetime_ru.png)

При клике по шестерёнке откроется окно настройки, в котором надо указать, в течение какого времени прокси считается живым.

### **Выдача прокси** ###
