## **Для чего используется чёрный список?**


Если прокси, содержащиеся в источнике, по каким-либо причинам не подходят для выполнения проекта или сам источник не вызывает доверия, а ZennoProxyChecker продолжает добавлять и проверять прокси с этих источников, тратя драгоценное время и ресурсы, то такой источник можно добавить в **чёрный список**, и вы больше его не увидите.

![blacklist1_ru.png](.\assets\Blacklist\blacklist1_ru.png)


## **Как настроить чёрный список**

Для создания чёрного списка необходимо перейти на вкладку *Источники*.

![blacklist2_ru.png](.\assets\Blacklist\blacklist2_ru.png)

Для добавления нескольких источников в чёрный список их необходимо выбрать в списке источников и в контекстном меню активировать пункт *Добавить в чёрный список*. При добавлении источников в чёрный список прокси, добавленные из этих источников, удаляются из базы.

![blacklist3_ru.png](.\assets\Blacklist\blacklist3_ru.png)
