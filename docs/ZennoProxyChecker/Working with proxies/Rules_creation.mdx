## **Зачем нужны правила?**


Правила — это набор условий, по которым можно взять прокси из списка «живых» прокси. Таким образом, правила применяются к тем прокси, которые уже прошли проверку. Правила можно использовать для того, чтобы настроить выдачу прокси в соответствии с различными критериями. Например, нужны только анонимные прокси или элитные, с максимальной скоростью и минимальной задержкой, незабаненные в Google и Twitter, только российские прокси для работы с российскими социальными сетями и т.п. 

Подробнее о настройке правил читайте [здесь](https://docs.zennolab.com/zennoproxychecker/Program%20interface/Rules).
