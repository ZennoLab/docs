## Описание.
### Новые фичи:  
:zap: Улучшен success rate reCAPTCHA для безбраузерного метода (Http).  
:zap: Обновлен браузерный движок CEF до версии **105.3**.    
:zap: Задания с ошибкой `ERROR_PROXY_FORMAT` будут попадать в список некорректных заданий на главном экране приложения.  
  
:heavy_plus_sign: Для передачи в программу информации о модуле для распознавания капчи можно отправлять его имя в виде суффикса в ключе защиты через двойное нижнее подчеркивание.  
Например: `00f87cb0f01330d33709ce3339ad0c8c__solvemedia`  
:heavy_plus_sign: Добавлена ссылка на справку в меню установки IP: **«Не вижу свой IP!»**.  
:heavy_plus_sign: Добавлена кнопка для генерации ключа защиты (в формате GUID).  
:heavy_plus_sign: Кнопка **«Очистить»** позволяет безвозвратно удалить забаненные прокси, а **«Восстановить»** – вернуть все прокси в список активных, которые находятся в списке забаненных на момент нажатия кнопки.    
:heavy_plus_sign: Добавлена возможность скрыть окно предупреждения об опасности при запуске сервиса без ключа защиты на публичном IP-адресе. Теперь сервис корректно стартует и после автоматических перезапусков. Сообщение появится после согласия включения сервиса без защиты.    


### Исправленные баги:  
:white_check_mark: Устранили случайно сохранившиеся задержки в коде для локальных сложных модулей.    
:white_check_mark: Теперь при добавлении и удалении модулей сохраняются настройки приложения. Раньше они сохранялись только во время закрытия приложения и не срабатывали при аварийном завершении процесса. Из-за этого приходилось перезапускать программу после добавления новых модулей, чтобы форсировать сохранение настроек. Теперь это не требуется.  
:white_check_mark: Откорректировали сообщение об ошибке при отсутствующем модуле распознавания. Теперь предложение добавить префикс «ZennoLab» будет появлятся только при наличии модуля с таким префиксом. В других случаях будет сообщение о предположительном наличии опечатки.    
:white_check_mark: Теперь в API RuCaptcha и 2Captcha на странице res.php поддерживается не только GET, но и POST-запросы.  
:white_check_mark: Исправлена корректность директории по умолчанию для профилей. Раньше она по умолчанию вела в C:\Users\admin\Documents\ZennoLab\CapMonster\GeneratedProfiles, независимо от имени текущего пользователя.  
:white_check_mark: Теперь корректно работает лимит на количество одновременно решаемых заданий http-процессов.
