## Описание.
### Новые фичи:  
:zap: Добавлена поддержка загрузки файлов по RuCaptcha API через multipart в base64.  
:zap: Добавлена поддержка возврата куков после решения ReCaptcha (по Anti-Captcha API).    
:zap: Движок CEF обновлен до 107 версии.      

### Исправленные баги:  
:white_check_mark: Изменён алгоритм ресайза изображений для модуля universal, что повысило точность распознавания капч маленького размера.    
:white_check_mark: Теперь RuCaptcha API учитывает все url-encoded параметры, идущие после action.
