## Описание.
### Новые фичи:  
:zap: Обновлён браузерный движок. Снижено потребление CPU - можно запустить до полутора раз больше потоков.  
:zap: Встроенные прокси - интеграция с hit-proxy.com. До 1000 подключений и безлимитный трафик, приобрести можно в личном кабинете. Цена 50USD в месяц.    
:zap: Ускорен старт программы (сервиса) за счёт ускорения шага "инициализация".  

:heavy_plus_sign: Добавлена поддержка распознавания математических каптч (например, картинка "2 + 7 = " - ответ будет 9). Для использования требуется передавать параметры `CapMonsterModule=ZennoLab.universal&calc=1`  
:heavy_plus_sign: Возможность отключения лога картинок, при очень высоких нагрузках значительно увеличивающая отзывчивость графического интерфейса и снижающая потребление CPU и оперативной памяти.  
:heavy_plus_sign: Оптимизации в работе очереди заданий ReCaptcha, повышающие производительность при очень высоких нагрузках.  
:heavy_plus_sign: Правки по Chrome-модулю распознавания ReCaptcha2, несколько повысившие принимаемость токенов и снизившие среднее время разгадывания.    


### Исправленные баги:  
:white_check_mark: Починили авто обновление модулей.    
:white_check_mark: Исправлен способ изменения размера изображений перед отправкой их на распознавание модулем universal (ранее расхождение в способах изменения размера приводило к значительному снижению точности распознавания этого модуля).  
:white_check_mark: После обновления в API ReCaptcha у нас перестали корректно выдаваться ошибки invalid-sitekey, а вместо них выдавались timeout-ы - исправлено.    
:white_check_mark: Исправлено импортирование кук, передаваемых вместе с запросом при решении ReCaptcha.  
:white_check_mark: Исправлена утечка памяти в очереди заданий, со временем приводившая к снижению скорости работы программы.  
:white_check_mark: Если при обновлении списка прокси по ссылке произошел сетевой сбой, CapMonster продолжит использоваться ранее загруженный список (вместо использования пустого списка прокси, как было ранее).  
:white_check_mark: Исправлен редкий случай, при котором программа не могла корректно перезапуститься при обновлении файлов лицензий.
