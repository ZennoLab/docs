## Описание.
### Новые фичи:  
:zap: Добавлена возможность сохранять профили у reCAPTCHA на Chrome движке.  

При успешном распознавании reCAPTCHA, профиль сохраняется для последующего переиспользования. Это уменьшает вероятность банов и повышает проходимость токенов. Профили общие для 2 и 3 версии.  

Профиль, поработавший несколько дней на разгадывании reCAPTCHA 2, даёт более качественные токены для reCAPTCHA 3.  
_______________________________________________
:zap: Оптимизировано потребление CPU у reCAPTCHA на Chrome движке.  
:zap: Улучшена принимаемость токенов reCAPTCHA.  

:heavy_plus_sign: Реализована поддержка протокола Anti-Captcha для разгадывания reCAPTCHA 3.  
:heavy_plus_sign: Добавлено отображение количества reCAPTCHA, которые разгадываются на текущий момент.  
:heavy_plus_sign: Добавлен метод получения информации о загруженности CapMonster: `http://127.0.0.3:80/getcmstatus`  

Возвращает **JSON** в формате:  
```
{«CpuLoad»:3, «RemoteRunningSlots»:0, «RemoteTotalSlots»:80, «Rc2TasksWaitingInQueue»:0, «Rc2InstancesRunning»:0, «Rc2InstancesWithTask»:0}  
```
:::info **Если включена защита, то надо передать ключ `getcmstatus?key=blablabla`**
:::
