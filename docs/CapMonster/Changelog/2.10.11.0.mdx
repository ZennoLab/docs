## Описание.
### Новые фичи:  
:zap: Добавлена возможность распознавать каптчи с буквами в разном регистре, указывая соответствующее значение параметра «casesensitive» в запросе.  
:zap: Добавлена возможность распознавать каптчи, состоящие только из цифр, указывая соответствующее значение параметра «numeric» в запросе.  
:zap: Улучшена принимаемость токенов ReCaptcha для ReCaptchaSiteKeyAddon.  
:heavy_plus_sign: Теперь, при недостатке системных ресурсов (CPU, RAM), для обработки входящей нагрузки показывается соответствующее сообщение.    

### Улучшены модули распознавания:  
:rocket: *universal* с поддержкой только числовых каптч — **83%**.  
:rocket: *universal* с поддержкой каптч в разном регистре — **42%**.  
:rocket: *facebook* — **64%**.  
:rocket: *3D каптча* — **90%**.  

### Исправленные баги:  
:white_check_mark: Исправлена ошибка, при которой прокси из запроса добавлялись в общий список забаненных прокси, а из него возвращались в общий список.      
:white_check_mark: Исправлена ошибка, при которой не показывалась кнопка диагностики.    
:white_check_mark: Исправлена ошибка, при которой ReCaptcha3 не разгадывалась из-за сломанных слешей.    
:white_check_mark: Исправлена ошибка, при которой при эмуляции сервисов иногда добавлялись обрезанные записи.
