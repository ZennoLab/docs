## Описание.
### Новые фичи:  
:zap: Добавлена возможность указывать отдельные прокси для ReCaptcha v3. Для ReCaptcha v3 критично важно иметь очень хорошие, желательно резидентные IP.  
:zap: Реализована новая логика взятия прокси из источника в CapMonster, для увеличения срока «жизни» прокси - теперь для распознавания берутся, в первую очередь, наименее использованные прокси из списка.  
:zap: Значительно уменьшено потребление места профилями ReCaptcha.  

:heavy_plus_sign: Добавлена возможность автоматического архивирования профилей ReCaptcha (снизит потребление места ещё, примерно, в три раза).  
:heavy_plus_sign: Улучшен алгоритм проверки правильности формата прокси.  
:heavy_plus_sign:  Если программа не может получить доступ к системным счётчикам производительности, автоматически будет произведена попытка восстановления. При провале восстановления программа всё равно запустится, но счётчики будут недоступны.  

### Исправленные баги:  
:white_check_mark: Исправлен баг, при котором ReCaptcha больше не распознавалась после перезапуска сервиса.      
:white_check_mark: Исправлена проблема с установкой прокси на инстанс, если инстанс решает более одного задания, профили отключены и стоит галка повышенного приоритета прокси из списка CapMonster.    
:white_check_mark: Исправлен баг с методом HttpRequest, при котором первая каптча (одна за запуск CapMonster) всегда решалась без прокси.    
:white_check_mark: Исправлена работа с методом FireFox при разгадывании ReCaptcha.      
:white_check_mark: Исправлена проблема отключения sitekey addon на некоторых системах.    
:white_check_mark: Исправлено появление ошибки об окончании 86400 дней Trial версии.    
:white_check_mark: Улучшена интеграция на решение ReCaptcha3 со сторонним софтом.
