## Описание.
### Новые фичи:  
:zap: Поддержка data-s параметра в API RuCaptcha и Anti-Capthca для решения reCAPTCHA v2 на поиске в Google и других его сервисов.  
:zap: Уменьшено потребление памяти при высоких нагрузках на CapMonster.    
:zap: Улучшена отзывчивость интерфейса под высокой нагрузкой.   

:heavy_plus_sign: Внесены правки для улучшения принимаемости токенов reCAPTCHA v2. Если Вы использовали профили, удалите их и начните нагуливать по новой.  
:heavy_plus_sign: Добавлена подсказка для пункта выбора «Протокола прокси» в настройках Sitekey Addon, т.к. было не понятно, что значит «automatic».    
:heavy_plus_sign: Получение статистики работы программы по API. Доступны значения всех лейблов с главной формы приложения в формате JSON.  
Пример использования: `curl «http://127.0.0.3:80/getRecognitionStatistics» –data «key=sampleKey»`      

### Исправленные баги:  
:white_check_mark: Использование профилей и Http-метода распознавания reCAPTCHA приводило к снижению производительности и засорению лог-файлов.      
:white_check_mark: Найдена и испаравлена утечка памяти при распознавании reCAPTCHA, проявлявшаяся только при высокой нагрузке.    
:white_check_mark: Исправлена проблема, при которой некоторые reCAPTCHA не разгадывались, если их отправляли пачками (почти мгновенно одну за другой).    
:white_check_mark: При загрузке прокси из списка полная очистка списка в UI не очищала реально используемый набор прокси.  
:white_check_mark: Загрузка прокси по ссылке не работала для некоторых сайтов, если использовалась https-ссылка.  
:white_check_mark: Загрузка прокси из файла или по ссылке игнорировала прокси с указанием host-а вместо IP-адреса.  
:white_check_mark: Служебные процессы запускались по относительному пути вместо абсолютного, из-за чего могли работать некорректно, если CapMonster запущен скриптом без указания working directory.
