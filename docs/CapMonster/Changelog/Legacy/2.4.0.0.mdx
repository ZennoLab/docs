## Описание.
### Новые фичи:  
:zap: Новая возможность добавления дополнительных размеров каптч для каждого модуля. Функция доступна через контекстное меню в списке модулей. Это функция поможет, когда Ваша каптча похожа на ту, для которой уже есть обученный модуль, но анализатор её не признаёт из-за других размеров изображения самой каптчи.  
:zap: Та же настройка только доступная для редактирования нами для всех пользователей централизованно.  
:zap: Добавлена эмуляция сервиса DeathByCaptcha.  

:heavy_plus_sign: В описании модулей отображается информация о каптче - простая она или сложная, т.е. действуют ли на неё ограничения потоков.    
:heavy_plus_sign: Настройка «Подробный лог для разработчиков» для ускорения поиска ошибок на устройстве пользователя.  
:heavy_plus_sign: CapMonster MCS: Добавлена настройка “Обработка регистра ответа” в дополнительные параметры обучения. В случае, если в настройках распознавания не установлена “Учитывать регистр символов” переведёт все символы ответа в нижний или верхний регистр.  
:heavy_plus_sign: CapMonster MCS: Добавлена настройка “Расстояния между словами” в дополнительные настройки обучения и настройки теста каптч.  
:heavy_plus_sign: CapMonster MCS: Добавлены настройки “Многострочная каптча” и “Минимальное расстояние” между строками в форму дополнительных настроек и форму настроек тестирования.  
:heavy_plus_sign: CapMonster MCS: Изменена работа “Линейки” в разделе “Центры масс”. Теперь дистанция высчитывается относительно двух координат (раньше только по X) т.е. дистанцию на плоскости.  
:heavy_plus_sign: CapMonster MCS: Добавлена возможность использование словаря для исправления ответа модуля, т.е. если ответ должен быть осмысленным словом или некоторой фиксированной фразой данная возможность может изменить ответ модуля на близкое слово или фразу. Включение/отключение этой возможности добавлено в дополнительные настройки обучения и настройки тестирования.  
:heavy_plus_sign: CapMonster MCS: Автонаполнение словаря - можно добавить в словарь слова и фразы из уже распознанных каптч.  
:heavy_plus_sign: CapMonster MCS: Фильтрация словаря на этапе создания по распознанным каптчам - можно отсортировать слова по частоте встречаемости в ответах и добавить те, которые встречаются несколько раз, а те слова, которые были введены работниками сервисов ручного распознавания с ошибками (по сути, не нужный мусор) не добавлять.  
:heavy_plus_sign: CapMonster MCS: Предупреждение о неправильной настройке “Учитывать регистр символов” в сборе символов. Активируется перед началом обучения.  

### Улучшены модули распознавания:  
:rocket: Новый модуль ReCaptcha2. Вероятность распознавания на хороших прокси - 25-48% (в завсисимости от способа использования).    
:rocket: Новый модуль KeyCaptcha (работает только с новым билдом ZennoPoster). Вероятность распознавания более 70%.   
:rocket: Поправлен модуль обычной ReCaptcha, теперь он распознает оба слова, включая то, которое раньше было не нужно. Вероятность примерно 33%.    
:rocket: Поправлен модуль Microsoft (Bing, Hotmail, etc) после изменения каптчи. Новая каптча распознаётся с результатом 77%.  
:rocket: Написана дополнительная система анализатора для разделения типов каптч Яндекса и Google - цифровых и буквенных. Теперь анализатор их практически не путает.    

### Исправленные баги:  
:white_check_mark: Исправлена ошибка, при которой запросы на распознавания не обрабатывались в CapMonster2, если некоторые настройки сервиса были пустыми.        
:white_check_mark: Исправлена ошибка, при которой из-за удаления временной директории были ошибки сохранения обученного модуля, при запуске нескольких одинаковых проектов обучения в нескольких копиях MCS.
