## Описание.
### Новые фичи:  
:zap: Добавлена настройка **Распознавать каптчи для всех модулей в параллельном режиме**, позволяющая использовать параллельный режим распознавания для всех модулей. Как и опция `ParallelMode=True` с версии 2.4.1.2, она позволяет модулям использовать все ядра процессора для однотипных каптч, ускоряя работу за счет большего потребления ресурсов.  
:zap: CapMonster MCS: Добавлена настройка для словаря **Использовать сложный анализ**. Позволяющая в выдаваемой фразы определить количество слов и исправить ошибки в словах.  

### Исправленные баги:  
:white_check_mark: Улучшена стабильность работы при использовании большого количества потоков.
