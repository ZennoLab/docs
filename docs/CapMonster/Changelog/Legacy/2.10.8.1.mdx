## Описание.
### Новые фичи:  
:zap: Добавлен режим, позволяющий избежать бана прокси при разгадывании ReCaptcha2 через ReCaptcha SiteKey Addon.  
:zap: Восстановлена работоспособность разгадывания ReCaptcha2 через ReCaptcha SiteKe yAddon без браузера.    
:zap: При выборе получения прокси по ссылке для ReCaptcha SiteKey Addon можно выбрать протокол прокси.  

:heavy_plus_sign: Добавлена поддержка 32 bit Chrome для ReCaptcha SiteKey Addon.  
:heavy_plus_sign: Добавлена настройка использовать прокси из списка для ReCaptcha SiteKey Addon вместо тех, что передаёт софт. Это позволит повысить принятие ответов, из-за лучшего подбора прокси.  

### Исправленные баги:  
:white_check_mark: Исправлена ошибка запуска webserver с PlatFormNotSupported Exception.  
:white_check_mark: Исправлена ошибка при парсинге изображений в запросе base64.  
:white_check_mark: Исправлена ошибка, когда не определяется задание ReCaptcha2 при отправке старым способом.
