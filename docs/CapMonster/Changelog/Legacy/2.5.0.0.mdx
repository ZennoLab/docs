## Описание.
### Новые фичи:  
:zap: Оптимизирована работа сервиса CapMonster при включенной настройке **Распознавать каптчи для всех модулей в параллельном режиме**.  
:zap: CapMonster MCS: Добавлена настройка для словаря **Использовать сложный анализ**. Позволяющая в выдаваемой фразе определить количество слов и исправить ошибки в словах.  

### :rocket: Улучшены модули распознавания:  
- MailRuMobile - 68%.
- AudioReCaptcha - 100%.
- FunCaptcha - 100%.
- WordPress (Sabre) - 38%.
- WordPress (Peters Anti Spam) - 65%.

### Исправленные баги:  
:white_check_mark: Исправлены ошибки при обработке дополнительных параметров для сервиса BypassСaptcha.  
:white_check_mark: Исправлено некорректное отображение полей интерфейса в CapMonster MCS.
