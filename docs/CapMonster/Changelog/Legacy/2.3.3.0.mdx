## Описание.
### Новые фичи:  
:zap: Добавлена возможность использовать GPU (видеокарты от Nvidia). Экономит 30-50% ресурсов процессора. Пока в режиме Beta. На мощных видеокартах есть значительное ускорение по сравнению с распознаванием на CPU.  
:zap: Добавлена настройка длины очереди каптч, которые ждут распознавания.    
:zap: Добавлена настройка таймаута каптч, которые ждут распознавания.    

:heavy_plus_sign: Добавлена настройка приоритета каптч, которые ждут распознавания.    
:heavy_plus_sign: Добавлена настройка **Отключать отчеты об ошибках программы (глобально)** в программу и инсталлер.  
:heavy_plus_sign: Добавлена поддержка сервиса RuoKuaiCaptcha.  
:heavy_plus_sign: Добавлена поддержка сервиса JsdatiCaptcha.  
:heavy_plus_sign: Увеличена скорость распознавания на CPU.  
:heavy_plus_sign: Добавлена поддержка сервиса ImageTyperzCaptcha.  
:heavy_plus_sign: CapMonster MCS: Автоподбор параметра **Расстояния между символами**.  
:heavy_plus_sign: CapMonster MCS: Автоподбор параметра порога распознавания.  
:heavy_plus_sign: CapMonster MCS: Добавлены фильтры: Выравнивание повернутого текста в горизонтальное положение и удаление фона для модуля VBuletin.  
:heavy_plus_sign: CapMonster MCS: CapMonster MCS: Добавлена возможность использования GPU для теста распознавания.  
:heavy_plus_sign: CapMonster MCS: Добавлены дополнительные настройки для обучения.  

### Добавлены фильтры в CapMonster MCS:  
:art: **Цвет:**  
- Автоконтраст.  

:wrench: **Морфология:**  
- Сужение;  
- Расширение;  
- Закрытие.  

:fog: **Сглаживание:**  
- Gaussian blur с регулировкой уровня размытия.  

:broom: **Удаление объектов:**  
- Быстрое удаление пятен;  
- Удаление кривых линий.  

:straight_ruler: **Геометрия:**  
- Модифицирован Resize добавлением регулировки длины и ширины.  

⚫⚪ **Бинаризация:**  
- Добавлен ускоренный детектор Canny;  
- Адаптивный порог.

### Исправленные баги:  
:white_check_mark:  Улучшена стабильность работы программы (вылеты через 20 минут работы).        
:white_check_mark: Устранены несколько утечек памяти.   
:white_check_mark: Поправлено не сохранение нескольких настроек при вылете программы.   
:white_check_mark: Исправлена ошибка, при которой отключенные модули использовались для распознавания.   
:white_check_mark: Исправлена ошибка, при которой распознавание через CaptchaBot.dll из ZennoPoster работало не более чем в 10 потоков.   
:white_check_mark: Исправлены некоторые ошибки, связанные с разрывом подключения во время работы сервиса CapMonster.   
:white_check_mark: Исправлена ошибка, при которой иногда распознавание выдавало пустой ответ через некоторое время, при использовании одного модуля установленного пользователем.
