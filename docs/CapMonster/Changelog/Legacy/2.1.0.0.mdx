## Описание.
### Новые фичи:  
:zap: Проект CapMonster MCS теперь представляет собой один файл (.cm2). Проекты старого формата (.cmp) при их загрузке в данной версии могут быть сохранены в новом формате.  
:zap: Добавлена эмуляция сервиса RipCaptcha.com.  
:zap: Добавлена возможность переключения между страницами в галереях с изображениями через кнопки клавиатуры (Left, Ctrl+Left, Right, Ctrl+Right).  

:heavy_plus_sign: Добавлен специальный фильтр YandexLogoCutter отрезающий логотип у Yandex-каптч.    
:heavy_plus_sign: Добавлена возможность размножения символов путём искажения уже имеющихся в проекте CapMonster MCS.  
:heavy_plus_sign: Добавлен аварийный перезапуск сервиса CapMonster в случае вылета программы.   
:heavy_plus_sign: Добавлена возможность проведения теста модуля в CapMonster MCS на изображениях из внешней директории.    
:heavy_plus_sign: Добавлена возможность указания типа каптч при сохранении модуля в CapMonster MCS.  
:heavy_plus_sign: Добавлена настройка автозапуска сервиса CapMonster после загрузки приложения.  
:heavy_plus_sign: CapMonster теперь дружит с A-Parser.  
:heavy_plus_sign: Небольшие изменения в интерфейсе логов CapMonster. Модули ZennoLab (теперь без префикса ZennoLab) в логах выделяются синим цветом, а пользовательские зелёным.  
:heavy_plus_sign: Добавлена возможность принудительного использования указанного модуля для распознавания всех поступающих изображений. При этом, если запрос был отправлен с параметром `CapMonsterModule=“Name”`, то распознавание будет использоваться для модуль “Name”. 

### :rocket: Улучшены модули распознавания:  
- Avito - 35%.
- Bing - 37%.
- Вконтакте - 22%.
- KCaptcha New - 53%.

### Исправленные баги:  
:white_check_mark: Исправлены утечки памяти при обучении в CapMonster MCS.          
:white_check_mark: Проект автоматически сохраняется перед обучением.  
:white_check_mark: Исправлены некоторые ошибки при эмуляции сервиса Anti-Captcha.  
:white_check_mark: Исправлены некоторые ошибки отображения загруженных изображений в галереях.
