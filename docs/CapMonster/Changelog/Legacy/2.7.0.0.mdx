## Описание.
### Новые фичи:  
:zap: Модуль ReCaptcha2 теперь может эффективно использовать весь процессор.  
:zap: Добавлены новые конфигурации нейросетей, что позволяет обучать более качественные модули.  
:zap: Добавлена обработка дополнительных настроек сервисов распознавания в перехвате CapMonster, а именно: `regsense`, `numeric`, `calc`, `min_len`, `max_len`, `is_russian`.  

:heavy_plus_sign: Теперь CapMonster умеет считать. В настройках модулей распознавания каптч в MCS появилась настройка **«Математическое действие»**.  
:heavy_plus_sign: Улучшены средства диагностики проблем. 

### :rocket: Улучшены модули распознавания:  
- Drupal - 56%.
- GoogleWords - 20%.
- KCaptchaNew - 74%.
- KCaptchaOld - 79%.
- mailru - 92%.
- mailru2016 - 64%.
- mailruanonimizer - 92%.
- mailrumobile - 95%.
- vk - 45%.
- YandexDigits - 80%.
- GoogleDigits - 54%.
- Avito - 70%.
- botdetect - 73%.  

### Исправленные баги:  
:white_check_mark: Исправлен вызов формы imacros по адресу anti-captcha.com/imacros.html.  
:white_check_mark: При переименовании каптчи в CapMonster MCS так же менялась первая каптча на странице галереи.  
:white_check_mark: Исправлено мерцание контролов при отображении настроек фильтров.
