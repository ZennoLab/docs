## Описание.
### Новые фичи:  
:zap: Улучшены средства диагностики проблем в CapMonster.  
:zap: Добавлена настройка **«Не использовать дополнительные программы при распознавании»**. Настройка будет полезна для тех, у кого возникают трудности с CMConnector.  
:zap: Добавлен модуль распознавания **рек** в ReCaptcha2.  

### Исправленные баги:  
:white_check_mark: Исправлены ошибки в распознавании аудиокаптч, приводившие к зависанию.  
:white_check_mark: Не выдавалось сообщение о том, что Skype мешает запуститься сервису CapMonster, для новых версий Skype.
