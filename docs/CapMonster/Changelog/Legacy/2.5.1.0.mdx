## Описание.
### Новые фичи:  
:zap: Добавили настройку “Не распознавать повторно каптчи с жалобами”, чтобы предотвратить зацикливание одной и той же каптчи при работе с некоторыми программами.  
:zap: При запуске на Windows Server 2008, 2012 программа определяет наличие кодеков для аудиокаптч, и предлагает их установить при необходимости.  
:zap: CapMonster MCS: Оптимизировано распознавание на GPU, устранена ошибка в распознавании на более старых версиях видеокарт Nvidia.  

:heavy_plus_sign: Увеличена стабильность и оптимизирован процесс работы сервиса CapMonster.  
:heavy_plus_sign: Добавлена поддержка перехвата запросов на сервис 2Captcha.  
:heavy_plus_sign: Добавлена поддержка API AntiGate (Anti-Captcha) для отправки ReCaptcha2. Данное API возможно использовать для распознавания ReCaptcha2 средствами CapMonster.  
:heavy_plus_sign: При использовании модуля ReCaptcha2 и возникновении ошибки, в лог распознавания выводится соответствующее сообщение.  
:heavy_plus_sign: CapMonster MCS: При использовании словаря теперь учитывается регистр шаблонных слов.  
:heavy_plus_sign: CapMonster MCS: Добавлена функция “100% распознавание” при распознавании каптч из тестовой коллекции через сервисы распознавания. 

### :rocket: Улучшены модули распознавания:  
- KCaptchaNew Small - 66%.
- KCaptchaOld Small - 50%.
- WordPress (Classic New) Small - 52%.
- WordPress (Peters Anti Spam) NoLogo - 58%.
- Sosblogs - 99%.

### Исправленные баги:  
:white_check_mark: Исправлены падения или зависания CapMonster MCS во время обучения.  
:white_check_mark: Исправлены ошибки перехвата запроса из GSA search engine ranker через сервисы CaptchaBot, ByPassCaptcha, DeathByCaptcha, DeCaptcha.  
:white_check_mark: Исправлены ошибки перехвата запроса для AntiGate (Anti-Captcha), ByPassCaptcha, RipCaptcha, RuCaptcha.  
:white_check_mark: Исправлена ошибка повисания при распознавании каптч Яндекса, Google.  
:white_check_mark: Исправлена ошибка некорректного распознавания AudioReCaptcha из 10 цифр.  
:white_check_mark: Исправлен баг с фильтром Closing при редактировании списка фильтров.  
:white_check_mark: Исправлены некоторые ошибки, возникающие при автоматическом перезапуске CapMonster.  
:white_check_mark: Исправлена ошибка перехвата запросов от Key Collector.
