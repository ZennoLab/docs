## Описание.
### Новые фичи:  
:zap: В настройках распознавания добавлена опция **Получение ответа с задержкой, если каптча ещё не готова**, в соответствии с реализацией API AntiGate.  

По умолчанию, настройка включена для повышения совместимости со сторонними программами. В высоконагруженных системах (десятки и сотни потоков распознавания), отключение этой настройки может уменьшить скорость распознавания графических каптч.  

### :rocket: Улучшены модули распознавания:  
- Hotmail.

### Исправленные баги:  
:white_check_mark: При обновлении программы с версий 2.5.6.0(1) на более новую, при первом запуске могли отображаться не все модули.  
:white_check_mark: Исправлена ошибка `install.res????…` при установке, возникавшая на некоторых системах.
