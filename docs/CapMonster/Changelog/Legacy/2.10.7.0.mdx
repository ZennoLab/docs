## Описание.
### Новые фичи:  
:zap: Повышена производительность системы распознавания каптч удаленных модулей.  
:zap: Добавлена система автоматического контроля прокси:  
- загрузка прокси из разных источников: списка, файл, по ссылке;  
- автоматическое ведение чёрного списка.    

:zap: Добавлена настройка контроля свободных ресурсов для запусков RC2Instance и RC2InstanceChrome, что увеличит стабильность и качество работы.  

### Исправленные баги:  
:white_check_mark: Исправлена работа без отображения RC2InstanceChrome через IPv6 прокси.
