## Описание.
### Новые фичи:  
:zap: Добавлено автоматическое обновление и загрузка новых модулей с сервера ZennoLab.  
:zap: Значительно улучшена работа системы определения типа принятой каптчи.  
:zap: Изменена политика работы сервиса CapMonster, которая позволяет запускать CapMonster без конфликтов вместе с некоторыми приложениями (Apache, IIS, MSSQL Server reporting services, Skype и т.д.).  

:heavy_plus_sign: Добавлена настройка **Порт** для CapMonster.    
:heavy_plus_sign: Добавлена настройка **IP** для CapMonster. Есть возможность выбора IP из списка возможных или использовать автоматическое определения используемого IP.  
:heavy_plus_sign: CapMonster перехватывает запросы баланса на сервисы распознавания и симулирует некоторое количество средств даже если авторизационные данные не корректны.  
:heavy_plus_sign: Добавлена обработка запросов для сервисов о неправильно разгаданных каптч.  
:heavy_plus_sign: Уменьшено потребление памяти у сервиса CapMonster.  
:heavy_plus_sign: Добавлена обработка запросов из ZennoPoster через CapMonster2.dll.  
:heavy_plus_sign: Добавлена поддержка эмуляции сервиса RuCaptcha.com в CapMonster.  
:heavy_plus_sign: CapMonster MCS: Добавлена возможность удаления элементов галереи по кнопке Delete.  
:heavy_plus_sign: CapMonster MCS: Добавлена функция **Удалить каптчи по символу**, удаляет все каптчи содержащие указанные символ.  
:heavy_plus_sign: CapMonster MCS: Добавлена функция “Удалить символ”, удаляет указанный символ из текстов каптч в указанных коллекциях.  
:heavy_plus_sign: CapMonster MCS: Добавлена функция “Замена символа”, заменяет указанный символ в текстах каптч на другой в указанных коллекциях.  
:heavy_plus_sign: CapMonster MCS: Добавлены настройки шрифта и цвета для отображения текста каптч в галереях.  
:heavy_plus_sign: CapMonster MCS: Добавлен фильтр FixedSize (раздел “Геометрия”) для установки единого фиксированного значения размеров для всех обрабатываемых изображений.  
:heavy_plus_sign: CapMonster MCS: Добавлен фильтр RemoveBlobs (раздел “Удаление шума”) удаляющий пятна из изображения.  
:heavy_plus_sign: CapMonster MCS: Добавлен фильтр RemoveDots (раздел “Удаление шума”) удаляющий точечный шум из изображения.  
:heavy_plus_sign: CapMonster MCS: Добавлен модуль для распознавания через сервис rucaptcha.com.  

### :rocket: Улучшены модули распознавания:  
- ArticleMS - 83%.
- BotDetect - 46%.
- MailRu - 64%.
- PHP Link Directory - 95%. 
- Rambler - 79%.
- RecaptchaMiddleFeb15 - 55%.

:white_check_mark: Исправлены некоторые баги искажения символов.          
:white_check_mark: Исправлены ошибки обработки центров масс и получения символов из изображения для обучения.  
:white_check_mark: Исправлены некоторый ошибки работы горячих кнопок в галереях каптч.  
:white_check_mark: Исправлен баг, изменяющий текст каптчи в тестовой коллекции.  
:white_check_mark: Исправлены некоторые ошибки, при распознавании каптч с прозрачностью, в сервисе CapMonster.
