## Минимальные требования.
- **Процессор:** Intel или AMD от 2 ядер, не менее 2,2 Ггц каждое.  
- **RAM:** не менее 2048 Мб.  
- **Место на накопителе:** не менее 1024 Мб.  
- **Видеокарта:** любая.  
- **Операционная система:** Windows 10 x64 и более поздние версии (Server Core не поддерживается).  
- **Наличие .Net Framework 4.6.2+.**  
- **Также Visual C++ redistributable 2015-2019.**  
- **Права администратора.** Они понадобятся для установки и запуска программы.  
- **Интернет.** Обязателен. Без него не получится работать.  

## Рекомендуемые требования.  
- **Процессор:** Intel или AMD от 4 ядер, не менее 3,1 Ггц каждое.  
- **RAM:** 4 Гб.
- **Место на накопителе:** 2048 Мб и больше.  
- **Видеокарта:** Nvidia GeForce с поддержкой CUDA.  
- **Операционная система:** Windows 10 x64 и более поздние версии (Server Core не поддерживается).  
- **Наличие .Net Framework 4.6.2+.**  
- **Также Visual C++ redistributable 2015-2019.**  
- **Права администратора.** Они понадобятся для установки и запуска программы.  
- **Интернет.** Обязателен. Без него не получится работать.
