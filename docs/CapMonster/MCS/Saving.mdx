## Сохранить модуль.
Когда работа над модулем завершена, и результат вас устраивает, перейдите в режим **«Тестирование модуля»** и нажмите **«Сохранить модуль»**. Затем укажите путь для сохранения.  

![Сохранить модуль](./assets/Saving.png) 

Теперь вы получили собственный полностью готовый модуль распознавания. Можете добавить его в CapMonster и использовать при решении капч.
