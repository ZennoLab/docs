27.08.2026

**Добавлено:**

[+] Добавлен **ИИ-помощник** в ProjectMaker. Встроенная панель общения с большими языковыми моделями (OpenAI, Claude, Gemini, DeepSeek, Perplexity). Есть два режима работы:

- **Assistant** — только чтение. Ассистент отвечает на вопросы, объясняет, что делает выбранный кубик, разбирает ошибки последнего запуска, рассказывает о доступных параметрах. Проект не меняется — безопасно для боевых сценариев.
- **Agent** — полный доступ. Ассистент может самостоятельно:
    - добавлять, изменять, перемещать и удалять кубики любых типов из каталога ZennoPoster;
    - выстраивать связи между ними (ветки успеха и ошибки), создавать и переименовывать группы;
    - создавать и заполнять таблицы, списки, переменные, привязывать таблицы к Google Sheets;
    - управлять запущенным браузером: открывать и переключать вкладки, переходить по URL, читать DOM, кликать, вводить текст, генерировать события;
    - запускать отдельные кубики и читать их логи, чтобы итеративно отлаживать сценарий;
    - писать код для кубиков OwnCode|CSharp — ассистент знает актуальный C# API проекта (`IZennoPosterProjectModel`, `Instance` и другие).

Документация: [ИИ-помощник](../get-started/ai-assistant) · [MCP Setup](../get-started/MCP_Setup).

[+] Также добавлен **новый ИИ-кубик**. Новый тип действия для вызова LLM прямо из сценария: те же провайдеры, что и в чате, единая настройка API-ключей в настройках программы. Подходит для генерации текста, классификации, извлечения данных и перевода — встраивается в существующие проекты без внешних скриптов.

[+] Возможность одновременного запуска PM для ZennoDroid и PM для ZennoPoster (**ИИ-агенты и MCP-службы не мешают работе друг друга**).

[+] **ZD PRO.** Добавлена возможность использовать **новый эмулятор** [LDPlayer 14](https://www.ldplayer.net/) (на базе Android 14).

[+] **ZD ENTERPRISE.** Добавлена возможность использовать в качестве устройства запущенный **эмулятор LDPlayer 14**.

[+] **ZD PRO.** Возможность выполнять команды, которым необходимы **права суперпользователя**, без включения соответствующей настройки (Root).

[+] **ZD PRO.** Отключена анимация интерфейса Android для **ускорения работы**.

[+] **Вся справочная информация** из программы теперь ведёт на новую документацию.

[+] **Конструктор действий** вынесен в отдельную док-панель (можно настроить его положение по своему усмотрению).

[+] **Scrcpy** обновлен до версии 4.1.0.

[+] Добавлена **эмуляция реальных нажатий на экран** (работают на защищённых страницах, нажатия видны через `getevent`, нажатие имеет размер).
Включается на вкладке настроек параметром «Использовать улучшенные нажатия» или через код C# (выполнять перед подключением к устройству):

```csharp
instance.DroidInstance.Input.SetNativeEventMode(true);
```

[+] **ZD ENTERPRISE.** Добавлена возможность эмуляции реальных нажатий на устройствах без дисплея (тачпада).

[+] При выполнении экшена **Получить куки приложения** зашифрованные значения (`encrypted_value`) автоматически расшифровываются.

[+] Добавлены новые методы для работы с куки через код C#: [получение](../API/App#getcookie), [импорт](../API/App#importcookie), [удаление](../API/App#deletecookie).

```csharp
string GetCookie(string packageName, string host, string name = null, bool persistentOnly = false, bool secureOnly = false, bool httpOnly = false);

string ImportCookie(string packageName, string cookies, bool replaceAll = false);

string DeleteCookie(string packageName, string host = null, string name = null, bool persistentOnly = false, bool secureOnly = false, bool httpOnly = false);
```

**Исправлено:**

[\] **ZD ENTERPRISE.** Исправлен баг, из-за которого при включении VPN ZennoDroid не видел устройства, расположенные в локальной сети. Добавлено сохранение диапазона сканирования, заданного в Менеджере устройств: после перезапуска ZennoDroid будет искать устройства в последнем просканированном диапазоне.

[\] Исправлен баг, из-за которого при первой установке **Clash** не применялся **белый/чёрный список**.

[\] **ZD ENTERPRISE.** Исправлена установка **Clash** при использовании KernelSU.

[\] **ZD PRO.** В LDPlayer исправлена **отправка и получение файлов**, содержащих пробелы в названии.

[\] Исправлено **прерывание выполнения работы шаблона** при потере связи с устройством.

[\] Исправлено **падение ZennoDroid при массовой остановке работы шаблонов** из-за потери связи с интернетом.

[\] Исправлено **прерывание выполнения команд** Adb Shell по таймауту.

[\] Исправлен баг, из-за которого при использовании эмуляции реальных нажатий на экране мог появиться курсор мыши.

[\] **ZD PRO.** Исправлен полный сброс при использовании эмулятора LDPlayer 14.

[\] Исправлена **повышенная нагрузка в простое** при установке ZennoBrowser.
