**Добавлено:**

[+] У ZennoDroid и ProjectMaker появился **публичный HTTP API и комплект MCP-серверов**. Продуктом теперь можно управлять извне — из собственных скриптов и приложений или прямо из AI-ассистента (Claude Code, Cursor и любого другого MCP-клиента): читать и редактировать проекты, ставить задачи на выполнение, управлять браузером.

- **Публичный REST API (PublicAPI)** — более 100 операций под единым контрактом: работа с проектом в ProjectMaker (дерево действий, переменные, списки, таблицы, статические данные), управление задачами и сессиями выполнения в ZennoDroid, информация с устройства (дерево элементов, установленные приложения). Контракт описан в OpenAPI — по спецификации можно сгенерировать клиент для любого языка.
- **API-ключи с гибкими правами.** Ключи выпускаются в ProjectMaker (Settings → API Keys); для каждого ключа задаётся набор разрешений (scopes) и максимальный уровень операций (tier) — от строго read-only до полного управления. Ключ показывается один раз при создании; все ошибки авторизации API возвращает в структурированном виде, с указанием, каких именно прав не хватило.
- **MCP-серверы для AI-ассистентов.** Три сервера — ProjectMaker (редактирование проекта), Android (информация с устройства), ZennoDroid (задачи и сессии) — публикуются как готовые self-contained сборки: скачали, вписали свой API-ключ, подключили к своему LLM-клиенту. Права ассистента определяются вашим ключом. Серверы принимают подключения только с локальной машины.

Встроенный AI-чат продукта работает на этой же инфраструктуре — та же модель прав и тот же API, никаких скрытых привилегированных каналов.

Публичные серверы — в репозитории [README](https://github.com/ZennoLab/zennoposter-mcp/blob/main/README.ru.md).  
Документация (гайд интегратора, интерактивный OpenAPI-контракт, справочник операций, коды ошибок и политика версионирования): [zennolab.github.io/zennoposter-mcp](https://zennolab.github.io/zennoposter-mcp/ru/) — там же на GitHub лежат релизы MCP-серверов.

[+] Добавлены **инструменты сохранения, загрузки и закрытия проекта** ProjectMaker.

- `save_project` и `open_project` возвращают признак свежести файла: `fileHash` (SHA-256 содержимого .zp на диске, считается после записи), `fileSizeBytes`, `lastWriteTimeUtc`. Повторное открытие того же файла даёт идентичный хеш — так можно убедиться, что на диске именно то, что ожидалось.
- `get_project_info` дополнен флагом `hasUnsavedChanges` и теми же полями; хеш считается только когда несохранённых правок нет.
- `close_project` закрывает открытый проект. По умолчанию проект с несохранёнными правками не закрывается: возвращается `409 failed_precondition`, чтобы работа не пропала молча. Чтобы закрыть с потерей правок, нужно явно передать `discardUnsavedChanges: true`.

[+] Улучшены **инструменты чтения структуры проекта**.

- `get_project_structure` отдаёт граф: узлы (тип, метка, стартовая точка, switch, отключённость, принадлежность к error-ветке, groupId/actionId) и рёбра (OnSuccess/OnError/Default/Case-N, включая неявные переходы). Ответ трёхуровневый — обзор групп, срез по группе или полный граф, чтобы не раздувать ответ на больших шаблонах.
- `find_path(from, to)` — кратчайший маршрут между двумя кубиками.
- `get_action_connections(actionId)` — все входящие и исходящие связи и ветки конкретного кубика.

[+] Переименован пакет приложения **Appium**. Изменено стандартное имя `io.appium.uiautomator2.server`, по которому приложения могли определять автоматизацию. Изменён стандартный порт приложения, который также мог быть использован для детекта.

[+] Добавлен экшен [**Проект Visual Studio**](../project-editor/custom-code/Visual_Studio_Project). Позволяет использовать в проекте ZennoDroid проекты, созданные в Microsoft Visual Studio 2022/2026.

[+] **ZD ENTERPRISE.** Добавлен новый способ ввода текста: [**ZennoKeyboard**](../Settings/InputMethods#zennokeyboard). Автоматически устанавливается при подключении к устройству и вводит символы так, как если бы их набирали на клавиатуре. Обменивается данными с программой напрямую, результат ввода подтверждается устройством: если поле не приняло текст или приложение закрылось, экшен сразу завершится ошибкой, а не продолжит работу так, будто текст введён.

[+] **ZD ENTERPRISE.** **Эмуляция нахождения телефона в руках.** Антидетект для телефонов, неподвижно расположенных на стойке. Включается автоматически при использовании подмены устройства.

[+] **ZD ENTERPRISE.** Расширен **API для управления эмуляторами BlueStacks 5 и MSI App Player 5**. Добавлена возможность получить root в офлайн-режиме, без перезагрузки эмулятора, с помощью [**SetupRootOffline**](../API/BlueStacks5#setuprootoffline). Поддержка актуальной версии Magisk 30.7 и NeoZygisk (устанавливаются автоматически).

[+] **ZD ENTERPRISE.** Добавлена **эмуляция камеры (beta)**. Модуль **ZennoVCam** 3.3.31 подменяет камеру приложения видеофайлом: приложение получает кадры видео так, как будто они пришли с камеры устройства. [Свой код C#](../API/App#setvideoforfakecamera).

Эмуляция камеры на фермах **без физической камеры** (beta). [Свой код C#](../API/App#setvideoforfakecamera).

**Вращение**, изменение **масштаба** и **положения** видео для виртуальной камеры. [Свой код C#](../API/App#setfakecameraframing).

[+] **ZD ENTERPRISE.** В [Менеджер устройств](../Tools/Device_Manager_Ent) добавлен **мониторинг устройств**. Монитор с заданным интервалом опрашивает устройства из списка и сам переподключает те, что отвалились. Это основной инструмент для работы с пулом устройств по сети: адреса перечисляются один раз во вкладке «Настройки», а дальше монитор держит их подключенными без ручного вмешательства.

[+] **ZD ENTERPRISE.** В мониторинг устройств в сети добавлено ограничение максимального количества попыток подключения.
