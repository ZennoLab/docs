# ZennoDroid 1.1.0.0

### Новые фичи:

[+] Актуальная версия BlueStacks.

[+] При первом запуске ZennoDroid производится скачивание, установка и настройка виртуальной машины BlueStacks нужной версии.

[+] Настройка параметров: возможность перезаписи файла build.prop, установка имени WiFi сети, установка GPS координат, установка IMEI и других параметров через GUID BlueStacks.

[+] Добавлен root в BlueStacks.

[+] Добавлена возможность выполнения консольных команд.

[+] Улучшение интерфейса и отзывчивости виртуальной машины.

[+] Улучшение стабильности.

[+] Добавлена [статья](https://zennolab.atlassian.net/wiki/spaces/RU/pages/534053867 "https://zennolab.atlassian.net/wiki/spaces/RU/pages/534053867") *(ссылка устарела)* в вики о двух способах работы с виртуальной машины:

- виртуальная машина сохраняет состояние при завершении проекта;

- создание чистых виртуальных машин каждый раз при новом выполнении проекта.

### Исправленные баги:

[\] Исправлены проблемы с запуском на Windows Server.

[\] Исправлены ошибки с вылетом программы при вертикальной ориентации экрана.

[\] Исправлена работа Diagnostics.

[\] Исправлена ошибка, когда ZennoPoster не работал одновременно с ZennoDroid.

[\] Множество других исправлений.
