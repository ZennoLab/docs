18.06.2026

**Добавлено:**

[+] **ZD ENTERPRISE.** Экшен [«Управление LSPosed»](../Enterprise/LSPosed_Control) теперь поддерживает оригинальную версию [**LSPosed** 2.0.4](https://www.dropbox.com/scl/fi/i03ks4pxhz0dvmygn7r8x/LSPosed-v2.0.4-7741-release.zip?rlkey=uw08x4ir7euwf9lxj5hd9kiom&st=ev6yi6lh&dl=0) (без CLI):

- Информация о LSPosed
- Настройка списка приложений
- Включение и выключение модулей
- Полный бэкап и восстановление настроек
- Открытие и закрытие LSPosed

Для обхода ограничений, связанных с отсутствием возможности управления LSPosed, используется модуль ZennoLSPosed Helper.

[+] Для функции исправления **пропадания структуры WebView** в дереве элементов:

```csharp
instance.DroidInstance.WebView.EnableForcedRenderWebView();
```

Также добавлена возможность отключить режим (в случае возникновения проблем):

```csharp
instance.DroidInstance.WebView.DisableForcedRenderWebView();
```

[+] **ZD ENTERPRISE.** Отключено уведомление в Chrome при использовании режима **ForcedRenderWebView**. Необходимо добавить Chrome в список подмены модуля ZennoDroid.

[+] **ZD ENTERPRISE.** Исправлен баг в браузере Яндекс, из-за которого в нем не работал режим **ForcedRenderWebView**. Необходимо добавить Yandex в список подмены модуля ZennoDroid.

[+] Добавлено **автоматическое обновление версии Clash** до актуальной версии.

[+] **Clash** обновлен до 1.19.24.

[+] **OpenCvSharp** обновлен до 4.13.

[+] **FFMpeg** обновлен до 8.1.1.

[+] **Appium Settings** обновлен до 7.0.28.

[+] **UIAutomator** обновлен до 9.11.2.

[+] **Frida** обновлена до 17.9.6.

[+] **ZD ENTERPRISE.** **Модуль ZennoDroid** обновлен до версии 2.3.3.
Улучшено взаимодействие с сервисом LSPosed.
Добавлена поддержка режима ForcedRenderWebView.

[+] **ZD ENTERPRISE.** **Модуль ZennoBackup** обновлен до версии 2.0.0.
Исправления при взаимодействии с сервисом LSPosed.

[+] Добавлены **XML комментарии** для всех методов и свойств интерфейса `IDroidInstanceAPI` при использовании экшена «Свой код C#».

[+] **Справка расширена** подробным описанием всех методов, входящих в [основной](../API/DroidInstance) и [дополнительный](../API/DroidExtra) API.

**Исправлено:**

[\] **ZD ENTERPRISE.** Исправлены ошибки при работе с **модулем ZennoDroid**:

- Исправлена ошибка при выполнении экшена «Сгенерировать устройство (apply)».
- Исправлена ошибка, из-за которой выдавалось сообщение «Модуль выключен».

[\] Исправлен **баг при установке** apk и bundle apk (apks, apkm, xapk) с кэшированием.

[\] Исправлен баг, из-за которого при включении в UIAutomator режима MultiWindows **дерево элементов** отображалось не полностью:

```csharp
instance.DroidInstance.AppiumDriver.UpdateSettings("enableMultiWindows", true);
```

[\] **ZD ENTERPRISE.** Исправлен **критический баг при установке прокси**, из-за которого устройство отключалось и могло уйти в оффлайн (при использовании устройств, подключенных по сети).

[\] Исправлено **некорректное завершение захвата изображения** при выполнении проекта в ZennoDroid.

[\] Исправлена ошибка, если при получении bundle apk (apks) приложения отсутствовала **папка назначения**.
