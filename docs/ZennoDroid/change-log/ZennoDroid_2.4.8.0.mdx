18.02.26

**Добавлено:**

[+] **ZD ENTERPRISE.** Добавлен **экшен для эмуляции наличия включенного WiFi**. Используется для прошивок, которые не видят наличия интернет-подключения при отключенном WiFi. В API C# добавлен параметр AddWiFiEmulation для включения эмуляции WiFi.

```csharp
var filter = new DeviceFilter();
filter.Country = "us";
var options = new DeviceOptions();
options.AddWiFiEmulation = true;

var json = instance.DroidInstance.Settings.GenerateRandomLSPosedSettings(filter, options);
instance.DroidInstance.Settings.SetLSPosedSettings(json);
```

[+] В API C# добавлен **метод для быстрой смены качества захвата изображения**. Можно выполнять как до подключения к устройству, так и после.

```csharp
// 0 - Очень низкое качество, 5 - Низкое 10 - Высокое
instance.DroidInstance.Screen.SetCaptureScreenQuality(10);
```

[+] **ZD ENTERPRISE.** В API C# добавлен **метод для патча библиотеки Flutter** (ReFlutter), с целью дальнейшего перехвата и анализа трафика в Burp Suite.

```csharp
// Патч библиотеки
instance.DroidInstance.App.PatchFlutterLib("tech.httptoolkit.pinning_demo", "10.0.2.2:8083");
// Восстановление исходной библиотеки
instance.DroidInstance.App.RestoreFlutterLib("tech.httptoolkit.pinning_demo");
```

[Пример](https://www.dropbox.com/scl/fi/qck8cl7eiuqy61u508goe/Flutter_Patch_Restore.mp4?rlkey=xfavaqx4twy0atd49sdz4l26b&st=qfbcx200&dl=0) использования. [Приложение](https://github.com/httptoolkit/android-ssl-pinning-demo/releases/latest) для проверки перехвата запросов через Flutter

[+] В API C# добавлен **метод для получения пути к папке установленной программы** (Путь меняющийся при переустановке, имеет формат: `/data/app/~~y085wNyYQQpQwtJ1jpUYOg==/com.android.chrome-rD8qfdRUT680QgUrsaftWQ==`)

```csharp
return instance.DroidInstance.App.AppDir("com.android.chrome");
```
