# ZennoDroid 2.3.7.0

### Добавлено:

[+] Расширен список эмулируемых моделей устройств (около 300 наименований). IMEI генерируемых моделей соответствуют реальным устройствам.

[+] Добавлена возможность получить файл с устройства.

[+] Добавлена возможность отправить файл на устройство. В случае отправки медиафайлов они будут автоматически обновляться в галерее.

[+] Добавлена возможность получить установочный файл приложения с устройства в формате apk или apk bundle (apks).

### Исправлено:

[\] Исправлена ошибка при запуске приложения на Windows 7.

[\] В экшен «Модель устройства» добавлено поле ro.build.fingerprint.

[\] Исправлена ошибка при прерывании работы шаблона.

[\] Исправлена ошибка при отправке файлов на разделы, смонтированные только на чтение.

[\] Добавлено уведомление об ошибке при выполнении шаблонов, если предварительно не было выбрано устройство.

[\] Добавлены таймауты при отправке/получении файлов, установке приложений для предотвращения зависания данных операций при выполнении.

[\] Исправлено ожидание подключения через adb перед выполнением экшена «Консольная команда».

[\] Исправлено ожидание завершения работы с устройствами при выполнении шаблонов.

[\] Исправлено медленное обновление превью инстансов.

[\] Исправлен автоматический перезапуск ADB сервера при падении процесса.

[\] Обновлены библиотеки Newtonsoft.Json до версии 13.0.3.

[\] Для сервиса SmsHub добавлено "www" в адрес запроса баланса.

[\] Удaлено два неактуальных смс-сервиса: Smska и SmsVk.

[\] Изменены url'ы по умолчанию для следующих сервисов: SmsAcktiwator на [<u data-renderer-mark="true">https://smsak.org/api/</u>](https://smsak.org/api/?roistat_visit=1569121 "https://smsak.org/api/?roistat_visit=1569121") , SmsActivate на [<u data-renderer-mark="true">https://api.sms-activate.org/stubs/handler_api.php</u>](https://api.sms-activate.org/stubs/handler_api.php?roistat_visit=1569121 "https://api.sms-activate.org/stubs/handler_api.php?roistat_visit=1569121") и VirtualSms на [<u data-renderer-mark="true">https://api.sms-activate.org/stubs/handler_api.php</u>](https://api.sms-activate.org/stubs/handler_api.php?roistat_visit=1569121 "https://api.sms-activate.org/stubs/handler_api.php?roistat_visit=1569121") . Уже имеющиеся конфиги сервисов не обновятся.
