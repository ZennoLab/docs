30.10.2026

**Добавлено:**

[+] В окно «Устройство» добавлено **меню часто используемых действий** ([ZD Enterprise](../pm/Interface/DeviceWindow#меню-действий), [ZD Pro](../pm/Interface/DeviceWindowEmulator#меню-действий)):

- работа с приложениями устройства (установка, открытие, очистка и т. д.);
- работа с файлами устройства (отправка, получение, обзор и управление);
- поддерживается режим Drag'n'Drop: при перетаскивании файла в окно «Устройство» вызывается либо меню установки приложения, либо меню отправки, в зависимости от расширения файла;
- **ZD ENTERPRISE.** Magisk: включение, выключение, удаление и установка модулей, быстрая установка встроенных Busybox и LSPosed;
- **ZD ENTERPRISE.** LSPosed: настройка модуля (выбор приложений из списка), генератор устройства с фильтрами;
- диагностика: сведения об устройстве, сбор логов, очистка logcat;
- запуск, остановка, перезагрузка (у эмулятора — перезапуск), разблокировка экрана;
- **ZD ENTERPRISE.** включение adb по Wi-Fi;
- проверка внешнего IP, в том числе через Chrome;
- другие действия: «Сделать скриншот» (сохранение экрана устройства в PNG), «Закрыть участок», «Приблизить», «Отдалить» и «Запись движений мыши»;
- «Устройство» → «Сменить язык системы...»;
- «Активное приложение» → «Получить APK...»;
- **ZD ENTERPRISE.** «Magisk / LSPosed» → «Очистить профиль устройства»;
- «Выполнить команду...» — выполнение команды Adb Shell.

[+] Действия меню, отмеченные красной точкой, **записываются в проект**.

[+] **ZD ENTERPRISE.** В меню окна [«Устройство»](../pm/Interface/DeviceWindow#безопасный-запуск) добавлен **безопасный запуск** телефона: «Диагностика» → «Безопасный запуск» → «Захват H.264» или «Обновление вручную». Используется для подключения к устройству без физического экрана, на котором возникли проблемы с Root.

[+] **ZD ENTERPRISE.** API проекта: [`Action.Reboot()`](../API/Action#reboot) — **перезагрузка телефона**.

[+] API проекта: [`Proxy.GetExternalIp()`](../API/Proxy#getexternalip) и [`Proxy.GetExternalIpInBrowser()`](../API/Proxy#getexternalipinbrowser) — **проверка внешнего IP устройства**.

[+] В режим «Следовать за курсором» добавлена **пауза по F9**: выбор элемента под курсором замирает, и курсор можно довести до панелей «Дерево элементов» и «Свойства элемента», не потеряв элемент. Повторное нажатие F9 снимает паузу.

[+] Добавлена **панель результатов поиска** по проекту: все совпадения сразу одним списком с указанием, где найдено (имя, комментарий, параметры, код), переход к кубику щелчком по строке, фильтр по типу кубика и поиск по всем открытым проектам.

[+] **ZD PRO.** Поддержка эмулятора [**MuMu Player**](https://www.mumuplayer.com/ru) (Android 12 и Android 15). Дополнительно к возможностям самого эмулятора:

- отключение рекламы при загрузке и на рабочем столе;
- смена оператора связи, IMSI, серийного номера SIM-карты;
- смена Android ID для приложений;
- подмена видеокарты и шум Canvas;
- работа с root без его включения в настройках эмулятора.

Как установить эмулятор и подключить его к ZennoDroid — в статье [**Установка MuMu**](../pro-lite/MuMu_Install).

[+] В окне выбора прокси можно указать **способ проксирования** (Proxifier, Redsocks, Clash).

[+] **ZD ENTERPRISE.** **LSPosed 2.2.1** теперь входит в состав ZennoDroid. Его можно установить через [меню действий](../Enterprise/LSPosed#установка-через-меню-действий-zennodroid-262). Управляется через собственный CLI (включается автоматически, необходима разовая перезагрузка телефона).

[+] **ZD ENTERPRISE.** Добавлен [**кубик для смены числа ядер и объёма памяти**](../Android/Enterprise/setting#управление-производительностью). Нужен для ручной подмены, если используется собственный генератор устройств. При использовании встроенного генератора значения задаются автоматически.

[+] Приложения, установленные через ZennoDroid, определяются как **установленные из Google Play**.

[+] **Нажатия и жесты** в режиме «Использовать улучшенные нажатия» ([ZD Enterprise](../Settings/Settings_for_Enterprise#использовать-улучшенные-нажатия), [ZD Pro](../Settings/Settings_for_Android#использовать-улучшенные-нажатия)) стали ещё ближе к реальным касаниям пальца: по ходу нажатия меняются размер касания и скорость, повторы всегда немного отличаются друг от друга.

[+] **ZD ENTERPRISE.** Модуль **ZennoDroid** обновлён до версии 4.0.5. Модуль значительно переработан: после первого применения параметров **необходимо один раз перезагрузить телефон**, в дальнейшем подмены работают без перезагрузки.

- Подмена **числа ядер и объёма памяти** в Chrome.
- Реализовано большое количество исправлений и новых хуков для **согласованности подменяемых параметров**.
- **ZennoKeyboard** видна приложениям как системная клавиатура.
- Улучшено **скрытие приложений**.

[+] **ZD ENTERPRISE.** Модуль **ZennoVCam** обновлён до версии 4.0.0. Модуль значительно переработан для более стабильной работы, исправлены найденные ошибки.

**Исправлено:**

[\] Исправлен **захват экрана** во всех режимах (H.264, MJPEG, off), из-за которого проекты нестабильно работали в многопоточном режиме.

[\] Исправлена задержка перед воспроизведением **записанных движений мыши** [`Input.FreeMove`](../API/Input#freemove).

[\] Исправлено нестабильное **выполнение JavaScript** при холодном запуске Chrome (не удалось подключиться к websocket; websocket не найден).

[\] **ZD ENTERPRISE.** **LSPosed Helper** больше не показывает уведомление при каждом применении настроек.

[\] Исправлены сбои при **бэкапе и восстановлении приложений**.

[\] Исправлены различные сбои при выполнении **запроса дерева элементов**.

[\] Исправлена ошибка, из-за которой на Android 12+ **дерево элементов** не читалось, пока на экране отображалось всплывающее сообщение.

[\] **ZD ENTERPRISE.** Исправлено включение **Clash через интернет-подключение компьютера** на некоторых телефонах.

[\] Исправлена **утечка DNS** при работе через Clash, в том числе при использовании DoH (`https://1.1.1.1/dns-query`) и DoT (`tls://1.1.1.1`).

[\] Исправлена работа **белого и чёрного списков приложений** Clash, если названия были разделены пробелами.

[\] **ZD ENTERPRISE.** Исправлено включение и отключение **Clash через интернет-подключение компьютера**, если в DNS-серверах указан DoT (например, `tls://1.1.1.1`): возникала ошибка запуска прокси.

[\] **ZD ENTERPRISE.** Исправлена **смена языка системы** на некоторых прошивках (не менялся регион).

[\] Исправлено **отслеживание подключения устройств** после смены adb-сервера (например, Android Studio).

[\] Исправлена отправка **Cookie в HTTP-запросах**.

[\] Исправлено **ручное сопоставление переменных** в кубике «Проект в проекте».

[\] Исправлено применение **директив using** к общему коду.

[\] Исправлена **«Быстрая проверка»** при отладке C#.

[\] **ZD ENTERPRISE.** Исправлено **зависание выполнения потока**.

[\] **ZD ENTERPRISE.** Исправлен **поиск по проекту**: кубик можно найти по ID действия.

[\] **ZD PRO.** Исправлен **захват экрана MuMu** в режиме «Использовать улучшенные нажатия».
