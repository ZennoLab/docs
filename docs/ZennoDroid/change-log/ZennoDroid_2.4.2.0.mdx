# ZennoDroid 2.4.2.0

### Добавлено:

[+] Добавлен новый метод проксирования трафика: Clash.

[+] На вкладку настроек Android в способ проксирования трафика добавлен новый метод - Clash. Дополнительные настройки проксирования (DNS, IP адрес) убраны в экшен "Установить прокси".

[+] В экшен "Установить прокси" добавлена возможность выбирать способ проксирования трафика:

- По умолчанию (используется способ указанный на странице настроек).
- Proxifier.
- Redsocks.
- Clash.

[+] При использовании Clash в экшене "Установить прокси" имеется возможность указать:

- Локальный IP адрес.
- Локальный IPv6 адрес.
- Адреса DNS серверов (через запятую).
- Белый список приложений (через запятую). Проксируются только указанные в списке приложения, остальные используют прямое подключение.
- Черный список приложений (через запятую). Указанные в списке приложения используют прямое подключение, остальные приложения проксируются.

Одновременно можно использовать либо белый, либо черный список.

[+] При использовании Clash возможно использование IPv6-прокси.

[+] В режиме Clash при использовании socks-прокси весь UDP трафик автоматически проксируется (при условии, что прокси поддерживает UDP). При проверке утечки IP через WebRTC будет отображаться либо адрес прокси, либо неопределенный адрес (если прокси не поддерживает UDP или при использовании http-прокси).

[+] Добавлены новые методы в API для установки прокси с возможностью указать дополнительные настройки (способ проксирования, DNS, IP адреса, списки приложений).
Посмотреть примеры использования настроек можно с помощью конвертации экшена "Установить прокси" в C# код (через контекстное меню)
*instance.DroidInstance.Proxy.SetProxy(string proxy, IDroidProxySettings settings);

### Исправлено:

[\] Исправлен баг, из-за которого мог перестать работать монитор подключенных устройств и переставала обновляться информация об их состоянии.

[\] В настройки выполнения проектов добавлен пункт "Использовать обновленный метод поиска элементов".
Данная настройка исправляет баг, из-за которого при классическом поиске элементов не учитывалось первое условие в списке (при наличии двух и более условий). Экшен мог завершиться успехом даже если первое условие не выполнялось. Используйте с осторожностью. Возможно изменение в логике старых шаблонов.

[\] Исправлена конвертация в C# экшена "Удалить аккаунты".

[\] Исправлена конвертация в C# экшена "Получить аккаунты".

[\] Исправлена ошибка при выполнении javascript в Microsoft Bing Search.

[\] Исправлена работа экшена "Установить прокси", когда в качестве адреса прокси была указана пустая строка.

[\] Исправлено зависание ProjectMaker и ZennoDroid при закрытии приложения.
