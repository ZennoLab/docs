# ZennoDroid 2.4.5.0

### Добавлено:

[+] **ZD ENTERPRISE.** Модуль ZennoDroid обновлен до версии 1.11.1. Добавлена подмена TAC устройства. TAC - уникальный код модели мобильного устройства. Является частью (первые 8 цифр) IMEI, которую могут запрашивать обычные (несистемные) приложения

[+] **ZD PRO.** Добавлена возможность сменить тип используемого эмулятора без перезапуска Project Maker и ZennoDroid

[+] В экшен Установка Apk добавлена возможность кэшировать файлы устанавливаемых приложений. Поддерживается кэширование apk и bundle apk (apks, xapk, apkm). Если требуется переустанавливать приложения это позволит не отправлять каждый раз файл на устройство, что значительно снижает нагрузку на канал связи. Если файл не использовался более 3-х дней происходит его автоматическое удаление.

[+] **ZD ENTERPRISE.** В экшен «Установка Apk» добавлена возможность устанавливать файлы с правами суперпользователя. Поддерживается установка apk и bundle apk (apks, xapk, apkm). Данная возможность может быть использована для установки приложений на телефоны с прошивкой MIUI, чтобы избежать всплывающего запроса на установку приложений.

[+] На вкладку Инстансы и Превью инстансов добавлена возможность выбрать формат отображения (альбомный/портретный)

[+] Добавлена возможность сохранить проект как плагин

[+] Обновлен компонент, отвечающий за текстовые поля в Project Maker. Новый компонент поддерживает большее количество символов, в том числе эмоджи. Также поддерживается синтаксис C# вплоть до 13 версии языка. Обращаем ваше внимание, что компилятор C# пока что поддерживает версию языка только 7.3, что может вызвать неудобства.

[+] ScrCpy обновлен до версии 3.3.2

[+] Clash обновлен до версии 1.19.13

[+] BoxForRoot обновлен до версии 1.10.2 (скрипты для Clash)

### Исправлено:

- **ZD ENTERPRISE.** Исправлена ошибка при установке и получении буфера обмена на некоторых телефонах Samsung (S9, S10);
- **ZD PRO.** Исправлена ошибка из-за которой не работала смена типа используемого эмулятора при первом запуске программы;
- **ZD PRO.** Исправлена ошибка из-за которой при смене типа используемого эмулятора меню Frida и Установленные приложения были неактивны;
- Исправлена ошибка при восстановлении бэкапа: RestoreAppData Входная строка имела неверный формат;
- Исправлена ошибка приводившая к падению ADB сервера при установке больших приложений;
- Исправлены ошибки в базе данных моделей устройств;
- Исправлено отображение инстансов при переходе между вкладками Превью инстансов и Инстансы;
- Исправлен парсинг отрицательных координат в Дереве элементов;
- Исправлен баг приводивший к падению программы при использовании очень низкого разрешения на устройстве;
- Исправлено отображение превью инстансов при смене формата после запуска шаблона;
- Исправлена неправильная конвертация экшена "Эмуляция swipe" в C# код.
