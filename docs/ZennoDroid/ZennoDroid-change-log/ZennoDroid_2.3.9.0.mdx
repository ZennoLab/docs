# ZennoDroid 2.3.9.0

### Добавлено:

[+] Добавлен экшен «Удалить аккаунт».

[+] Добавлен экшен «Получить аккаунты».

[+] На вкладку настроек добавлена возможность выбор качества захвата изображения (Высокое/Низкое, примерно соответствует FullHD и HD качеству). Позволяет значительно снизить нагрузку при работе с большим количеством потоков.

[+] В экшен «HCaptcha» добавлено разгадывание по картинкам через CapMonster Cloud (только английские задания).

[+] На панель инструментов и в меню Инструменты добавлена возможность открыть «Менеджер устройств».

[+] В ZennoDroid (в окно отображения инстансов) добавлен вывод информации о названии устройства.
Теперь подпись под окном инстанса отображается в формате: Проект [НазваниеУстройства] Порт.

[+] В экшен «Смена языка» добавлена возможность указать регион (страну): en-US, en-CA, fr-FR,...

[+] Небольшие визуальные изменения в «Выбор способа захвата изображения». Можно переключаться между H.264(стандартно) и MJPEG.

[+] Добавлена проверка на валидность названия приложения при получении и очистке уведомлений, а также при получении куки.

### Исправлено:

[\] Исправлено разгадывание ReCaptcha2 через CapMonster Cloud в браузере Chrome 117 и выше (только английские задания).

[\] Исправлено автодополнение макросов `{AndroidKeys}` в экшенах «Установка значения» и «Конструктор действий».

[\] Исправлено включение автоповорота при запуске приложений.

[\] Исправлена работа в режиме моста в Android 9 при использовании RNDIS.

[\] Исправлена ошибка при конвертации экшена «Получить список устройств» в C# код.

[\] Исправлено получение apk (apks) приложения с устройства.

[\] Исправлен поиск текста по проекту (Ctrl - F3) в экшенах использующих классический поиск элементов: получить/установить значение, выполнить событие и других.

[\] Исправлено получение файла с устройства.
