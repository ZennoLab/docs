# ZennoDroid 2.3.3.0

### Новые фичи:

[+] Добавлена возможность проксировать трафик с помощью Redsocks2 (доступно только на образах Android 7х64 и Android 9). Redsocks2 поддерживает адреса прокси только в виде `IP:Port`.

[+] При использовании Redsocks2 добавлена возможность задать адреса DNS и проксировать DNS-запросы.

[+] При использовании Redsocks2 публичный IP адрес через WebRTC совпадает с адресом прокси.

[+] Добавлена возможность отключить использование Proxifier.

[+] Добавлена возможность распознать hCaptcha в приложении через сервисы распознавания.

[+] Добавлена возможность распознать hCaptcha (с кнопкой/без кнопки сабмита) в браузере Chrome через сервисы распознавания.

[+] Добавлена возможность установить/запустить сервер Frida. Выполнить скрипт. (Кнопка на панели рядом с кнопкой «Установленные приложения»).

[+] Улучшена работа в многопоточном режиме при одновременной отправке большого количества команд на устройства.

### Исправленные баги:

[\] Исправлена ситуация, когда переставали отображаться всплывающие уведомления в ZennoDroid.

[\] Исправлена ошибка, когда даже при корректном завершении программы при повторном запуске ZennoDroid возникало окно восстановления проектов.

[\] Исправлена ошибка «Remote WebSocket not found» при выполнении javascript на странице.

[\] Исправлена ошибка, когда при выполнении экшена «Консольная команда ADB Shell» возвращался не полный ответ.

[\] Исправлена ошибка ERROR\_RECAPTCHA\_INVALID\_DOMAIN при отправке hCaptcha на распознавание.

[\] Исправлен баг, из-за которого Frida видела не более 10-15 подключенных устройств.

[\] Исправлена очень долгая инициализация при первом получении дерева элементов.
