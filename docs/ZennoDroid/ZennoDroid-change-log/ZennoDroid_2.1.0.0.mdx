# ZennoDroid 2.1.0.0

### Новые фичи:

[+] Добавлено действие создание виртуальной машины с возможностью получения индекса или названия после выполнения.

[+] Добавлено действие клонирование виртуальной машины с возможностью получения индекса или названия после выполнения.

[+] Добавлено действие импортирование виртуальной машины формата .ovo с возможностью получения индекса или названия после выполнения.

[+] Извлечение структуры элементов экрана в виде XML строки.

[+] Добавлен переключатель для автоматического обновления дерева элементов при клике.

[+] Макрос переменной окружения для пути к директории MEmu `{ -Environment.EmulatorDirectory- }`

[+] Добавлена опция ожидания в экшенах установки, взятия значения и выполнения события.

[+] Обновлен ярлык для ProjectMaker.

### Исправленные баги:

[\] Исправлен некорректный захват изображения при старте виртуальной машины.

[\] Исправлено поведение, когда неправильно определялись координаты клика по картинке при включенном масштабировании в Windows 7.

[\] Исправлена ситуация, когда вместо окна эмулятор отображалась тонкая вертикальная линия.
