# ZennoDroid 2.3.5.0

### Новые фичи:

[+] Добавлена возможность сохранить и восстановить аккаунт Google и некоторых приложений («Свой код C#»).

[+] Добавлена возможность указать имя отправителя при эмуляции отправки SMS на устройство.

[+] Добавлена возможность выполнения JavaScript на странице из экшена «Свой код С#».
```csharp
var url = instance.DroidInstance.WebView.EvaluateScript("return window.location.href");
```

[+] Добавлена возможность распознавания ReCaptcha2 по картинкам через CapMonsterCloud (только английские задания).

[+] Ускорена инициализация при первом получении дерева элементов.

[+] Обновлены Appium до 5.8, FFmpeg до 6.0.

[+] Автоматическое открытие изображений в ReCaptcha2.

### Исправленные баги:

[\] Исправлена ошибка при эмуляции отправки SMS на устройство.

[\] Улучшена работа настройки «Исправлять ошибки build.prop».

[\] Исправлена ошибка при получении названия активного приложения.

[\] Исправлена ошибка при очистке уведомлений в шторке.
