# ZennoDroid 2.3.4.0

### Новые фичи:

[+] В экшен распознавания HCaptcha добавлены пункты «Использовать прокси проекта» и «Использовать куки проекта».

[+] Добавлен экшен «Распознать ReCaptcha» (через SiteKey).

[+] Добавлена возможность выполнять скрипты для Frida. «*Свой код C#»

[+] Добавлена возможность установить и выполнить SQL-запросы к базам данных приложений через SQLite3. «*Свой код C#»

[+] Добавлена возможность получить куки из браузеров и из приложений содержащих WebView (отображающие веб-контент). «*Свой код C#»

[+] Добавлена возможность сменить дату и время на устройстве. «*Свой код C#»

[+] Добавлена конвертация отдельных экшенов в код C# через контекстное меню (все экшены из групп Действия с устройством и Действия с приложением, тач, свайп, ввод символов, поиск по картинке, а также часть экшенов из групп Утилиты и Настройки).

[+] Добавлена возможность получить список устройств с дополнительной информацией (индексы, названия, запущенные, занятые в ZD). «*Свой код C#»

[+] Увеличены значения для профиля по умолчанию (CPU = 2 ядра, RAM = 2ГБ).

[+] Добавлена настройка «Исправлять ошибки build.prop».

:::important
Исправляет проблему, из-за которой `ro.boot.hardware` и `Build.HARDWARE` всегда равны `Intel`, а также баг в Android 9, из-за которого при установке CPU от 1-го до 3-х вместо названия модели устройства и ряда других параметров отображается `Unknown`.
:::

### Исправленные баги:

[\] Исправлена функция настройки почтовых сервисов.

[\] Исправлено удаление устройств с названием состоящим только из цифр.

[\] Исправлено открытие меню настроек проекта.

[\] Исправлена ошибка при использовании точек останова в экшене «Свой код C#».

[\] Исправлена ошибка при работе с устройствами с Android 9 в режиме моста (bridge).

[\] Исправлена функция «Закрыть все приложения».

[\] Исправлено долгое открытие меню настроек Android.

[\] Частично исправлены проблемы при выполнении JavaScript в Chrome 111 и выше.

[\] Исправлены ошибки при захвате изображения в режиме MJPEG.

[\] Исправлен выход по таймауту при зависании MEmu на старте.

[\] Исправлены ошибки, приводившие к блокировке запуска новых потоков в ZennoDroid.

[\] Исправлена ошибка при очистке поля ввода.

[\] Исправлен баг в MEmu с Android 9, из-за которого при установке CPU от 1-го до 3-х вместо названия модели устройства и ряда других параметров отображалось **Unknown**.

[\] В значениях *ro.boot.hardware, *Build.HARDWARE теперь не указан Intel.

[\] Исправлена ошибка при поиске эмулятора по названию.

[\] В меню «Установленные приложения» не отображалась информация о названиях приложений.

[\] Исправлена проблема, из-за которой возникала ошибка «Выполнение действия Запустить устройство Can't send rs binary» и зависала отправка команд через ADB.

[\] Исправлена ошибка при очистке поля ввода в MEmu 9.
