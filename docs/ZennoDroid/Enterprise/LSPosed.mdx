## Описание. 
Модуль ZennoDroid необходим для подмены основных параметров устройства: IMEI, Android ID, сотового оператора, модели, WiFi, Bluetooth и других.  
:::info **Для функционирования модуля необходимы Root-права**
Поддерживаются телефоны с Android 9-16 
:::  

Начиная с версии ZennoDroid 2.5.0.0, для установки модуля необходим [**Magisk**](https://github.com/topjohnwu/Magisk/releases/latest) с активным **Zygisk** и **LSPosed v.2**.  
_________________

### Активация встроенного Zygisk

### Активация стороннего Zygisk
Для улучшения антидетекта Magisk рекомендуется использовать сторонний Zygisk (например, [**Zygisk Next**](https://github.com/LSPosed/ZygiskNext/releases/latest)) вместо встроенного в Magisk.  

1. Скачиваем модуль Zygisk Next. В [**меню действий**](../pm/Interface/DeviceWindow#меню-действий) окна устройства выбираем **Magisk / LSPosed** → **Установить модуль...**, указываем скачанный файл и нажимаем **Установить**.  
2. Открываем настройки Magisk и выключаем встроенный **Zygisk**.  
3. Перезагружаем устройство.

## Установка LSPosed Framework    
### Установка через меню действий (ZennoDroid 2.6.2+)
**LSPosed v.2** поставляется вместе с ZennoDroid, установить его можно прямо из ProjectMaker через Меню действий:  

1. В [**меню действий**](../pm/Interface/DeviceWindow#меню-действий) окна устройства выбираем **Magisk / LSPosed** → **Модули...** - откроется окно [**Модули Magisk**](../pm/Interface/DeviceWindow#модули-magisk).  
2. Нажимаем **Установить...** → **Установить LSPosed**.  
3. Когда внизу окна появится надпись *Модуль установлен*, перезагружаем устройство, например пунктом меню [**Устройство** → **Перезагрузить**](../pm/Interface/DeviceWindow#устройство).

## Установка модуля «ZennoDroid»  
### Установка через меню действий (ZennoDroid 2.6.2+)
Модуль ZennoDroid проще всего установить прямо из ProjectMaker:  

1. В [**меню действий**](../pm/Interface/DeviceWindow#меню-действий) окна устройства выбираем **Magisk / LSPosed** → **Настройка модуля...** - откроется окно [**Настройка модуля LSPosed**](../pm/Interface/DeviceWindow#настройка-модуля-lsposed).  
2. Оставляем в поле **Модуль** `com.zennolab.zennodroid`, ставим флажок **Включить модуль** и отмечаем приложения, к которым будет применяться подмена параметров устройства.  
3. Нажимаем **Применить**.  

ZennoDroid сам установит модуль и включит его для отмеченных приложений.

### Важная информация  
- Рекомендуем добавлять в список подмены только те приложения, для которых действительно требуется изменять данные. **Не нужно добавлять в список системный фреймворк (system framework)**.  
- Если после активации вы удалили приложение, а затем установили его повторно, необходимо обязательно заново активировать приложение в списке подмены **(снять и установить галочку)**.  
  
:::tip **В LSPosed есть визуальный баг**
При удалении приложения оно также автоматически удаляется из списка подменяемых. Однако после повторной установки приложение автоматически не попадает в список подменяемых (галочка при этом стоит, но подмены не работают).
:::     
  
- По умолчанию в списке программ отображаются не все приложения. Если вы не видите нужного, например, Google Chrome, то нужно зайти в меню **Настройки** и выбрать нужную группу.

:::tip **Можно закрывать приложения и до подмены.**
Но тогда некоторые системные приложения тут же перезапускаются, поэтому могут считать старые параметры.
:::

## API для управления LSPosed (ZennoDroid 2.4.0+)
В версии **ZennoDroid 2.4.0** мы добавили API для управления LSPosed.

Основные функции:
- включить и выключить нужный модуль;  
- выбрать приложения в списке подмены нужного модуля, а также добавить или удалить их из списка;  
- создать и восстановить бэкап настроек (поддерживается сохранение как на телефон, так и на компьютер);  
- получить информацию о LSPosed.

### Видеоинструкция (пример работы с API)
