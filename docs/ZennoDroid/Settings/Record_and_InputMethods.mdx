## Автоматически вставлять макрос директории.  
:::tip **Эта настройка работает даже *при выключенной записи* проекта.**
:::   

В ZennoDroid существуют [**переменные окружения**](../pm/Creating/Variables). Например, `{-Project.Directory-}`, в которой хранится путь к директории, где сохранён файл проекта.  
:::info **Если проект не сохранён на диске, то переменная содержит пустую строку.**
::: 

При включении данной настройки во время создания проекта ProjectMaker будет подставлять макрос **директории проекта** туда, куда это возможно. Например, в другие настройки и экшены. Указываемый путь должен находиться в той же папке, что и файл проекта, либо в одной из подпапок.

## Запись нажатий.  
:::info **Выбор режима группой доступен начиная с версии ZennoDroid 2.6.3.0.**
Раньше режим задавали две галочки, **Запись нажатий через поиск по картинкам** и **Запись действий по координатам**, а по дереву элементов нажатия записывались, когда обе сняты.
:::

Режим определяет, каким экшеном запишется нажатие внутри [**Окна устройства**](../pm/Interface/DeviceWindow):  
- **По картинкам** - клик по фрагменту экрана вокруг точки нажатия: экшен клика по картинке, как в [**Поиске по картинке**](../pm/Creating/SearchByPic). Цветовой режим и область поиска для него задаются [**ниже**](#поиск-по-картинкам).  
- **По дереву элементов** - действие над элементом из [**Дерева элементов**](../pm/Interface/ElementTree): экшен [**Выполнить событие**](../Android/pro-lite/RunEvent) с событием *touch* или, если кнопку мыши удерживали, *long touch*. Если элемента в точке нажатия нет, запишется касание по координатам.  
- **По координатам** - касание в точке нажатия: экшен [**эмуляции touch**](../Android/pro-lite/Touch_Emulation) с координатами нажатия.  

Свайпы, масштабирование и ввод текста записываются одинаково в любом режиме.  

Во время записи режим переключается и кнопками в [**заголовке окна устройства**](../pm/Interface/DeviceWindow#режим-записи). Это та же настройка: изменение в заголовке сразу видно на вкладке, и наоборот. Новый режим действует со следующего нажатия.  

:::warning **Если координаты записываются в пикселях, разрешение эмулятора должно быть одинаковым во время создания и выполнения проекта!**
Об этом напоминает звёздочка у **По координатам**. Чтобы проект работал на устройствах с разным разрешением, включите [**координаты в процентах от экрана**](#координаты-в-процентах-от-экрана), и звёздочка пропадёт.
:::

## Автообновление дерева элементов.  
:::info **Доступно начиная с версии ZennoDroid 2.6.3.0. Включено по умолчанию.**
:::

Во время записи в режиме **По дереву элементов** ZennoDroid перед каждым нажатием в окне устройства заново читает [**дерево элементов**](../pm/Interface/ElementTree), чтобы записывались элементы текущего экрана. Без автообновления дерево остаётся от экрана, на котором его загрузили: после перехода на другой экран запишутся элементы прежнего, пока дерево не обновят на его панели.  

Поэтому во время такой записи нажатие уходит на устройство, когда кнопку мыши отпустят: так ZennoDroid успевает прочитать дерево и отличает касание от долгого нажатия и свайпа. Вне записи нажатия и свайпы идут на устройство сразу.  

Тот же переключатель есть в [**заголовке окна устройства**](../pm/Interface/DeviceWindow#режим-записи).

## Координаты в процентах от экрана.  
:::info **Доступно начиная с версии ZennoDroid 2.6.3.0.**
:::

С этой настройкой запись сохраняет координаты не в пикселях, а в процентах от ширины и высоты экрана, с точностью до сотых: например, `27.99%` вместо `302`. Проценты получают все экшены, которые запись создаёт с координатами:  
- [**эмуляция touch**](../Android/pro-lite/Touch_Emulation#координаты-в-процентах) для нажатий по координатам;  
- [**эмуляция swipe**](../Android/pro-lite/Swipe) для свайпов;  
- [**масштабирование**](../Android/pro-lite/Utilities#масштабирование) для жестов масштаба.  

Настройка не зависит от режима [**записи нажатий**](#запись-нажатий): режим решает, записывать ли нажатия по координатам, а эта настройка - в чём записывать сами координаты. Свайпы и масштабирование записываются с координатами всегда, поэтому для них проценты работают в любом режиме. Во время записи проценты включаются и кнопкой **%** в [**заголовке окна устройства**](../pm/Interface/DeviceWindow#режим-записи).  

Записанный так проект выполняется на устройствах с другим разрешением без правки координат. Ограничения те же, что у [**координат в процентах**](../Android/pro-lite/Touch_Emulation#координаты-в-процентах) в экшенах: поворот экрана не учитывается, а кнопка на экране с другим соотношением сторон может оказаться в другом месте.

## Поиск по картинкам.  
Значения по умолчанию для [**Поиска по картинке**](../pm/Creating/SearchByPic), в том числе для записи нажатий в режиме **По картинкам**.  
### Цветовой режим.  
Поиск по картинке будет по умолчанию производиться в одном из режимов:    
- **RGB**. Поиск по цветному изображению.        
- **Gray**. Картинка только с оттенками серого.      
- **Black**. Черно-белый режим.  
![Цветовой режим](./assets/Record_and_InputMethods/Record_and_InputMethods_pic4.png) 
:::tip **Советуем.**
*Для ускорения поиска производите поиск в режиме **Gray** или **Black***
:::   
 
### Область поиска.  
Выбор области, которая будет выставляться по умолчанию:  
- По всему экрану.  
- По выделенной области экрана. 
:::info **В целях снижения нагрузки на CPU лучше производить поиск по области экрана.**
:::
