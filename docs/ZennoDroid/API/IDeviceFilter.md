## Описание

`IDeviceFilter` используется для задания фильтров при выборе или создании устройств/эмуляторов для подмены через LSPosed. Позволяет ограничить выбор по различным характеристикам устройства, таким как страна, производитель, модель, версия Android и графический процессор.

## Методы

- **`string GpuVendor { get; set; }`**  
    Производитель GPU.
    
    **Описание:**  
    Например: `Qualcomm`, `ARM`.
