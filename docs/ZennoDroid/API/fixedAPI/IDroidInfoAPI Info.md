## Описание

`IDroidInfoAPI` предоставляет базовую информацию об устройстве или эмуляторе в ZennoDroid. Используется для получения идентификаторов, сетевых параметров и данных, необходимых для подключения и управления устройством.

## Свойства

- **`int Index { get; }`**  
    Индекс устройства.
    
    **Возвращает:**  
    Уникальный числовой идентификатор устройства в системе.
    

---

- **`string Title { get; }`**  
    Отображаемое название устройства.
    
    **Возвращает:**  
    Человекочитаемое имя (например, заданное пользователем).
    

---

- **`string Name { get; }`**  
    Внутреннее имя устройства.
    
    **Возвращает:**  
    Системное имя (используется для работы API).
    

---

- **`int UiPort { get; }`**  
    UI-порт устройства.
    
    **Возвращает:**  
    Порт, используемый для взаимодействия с интерфейсом устройства (например, для UI-автоматизации).
    

---

- **`string AddressPort { get; }`**  
    Адрес и порт подключения.
    
    **Возвращает:**  
    Строку в формате `IP:Port` (например: `127.0.0.1:5555`), используемую для подключения через ADB или другие инструменты.
    

---

### Важные замечания

- `Index`, `Name` и `Title` — разные идентификаторы:
    - `Index` — числовой;
    - `Name` — системный;
    - `Title` — отображаемый.
- `AddressPort` используется для:
    - ADB-подключения;
    - сетевого взаимодействия с устройством.
- `UiPort` может применяться:
    - для Appium;
    - для внутренних механизмов управления UI.
