## Описание

`IDeviceOptions` определяет дополнительные параметры генерации и настройки устройства в ZennoDroid. Используется совместно с `IDeviceFilter` для создания более реалистичных и вариативных профилей устройств.
## Свойства

- **`bool? AddCanvasNoise { get; set; }`**  
    Добавляет шум Canvas.
    
    **Описание:**  
    Включает модификацию Canvas-отпечатка (fingerprint), чтобы избежать точного совпадения между устройствами.
    

---

- **`bool? AddGpu { get; set; }`**  
    Добавляет параметры GPU.
    
    **Описание:**  
    Генерирует и применяет характеристики графического процессора.
    

---

## ПРОВЕРИТЬ!
- **`bool? AddWebView { get; set; }`**  
    Добавляет параметры WebView.
    
    **Описание:**  
    Влияет на конфигурацию WebView (например, user-agent, поведение браузера внутри приложения).
    

---

- **`bool? AddWiFiEmulation { get; set; }`**  
    Добавляет эмуляцию Wi-Fi.
    
    **Описание:**  
    Позволяет имитировать параметры Wi-Fi соединения (SSID, MAC и т.д.).
