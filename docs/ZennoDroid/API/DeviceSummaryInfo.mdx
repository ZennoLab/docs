# DeviceSummaryInfo
<DisclaimerNotice />
## Описание

`IDeviceSummaryInfo` содержит краткую информацию об устройстве или эмуляторе. Используется для получения базовых сведений о состоянии и идентификации устройства без необходимости полного подключения.
## Свойства


### Index

- **`int Index { get; }`**  
    Уникальный индекс устройства.
    
    **Возвращает:**  
    Числовой идентификатор, используемый для обращения к устройству в системе.

---

### IsBusy

- **`bool IsBusy { get; }`**  
    Указывает, занято ли устройство.
    
    **Возвращает:**  
    `true`, если устройство используется (например, выполняется сценарий); иначе `false`.

---

### IsRunning

- **`bool IsRunning { get; }`**  
    Готовность устройства к работе.
    
    **Возвращает:**  
    `true`, если устройство готово к работе: идёт захват экрана, при этом эмулятор запущен и подключён, а физический телефон подключён; иначе `false`.

---

### Name

- **`string Name { get; }`**  
    Внутреннее имя устройства.
    
    **Возвращает:**  
    Системное имя (например, идентификатор инстанса).

---

### Title

- **`string Title { get; }`**  
    Отображаемое название устройства.
    
    **Возвращает:**  
    Человекочитаемое имя (например, заданное пользователем).
