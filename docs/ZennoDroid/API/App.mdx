# App API
<DisclaimerNotice />
## Описание

`IDroidAppAPI` предназначен для управления приложениями на Android-устройстве в ZennoDroid. Предоставляет методы для работы с данными приложений, аккаунтами, уведомлениями, cookies и состоянием приложений.

Большинство методов принимают параметр `packageName` — имя пакета приложения. Для поиска нужного имени используйте инструмент [**Установленные приложения**](../Tools/Installed_App).

Повторяет логику работы кубика **Действия с приложением** для версий [**Lite/Pro**](../Android/pro-lite/App) и [**Enterprise**](../Android/Enterprise/App).
## Свойства

- **`string Top { get; }`**  
    Текущее активное приложение.

### AddAccount

- **`bool AddAccount(string name, string type, string password)`**  
    Добавляет аккаунт на устройство.
    
    **Параметры:**
    - `name` — имя аккаунта (например, email или логин);
    - `type` — тип аккаунта (например: `com.google`, `com.facebook.auth.login`);
    - `password` — пароль аккаунта.
    
    **Возвращает:**  
    `true`, если аккаунт успешно добавлен; иначе `false`.

- **`bool AddAccount(string name, string type, string password, string metadata)`**  
    Добавляет аккаунт с дополнительными метаданными.
    
    **Параметры:**
    - `name` — имя аккаунта;
    - `type` — тип аккаунта;
    - `password` — пароль;
    - `metadata` — дополнительные данные аккаунта (например, токены, параметры авторизации в JSON или строковом виде).
    
    **Возвращает:**  
    `true`, если аккаунт успешно добавлен; иначе `false`.

### BackupAppData

- **`void BackupAppData(string packageName, string pathToBackup)`**  
    Создаёт резервную копию данных приложения.
    
    **Параметры:**
    - `packageName` — имя пакета приложения;
    - `pathToBackup` — путь для сохранения бэкапа.

- **`void BackupAppData(string packageName, string pathToBackup, bool savePermissions)`**  
    Создаёт резервную копию с возможностью сохранения разрешений приложения.
    
    **Параметры:**
    - `savePermissions` — сохранять ли текущие разрешения приложения.

- **`void BackupAppData(string packageName, string pathToBackup, bool savePermissions, string accountType)`**  
    Расширенное резервное копирование с учётом типа аккаунта.
    
    **Параметры:**
    - `savePermissions` — сохранять разрешения;
    - `accountType` — тип аккаунта (например: `com.yandex.passport`, `com.twitter.android.auth.login`). Тип аккаунта можно узнать с помощью метода `GetAccounts(string packageName)`.

#### Пример.  
```csharp
var app = instance.DroidInstance.App;

var packageName = "com.android.chrome"; // Имя приложения
var pathSave = @"/dir/bakups/name_bakup"; // Путь куда сохранить бэкап
app.BackupAppData(packageName, pathSave); // Сделать бэкап
```

### DeleteCookie

- **`string DeleteCookie(string packageName, string host = null, string name = null, bool persistentOnly = false, bool secureOnly = false, bool httpOnly = false)`**  
    Удаляет cookies из Chromium-хранилища приложения. Фильтры совпадают с фильтрами `GetCookie` и применяются на устройстве.
    
    **Параметры:**
    - `packageName` — имя пакета;
    - `host` — фильтр по домену: удаляются cookies этого домена и его поддоменов, несколько доменов указываются через запятую. Пустое значение — любой домен;
    - `name` — фильтр по имени cookie (точное совпадение), несколько имён указываются через запятую. Пустое значение — любое имя;
    - `persistentOnly` — удалять только постоянные cookies, не трогая сессионные;
    - `secureOnly` — удалять только cookies с флагом `Secure`;
    - `httpOnly` — удалять только cookies с флагом `HttpOnly`.
    
    **Возвращает:**  
    JSON-отчёт об удалении: сколько cookies проверено и удалено по каждой базе.

#### Пример.  
```csharp
var app = instance.DroidInstance.App;

var packageName = "com.android.chrome"; // Имя приложения

// Удалить одну куку домена example.com и его поддоменов
var report = app.DeleteCookie(packageName, "example.com", "sid");
project.Json.FromString(report);

// Полная очистка хранилища куки приложения
app.DeleteCookie(packageName);
```

:::warning Важные замечания
- Вызов **без фильтров удаляет все cookies** приложения.
- Нужен **root**: при удалении приложение принудительно останавливается, а запись идёт в его каталог данных.
- Если приложение ещё ни разу не запускалось, хранилище cookies не создано и метод вернёт пустую строку.
:::

### GetCookie

- **`string GetCookie(string packageName)`**  
    Получает cookies приложения.
    
    **Параметры:**
    - `packageName` — имя пакета.
    
    **Возвращает:**  
    Строку с cookies.

- **`string GetCookie(string packageName, string host, string name = null, bool persistentOnly = false, bool secureOnly = false, bool httpOnly = false)`**  
    Получает cookies приложения с фильтрацией. Фильтры применяются на устройстве до расшифровки значений, поэтому вариант удобен для больших хранилищ.
    
    **Параметры:**
    - `packageName` — имя пакета;
    - `host` — фильтр по домену: берутся cookies этого домена и его поддоменов, несколько доменов указываются через запятую. Пустое значение — любой домен;
    - `name` — фильтр по имени cookie (точное совпадение), несколько имён указываются через запятую. Пустое значение — любое имя;
    - `persistentOnly` — исключить сессионные cookies;
    - `secureOnly` — оставить только cookies с флагом `Secure`;
    - `httpOnly` — оставить только cookies с флагом `HttpOnly`.
    
    **Возвращает:**  
    Строку с cookies в том же формате, что и `GetCookie(packageName)`.

#### Пример.  
```csharp
var app = instance.DroidInstance.App;

var packageName = "com.android.chrome"; // Имя приложения
var cookies = app.GetCookie(packageName); // Получить куки приложения

// Только постоянные Secure-куки домена example.com и его поддоменов
var filtered = app.GetCookie(packageName, "example.com", null, true, true);
```

### ImportCookie

- **`string ImportCookie(string packageName, string cookies, bool replaceAll = false)`**  
    Импортирует cookies в Chromium-хранилище приложения. Значения шифруются на устройстве по той же схеме, которую использует само приложение.
    
    **Параметры:**
    - `packageName` — имя пакета;
    - `cookies` — cookies в виде JSON-массива в формате ZennoLab (такой же, какой возвращает `GetCookie`);
    - `replaceAll` — `true` — очистить хранилище перед импортом, `false` — дописать cookies и обновить существующие.
    
    **Возвращает:**  
    JSON-отчёт об импорте: сколько cookies добавлено, заменено, пропущено и не удалось записать по каждой базе.

#### Пример.  
```csharp
var app = instance.DroidInstance.App;

var packageName = "com.android.chrome"; // Имя приложения

var cookies = @"[{
  ""domain"": "".example.com"",
  ""name"": ""sid"",
  ""value"": ""abc123"",
  ""path"": ""/"",
  ""expirationDate"": 1790000000,
  ""httpOnly"": true,
  ""secure"": true,
  ""sameSite"": ""Lax"",
  ""is_persistent"": true
}]"; // Куки в формате ZennoLab

var report = app.ImportCookie(packageName, cookies); // Дописать куки в хранилище приложения
project.Json.FromString(report);
```

:::warning Важные замечания
- Нужен **root**: при импорте приложение принудительно останавливается, а запись выполняется от его имени.
- Приложение должно быть запущено хотя бы один раз, иначе хранилище cookies ещё не создано и метод вернёт ошибку.
:::

### InjectScript

- **`void InjectScript(string packageName, string script)`**  
    Внедряет JavaScript-скрипт в приложение, который выполняется перед загрузкой страницы.
    
    **Параметры:**
    - `packageName` — имя пакета;
    - `script` — код скрипта.

#### Пример.  
```csharp
var app = "com.android.chrome";
var script = project.Variables["script"].Value;

instance.DroidInstance.App.Close(app); // Закрыть приложение

var lspHelper = new LSPosedHelper(instance.DroidInstance);
lspHelper.SetPackages(app); // Задать приложение в списке подмены модуля ZennoDroid
lspHelper.EnableModule(); // Включить модуль ZennoDroid

instance.DroidInstance.Settings.SetLSPosedSettings("{ \"UseInjectScript\":true }"); // Включить возможность выполнять javascript перед загрузкой страницы
instance.DroidInstance.App.InjectScript(app, script); // Задать скрипт, который будет выполняться перед загрузкой

instance.DroidInstance.App.Open(app); // Отрыть приложение
```
Переменная проекта *script* содержит код, который нужно выполнить.
```javascript
(() => {
  const ID = "hello-world-date-banner";
  const existing = document.getElementById(ID);
  const text = `Hello world — ${new Date().toLocaleString()}`;

  if (existing) {
    existing.textContent = text; // already added: just update
    return;
  }

  const el = document.createElement("div");
  el.id = ID;
  el.textContent = text;
  el.style.cssText =
    "padding:8px 12px;background:#fffbcc;color:#111;" +
    "font:14px/1.4 system-ui;border-bottom:1px solid #e6d98c;";
  (document.body || document.documentElement).prepend(el);
})();
```

### RemoveAccount

- **`bool RemoveAccount(string name, string type)`**  
    Удаляет аккаунт.
    
    **Параметры:**
    - `name` — имя аккаунта;
    - `type` — тип аккаунта.
    
    **Возвращает:**  
    `true`, если успешно удалён.

:::tip **Часто аккаунт хранится не в самом приложении, а в менеджере аккаунтов.**
Например, у приложений Яндекс Go, Яндекс Почта и Яндекс Музыка общая система авторизации. Поэтому при удалении одного из приложений у двух других всё равно останется доступ к аккаунту.  

В таких случаях нужно достать аккаунты из приложения и принудительно их удалить.
:::

### SetVideoForFakeCamera

- **`void SetVideoForFakeCamera(string packageName, string videoSource)`**  
    Подменяет камеру приложения видеофайлом: приложение получает кадры видео так, как будто они пришли с камеры устройства. Видео проигрывается по кругу, без звука, все потоки кадров остаются виртуальными. Если приложению нужно ещё и сохранять фотографии, используйте перегрузку с параметрами воспроизведения.
    
    **Параметры:**
    - `packageName` — имя пакета приложения;
    - `videoSource` — путь к видео. Либо локальный путь на ПК (например, `c:\source.mp4`) — тогда файл отправляется на устройство, либо путь, который уже существует на устройстве (начинается с `/`, например `/sdcard/Download/source.mp4`) — тогда файл копируется без передачи с ПК. Пустая строка отключает подмену и возвращает реальную камеру.
    
    **Описание:**  
    Подходит любой контейнер, который умеет декодировать MediaCodec (`.mp4`, `.mkv`, `.webm`, `.3gp`, `.m4v`, `.mov`), а разрешение видео не обязано совпадать с тем, которое запрашивает приложение.
    
    Видео кешируется на устройстве по хешу содержимого, поэтому повторная отправка того же файла — или его использование для другого приложения — не передаёт его второй раз.
    
    Видео можно заменить на ходу: следующий вызов переключает воспроизведение, не перезапуская ни приложение, ни его сессию камеры.

- **`void SetVideoForFakeCamera(string packageName, string videoSource, bool loop, bool mute, bool photo)`**  
    То же самое, но с явно заданными параметрами воспроизведения.
    
    **Параметры:**
    - `packageName` — имя пакета приложения;
    - `videoSource` — путь к видео на ПК или на устройстве, либо пустая строка для отключения подмены;
    - `loop` — запускать видео заново, когда оно закончилось. При `false` на экране остаётся последний кадр;
    - `mute` — заглушить звуковую дорожку видео. Передайте `false`, чтобы звук проигрывался;
    - `photo` — разрешить приложению-камере довести до конца сохранение фотографии.

#### Пример.  
```csharp
var app = instance.DroidInstance.App;

var packageName = "com.android.chrome"; // Имя приложения

// Видео с ПК: отправляется на устройство, проигрывается по кругу и без звука
app.SetVideoForFakeCamera(packageName, @"c:\source.mp4");

// Видео, которое уже лежит на устройстве: со звуком, без повтора, с сохранением фото
app.SetVideoForFakeCamera(packageName, "/sdcard/Download/source.mp4", false, false, true);

// Вернуть реальную камеру
app.SetVideoForFakeCamera(packageName, "");
```

:::warning Важные замечания
- Нужен модуль **ZennoVCam**: он должен быть установлен, включён и добавлен в список подмены для целевого приложения.
- Параметр `photo` по умолчанию выключен, потому что это компромисс, а не улучшение: чтобы сохранение фотографии прошло, модуль отдаёт реальной камере вспомогательные потоки кадров (замер экспозиции, миниатюры). Оставьте `false` для сканеров и KYC-приложений, которые читают кадры через такие потоки, — иначе они получат изображение реальной камеры.
:::
