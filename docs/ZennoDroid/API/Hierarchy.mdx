# Hierarchy API
<DisclaimerNotice />

## Описание

`IDroidHierarchyAPI` предоставляет доступ к дереву элементов интерфейса текущего экрана устройства. Используется для получения структуры UI в виде XML-дерева всех элементов и их взаимосвязей.

_______________________________________________
## Методы

### GetLayout

- **`string GetLayout()`**  
    Возвращает XML-дерево текущего экрана с полной иерархией элементов интерфейса и их атрибутами (`bounds`, `text`, `resource-id`, `class` и др.). XML-код проходит постобработку: из имён тегов удаляются полные префиксы Java-пакетов, поэтому имена узлов остаются короткими и читаемыми (например, `android.widget.TextView` превращается в `TextView`). Чтобы получить необработанный XML, используйте [`AppiumDriver.GetRawSource()`](./AppiumDriver#getrawsource).
    
    **Возвращает:**  
    XML-строку с иерархией элементов интерфейса (без префиксов пакетов в именах тегов).

#### Пример.  
```csharp
var xml = instance.DroidInstance.Hierarchy.GetLayout(); // Получить XML текущего экрана устройства
```
