# ActionEmulator API
<DisclaimerNotice />
## Описание

`IDroidActionEmulatorAPI : IDroidActionAPI`

Интерфейс `IDroidActionEmulatorAPI` расширяет базовый [`IDroidActionAPI`](./Action) и предоставляет методы для управления эмуляторами **MEmu** и **LDPlayer** в ZennoDroid. Позволяет создавать, клонировать, импортировать, удалять и настраивать виртуальные устройства.
## Свойства

### Action

- **`IDroidActionEmulatorAPI Action`**  
    Действия с эмулятором. Кроме перечисленных ниже доступны все базовые действия из [`IDroidActionAPI`](./Action).

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.SelectByTitle("Samsung_S23"); // Базовое действие из IDroidActionAPI
var index = droid.Action.Clone(); // Действие, которое есть только у эмулятора
```

## Методы


### Clone

- **`int Clone()`**  
    Создаёт копию текущего эмулятора.
    
    **Возвращает:**  
    Индекс нового эмулятора.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.SelectByTitle("Samsung_S23"); // Выбрать эмулятор, с которого снимаем копию
var index = droid.Action.Clone(); // Индекс копии
```

---

### Create

- **`int Create(string version)`**  
    Создаёт новый эмулятор с указанной версией Android.
    
    **Параметры:**
    - `version` — версия Android.  
    Возможные значения для **MEmu**:
        - `"71"` — Android 7.1 (x86)
        - `"76"` — Android 7.1 (x64)
        - `"96"` — Android 9.0 (x64)
        - `"120"` — Android 12.0 (x64)
    
    **LDPlayer** всегда создаёт эмулятор с Android 9.
    
    **Возвращает:**  
    Индекс созданного эмулятора.

#### Пример.
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;
var index = droid.Action.Create("96");
```

---

### DeleteByIndex

- **`void DeleteByIndex(int index)`**  
    Удаляет эмулятор по индексу.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.DeleteByIndex(2); // Удалить эмулятор с индексом 2
```

### DeleteByName

- **`void DeleteByName(string name)`**  
    Удаляет эмулятор по имени.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.DeleteByName("MEmu_1"); // Удалить эмулятор по внутреннему имени
```

### DeleteByTitle

- **`void DeleteByTitle(string title)`**  
    Удаляет эмулятор по отображаемому названию.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.DeleteByTitle("Samsung_S23"); // Удалить эмулятор по отображаемому названию
```

### Export

- **`void Export(string path)`**  
    Экспортирует текущий эмулятор в файл.
    
    **Параметры:**
    - `path` — путь для сохранения.
    
    Формат файла бэкапа: MEmu — `*.ova`, LDPlayer — `*.ldbk`.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.SelectByTitle("Samsung_S23"); // Выбрать эмулятор
droid.Action.Export(project.Path + "Samsung_S23.ova"); // Сохранить копию в файл
```

---

### FactoryReset

- **`void FactoryReset(bool resetSystem)`**  
    Выполняет сброс эмулятора к заводским настройкам.
    
    **Параметры:**
    - `resetSystem` — если `true`, выполняется полный сброс с системными данными; если `false` — сбрасываются только пользовательские данные.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.SelectByTitle("Samsung_S23"); // Выбрать эмулятор
droid.Action.FactoryReset(false); // Сбросить только пользовательские данные
droid.Action.FactoryReset(true); // Сбросить вместе с системными данными
```

---

### Import

- **`int Import(string path)`**  
    Импортирует эмулятор из файла.
    
    **Параметры:**
    - `path` — путь к файлу/архиву эмулятора.
    
    **Возвращает:**  
    Индекс импортированного эмулятора.
    
    Формат файла бэкапа: MEmu — `*.ova`, LDPlayer — `*.ldbk`.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

var index = droid.Action.Import(project.Path + "Samsung_S23.ova"); // Индекс импортированного эмулятора
droid.Action.SelectByIndex(index);
droid.Action.Start();
```

---

### Rename

- **`void Rename(int index, string title)`**  
    Переименовывает эмулятор по индексу.

- **`void Rename(string name, string title)`**  
    Переименовывает эмулятор по имени.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.Rename(0, "Samsung_S23"); // Переименовать эмулятор с индексом 0
droid.Action.Rename("MEmu_1", "Samsung_S23"); // Переименовать эмулятор по внутреннему имени
```

### RenameTo

- **`void RenameTo(string title)`**  
    Переименовывает текущий эмулятор.

#### Пример.  
```csharp
var droid = instance.DroidInstance as IDroidInstanceEmulatorAPI;

droid.Action.SelectByIndex(0); // Выбрать эмулятор
droid.Action.RenameTo("Samsung_S23"); // Переименовать выбранный эмулятор
```
